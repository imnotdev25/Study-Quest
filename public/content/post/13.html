🚀 Starting point

An agent acts in turns: it calls a tool, reads the result, calls another, and finally answers. TRL v1.16 trains this with GRPOTrainer(environment_factory=Env). The trainer makes one Env per rollout, calls reset() for the prompt, exposes every other public method (with type hints and a Google-style docstring) as a tool, runs the tool loop, and adds get_reward() to the reward. Tool outputs are observations, not actions, so they’re masked from the loss (RL book, Topic 35).

One rollout. Every rollout in a GRPO group runs this loop, and the rewards are compared within the group.

✏️ Derivation: designing the reward and the group

Step 1. \(R=\mathbb 1[\text{correct}]-c\cdot\#\text{calls}\). Without \(c\) the agent can call tools endlessly; with \(c\) too large it never calls them. Here \(c=0.05\): the careful agent below scores 0.70 (correct, 6 calls), the guessing agent 0.

Step 2. A correct answer must be worth more than its tool cost: with \(k\) calls needed, choose \(c<1/k\), or the optimum is to guess.

Step 3. Group baseline: if each reset() samples a new task, the \(G\) rollouts in a group face different tasks and the group mean is a noisy baseline. Pass the same seed column to all members (the trainer forwards dataset columns to reset) so they share one task.

Step 4. Cap turns with max_tool_calling_iterations, so a looping agent ends its rollout instead of the run.

"""Agentic RL: a tool-using environment for TRL's GRPOTrainer(environment_factory=...).

The trainer creates one environment per rollout, calls reset() to get the prompt, exposes every other
public method as a tool, runs the multi-turn tool-calling loop itself, and adds get_reward() to the reward.

Local test (drives the environment by hand):  python tool_env.py
On Modal (Qwen3-0.6B, 1x H100):               modal run tool_env.py::train_remote
"""
import random

import modal


class ShopEnv:
    """Answer a question about an order using lookup tools. Reward: correct final answer, minus a cost per call."""

    PRICES = {"apple": 0.5, "bread": 2.25, "coffee": 7.0, "eggs": 3.1, "milk": 1.2}
    CALL_COST = 0.05

    def reset(self, **kwargs) -> str:
        rng = random.Random(kwargs.get("seed"))
        self.items = {k: rng.randint(1, 5) for k in rng.sample(sorted(self.PRICES), 3)}
        self.calls, self.answer = 0, None
        self.target = round(sum(self.PRICES[k] * n for k, n in self.items.items()), 2)
        order = ", ".join(f"{n} x {k}" for k, n in self.items.items())
        return f"An order contains {order}. What is the total price? Use the tools, then call submit."

    def price(self, item: str) -> float:
        """Look up the unit price of an item.

        Args:
            item: Name of the item, e.g. "milk".

        Returns:
            The unit price in dollars, or -1 if the item is unknown.
        """
        self.calls += 1
        return self.PRICES.get(item.strip().lower(), -1.0)

    def multiply(self, a: float, b: float) -> float:
        """Multiply two numbers.

        Args:
            a: First number.
            b: Second number.

        Returns:
            The product a * b.
        """
        self.calls += 1
        return a * b

    def submit(self, total: float) -> str:
        """Submit the final total price. Call this exactly once, at the end.

        Args:
            total: The total price in dollars.

        Returns:
            A confirmation message.
        """
        self.answer = total
        return "submitted"

    def get_reward(self) -> float:
        correct = self.answer is not None and abs(self.answer - self.target) < 0.01
        return float(correct) - self.CALL_COST * self.calls


app = modal.App("pt-book-agent")
image = modal.Image.debian_slim(python_version="3.12").uv_pip_install(
    "trl[vllm]==1.16.0", "transformers==5.20.2", "datasets==5.1.0", "accelerate==1.15.0"
).add_local_python_source("tool_env")
models = modal.Volume.from_name("pt-book-models", create_if_missing=True)


@app.function(gpu="H100", image=image, volumes={"/models": models}, timeout=6 * 60 * 60)
def train_remote(max_steps: int = 300):
    from datasets import Dataset
    from trl import GRPOConfig, GRPOTrainer

    # Same seed for every member of a group -> identical initial state -> a clean group baseline.
    ds = Dataset.from_dict({"prompt": [[{"role": "user", "content": "Start."}]] * 4000, "seed": list(range(4000))})
    args = GRPOConfig(output_dir="/models/qwen3-0.6b-agent", max_steps=max_steps, num_generations=8,
                      per_device_train_batch_size=16, learning_rate=1e-6, max_tool_calling_iterations=8,
                      chat_template_kwargs={"enable_thinking": False}, bf16=True, use_vllm=True,
                      vllm_mode="colocate", report_to="none")
    trainer = GRPOTrainer(model="Qwen/Qwen3-0.6B", args=args, train_dataset=ds, environment_factory=ShopEnv)
    trainer.train()
    trainer.save_model("/models/qwen3-0.6b-agent")
    models.commit()


if __name__ == "__main__":
    env = ShopEnv()
    print(env.reset(seed=3))
    # A careful agent: price -> multiply for each item, then submit the sum.
    total = sum(env.multiply(env.price(k), n) for k, n in env.items.items())
    env.submit(round(total, 2))
    print(f"careful agent: {env.calls} calls, reward {env.get_reward():.2f}")
    env.reset(seed=3)
    env.submit(10.0)                                       # guesses without tools
    print(f"guessing agent: {env.calls} calls, reward {env.get_reward():.2f}")
