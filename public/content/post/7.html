🚀 Starting point

A base model continues text; it doesn’t answer. SFT trains it on conversations written in a fixed chat template, with the loss counted only on the assistant’s tokens. The objective is the conditional likelihood \(\log p_\theta(\text{response}\mid\text{prompt})\) (LLM Fundamentals, Session 12). Everything new in practice is about formatting, masking and efficiency.

A ChatML-style template (Qwen, SmolLM). assistant_only_loss=True sets every grey token’s label to \(-100\). The end-of-turn token is trained, or the model never learns to stop.

✏️ Derivation: what packing does to the loss

Step 1. Without packing, a batch is padded to its longest example: if lengths are \(100\) and \(2000\), almost half the compute is padding.

Step 2. Packing concatenates examples into full rows of max_length. TRL’s default "bfd" (best-fit decreasing) places each example whole into the row with the least space left that still fits.

Step 3. With padding_free, TRL passes per-example position IDs so FlashAttention treats each example as its own sequence: no attention across example boundaries.

Step 4. The loss stays a mean over trained (assistant) tokens of the whole batch; since TRL averages tokens across devices (average_tokens_across_devices=True), accumulation is exact (LLM Fundamentals, Session 50).

"""Supervised fine-tuning with TRL: base model -> instruction follower.

Local smoke test:  python sft.py                       (tiny model, CPU, a few steps)
On Modal:          modal run sft.py::train_remote      (Qwen3-0.6B-Base on smoltalk, 1x H100)
"""
import modal

MODEL = "Qwen/Qwen3-0.6B-Base"
DATASET = ("HuggingFaceTB/smoltalk", "all")


def run_sft(model, dataset, output_dir, lora=True, **overrides):
    from peft import LoraConfig
    from trl import SFTConfig, SFTTrainer

    defaults = dict(
        output_dir=output_dir,
        max_length=2048,
        packing=True,                        # pack short chats into full 2048-token rows
        per_device_train_batch_size=8,
        gradient_accumulation_steps=4,
        learning_rate=1e-4 if lora else 2e-5,
        lr_scheduler_type="cosine",
        warmup_steps=0.03,                   # a float < 1 is a fraction of total steps
        num_train_epochs=1,
        logging_steps=10,
        save_strategy="no",
        report_to="none",
    )
    args = SFTConfig(**{**defaults, **overrides})   # smoke tests override some defaults
    peft = LoraConfig(r=16, lora_alpha=32, target_modules="all-linear", task_type="CAUSAL_LM") if lora else None
    trainer = SFTTrainer(model=model, args=args, train_dataset=dataset, peft_config=peft)
    trainer.train()
    return trainer


app = modal.App("pt-book-sft")
image = modal.Image.debian_slim(python_version="3.12").uv_pip_install(
    "torch==2.14.1", "transformers==5.20.2", "trl==1.16.0", "datasets==5.1.0", "peft==0.21.2", "accelerate==1.15.0"
)
out = modal.Volume.from_name("pt-book-models", create_if_missing=True)


@app.function(gpu="H100", image=image, volumes={"/models": out},
              secrets=[modal.Secret.from_name("huggingface-secret")], timeout=6 * 60 * 60)
def train_remote(n_examples: int = 100_000):
    from datasets import load_dataset

    ds = load_dataset(*DATASET, split="train").shuffle(seed=0).select(range(n_examples))
    trainer = run_sft(MODEL, ds, "/models/qwen3-0.6b-sft", lora=False, bf16=True, assistant_only_loss=True)
    trainer.save_model("/models/qwen3-0.6b-sft")
    out.commit()


if __name__ == "__main__":
    from datasets import Dataset

    chats = [{"messages": [{"role": "user", "content": f"What is {a} plus {b}?"},
                           {"role": "assistant", "content": f"{a} plus {b} is {a + b}."}]}
             for a in range(10) for b in range(10)]
    trainer = run_sft("trl-internal-testing/tiny-Qwen2ForCausalLM-2.5", Dataset.from_list(chats), "/tmp/sft_smoke",
                      max_length=64, per_device_train_batch_size=4, gradient_accumulation_steps=1,
                      max_steps=12, logging_steps=4, learning_rate=1e-2, bf16=False, use_cpu=True)
    logs = [h["loss"] for h in trainer.state.log_history if "loss" in h]
    print("SFT smoke test losses:", [round(l, 3) for l in logs])

Full fine-tuning or LoRA? Full SFT (lora=False, lr \(\approx2\times10^{-5}\)) changes every weight and is what labs ship. LoRA (lr \(\approx10^{-4}\), 10–100\(\times\) less optimizer memory) is close in quality for narrow tasks and is the right default on a single 24 GB GPU.
