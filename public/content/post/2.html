🚀 Starting point

Pre-training data starts as Common Crawl: petabytes of raw HTML, mostly boilerplate, spam and near-copies. A data pipeline turns it into clean text in five steps: extract main text from HTML, identify language, apply heuristic filters, deduplicate, and filter by quality with a model. Data quality moves benchmark scores more than almost any architecture change.

The data funnel. FineWeb (HuggingFace, 2024) applies steps 1–5 to 96 Common Crawl snapshots to get 15T tokens; FineWeb-Edu adds step 6 and keeps 1.3T.

Heuristic filters

Simple rules remove most garbage cheaply: too short or too long, mostly symbols, mostly bullet lists, almost no common English words. These are from the Gopher paper (Rae et al., 2021). FineWeb adds C4-style rules and its own (e.g. fraction of lines ending in punctuation).

"""Quality filtering: Gopher-style heuristic rules, plus a model-based educational-quality scorer.

Run:  python quality.py      (heuristics run anywhere; the classifier part runs on Modal)
"""
import re

import modal

STOPWORDS = {"the", "be", "to", "of", "and", "that", "have", "with"}


def gopher_rules(text: str) -> dict[str, bool]:
    """A subset of the Gopher (Rae et al., 2021) quality rules. A doc is kept only if every rule passes."""
    words = text.split()
    n = len(words)
    alpha = [w for w in words if re.search(r"[a-zA-Z]", w)]
    lines = [l for l in text.splitlines() if l.strip()]
    return {
        "length_50_to_100k_words": 50 <= n <= 100_000,
        "mean_word_length_3_to_10": n > 0 and 3 <= sum(map(len, words)) / n <= 10,
        "symbol_to_word_ratio_lt_0.1": n > 0 and (text.count("#") + text.count("...")) / n < 0.1,
        "80pct_words_alphabetic": n > 0 and len(alpha) / n >= 0.8,
        "at_least_2_stopwords": len(STOPWORDS & {w.lower() for w in words}) >= 2,
        "lt_90pct_lines_bulleted": not lines or sum(l.lstrip().startswith(("-", "*", "•")) for l in lines) / len(lines) < 0.9,
    }


def keep(text: str) -> bool:
    return all(gopher_rules(text).values())


# ---- Model-based filter (FineWeb-Edu style), run on a GPU ----
app = modal.App("pt-book-quality")
image = modal.Image.debian_slim(python_version="3.12").uv_pip_install(
    "torch==2.14.1", "transformers==5.20.2", "datasets==5.1.0"
)


@app.function(gpu="L4", image=image, timeout=30 * 60)
def score_fineweb(n_docs: int = 2000) -> list[tuple[float, str]]:
    """Score raw FineWeb docs 0-5 for educational value with the FineWeb-Edu classifier; FineWeb-Edu keeps >= 3."""
    import torch
    from datasets import load_dataset
    from transformers import AutoModelForSequenceClassification, AutoTokenizer

    name = "HuggingFaceFW/fineweb-edu-classifier"
    tok = AutoTokenizer.from_pretrained(name)
    model = AutoModelForSequenceClassification.from_pretrained(name, dtype=torch.bfloat16).cuda().eval()
    docs = load_dataset("HuggingFaceFW/fineweb", name="sample-10BT", split="train", streaming=True).take(n_docs)
    out = []
    for d in docs:
        x = tok(d["text"], truncation=True, max_length=512, return_tensors="pt").to("cuda")
        with torch.no_grad():
            score = model(**x).logits.squeeze().float().item()     # a regression head: one number
        out.append((round(score, 2), d["text"][:80]))
    return sorted(out, reverse=True)


@app.local_entrypoint()
def main():
    scored = score_fineweb.remote()
    print("kept (score >= 3):", sum(s >= 3 for s, _ in scored), "of", len(scored))
    for s, t in scored[:3] + scored[-3:]:
        print(s, t)


if __name__ == "__main__":
    good = ("The water cycle describes how water evaporates from the surface of the earth, rises into the "
            "atmosphere, cools and condenses into clouds, and falls again as precipitation. ") * 3
    spam = "BUY NOW!!! ### $$$ ### click ### here ### " * 20

        failed = [k for k, ok in gopher_rules(t).items() if not ok]
        print(f"{name}: keep={keep(t)}  failed={failed}")

Deduplication with MinHash

✏️ Derivation: why MinHash estimates Jaccard similarity

Step 1. Represent a document as its set of word 5-grams (shingles), \(A\). Similarity of two documents: Jaccard \(J(A,B)=\frac{|A\cap B|}{|A\cup B|}\).

Step 2. Take a random permutation \(\pi\) of all possible shingles, and define \(h(A)=\min_{x\in A}\pi(x)\).

Step 3. Look at the element of \(A\cup B\) that comes first under \(\pi\). It’s equally likely to be any element of \(A\cup B\). \(h(A)=h(B)\) exactly when that first element is in both sets.

Step 4. So \(P[h(A)=h(B)]=\frac{|A\cap B|}{|A\cup B|}=J\). With \(K\) independent hash functions (cheap substitutes for permutations, \(h_i(x)=(a_ix+b_i)\bmod p\)), the fraction of matching signature entries estimates \(J\) with standard error \(\sqrt{J(1-J)/K}\).

Step 5. LSH banding: comparing every pair of \(10^9\) docs is impossible. Split each \(K\)-value signature into \(b\) bands of \(r\) rows, and only compare docs that share an entire band. One band matches with probability \(J^r\), so \(P(\text{candidate})=1-(1-J^r)^b\).

Step 6. That’s an S-curve with its steepest point near \(J^*\approx(1/b)^{1/r}\). FineWeb uses \(b=14,r=8\) (112 hashes); with \(b=16,r=8\), \(J^*=16^{-1/8}=0.707\).

LSH turns a soft similarity into a sharp threshold. More rows per band move the threshold right; more bands move it left.

"""Exact and near-duplicate removal (MinHash + LSH) and benchmark decontamination.

Run:  python dedup.py      (pure Python + NumPy; runs anywhere)
"""
import hashlib
import re

import numpy as np

PRIME = (1 << 61) - 1


def shingles(text: str, n: int = 5) -> set[int]:
    """Word n-grams, hashed to 64-bit integers."""
    words = re.findall(r"\w+", text.lower())
    grams = {" ".join(words[i:i + n]) for i in range(max(1, len(words) - n + 1))}
    return {int.from_bytes(hashlib.blake2b(g.encode(), digest_size=8).digest(), "little") for g in grams}


class MinHasher:
    """K hash functions h_i(x) = (a_i x + b_i) mod p. A signature keeps the min of each over a doc's shingles."""

    def __init__(self, num_perm: int = 128, seed: int = 0):
        rng = np.random.default_rng(seed)
        self.a = rng.integers(1, PRIME, size=num_perm, dtype=np.uint64)
        self.b = rng.integers(0, PRIME, size=num_perm, dtype=np.uint64)

    def signature(self, sh: set[int]) -> np.ndarray:
        x = np.fromiter(sh, dtype=np.uint64)[:, None] % PRIME
        # Python ints avoid uint64 overflow in a*x; fine for a teaching example.
        vals = (self.a.astype(object) * x.astype(object) + self.b.astype(object)) % PRIME
        return vals.min(axis=0).astype(np.uint64)


def jaccard(a: set, b: set) -> float:
    return len(a & b) / len(a | b)


def lsh_candidates(sigs: list[np.ndarray], bands: int, rows: int) -> set[tuple[int, int]]:
    """Split each signature into `bands` bands of `rows` values; docs sharing any band are candidates."""
    pairs = set()
    for band in range(bands):
        buckets: dict[bytes, list[int]] = {}
        for i, s in enumerate(sigs):
            buckets.setdefault(s[band * rows:(band + 1) * rows].tobytes(), []).append(i)
        for ids in buckets.values():
            pairs |= {(ids[x], ids[y]) for x in range(len(ids)) for y in range(x + 1, len(ids))}
    return pairs


def lsh_probability(s: float, bands: int, rows: int) -> float:
    """P(two docs with Jaccard s become candidates) = 1 - (1 - s^r)^b."""
    return 1 - (1 - s ** rows) ** bands


def contaminated(doc: str, benchmark_ngrams: set[str], n: int = 13) -> bool:
    """Flag a training doc that shares any n-gram with a benchmark (13-grams are a common choice)."""
    words = re.findall(r"\w+", doc.lower())
    return any(" ".join(words[i:i + n]) in benchmark_ngrams for i in range(len(words) - n + 1))

Model-based quality filtering

FineWeb-Edu: Llama-3-70B-Instruct rated 450K web pages 0–5 for educational value; a small classifier (a regression head on a BERT-style encoder) was trained to imitate those ratings and run over all 15T tokens; pages scoring \(\ge3\) were kept. Models trained on it beat models trained on full FineWeb on knowledge benchmarks like MMLU and ARC at the same token count. DCLM (2024) uses a fastText classifier whose positives are instruction-style text (OpenHermes, r/ExplainLikeImFive), and gets about 4T tokens. The score_fineweb function above runs the FineWeb-Edu classifier on a Modal L4.
