🚀 Starting point

Safety post-training uses the same trainers as everything else, with safety data in the mix: harmful requests with good refusals or safe completions, benign requests that look risky with helpful answers (to prevent over-refusal), and preference pairs where the safer response wins. A safe completion helps with the legitimate part of a request (“how do I store medication safely around kids”) instead of refusing everything near the topic.

✏️ Derivation: Safe RLHF: helpfulness subject to a harm budget

Step 1. Train two models (Chapter 12): reward \(R(x,y)\) for helpfulness and cost \(C(x,y)\) for harm.

Step 2. Objective: \(\max_\pi\ \mathbb E[R]\) subject to \(\mathbb E[C]\le d\). A single blended reward \(R-\lambda C\) with a fixed \(\lambda\) can’t guarantee the constraint.

Step 3. Lagrangian: \(\mathcal L(\pi,\lambda)=\mathbb E[R]-\lambda(\mathbb E[C]-d)\), \(\lambda\ge0\). Alternate a policy step on \(R-\lambda C\) with \(\lambda\gets\max(0,\lambda+\eta(\hat C-d))\) (RL book, Topic 151).

Step 4. \(\lambda\) rises while the policy is too harmful and falls once it’s within budget, so the exchange rate between helpfulness and harmlessness is set by the data, not guessed.

"""Constitutional AI data: draft -> critique against a principle -> revise.
Produces SFT rows (prompt, revision) and preference rows (revision chosen over draft).

Local test of the prompt builders:  python constitution.py
On Modal (Qwen3-8B with vLLM):       modal run constitution.py::critique_revise
"""
import random

import modal

CONSTITUTION = [
    "Identify ways the response could help someone cause serious harm, and rewrite it to remove that help "
    "while still addressing any legitimate need behind the request.",
    "Identify any part of the response that refuses or lectures unnecessarily when the request is harmless, "
    "and rewrite it to be directly helpful.",
    "Identify claims in the response that are inaccurate or overconfident, and rewrite it to be honest about uncertainty.",
    "Identify anything disrespectful, demeaning or biased in the response, and rewrite it to be respectful.",
]


def critique_prompt(request, draft, principle):
    return (f"Request: {request}\n\nResponse: {draft}\n\nCritique the response with this principle in mind: "
            f"{principle.split(', and rewrite')[0]}. Be specific and brief.")


def revise_prompt(request, draft, critique, principle):
    return (f"Request: {request}\n\nResponse: {draft}\n\nCritique: {critique}\n\n"
            f"Rewrite the response following this principle: {principle} Output only the new response.")


def rows(request, draft, revision):
    sft = {"messages": [{"role": "user", "content": request}, {"role": "assistant", "content": revision}]}
    pref = {"prompt": [{"role": "user", "content": request}],
            "chosen": [{"role": "assistant", "content": revision}],
            "rejected": [{"role": "assistant", "content": draft}]}
    return sft, pref


app = modal.App("pt-book-constitution")
image = (modal.Image.debian_slim(python_version="3.12").uv_pip_install("vllm==0.32.0", "datasets==5.1.0")
         .add_local_python_source("constitution"))
data = modal.Volume.from_name("pt-book-data", create_if_missing=True)


@app.function(gpu="H100", image=image, volumes={"/data": data}, timeout=3 * 60 * 60,
              secrets=[modal.Secret.from_name("huggingface-secret")])
def critique_revise(n: int = 5000, teacher: str = "Qwen/Qwen3-8B"):
    from datasets import Dataset, load_dataset
    from vllm import LLM, SamplingParams

    prompts = load_dataset("PKU-Alignment/PKU-SafeRLHF", split="train").shuffle(seed=0).select(range(n))["prompt"]
    llm, sp = LLM(teacher, max_model_len=8192), SamplingParams(temperature=0.7, max_tokens=768)
    chat = lambda msgs: [o.outputs[0].text for o in llm.chat([[{"role": "user", "content": m}] for m in msgs], sp,
                                                              chat_template_kwargs={"enable_thinking": False})]
    rng = random.Random(0)
    principles = [rng.choice(CONSTITUTION) for _ in prompts]
    drafts = chat(prompts)
    critiques = chat([critique_prompt(r, d, p) for r, d, p in zip(prompts, drafts, principles)])
    revisions = chat([revise_prompt(r, d, c, p) for r, d, c, p in zip(prompts, drafts, critiques, principles)])
    pairs = [rows(r, d, v) for r, d, v in zip(prompts, drafts, revisions)]
    Dataset.from_list([s for s, _ in pairs]).save_to_disk("/data/cai_sft")
    Dataset.from_list([p for _, p in pairs]).save_to_disk("/data/cai_pref")
    data.commit()


if __name__ == "__main__":
    req, draft = "Is it safe to mix bleach and vinegar for cleaning?", "Sure, mix them for a stronger cleaner."
    print(critique_prompt(req, draft, CONSTITUTION[0]))
    print("---")
    sft, pref = rows(req, draft, "No. Mixing them releases chlorine gas, which is toxic. Use them separately and ventilate.")
    print("SFT keys:", list(sft), "| preference keys:", list(pref), "| chosen starts:", pref["chosen"][0]["content"][:30])
