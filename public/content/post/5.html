🚀 Starting point

One GPU runs out of either memory or time. Data parallelism copies the model to every GPU and splits the batch. Sharding (ZeRO / FSDP) splits the model’s state across GPUs, so each holds \(1/G\). Tensor and pipeline parallelism split the model’s computation when even a sharded layer is too big or too slow.

Training state for an 8B model on 8 GPUs (16 bytes/parameter, activations excluded). Only full sharding gets it to 16 GB per GPU.

✏️ Derivation: what FSDP communicates

Step 1. DDP: each GPU computes gradients on its own batch, then an all-reduce averages them. Ring all-reduce sends about \(2\Phi\) bytes per GPU for a gradient of \(\Phi\) bytes, independent of \(G\).

Step 2. FSDP: before a block’s forward, all-gather its weight shards into a full copy; free it after. Backward: all-gather again, compute gradients, then reduce-scatter, so each GPU ends up with the summed gradient for its own shard only. Each GPU then updates only its shard.

Step 3. Volume per step \(\approx\Phi\) (all-gather forward) \(+\Phi\) (all-gather backward) \(+\Phi\) (reduce-scatter) \(=3\Phi\): 1.5\(\times\) DDP’s traffic, in exchange for \(G\times\) less memory.

Step 4. The traffic overlaps with compute: FSDP prefetches block \(\ell+1\)’s weights while block \(\ell\) computes. That’s why it shards per block (fully_shard(blk) in the code), not the whole model at once.

Step 5. When FSDP isn’t enough: tensor parallelism splits each matrix multiply across GPUs inside a node (fast NVLink); pipeline parallelism puts different layers on different nodes; expert parallelism spreads MoE experts; context parallelism splits very long sequences. Frontier runs combine all of them (“4D/5D parallelism”).

"""Multi-GPU pre-training with FSDP2 (fully_shard): every GPU holds 1/N of the weights, grads and Adam state.

Local smoke test (2 CPU processes):  torchrun --nproc_per_node=2 fsdp_train.py
On Modal (8x H100):                  modal run fsdp_train.py::launch
"""
import os
import time

import modal
import torch
import torch.distributed as dist

from pretrain_gpt import GPT, Config, lr_at, make_optimizer


def main(max_steps: int = 20, small: bool = True):
    from torch.distributed.device_mesh import init_device_mesh
    from torch.distributed.fsdp import MixedPrecisionPolicy, fully_shard

    cuda = torch.cuda.is_available()
    dist.init_process_group("nccl" if cuda else "gloo")
    rank, world = dist.get_rank(), dist.get_world_size()
    device = torch.device(f"cuda:{int(os.environ['LOCAL_RANK'])}" if cuda else "cpu")
    if cuda:
        torch.cuda.set_device(device)

    c = (Config(vocab_size=1024, d_model=64, n_layers=2, n_heads=4, seq_len=32, batch_size=4, max_steps=max_steps, warmup=2)
         if small else Config(max_steps=max_steps))
    torch.manual_seed(0)
    model = GPT(c).to(device)

    # Shard each block separately, then the root. BF16 compute, FP32 gradient reduction.
    mesh = init_device_mesh("cuda" if cuda else "cpu", (world,))   # explicit: avoids picking MPS on a Mac
    kw = {"mesh": mesh, **({"mp_policy": MixedPrecisionPolicy(param_dtype=torch.bfloat16, reduce_dtype=torch.float32)} if cuda else {})}
    for blk in model.blocks:
        fully_shard(blk, **kw)
    fully_shard(model, **kw)

    opt = make_optimizer(model, c, fused=cuda)
    g = torch.Generator().manual_seed(1234 + rank)                 # each rank sees different data
    t0 = time.time()
    for step in range(c.max_steps):
        x = torch.randint(0, c.vocab_size, (c.batch_size, c.seq_len + 1), generator=g).to(device)
        for grp in opt.param_groups:
            grp["lr"] = lr_at(step, c)
        loss = model(x[:, :-1], x[:, 1:])
        loss.backward()                                            # reduce-scatter: each rank keeps its shard of grads
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        opt.step()                                                 # each rank updates only its shard
        opt.zero_grad(set_to_none=True)
        if rank == 0 and step % 5 == 0:
            local = sum(p.to_local().numel() for p in model.parameters())
            total = sum(p.numel() for p in model.parameters())
            print(f"step {step:3d} loss {loss.item():.3f}  params on this rank {local:,} of {total:,}  "
                  f"({time.time() - t0:.1f}s)")
    dist.destroy_process_group()


app = modal.App("pt-book-fsdp")
image = (modal.Image.debian_slim(python_version="3.12")
         .uv_pip_install("torch==2.14.1", "transformers==5.20.2", "datasets==5.1.0")
         .add_local_python_source("pretrain_gpt", "fsdp_train"))


@app.function(gpu="H100:8", image=image, timeout=4 * 60 * 60)
def launch(max_steps: int = 1000):
    import subprocess

    subprocess.run(["torchrun", "--nproc_per_node=8", "-m", "fsdp_train", "--full", str(max_steps)], check=True)


if __name__ == "__main__":
    import sys

    if "--full" in sys.argv:
        main(max_steps=int(sys.argv[sys.argv.index("--full") + 1]), small=False)
    else:
        main()
