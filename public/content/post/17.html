🚀 Starting point

For SFT, you need prompts and responses. Responses are easy: ask a strong model. Diverse, realistic prompts are the hard part. Each method below is a different answer to “where do the prompts come from?”

Method where prompts come from known datasets
Self-Instruct (2022) 175 human seeds; the model writes new tasks in their style, filtered by ROUGE overlap Alpaca (52K)
Evol-Instruct (2023) rewrite prompts to be harder (add constraints, deepen, concretize) over several rounds WizardLM, WizardCoder
Magpie (2024) none: give an aligned model only the chat template up to the user turn, and it writes a user query itself Magpie-Pro-300K-Filtered, part of SmolTalk
Persona-driven (2024) “You are <persona>. Write a problem you’d face” over a billion personas PersonaHub, Tulu 3 math/code, nvidia/Nemotron-Personas-*
Rejection sampling real problems with answers; sample many solutions, keep verified ones OpenThoughts, NuminaMath, R1 distills
LLM-as-judge any prompts; responses scored or ranked by a judge model UltraFeedback (preferences)
✏️ Derivation: why Magpie works

Step 1. An aligned chat model has been trained on \(p(\text{user turn}, \text{assistant turn})\) in its template, so it models the distribution of user queries too.

Step 2. Sampling from \(p(\text{user text}\mid\texttt{<|im\_start|>user\textbackslash n})\) draws from that learned query distribution. High temperature (1.0, top-\(p\) 0.99) spreads samples across it.

Step 3. Then sample the answer from \(p(\text{assistant}\mid\text{query})\) at a lower temperature. The result is a conversation in the model’s own distribution, with no human seed.

Step 4. The catch: queries reflect what the teacher was trained on, with many near-duplicates. That’s why magpie runs near_dedup and drops very short queries.

✏️ Derivation: rejection sampling as expectation-maximization

Step 1. Goal: maximize \(\log p_\theta(\text{correct}\mid x)=\log\sum_yp_\theta(y|x)\,\mathbb 1[\text{verify}(y)]\), marginalizing over reasoning traces \(y\).

Step 2. E-step: sample \(y\sim p_{\text{teacher}}(\cdot|x)\) and keep those that verify. These approximate samples from the posterior \(p(y\mid x,\text{correct})\).

Step 3. M-step: SFT on the kept traces, i.e. maximize \(\sum\log p_\theta(y|x)\) over them.

Step 4. With the student as its own teacher and repeated rounds, that’s expert iteration (RL book, Topic 169). With a stronger teacher, it’s distillation of reasoning: how OpenThoughts and most “R1-distill” models are made.

Step 5. Cap traces per problem (2 here) so easy problems, which give many correct samples, don’t dominate the dataset.

"""Synthetic data with an LLM: rephrased pre-training text, Magpie instructions, persona prompts,
and rejection-sampled reasoning traces, all generated with vLLM on Modal.

Local test of the filters:  python synth.py
On Modal:                   modal run synth.py::magpie         (or ::rephrase, ::rejection_sample)
"""
import re

import modal

TEACHER = "Qwen/Qwen3-8B"

REPHRASE_PROMPTS = {   # WRAP / Nemotron-CC style: same facts, new style
    "wiki": "Rewrite the following text as a clear, well-organized encyclopedia article. Keep every fact.\n\n{doc}",
    "qa": "Read the text and write 5 diverse question-answer pairs that test understanding of it.\n\n{doc}",
    "textbook": "Turn the following text into a short textbook section for a high-school student, with an example.\n\n{doc}",
}


# ---------- pure functions (tested locally) ----------
def boxed(text):
    m = re.findall(r"\\boxed\{([^{}]*)\}", text)
    return m[-1].replace(",", "").strip() if m else None


def is_correct(text, ref):
    p = boxed(text)
    try:
        return p is not None and abs(float(p) - float(ref)) < 1e-6
    except ValueError:
        return False


def judge_score(text):
    """Parse 'Score: 7/10' from an LLM-judge reply; None if absent."""
    m = re.search(r"Score:\s*(\d+(?:\.\d+)?)\s*/\s*10", text)
    return float(m[1]) if m else None


def near_dedup(texts, threshold=0.7):
    """Drop near-duplicate generations (synthetic data repeats itself a lot)."""
    from dedup import MinHasher, shingles

    mh, kept, sigs = MinHasher(64), [], []
    for t in texts:
        s = mh.signature(shingles(t, n=3))
        if all((s == o).mean() < threshold for o in sigs):
            kept.append(t)
            sigs.append(s)
    return kept


# ---------- Modal + vLLM ----------
app = modal.App("pt-book-synth")
image = (modal.Image.debian_slim(python_version="3.12")
         .uv_pip_install("vllm==0.32.0", "datasets==5.1.0")
         .add_local_python_source("dedup", "synth"))
out = modal.Volume.from_name("pt-book-data", create_if_missing=True)
GPU = dict(gpu="H100", image=image, volumes={"/data": out}, timeout=3 * 60 * 60,
           secrets=[modal.Secret.from_name("huggingface-secret")])


def llm():
    from vllm import LLM
    return LLM(TEACHER, max_model_len=8192, gpu_memory_utilization=0.9)


@app.function(**GPU)
def rephrase(n_docs: int = 5000):
    """Pre-training data: rewrite web documents in several styles."""
    from datasets import Dataset, load_dataset
    from vllm import SamplingParams

    docs = [d["text"][:4000] for d in load_dataset("HuggingFaceFW/fineweb", name="sample-10BT",
                                                   split="train", streaming=True).take(n_docs)]
    chats = [[{"role": "user", "content": p.format(doc=d)}] for d in docs for p in REPHRASE_PROMPTS.values()]
    gens = llm().chat(chats, SamplingParams(temperature=0.7, max_tokens=1024),
                      chat_template_kwargs={"enable_thinking": False})
    Dataset.from_list([{"text": g.outputs[0].text} for g in gens]).save_to_disk("/data/rephrased")
    out.commit()


@app.function(**GPU)
def magpie(n: int = 20_000):
    """SFT data with no seed prompts: feed only the template prefix up to the user turn,
    so the aligned model writes a plausible user query itself; then answer it."""
    from datasets import Dataset
    from vllm import SamplingParams

    model = llm()
    prefix = "<|im_start|>user\n"                                  # Qwen chat template, user turn opened
    qs = model.generate([prefix] * n, SamplingParams(temperature=1.0, top_p=0.99, max_tokens=256, stop=["<|im_end|>"]))
    queries = near_dedup([q.outputs[0].text.strip() for q in qs if len(q.outputs[0].text.split()) >= 5])
    ans = model.chat([[{"role": "user", "content": q}] for q in queries],
                     SamplingParams(temperature=0.7, max_tokens=1024), chat_template_kwargs={"enable_thinking": False})
    rows = [{"messages": [{"role": "user", "content": q}, {"role": "assistant", "content": a.outputs[0].text}]}
            for q, a in zip(queries, ans)]
    Dataset.from_list(rows).save_to_disk("/data/magpie")
    out.commit()
    return len(rows)


@app.function(**GPU)
def persona_prompts(n: int = 10_000):
    """Diversity from personas: 'You are <persona>. Write a hard math word problem you would face.'"""
    from datasets import Dataset, load_dataset
    from vllm import SamplingParams

    personas = load_dataset("proj-persona/PersonaHub", "persona", split="train").select(range(n))["persona"]
    chats = [[{"role": "user", "content": f"Persona: {p}\nWrite one challenging math word problem this person "
                                          f"might face in their work. Output only the problem."}] for p in personas]
    gens = llm().chat(chats, SamplingParams(temperature=0.8, max_tokens=300), chat_template_kwargs={"enable_thinking": False})
    Dataset.from_list([{"problem": g.outputs[0].text.strip()} for g in gens]).save_to_disk("/data/persona_math")
    out.commit()


@app.function(**GPU)
def rejection_sample(k: int = 8):
    """Reasoning traces: sample k solutions per GSM8K problem, keep only verified-correct ones."""
    from datasets import Dataset, load_dataset
    from vllm import SamplingParams

    ds = load_dataset("openai/gsm8k", "main", split="train")
    refs = [a.split("####")[-1].replace(",", "").strip() for a in ds["answer"]]
    chats = [[{"role": "user", "content": q + "\nReason step by step, end with \\boxed{answer}."}] for q in ds["question"]]
    gens = llm().chat(chats, SamplingParams(n=k, temperature=0.8, max_tokens=4096))  # thinking on: long traces
    rows, solved = [], 0
    for q, ref, g in zip(ds["question"], refs, gens):
        good = [o.text for o in g.outputs if is_correct(o.text, ref)]
        solved += bool(good)
        rows += [{"messages": [{"role": "user", "content": q}, {"role": "assistant", "content": t}]}
                 for t in near_dedup(good)[:2]]                    # at most 2 distinct traces per problem
    Dataset.from_list(rows).save_to_disk("/data/gsm8k_traces")
    out.commit()
    return {"problems": len(ds), "solved_at_least_once": solved, "traces_kept": len(rows)}
