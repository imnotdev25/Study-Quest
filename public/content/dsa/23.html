Formulas to Remember

  • Stable softmax: subtract the row max; \(\log\text{softmax} = z - \text{logsumexp}(z)\).

  • Cross-entropy gradient w.r.t. logits: \(p - y\). Sigmoid: \(\sigma' = \sigma(1-\sigma)\).

  • Attention: \(\text{softmax}(QK^\top/\sqrt{d_k})V\). KV bytes/token: \(2\cdot L\cdot H_{kv}\cdot d_k\cdot b\).

  • AUC \(= \big(R_+ - n_+(n_++1)/2\big)/(n_+n_-)\). NDCG: \(\sum (2^{rel}-1)/\log_2(i+1)\), normalized.

  • Cohen’s \(\kappa = (p_o - p_e)/(1 - p_e)\). PSI \(= \sum (a - e)\ln(a/e)\).

  • Downsampling correction: \(p = q/(q + (1-q)/r)\).

  • Bloom filter: about 10 bits per item for 1% false positives; \(k = (m/n)\ln 2\).

  • MinHash: \(\Pr[\text{match}] = J(A,B)\); LSH candidate probability \(1 - (1 - J^r)^b\).

  • Master theorem: compare \(f(n)\) with \(n^{\log_b a}\).

  • A/B sample size per arm for a proportion: \(\approx 16\,p(1-p)/\delta^2\).
