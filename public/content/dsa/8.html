👋 Intro

Weighted shortest paths (Dijkstra, Bellman–Ford, Floyd–Warshall, A*), minimum spanning trees (Kruskal, Prim), maximum flow and minimum cut, bipartite matching, and the Hungarian algorithm, with the proofs that make each correct and the conditions under which each one fails.

Dijkstra’s Algorithm

🌱 Beginner

Imagine water flowing from the source through pipes of different lengths. It reaches nearby junctions first. Dijkstra always finalizes the closest not-yet-finalized junction, because nothing can reach it sooner: every other path would have to go through junctions that are already farther away.

Dijkstra with a binary heap (lazy deletion)

Input: graph with non-negative weights \(w\), source \(s\)
\(dist[v] \gets \infty\); \(dist[s] \gets 0\); \(H \gets\) min-heap \(\{(0, s)\}\)
while \(H\) not empty do
\((d, u) \gets\) pop\((H)\)
if \(d > dist[u]\) then
continue ▷ stale entry: a shorter path was found later
end
for each edge \((u, v, w)\) do
if \(dist[u] + w < dist[v]\) then
\(dist[v] \gets dist[u] + w\); \(parent[v] \gets u\); push \((dist[v], v)\)
end
end
end
return \(dist\)
❓ Why

Claim: when \(u\) is popped with \(d = dist[u]\), that distance is final. Suppose a shorter path existed. It leaves the set of finalized nodes at some edge \((x, y)\) with \(y\) not finalized. Then \(dist[y] \le dist[x] + w(x,y) \le\) length of that path \(< d\), so \(y\) would have been popped before \(u\). Contradiction. The step “the rest of the path after \(y\) only adds length” is exactly where non-negative weights are required; with a negative edge later on the path, the argument fails and Dijkstra can return wrong answers.

📡 Interview signals

“Minimum cost / time / effort to reach,” network delay time, cheapest flight (with at most \(k\) stops: state = (node, stops), or Bellman–Ford limited to \(k+1\) rounds), path with maximum probability (maximize a product = Dijkstra on \(-\log p\), or a max-heap variant), minimum effort path (minimize the maximum edge on the path: Dijkstra where path cost is the max, or binary search plus BFS, or a union-find on sorted edges).

Bellman–Ford and Negative Cycles

Bellman–Ford

\(dist[v] \gets \infty\); \(dist[s] \gets 0\)
for \(i \gets 1\) to \(V-1\) do
for each edge \((u, v, w)\) do
if \(dist[u] + w < dist[v]\) then
\(dist[v] \gets dist[u] + w\)
end
end
end
for each edge \((u, v, w)\) do
if \(dist[u] + w < dist[v]\) then
return NEGATIVE CYCLE
end
end
return \(dist\)
❓ Why

After round \(i\), \(dist[v]\) is at most the length of the shortest path to \(v\) using at most \(i\) edges (induction on \(i\)). A shortest path without cycles has at most \(V-1\) edges, so \(V-1\) rounds suffice. If anything still improves in round \(V\), some path keeps getting shorter by looping, which means a reachable negative cycle. Detecting arbitrage in currency exchange (edge weight \(-\log(\text{rate})\)) is the classic application.

Floyd–Warshall

🔧 Intermediate

\(dist[i][j] \gets \min(dist[i][j], dist[i][k] + dist[k][j])\) for \(k\) in the outer loop, then \(i\), then \(j\). After processing \(k\), \(dist[i][j]\) is the shortest path using only intermediate nodes from \(\{0..k\}\). The loop order matters: \(k\) must be outermost. \(O(V^3)\) time, \(O(V^2)\) space. Also computes transitive closure (with booleans) and detects negative cycles (\(dist[i][i] < 0\)).

A* Search

🔧 Intermediate

A* is Dijkstra ordered by \(f(v) = g(v) + h(v)\), where \(g\) is the cost so far and \(h\) is a heuristic estimate of the remaining cost. If \(h\) never overestimates (admissible), A* returns an optimal path; if it is also consistent (\(h(u) \le w(u,v) + h(v)\)), each node is expanded at most once. On a grid, Manhattan distance (4-neighbors) or Euclidean distance is admissible. \(h = 0\) is Dijkstra; a better \(h\) explores fewer nodes.

Minimum Spanning Trees

🌱 Beginner

Connect every town with roads using the least total road length, without building any loop. Kruskal’s method: sort all possible roads by length and build each one unless it would create a loop.

Kruskal’s MST

sort edges by weight ascending; \(T \gets []\); initialize union-find on \(V\) nodes
for each edge \((u, v, w)\) in sorted order do
if then ▷ true if \(u\), \(v\) were in different components
append \((u, v, w)\) to \(T\)
if \(|T| = V-1\) then
break
end
end
end
return \(T\)
❓ Why

The cut property: for any partition of the nodes into two sets, the lightest edge crossing the cut belongs to some MST. Proof by exchange: if an MST \(T\) does not contain the lightest crossing edge \(e\), add \(e\) to \(T\); this creates a cycle that must cross the cut again through some edge \(e'\) with \(w(e') \ge w(e)\); removing \(e'\) gives a spanning tree no heavier than \(T\). Kruskal’s chosen edge is the lightest crossing the cut between its endpoint’s component and the rest, so every choice is safe. Time: \(O(E\log E)\) Space: \(O(V)\). Prim grows one tree, always adding the lightest edge leaving it (a heap), \(O(E\log V)\); better for dense graphs with an adjacency matrix (\(O(V^2)\) without a heap).

🤖 ML connection

Single-linkage hierarchical clustering is exactly Kruskal: merge the two closest clusters repeatedly; stopping at \(k\) components gives \(k\) clusters (equivalently, remove the \(k-1\) heaviest MST edges). HDBSCAN builds on a minimum spanning tree of mutual reachability distances.

Maximum Flow and Minimum Cut

A flow network: edge labels are capacities. Max flow from s to t is 14 here.

🔧 Intermediate

Ford–Fulkerson: repeatedly find a path from \(s\) to \(t\) in the residual graph (remaining capacity forward, plus “undo” capacity backward for flow already sent) and push the bottleneck amount along it. Edmonds–Karp finds augmenting paths with BFS (shortest first): \(O(VE^2)\). Dinic’s algorithm uses BFS level graphs and blocking flows: \(O(V^2E)\), much faster in practice, \(O(E\sqrt V)\) on unit-capacity bipartite graphs.

❓ Why

Max-flow min-cut theorem: the maximum flow equals the minimum total capacity of edges whose removal separates \(s\) from \(t\). When no augmenting path remains, the nodes reachable from \(s\) in the residual graph form a cut whose forward edges are all saturated and backward edges all empty, so the flow equals that cut’s capacity; since no flow can exceed any cut, both are optimal. Backward residual edges are what allow the algorithm to fix earlier bad choices.

Bipartite Matching and Assignment

🔧 Intermediate

Maximum bipartite matching: add a source connected to every left node and a sink connected from every right node, all capacities 1; max flow = maximum matching. The direct augmenting-path algorithm (Kuhn’s) is \(O(VE)\); Hopcroft–Karp is \(O(E\sqrt V)\). Weighted assignment (minimum-cost perfect matching of \(n\) workers to \(n\) jobs) is solved by the Hungarian algorithm in \(O(n^3)\), or by min-cost max-flow.

🤖 ML connection

  • DETR-style object detection matches predicted boxes to ground-truth boxes with the Hungarian algorithm before computing the loss, so each object is predicted exactly once (no NMS needed).

  • Multi-object tracking assigns detections in a new frame to existing tracks with Hungarian matching on IoU or appearance cost.

  • Ride matching and delivery dispatch are assignment problems at scale.

  • Graph cuts perform image segmentation (min-cut between foreground and background seeds).

  • Optimal transport (Sinkhorn) generalizes assignment to soft matching and appears in distribution alignment and some loss functions.

Euler Paths

🔧 Intermediate

An Euler path uses every edge exactly once. In a directed graph it exists iff the graph is connected (ignoring isolated nodes) and at most one node has \(out - in = 1\) (the start), at most one has \(in - out = 1\) (the end), and all others are balanced. Hierholzer’s algorithm: DFS that removes edges as it uses them, appending a node to the result when it has no unused edges left, then reverse. \(O(E)\). Applications: “reconstruct itinerary” (use a min-heap per node for lexicographic order), de Bruijn sequences (“cracking the safe”), genome assembly.

🎤 Interview: Network delay time

“Given directed weighted edges and a source, how long until all nodes receive the signal?” Answer = the maximum over nodes of the shortest-path distance, or \(-1\) if some node is unreachable. Weights are non-negative times, so Dijkstra. Build an adjacency list, run Dijkstra with lazy deletion, take the max finite distance. \(O(E\log V)\). Trace a small graph to show stale entries being skipped. Follow-ups: negative delays (Bellman–Ford); the graph is huge and on disk (Dijkstra with an external priority queue, or contraction hierarchies used by map routing); many queries on a fixed road network (precomputation such as contraction hierarchies or landmarks with A*).

🔑 Takeaways

  • Dijkstra for non-negative weights; know exactly why negatives break it.

  • Bellman–Ford handles negatives and finds negative cycles; DAGs need only topological DP.

  • MSTs come from the cut property: Kruskal with union-find, Prim with a heap.

  • Max flow = min cut; matching and assignment reduce to flow or the Hungarian algorithm.
