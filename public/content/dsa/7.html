👋 Intro

How to represent graphs (including implicit ones like grids and state spaces), BFS and DFS and what each guarantees, multi-source BFS, cycle detection, bipartite checks, topological sorting (Kahn and DFS), strongly connected components, and bridges. In ML, graphs are computation graphs, data pipelines, knowledge graphs, and the input to graph neural networks.

Representing Graphs

🔧 Intermediate
Representation Space Edge check Iterate neighbors
Adjacency list \(O(V+E)\) \(O(\deg)\) \(O(\deg)\)
Adjacency matrix \(O(V^2)\) \(O(1)\) \(O(V)\)
Edge list \(O(E)\) \(O(E)\) \(O(E)\) (good for Kruskal, Bellman–Ford)

Use adjacency lists by default (most graphs are sparse). Implicit graphs are not stored at all: a grid (neighbors are the 4 or 8 adjacent cells), a word ladder (neighbors differ by one letter), a lock combination, or a puzzle state. Recognizing that a problem is a graph search over states is often the whole trick.

Breadth-First Search

🌱 Beginner

Drop a stone in a pond. Ripples reach everything 1 step away, then 2 steps, then 3. BFS explores a graph the same way, so the first time it reaches a node, it has found the shortest path in number of edges.

BFS shortest path in an unweighted graph

Input: graph \(G\), source \(s\)
\(dist[v] \gets \infty\) for all \(v\); \(dist[s] \gets 0\); \(Q \gets [s]\)
while \(Q\) not empty do
\(u \gets\) dequeue\((Q)\)
for each neighbor \(v\) of \(u\) do
if \(dist[v] = \infty\) then ▷ mark when enqueued, not when dequeued
\(dist[v] \gets dist[u] + 1\); \(parent[v] \gets u\); enqueue \(v\)
end
end
end
return \(dist\), \(parent\)
❓ Why

Invariant: the queue always holds nodes with distances \(d\) followed by nodes with distance \(d+1\), never more than two consecutive values. So nodes are dequeued in non-decreasing distance order, and the first discovery of a node comes from a node at minimum distance. Time: \(O(V+E)\) Space: \(O(V)\). Marking at enqueue time matters: marking at dequeue time lets the same node be enqueued many times, blowing up time and memory on dense graphs.

🔧 Intermediate

Multi-source BFS: start with all sources in the queue at distance 0. Solves “rotting oranges,” “distance to nearest gate,” “01 matrix” in \(O(V+E)\) instead of one BFS per source. Bidirectional BFS searches from both ends and stops when the frontiers meet; with branching factor \(b\) and distance \(d\), it explores about \(2b^{d/2}\) nodes instead of \(b^d\) (word ladder). 0-1 BFS: edges weigh 0 or 1; use a deque, push 0-weight neighbors to the front and 1-weight to the back. \(O(V+E)\) shortest paths without a heap.

Depth-First Search

DFS with three colors (detects cycles in directed graphs)

\(color[v] \gets\) WHITE for all \(v\) ▷ WHITE unvisited, GRAY on stack, BLACK done
function Visit(\(u\))
\(color[u] \gets\) GRAY
for each neighbor \(v\) of \(u\) do
if \(color[v] =\) GRAY then
return CYCLE ▷ back edge to an ancestor
end
if \(color[v] =\) WHITE and \(=\) CYCLE then
return CYCLE
end
end
\(color[u] \gets\) BLACK; append \(u\) to \(finished\)
return OK
end
❓ Why

In a directed graph, a cycle exists exactly when DFS finds an edge to a node that is still on the recursion stack (GRAY): that node is an ancestor, so the edge closes a loop. An edge to a BLACK node only reaches finished work and is not a cycle. In an undirected graph, a simpler rule applies: any visited neighbor other than the parent indicates a cycle (or use union-find).

🔧 Intermediate

What DFS is good at: connected components (count how many times you start a new DFS), flood fill and islands, path existence, cycle detection, topological order (reverse finishing order), and backtracking (Chapter 11). DFS does not find shortest paths. On large grids, use an explicit stack to avoid recursion limits.

🔧 Intermediate

Bipartite check: BFS or DFS coloring with two colors; the graph is bipartite iff no edge joins two nodes of the same color, equivalently iff it has no odd cycle. Applications: “possible bipartition,” two-team assignment, detecting conflicts.

Topological Sort

🌱 Beginner

To get dressed, socks before shoes, shirt before jacket. A topological order lists tasks so every task comes after everything it depends on. It exists only if the dependencies have no cycle.

A DAG and a topological order.

Kahn’s algorithm (BFS topological sort)

compute \(indeg[v]\) for all \(v\); \(Q \gets\) all \(v\) with \(indeg[v] = 0\); \(order \gets []\)
while \(Q\) not empty do
\(u \gets\) dequeue\((Q)\); append \(u\) to \(order\)
for each edge \(u \to v\) do
\(indeg[v] \gets indeg[v] - 1\)
if \(indeg[v] = 0\) then
enqueue \(v\) ▷ all prerequisites done
end
end
end
if \(|order| < V\) then
return CYCLE ▷ remaining nodes are on or behind a cycle
end
return \(order\)
❓ Why

A node enters the queue only when all its predecessors are already in order, so every edge points forward. If a cycle exists, no node on it ever reaches in-degree zero, so fewer than \(V\) nodes are output: Kahn’s algorithm detects cycles for free. The DFS alternative outputs nodes in reverse finishing order: a node finishes only after everything reachable from it, so reversing puts it before all of them. Time: \(O(V+E)\) Space: \(O(V)\).

📡 Interview signals

Prerequisites, build order, course schedule, “alien dictionary” (derive edges from adjacent words’ first differing letter; watch for the invalid case where a word is a prefix of an earlier, longer word), “parallel courses” (BFS levels = minimum semesters), longest path in a DAG (DP in topological order), “sequence reconstruction” (unique order iff the queue never holds more than one node).

Strongly Connected Components

🔧 Intermediate

In a directed graph, an SCC is a maximal set of nodes that can all reach each other. Kosaraju: DFS to get finishing order; reverse all edges; DFS in decreasing finish order on the reversed graph; each tree is one SCC. Tarjan: one DFS tracking discovery index and low (the lowest index reachable via the subtree plus one back edge); a node with \(low = index\) is the root of an SCC, popped from a stack. Both \(O(V+E)\). Collapsing SCCs gives a DAG (the condensation), which turns cyclic problems into DAG DP. Used in 2-SAT, deadlock detection, and dependency analysis.

Bridges and Articulation Points

🧠 Expert

In an undirected graph, a bridge is an edge whose removal disconnects the graph, and an articulation point is such a vertex. Tarjan’s DFS computes \(disc[u]\) and \(low[u]\) = the smallest discovery time reachable from \(u\)’s subtree using at most one back edge. Tree edge \((u, v)\) is a bridge iff \(low[v] > disc[u]\) (the subtree of \(v\) cannot reach \(u\) or above any other way). Non-root \(u\) is an articulation point iff some child has \(low[v] \ge disc[u]\); the root is one iff it has two or more DFS children. “Critical connections in a network” is exactly this. \(O(V+E)\).

State-Space Search

🔧 Intermediate

Many puzzles are BFS on states. Shortest path visiting all nodes: state = (current node, bitmask of visited nodes), \(n\cdot 2^n\) states, BFS from every start simultaneously. Sliding puzzle: state = board as a string. Open the lock: state = 4-digit string, 8 neighbors, BFS avoiding dead ends. Keys and rooms / grid with keys: state = (row, col, keys held). The cost is the number of states times the branching factor; estimate it before coding.

🤖 ML connection

  • Autograd builds a DAG of operations; backpropagation visits it in reverse topological order so every node’s gradient is complete before it is pushed to its inputs (Chapter 18).

  • Pipelines and orchestrators (Airflow, Kubeflow, ML training DAGs, agent workflows) schedule tasks in topological order and detect cycles at definition time.

  • Graph neural networks aggregate neighbor features layer by layer, like a \(k\)-hop BFS; neighbor sampling (GraphSAGE) bounds the fan-out.

  • Knowledge graphs for RAG use BFS/DFS over entity relations (multi-hop retrieval, GraphRAG).

  • Web crawling for training data is BFS over links with deduplication and politeness constraints.

🎤 Interview: Course schedule II

“Return an order to take \(n\) courses given prerequisite pairs, or empty if impossible.” This is topological sort with cycle detection. Build an adjacency list from prerequisite to course and in-degree counts. Run Kahn’s algorithm; if the output has fewer than \(n\) courses, there is a cycle. \(O(V+E)\). Edge cases: courses with no prerequisites (start in the queue), duplicate pairs (in-degree counts handle them if consistent), self-loop (immediate cycle). Follow-ups: minimum number of semesters if you can take any number per semester (count BFS levels); at most \(k\) per semester (becomes NP-hard in general; bitmask DP for small \(n\)); find which courses form the cycle (DFS with colors, track the stack).

🔑 Takeaways

  • BFS gives shortest paths in unweighted graphs; mark nodes when enqueued.

  • DFS gives components, cycles (gray nodes), and finishing order.

  • Topological sort via Kahn detects cycles; it powers autograd and pipelines.

  • Recognize implicit graphs and state spaces; estimate the number of states first.
