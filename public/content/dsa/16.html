👋 Intro

The algorithms ML coding rounds ask you to implement and ML breadth rounds ask you to explain: linear and logistic regression, regularization, softmax and cross-entropy, kNN, k-means, Naive Bayes, decision trees, random forests, gradient boosting, PCA, SVMs, matrix factorization, and the evaluation metrics (ROC-AUC, PR-AUC, NDCG, calibration) with their algorithms.

How to answer an ML coding question.

State shapes and assumptions first (“\(X\) is \(n\times d\), \(y\) is length \(n\) with values in {0,1}”). Write a correct, vectorized baseline. Handle numerical stability. Test a normal case and an edge case (empty cluster, all one class, ties). Then discuss complexity and how it scales.

Linear Regression

🔧 Intermediate

Model \(\hat y = Xw + b\), loss (mean squared error) \(L = \frac{1}{n}\lVert Xw + b - y\rVert^2\). Gradient: \(\nabla_w L = \frac{2}{n}X^\top(Xw + b - y)\), \(\nabla_b L = \frac{2}{n}\sum(\hat y - y)\). Closed form (normal equation): \(w = (X^\top X)^{-1}X^\top y\), \(O(nd^2 + d^3)\); solve with a Cholesky or QR factorization rather than an explicit inverse, and use gradient descent when \(d\) or \(n\) is large. Ridge adds \(\lambda\lVert w\rVert^2\): \(w = (X^\top X + \lambda I)^{-1}X^\top y\), always invertible.

❓ Why

MSE is the maximum-likelihood objective if \(y = Xw + \varepsilon\) with Gaussian noise. L2 regularization is a Gaussian prior on \(w\) (MAP estimation); L1 (lasso) is a Laplace prior, whose sharp corner at zero produces exactly sparse weights. Lasso has no closed form; solve with coordinate descent and soft-thresholding \(w_j \gets \text{sign}(z)\max(|z| - \lambda, 0)\).

Logistic Regression

Logistic regression with batch gradient descent

Input: \(X \in \mathbb{R}^{n\times d}\) (standardized), \(y \in \{0,1\}^n\), learning rate \(\eta\), L2 strength \(\lambda\)
\(w \gets 0_d\); \(b \gets 0\)
for \(t \gets 1\) to \(T\) do
\(z \gets Xw + b\); \(p \gets \sigma(z)\) ▷ stable sigmoid: use \(e^{z}/(1+e^{z})\) when \(z<0\)
\(g_w \gets \frac{1}{n}X^\top(p - y) + \lambda w\); \(g_b \gets \frac{1}{n}\sum(p - y)\)
\(w \gets w - \eta\, g_w\); \(b \gets b - \eta\, g_b\)
if loss change \(<\) tolerance then
break
end
end
return \(w, b\)
❓ Why

Loss is binary cross-entropy \(-\frac1n\sum[y\log p + (1-y)\log(1-p)]\), the negative log-likelihood of a Bernoulli model. The gradient is the remarkably simple \(X^\top(p - y)/n\) because \(\sigma'(z) = \sigma(z)(1-\sigma(z))\) cancels with the derivative of the log. The loss is convex, so gradient descent reaches the global minimum. Compute the loss from logits with \(\log(1+e^{z}) - yz\), written stably as \(\max(z,0) - yz + \log(1+e^{-|z|})\), to avoid \(\log 0\). On linearly separable data, unregularized weights grow without bound; L2 fixes it.

Softmax and Cross-Entropy

Numerically stable softmax and cross-entropy

Input: logits \(Z \in \mathbb{R}^{n\times K}\), integer labels \(y\)
\(m \gets\) row-wise max of \(Z\); \(S \gets Z - m\) ▷ shift: softmax is shift-invariant
\(lse \gets \log\sum_k e^{S_{:,k}}\) ▷ log-sum-exp per row
\(\log P \gets S - lse\); \(P \gets e^{\log P}\)
\(loss \gets -\frac1n\sum_i \log P_{i, y_i}\)
\(\nabla_Z \gets (P - \text{onehot}(y))/n\) ▷ gradient w.r.t. logits
❓ Why

Without the max shift, \(e^{1000}\) overflows to infinity; with it, the largest exponent is \(e^0 = 1\) and nothing overflows. Subtracting a constant does not change softmax because it cancels in the ratio. The gradient \(P - Y\) is the same elegant form as logistic regression. This algorithm is the most frequently asked “easy” ML coding question, and the most frequently gotten wrong.

k-Nearest Neighbors

🔧 Intermediate

Predict by majority vote (classification) or mean (regression) of the \(k\) closest training points. Training is free; prediction costs \(O(nd)\) per query with brute force. Vectorize distances for a batch: \(\lVert a - b\rVert^2 = \lVert a\rVert^2 + \lVert b\rVert^2 - 2a^\top b\), one matrix multiply instead of a triple loop; select the top \(k\) with a partial sort (argpartition). Choose \(k\) by validation (odd \(k\) avoids ties in binary problems), scale features (distances are dominated by large-range features), and consider distance-weighted votes. Curse of dimensionality: in high dimensions all distances become similar, which is why kNN on raw features fails and kNN on learned embeddings works.

k-Means and k-Means++

k-means with k-means++ initialization

Input: points \(X\) (\(n\times d\)), \(k\)
\(C_1 \gets\) a random point
for \(j \gets 2\) to \(k\) do ▷ k-means++
\(D(x) \gets\) squared distance from \(x\) to its nearest chosen center
choose \(C_j \gets x\) with probability \(D(x)/\sum D\)
end
repeat
assign each \(x\) to its nearest center ▷ one \(n\times k\) distance matrix
for each cluster \(j\) do
if cluster \(j\) is empty then
reseed \(C_j\) with the point farthest from its center
else  
\(C_j \gets\) mean of points assigned to \(j\)
end
end
until assignments stop changing or max iterations
❓ Why

k-means minimizes inertia \(\sum_i \lVert x_i - C_{a(i)}\rVert^2\). The assignment step minimizes it for fixed centers; the update step (the mean minimizes squared distance) minimizes it for fixed assignments. Inertia never increases and there are finitely many assignments, so it converges, but only to a local minimum. k-means++ spreads initial centers out and is \(O(\log k)\)-competitive with the optimum in expectation. Run several restarts and keep the lowest inertia. Choose \(k\) with the elbow method or silhouette score. Each iteration is \(O(nkd)\). k-means assumes roughly spherical, similar-sized clusters; use GMMs or density methods (DBSCAN) otherwise.

🤖 ML connection

k-means builds the coarse quantizer of IVF vector indexes and the codebooks of product quantization (Chapter 18), clusters embeddings for data deduplication and diversity sampling, and initializes vocabularies in vector-quantized models.

Gaussian Mixtures and EM

🔧 Intermediate

A GMM models data as a weighted sum of Gaussians. EM alternates the E-step (responsibilities \(r_{ij} \propto \pi_j\,\mathcal{N}(x_i|\mu_j,\Sigma_j)\), computed with log-sum-exp) and the M-step (weighted means, covariances, and mixture weights). Each iteration never decreases the likelihood. k-means is the limit of EM with hard assignments and equal spherical covariances. Add a small value to covariance diagonals to avoid singularities when a component collapses onto one point.

Naive Bayes

🔧 Intermediate

\(P(y|x) \propto P(y)\prod_j P(x_j|y)\), assuming features are conditionally independent given the class. Multinomial NB for text: \(P(w|y) = \frac{\text{count}(w,y) + \alpha}{\sum_w \text{count}(w,y) + \alpha|V|}\) (Laplace smoothing prevents zero probabilities). Predict with log probabilities (sums, not products) to avoid underflow. Training is one counting pass, \(O(\text{nnz})\); it is a strong baseline for text classification with little data, and badly calibrated because the independence assumption double-counts correlated evidence.

Decision Trees

Find the best split for one numeric feature (Gini)

Input: values \(x\) and binary labels \(y\) for the rows at this node
sort rows by \(x\); \(P \gets \sum y\); \(N \gets\) number of rows
\(l_n \gets 0\); \(l_p \gets 0\); \(best \gets (\infty, \text{none})\)
for \(i \gets 0\) to \(N-2\) do
\(l_n \gets l_n + 1\); \(l_p \gets l_p + y_i\) ▷ move row \(i\) to the left side
if \(x_i = x_{i+1}\) then
continue ▷ can only split between distinct values
end
\(G_L \gets 1 - (l_p/l_n)^2 - (1 - l_p/l_n)^2\); similarly \(G_R\) for the right side
\(score \gets \frac{l_n}{N}G_L + \frac{N - l_n}{N}G_R\)
if \(score < best.score\) then
\(best \gets (score, (x_i + x_{i+1})/2)\)
end
end
return \(best\)
🔧 Intermediate

Sorting once and sweeping with running counts makes each feature \(O(N\log N)\) instead of \(O(N^2)\); histogram-based learners (LightGBM, XGBoost hist) bin values into about 256 buckets for \(O(N)\) per feature. Build the tree recursively (CART), stopping at max depth, minimum samples per leaf, or no impurity gain. Gini \(1 - \sum p_k^2\) and entropy \(-\sum p_k\log p_k\) give similar trees; regression trees use variance reduction. Trees need no feature scaling, handle mixed types, and overfit easily alone.

Ensembles: Bagging and Boosting

🔧 Intermediate

Random forest: train many deep trees on bootstrap samples, each split considering a random subset of features (about \(\sqrt d\)), then average. Bagging reduces variance; feature subsampling decorrelates trees so averaging helps more. Out-of-bag rows give a free validation estimate.

Gradient boosting: build shallow trees sequentially, each fitting the negative gradient of the loss with respect to the current predictions (the “pseudo-residuals”), added with a small learning rate. Boosting reduces bias.

Gradient boosting (generic loss)

\(F_0(x) \gets \arg\min_c \sum_i L(y_i, c)\) ▷ mean for MSE, log-odds for log loss
for \(m \gets 1\) to \(M\) do
\(r_i \gets -\partial L(y_i, F)/\partial F\,\big|_{F = F_{m-1}(x_i)}\) ▷ \(y - p\) for log loss
fit a regression tree \(h_m\) to \(\{(x_i, r_i)\}\)
set each leaf’s value to the step minimizing the loss in that leaf
\(F_m \gets F_{m-1} + \nu\, h_m\) ▷ shrinkage \(\nu \approx 0.05\)–0.1
end
🧠 Expert

XGBoost uses a second-order Taylor expansion: with gradients \(g_i\) and Hessians \(h_i\), the optimal leaf weight is \(w^* = -\frac{\sum g_i}{\sum h_i + \lambda}\) and the split gain is \(\frac12\left[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right] - \gamma\). LightGBM grows leaf-wise with histograms and gradient-based sampling; CatBoost uses ordered target statistics to avoid target leakage in categorical encoding. Gradient-boosted trees remain the strongest default for tabular data.

PCA

PCA via SVD

\(\mu \gets\) column means of \(X\); \(X_c \gets X - \mu\) ▷ centering is essential
\(U, S, V^\top \gets \text{SVD}(X_c)\) ▷ thin SVD
components \(\gets\) first \(k\) rows of \(V^\top\); explained variance \(\gets S_k^2/(n-1)\)
\(Z \gets X_c V_k\) ▷ project to \(k\) dimensions
❓ Why

The first principal component is the unit direction \(v\) maximizing the variance \(v^\top \Sigma v\) of projected data, which is the top eigenvector of the covariance \(\Sigma = X_c^\top X_c/(n-1)\) (Lagrange multipliers give \(\Sigma v = \lambda v\)). SVD of \(X_c\) gives the same vectors without forming \(\Sigma\) (more stable). Standardize features first if they use different units. For very large data, use randomized SVD or power iteration.

Support Vector Machines

🔧 Intermediate

A linear SVM finds the separating hyperplane with the largest margin, minimizing \(\frac{\lambda}{2}\lVert w\rVert^2 + \frac1n\sum\max(0, 1 - y_i w^\top x_i)\) (hinge loss, \(y \in \{-1, +1\}\)). Subgradient: for points with \(y_i w^\top x_i < 1\), contribute \(-y_i x_i\); others contribute 0. Only points on or inside the margin (support vectors) affect the solution. The kernel trick replaces dot products with \(k(x, x')\) (RBF, polynomial) to separate non-linearly in an implicit feature space, at \(O(n^2)\) memory for the kernel matrix.

Matrix Factorization for Recommendations

🔧 Intermediate

Approximate the user–item matrix \(R \approx UV^\top\) with \(k\)-dimensional user and item vectors, minimizing squared error on observed entries plus L2. Solve with SGD over observed ratings, or alternating least squares: fix \(V\) and each user vector has a closed-form ridge solution, then fix \(U\); ALS parallelizes well. For implicit feedback (clicks, views), weight observed interactions by confidence and treat missing as weak negatives. Modern systems use two-tower neural models (user tower and item tower producing embeddings, scored by dot product) trained with sampled softmax and in-batch negatives (Chapter 16), served with ANN search.

Evaluation Metrics and Their Algorithms

ROC-AUC by ranks (Mann–Whitney)

Input: scores \(s\), labels \(y \in \{0,1\}\) with \(n_+\) positives, \(n_-\) negatives
rank all scores ascending from 1, giving tied scores the average of their ranks
\(R_+ \gets\) sum of ranks of the positives
return \(\big(R_+ - n_+(n_+ + 1)/2\big) / (n_+ n_-)\)
❓ Why

AUC equals the probability that a random positive scores higher than a random negative (ties count half). \(R_+ - n_+(n_++1)/2\) counts exactly the (positive, negative) pairs where the positive ranks higher, so dividing by the number of pairs gives that probability. \(O(n\log n)\) instead of \(O(n_+ n_-)\). AUC is threshold-free and insensitive to class balance, which is also its weakness: with 99.9% negatives, a high AUC can still mean poor precision at useful thresholds, so use PR-AUC (average precision) for rare positives.

🔧 Intermediate

  • Precision / recall / F1: from the confusion matrix at a threshold; macro averaging gives each class equal weight, micro pools counts (equals accuracy for single-label multiclass).

  • Log loss rewards calibrated probabilities; Brier score is MSE on probabilities.

  • Calibration: bin predictions and compare mean prediction with the observed rate (reliability diagram, expected calibration error). Fix with Platt scaling (fit a logistic regression on the logit) or isotonic regression (a monotone step function, via pool-adjacent-violators) on a held-out set. Temperature scaling (divide logits by \(T\)) is the neural-network version.

  • Ranking: precision@\(k\), recall@\(k\), MRR (mean of \(1/\text{rank}\) of the first relevant item), and NDCG@\(k\): \(\text{DCG} = \sum_{i=1}^{k}\frac{2^{rel_i} - 1}{\log_2(i+1)}\), normalized by the DCG of the ideal ordering.

  • Regression: MSE/RMSE (penalize large errors), MAE (robust), MAPE (undefined at zero), \(R^2\).

Bias, Variance, and Experiments

🔧 Intermediate

Expected squared error = bias\(^2\) + variance + irreducible noise. High training error means high bias (bigger model, better features, less regularization); a large gap between training and validation error means high variance (more data, regularization, simpler model, ensembling). Learning curves (error vs training size) tell you whether more data will help.

A/B tests: pick a primary metric and guardrails, compute the sample size from the minimum detectable effect, randomize by user, run for full weekly cycles, and test once at the planned end (peeking inflates false positives; use sequential methods if you must look early). For a proportion, \(n \approx 16\,p(1-p)/\delta^2\) per arm for 80% power at \(\alpha = 0.05\). CUPED (regressing out pre-experiment behavior) reduces variance and required sample size.

🎤 Interview: Implement k-means in NumPy-style pseudocode

State shapes: X (n,d), k, returns centers (k,d) and labels (n,). Initialize with k-means++ (explain why). Assignment: distances via \(\lVert x\rVert^2 + \lVert c\rVert^2 - 2xc^\top\) (an \(n\times k\) matrix, clip tiny negatives to 0), argmin per row. Update: per-cluster mean; handle empty clusters by reseeding. Stop when labels stop changing or the inertia improvement is below a tolerance. Complexity \(O(nkd)\) per iteration, memory \(O(nk)\); for huge \(n\), use mini-batch k-means. Test on two well-separated blobs (should recover them) and on \(k = n\) (zero inertia). Follow-ups: choose \(k\); non-spherical clusters; scaling to a billion points (mini-batch, distributed assignment with a broadcast of centers).

🔑 Takeaways

  • Logistic regression and softmax share the gradient “prediction minus target”; compute losses from logits with log-sum-exp.

  • k-means alternates two minimizations; k-means++ and restarts fight local minima.

  • Trees: sorted sweep for splits; random forests cut variance, boosting cuts bias.

  • AUC is a ranking probability computed from ranks; know PR-AUC, NDCG, and calibration fixes.
