👋 Intro

The algorithms behind modern models, at the level research engineers and AI engineers are asked to implement and reason about: backpropagation, optimizers, normalization and initialization, convolution and NMS, attention and its variants, positional encodings (RoPE), the online softmax behind FlashAttention, KV caching, decoding strategies, speculative decoding, contrastive and preference losses (InfoNCE, DPO, PPO, GRPO), LoRA, quantization, vector search (HNSW, IVF-PQ), and distributed training.

Backpropagation

🌱 Beginner

A factory produces a bad product. To fix it, trace backward: how much did the last machine contribute to the defect, and how much did each earlier machine contribute through it? Backpropagation does exactly that with derivatives, reusing each machine’s answer instead of recomputing it.

Reverse-mode automatic differentiation

forward: evaluate operations in topological order, recording each node’s inputs (the tape)
\(\bar{L} \gets 1\); all other gradients \(\gets 0\)
for each node \(v\) in reverse topological order do
for each input \(u\) of \(v\) do
\(\bar u \gets \bar u + \bar v \cdot \partial v/\partial u\) ▷ chain rule; accumulate over all uses
end
end
❓ Why

Reverse order guarantees that when \(v\) is processed, \(\bar v\) already includes the contributions of every node that uses \(v\). The cost is a small constant times the forward pass, regardless of the number of parameters, which is why reverse mode (not forward mode) is used for scalar losses with millions of parameters. Memory is the catch: activations must be stored for the backward pass, which motivates activation checkpointing (recompute some activations in backward, trading about 30% more compute for much less memory). Verify gradients with finite differences: \(\frac{L(\theta + \epsilon) - L(\theta - \epsilon)}{2\epsilon}\) in double precision, compared by relative error.

🔧 Intermediate

Gradients of a linear layer \(Y = XW + b\) with upstream gradient \(G = \partial L/\partial Y\): \(\partial L/\partial W = X^\top G\), \(\partial L/\partial X = G W^\top\), \(\partial L/\partial b = \sum_{\text{rows}} G\). Shapes check the formulas: \(X\) is \(n\times d\), \(W\) is \(d\times h\), \(G\) is \(n\times h\). ReLU passes gradients where the input was positive. Softmax + cross-entropy together give \(P - Y\) (Chapter 17).

Optimizers

AdamW

Input: learning rate \(\eta\), \(\beta_1 = 0.9\), \(\beta_2 = 0.95\)–\(0.999\), \(\epsilon = 10^{-8}\), weight decay \(\lambda\)
\(m \gets 0\); \(v \gets 0\)
for \(t \gets 1, 2, \dots\) do
\(g \gets \nabla L(\theta)\) (after optional global-norm clipping)
\(m \gets \beta_1 m + (1-\beta_1) g\) ▷ momentum: running mean of gradients
\(v \gets \beta_2 v + (1-\beta_2) g^2\) ▷ running mean of squared gradients
\(\hat m \gets m/(1-\beta_1^t)\); \(\hat v \gets v/(1-\beta_2^t)\) ▷ bias correction for zero init
\(\theta \gets \theta - \eta\big(\hat m/(\sqrt{\hat v} + \epsilon) + \lambda\theta\big)\) ▷ decoupled decay
end
🔧 Intermediate

  • SGD with momentum accumulates velocity to move through ravines; Nesterov evaluates the gradient at the look-ahead point.

  • Adagrad / RMSProp / Adam scale each parameter’s step by the inverse root of its recent squared gradients, so rarely updated parameters take bigger steps.

  • AdamW applies weight decay directly to weights rather than adding \(\lambda\theta\) to the gradient; inside Adam, L2-through-the-gradient gets rescaled by \(1/\sqrt{v}\) and stops being proper regularization.

  • Memory: Adam stores two extra values per parameter, so a 7B-parameter model needs about \(7\text{B}\times(2 \text{ weights in BF16} + 4 \text{ FP32 master} + 8 \text{ moments}) \approx 100\) GB of training state before activations.

  • Schedules: linear warmup (stabilizes early Adam statistics) then cosine or linear decay; “warmup-stable-decay” is common for LLM pre-training.

  • Gradient clipping by global norm (e.g. 1.0) prevents loss spikes.

Initialization and Normalization

🔧 Intermediate

Initialization keeps activation variance stable across layers: Xavier/Glorot (\(\text{Var} = 2/(d_{in} + d_{out})\)) for tanh, He/Kaiming (\(2/d_{in}\)) for ReLU. Residual networks often scale the last layer of each block down (or initialize it to zero) so each block starts near the identity.

Normalization: BatchNorm normalizes each feature over the batch (running statistics at inference; problematic with small or variable batches and sequences). LayerNorm normalizes over features within each example: \(\frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}\gamma + \beta\), independent of batch size, standard in transformers. RMSNorm drops the mean subtraction: \(x/\sqrt{\text{mean}(x^2) + \epsilon}\cdot\gamma\), cheaper and used by most current LLMs. Pre-norm (normalize before attention/MLP, add the residual after) trains more stably at depth than post-norm. Dropout randomly zeroes activations with probability \(p\) during training and scales survivors by \(1/(1-p)\) (inverted dropout), so inference needs no change.

Convolution, IoU, and Non-Max Suppression

🔧 Intermediate

Output size of a convolution: \(\lfloor (W - K + 2P)/S\rfloor + 1\) for input width \(W\), kernel \(K\), padding \(P\), stride \(S\). Parameters per layer: \(K^2 C_{in} C_{out} + C_{out}\). Convolutions are implemented as matrix multiplies (im2col: unfold each receptive field into a column) or with FFT/Winograd for large kernels. Receptive field grows with depth, stride, and dilation.

Non-max suppression

Input: boxes with scores, IoU threshold \(\tau\) (e.g. 0.5)
sort boxes by score descending; \(keep \gets []\)
while boxes remain do
\(b \gets\) the highest-scoring remaining box; append to \(keep\)
remove every remaining box with \(\text{IoU}(b, \cdot) > \tau\) ▷ duplicates of the same object
end
return \(keep\)
🔧 Intermediate

IoU \(= \frac{\text{area}(A\cap B)}{\text{area}(A) + \text{area}(B) - \text{area}(A\cap B)}\), with intersection width \(\max(0, \min(x_2) - \max(x_1))\). NMS is \(O(n^2)\) worst case; run it per class, vectorize IoU against all remaining boxes, and consider Soft-NMS (decay scores instead of deleting) for crowded scenes. DETR-style detectors avoid NMS with Hungarian matching (Chapter 9).

Attention

🌱 Beginner

Reading “the animal didn’t cross the street because it was tired,” you decide what “it” means by looking back at the other words and weighing how relevant each is. Attention does this for every token: each token asks a question (query), every token offers a label (key) and content (value), and the answer is a relevance-weighted mix of contents.

Multi-head causal self-attention

Input: \(X \in \mathbb{R}^{n\times d}\), weights \(W_Q, W_K, W_V, W_O\), \(h\) heads, \(d_k = d/h\)
\(Q \gets XW_Q\), \(K \gets XW_K\), \(V \gets XW_V\); reshape each to \((h, n, d_k)\)
\(S \gets QK^\top/\sqrt{d_k}\) ▷ \((h, n, n)\) scores
\(S_{ij} \gets -\infty\) for \(j > i\) ▷ causal mask: no peeking at the future
\(A \gets \text{softmax}(S)\) along the last axis ▷ stable softmax
\(O \gets AV\); concatenate heads to \((n, d)\)
return \(OW_O\)
❓ Why

Why \(\sqrt{d_k}\): if query and key entries have unit variance, their dot product has variance \(d_k\); dividing by \(\sqrt{d_k}\) keeps scores at unit scale so softmax does not saturate into near one-hot outputs with vanishing gradients. Why multiple heads: each head can attend to a different kind of relation (syntax, coreference, position) in a lower-dimensional subspace at the same total cost. Cost: \(O(n^2 d)\) compute and \(O(n^2)\) memory for scores, the bottleneck for long contexts.

🔧 Intermediate

Variants that shrink the KV cache (the companion System Design book’s inference chapter covers serving): multi-query attention (all heads share one K/V head), grouped-query attention (\(g\) K/V heads shared by groups of query heads; used by most open LLMs), multi-head latent attention (compress K/V into a small latent vector). Sliding-window / local attention limits each token to the last \(w\) tokens: \(O(nw)\). Cross-attention takes queries from one sequence and keys/values from another (encoder–decoder, multimodal).

Positional Encodings

🔧 Intermediate

Attention by itself is permutation-invariant, so position must be injected. Sinusoidal: \(PE(p, 2i) = \sin(p/10000^{2i/d})\), \(PE(p, 2i+1) = \cos(\cdot)\), added to embeddings. Learned absolute embeddings do not extrapolate past the training length. RoPE (rotary): rotate each pair of query/key dimensions by angle \(p\,\theta_i\); then \(q_m^\top k_n\) depends only on the relative offset \(m - n\), because rotations compose: \((R_m q)^\top(R_n k) = q^\top R_{n-m} k\). Context extension methods (position interpolation, NTK-aware scaling, YaRN) rescale those angles. ALiBi adds a linear distance penalty to scores instead.

Online Softmax and FlashAttention

Online softmax-weighted sum (one query, streaming over key/value blocks)

\(m \gets -\infty\); \(\ell \gets 0\); \(o \gets 0_{d}\) ▷ running max, normalizer, output
for each block of scores \(s_{1..B}\) with values \(v_{1..B}\) do
\(m' \gets \max(m, \max_j s_j)\)
\(\ell \gets \ell\, e^{m - m'} + \sum_j e^{s_j - m'}\) ▷ rescale old sum to the new max
\(o \gets o\, e^{m - m'} + \sum_j e^{s_j - m'} v_j\)
\(m \gets m'\)
end
return \(o/\ell\)
❓ Why

Softmax seems to need all scores before normalizing, but partial results can be corrected when a larger maximum appears: multiplying by \(e^{m - m'}\) re-expresses the old sum relative to the new maximum. The final \(o/\ell\) is exactly \(\sum_j \text{softmax}(s)_j v_j\). FlashAttention applies this per tile of \(Q\), \(K\), \(V\) held in fast on-chip SRAM, never writing the \(n\times n\) score matrix to GPU memory. Compute is the same \(O(n^2d)\), but memory traffic falls dramatically and memory becomes \(O(n)\), which is why long-context training became practical. It is a memory-bandwidth optimization, not an approximation.

KV Cache

🔧 Intermediate

During generation, keys and values of past tokens never change, so cache them: each new token computes only its own \(q, k, v\), appends \(k, v\) to the cache, and attends over the cache. Per-token cost falls from recomputing \(O(n)\) tokens’ projections to \(O(1)\) projections plus an \(O(n)\) attention read. Cache size per token \(= 2 \times \text{layers} \times \text{KV heads} \times d_k \times \text{bytes}\); it, not compute, limits batch size in serving. An ML coding question may ask you to implement an append-only KV cache with preallocated buffers and a length pointer, and to show that incremental decoding matches full recomputation.

Decoding

Temperature, top-\(k\), and top-\(p\) (nucleus) sampling

Input: logits \(z\), temperature \(T > 0\), \(k\), \(p\)
\(z \gets z/T\) ▷ \(T<1\) sharpens, \(T>1\) flattens
if top-\(k\) then
set all but the \(k\) largest logits to \(-\infty\)
end
\(\pi \gets \text{softmax}(z)\)
if top-\(p\) then
sort \(\pi\) descending; keep the smallest prefix whose cumulative sum \(\ge p\)
(always keep at least the top token); zero the rest
end
renormalize \(\pi\) and sample a token ▷ CDF + binary search, Chapter 15
🔧 Intermediate

Greedy picks the argmax (deterministic, can repeat itself). Beam search keeps the \(B\) best partial sequences by total log-probability; normalize by length (or the beam favors short outputs); good for translation and constrained tasks, poor for open-ended text (bland, repetitive). Top-\(p\) adapts the candidate set to the model’s confidence, unlike a fixed \(k\). Repetition / frequency penalties lower logits of tokens already generated. Min-\(p\) keeps tokens with probability at least a fraction of the top token’s. Constrained decoding masks tokens that would violate a JSON schema or grammar at every step.

Speculative Decoding

Speculative decoding (acceptance rule)

draft model \(q\) proposes tokens \(x_1..x_\gamma\) autoregressively
target model \(p\) scores all \(\gamma\) positions in one forward pass
for \(i \gets 1\) to \(\gamma\) do
accept \(x_i\) with probability \(\min\big(1, p(x_i)/q(x_i)\big)\)
if rejected then
sample a replacement from the residual \(\propto \max(0, p - q)\); break
end
end
if all accepted, sample one bonus token from \(p\) at the next position
❓ Why

This is rejection sampling (Chapter 13) arranged so the output distribution is exactly the target’s: tokens where the draft over-proposes are thinned, and the residual distribution fills in what the draft under-proposes. Speedup depends on the acceptance rate; with greedy decoding the rule simplifies to “accept while the draft token equals the target’s argmax.”

Training Objectives

🔧 Intermediate

Language modeling: next-token cross-entropy averaged over positions; perplexity \(= \exp(\text{mean cross-entropy})\), comparable only between models with the same tokenizer. Masked LM (BERT) predicts masked tokens from both sides. Distillation: train a student on the teacher’s softened distribution, \(T^2\cdot\text{KL}(\text{softmax}(z_t/T)\,\Vert\,\text{softmax}(z_s/T))\).

Symmetric InfoNCE (CLIP-style contrastive loss)

Input: batch of \(B\) paired embeddings \(a_i, b_i\) (L2-normalized), temperature \(\tau\)
\(S \gets AB^\top/\tau\) ▷ \(B\times B\); the diagonal holds the positive pairs
\(L_a \gets\) cross-entropy of each row of \(S\) with target index \(i\)
\(L_b \gets\) cross-entropy of each column of \(S\) with target index \(i\)
return \((L_a + L_b)/2\)
🔧 Intermediate

Every other item in the batch serves as a negative, so larger batches give more negatives and better embeddings; the temperature controls how sharply hard negatives are penalized. The same loss trains dense retrievers (query, relevant passage) and two-tower recommenders. Triplet loss \(\max(0, d(a,p) - d(a,n) + \text{margin})\) is an older alternative needing hard-negative mining.

Preference Optimization

🔧 Intermediate

RLHF with PPO: train a reward model on human preference pairs with the Bradley–Terry loss \(-\log\sigma(r(x, y_w) - r(x, y_l))\), then optimize the policy to maximize reward minus a KL penalty to the reference model, using PPO’s clipped objective \(\min(\rho A, \text{clip}(\rho, 1-\epsilon, 1+\epsilon)A)\) with probability ratio \(\rho\) and advantages \(A\) from a value model.

DPO skips the reward model and RL loop: \[L = -\log\sigma\Big(\beta\big[\log\tfrac{\pi(y_w|x)}{\pi_{ref}(y_w|x)} - \log\tfrac{\pi(y_l|x)}{\pi_{ref}(y_l|x)}\big]\Big)\] computed from summed token log-probabilities of the chosen (\(y_w\)) and rejected (\(y_l\)) responses under the policy and a frozen reference. It is the closed-form consequence of the KL-regularized reward objective.

GRPO (group relative policy optimization) samples a group of responses per prompt, scores them (often with a verifiable reward: a correct math answer, passing tests), and uses each response’s reward standardized within its group as the advantage, removing the separate value model. It is widely used for training reasoning models with reinforcement learning on verifiable tasks.

Efficient Fine-Tuning and Quantization

🔧 Intermediate

LoRA: freeze \(W\) and learn a low-rank update \(\Delta W = \frac{\alpha}{r}BA\) with \(A \in \mathbb{R}^{r\times d}\), \(B \in \mathbb{R}^{d\times r}\), \(r \ll d\); initialize \(B = 0\) so training starts at the original model. Trainable parameters per layer fall from \(d^2\) to \(2dr\) (for \(d = 4096\), \(r = 16\): 16.8M \(\to\) 131K). At inference, merge \(W + \Delta W\) for zero overhead, or keep adapters separate to serve many fine-tunes on one base model. QLoRA trains LoRA adapters on a 4-bit quantized base model.

Quantization: map floats to \(b\)-bit integers with a scale (and zero point): \(q = \text{round}(x/s)\), \(s = \max|x|/(2^{b-1} - 1)\) for symmetric quantization. Per-channel or per-group (e.g. 128 values) scales reduce error from outliers. Weight-only INT4 (GPTQ, AWQ) helps memory-bound decoding; FP8 for weights and activations is common on recent GPUs. Mixed precision training: BF16 compute with FP32 master weights; FP16 needs loss scaling to avoid underflowing gradients, BF16 does not (same exponent range as FP32).

Vector Search

HNSW: a hierarchy of proximity graphs.

🔧 Intermediate

HNSW: each point is inserted into layer 0 and, with exponentially decreasing probability, into higher layers. Search starts at the top layer’s entry point, moves greedily to the closest neighbor until no improvement, drops a layer, and repeats; at layer 0 it runs a best-first search keeping a candidate min-heap and a result max-heap of size efSearch. Higher efSearch and more links per node (M) raise recall at the cost of latency and memory. Roughly logarithmic search time; high memory use (vectors plus graph).

IVF-PQ: k-means partitions vectors into \(n_{list}\) cells (inverted lists); a query probes the nprobe closest cells. Product quantization splits each vector into \(m\) sub-vectors and replaces each with the ID of its nearest centroid in a 256-entry codebook (1 byte), compressing a 768-dim float vector (3 KB) to \(m = 96\) bytes. Distances are computed with lookup tables (precompute the query’s distance to every codebook entry, then sum \(m\) table lookups per vector). Re-rank top candidates with exact vectors. Metrics: recall@\(k\) vs queries per second.

Distributed Training

🔧 Intermediate

  • Data parallelism: each GPU holds a model copy and a slice of the batch; gradients are averaged with all-reduce. Ring all-reduce sends \(2\frac{N-1}{N}\) times the gradient size per GPU, independent of \(N\), as a reduce-scatter followed by an all-gather.

  • ZeRO / FSDP: shard optimizer states (stage 1), gradients (stage 2), and parameters (stage 3) across data-parallel ranks, all-gathering parameters just in time for each layer. Memory per GPU falls roughly by \(N\).

  • Tensor parallelism splits each layer’s matrices across GPUs (column- then row-parallel in the MLP needs one all-reduce per block); keep it within a node.

  • Pipeline parallelism splits layers into stages and uses micro-batches to reduce idle “bubbles” (1F1B schedules).

  • Gradient accumulation simulates a large batch on small hardware: sum gradients over several micro-batches before one optimizer step.

🎤 Interview: Implement scaled dot-product attention with a causal mask

State shapes: Q, K, V are (batch, heads, n, d_k). Scores Q @ K.T / sqrt(d_k) give (batch, heads, n, n). Build the mask once as an upper-triangular boolean matrix and fill masked scores with a large negative number (not -inf if a row could be fully masked, which would produce NaN). Stable softmax over the last axis; multiply by V. Test: with a causal mask, changing a later token must not change earlier outputs; with identical keys, attention weights are uniform over allowed positions. Discuss \(O(n^2)\) memory and how FlashAttention’s online softmax avoids it; how a KV cache turns generation into one new query per step; padding masks for variable-length batches (combine with the causal mask by logical OR).

🔑 Takeaways

  • Backprop is reverse topological traversal with the chain rule; memory, not compute, is its constraint.

  • Stable softmax, the online softmax rescaling trick, and the \(\sqrt{d_k}\) scaling are must-know details.

  • KV caching, GQA/MQA, and speculative decoding exist because generation is memory-bound.

  • Contrastive, DPO, and GRPO losses are short formulas; know what each term does.

  • HNSW and IVF-PQ are the algorithms behind vector databases.
