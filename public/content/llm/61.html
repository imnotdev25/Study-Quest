🚀 Starting point

The goal: make the model prefer the responses humans chose. Start from the RLHF objective: maximize reward while staying close to a reference model, \(\max_\pi\ \mathbb E_{y\sim\pi}[r(x,y)]-\beta\,D_{\mathrm{KL}}(\pi\|\pi_{\text{ref}})\). DPO solves this objective in closed form and turns it into a classification loss on preference pairs, with no reward model and no sampling.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. For an autoregressive response, are token log-probabilities added or averaged to obtain its log-probability?

  2. Why must padding and prompt tokens be excluded when scoring a response?

For prompt \(x\), preferred response \(y^+\), and rejected response \(y^-\):

\[\log \pi_\theta(y\mid x) = \sum_{t\in\text{response}} \log \pi_\theta(y_t\mid x,y_{<t})\]

Define the policy preference margin:

\[\Delta_\theta = \log\pi_\theta(y^+\mid x) - \log\pi_\theta(y^-\mid x)\]

and the frozen reference-model margin:

\[\Delta_{\text{ref}} = \log\pi_{\text{ref}}(y^+\mid x) - \log\pi_{\text{ref}}(y^-\mid x)\]

DPO optimizes:

\[L_{\text{DPO}} = -\log\sigma\left( \beta(\Delta_\theta-\Delta_{\text{ref}}) \right)\]

Equivalently, using a numerically stable form:

\[L_{\text{DPO}} = \operatorname{softplus}\left( -\beta(\Delta_\theta-\Delta_{\text{ref}}) \right)\]

Interpretation: the policy should prefer \(y^+\) over \(y^-\) more strongly than the reference does.

For token logits:

\[Z^+,Z^-\in\mathbb{R}^{B\times T\times V}\]

the output is one scalar sequence log-probability per response:

\[s^+,s^-\in\mathbb{R}^{B}\]

The reference model must remain frozen. Accidentally allowing gradients through it increases memory and changes the intended optimization problem.

✏️ Derivation: from the KL-regularized objective to the DPO loss

Step 1. Rewrite the objective for one prompt: \(\sum_y\pi(y)\big[r(y)-\beta\log\frac{\pi(y)}{\pi_{\text{ref}}(y)}\big]=-\beta\sum_y\pi(y)\log\frac{\pi(y)}{\pi_{\text{ref}}(y)e^{r(y)/\beta}}\).

Step 2. Define \(Z=\sum_y\pi_{\text{ref}}(y)e^{r(y)/\beta}\) and \(\pi^*=\pi_{\text{ref}}e^{r/\beta}/Z\). The objective becomes \(-\beta D_{\mathrm{KL}}(\pi\|\pi^*)+\beta\log Z\), maximized exactly at \(\pi=\pi^*\).

Step 3. Solve for the reward: \(r(y)=\beta\log\frac{\pi^*(y)}{\pi_{\text{ref}}(y)}+\beta\log Z\).

Step 4. Bradley–Terry preference probability \(\sigma(r(y^+)-r(y^-))\). The \(\beta\log Z\) terms are identical for both responses and cancel: \(P(y^+\succ y^-)=\sigma\Big(\beta\big[\log\tfrac{\pi^*(y^+)}{\pi_{\text{ref}}(y^+)}-\log\tfrac{\pi^*(y^-)}{\pi_{\text{ref}}(y^-)}\big]\Big)\).

Step 5. Replace \(\pi^*\) with the trainable \(\pi_\theta\), and take the NLL of the observed preference: \(L_{\text{DPO}}=-\log\sigma\big(\beta(\Delta_\theta-\Delta_{\text{ref}})\big)\).

Step 6. Gradient: with \(u=\beta(\Delta_\theta-\Delta_{\text{ref}})\), \(\nabla L=-\beta\sigma(-u)\big[\nabla\log\pi_\theta(y^+)-\nabla\log\pi_\theta(y^-)\big]\). It pushes the preferred response up and the rejected one down, weighted by how wrong the current margin is.

⚙️ Algorithm: DPO training step
Input: pairs \((x,y^+,y^-)\), frozen \(\pi_{\text{ref}}\), policy \(\pi_\theta\), \(\beta\)
\(s_\theta^\pm\gets\sum_{t\in y^\pm}\log\pi_\theta(y_t\mid x,y_{<t})\) ▷ masked sums over response tokens
\(s_{\text{ref}}^\pm\gets\) the same under \(\pi_{\text{ref}}\), with no gradient
\(u\gets\beta\big[(s_\theta^+-s_\theta^-)-(s_{\text{ref}}^+-s_{\text{ref}}^-)\big]\)
\(L\gets\operatorname{mean}\softplus(-u)\); gradient step

def sequence_logp(logits, targets, mask, normalize=False):
    log_probs = F.log_softmax(logits, dim=-1)

    target_logp = log_probs.gather(
        dim=-1,
        index=targets.unsqueeze(-1),
    ).squeeze(-1)

    masked_logp = target_logp * mask.to(target_logp.dtype)
    sequence_sum = masked_logp.sum(dim=-1)

    if normalize:
        return sequence_sum / mask.sum(dim=-1).clamp_min(1)

    return sequence_sum


policy_chosen_logp = sequence_logp(
    policy_chosen_logits,
    chosen_targets,
    chosen_mask,
)

policy_rejected_logp = sequence_logp(
    policy_rejected_logits,
    rejected_targets,
    rejected_mask,
)

with torch.no_grad():
    reference_chosen_logp = sequence_logp(
        reference_chosen_logits,
        chosen_targets,
        chosen_mask,
    )

    reference_rejected_logp = sequence_logp(
        reference_rejected_logits,
        rejected_targets,
        rejected_mask,
    )

policy_margin = (
    policy_chosen_logp - policy_rejected_logp
)

reference_margin = (
    reference_chosen_logp - reference_rejected_logp
)

preference_logit = beta * (
    policy_margin - reference_margin
)

losses = F.softplus(-preference_logit)
loss = losses.mean()

Let:

\[z=\beta(\Delta_\theta-\Delta_{\text{ref}})\]

Then:

\[\frac{\partial L}{\partial\Delta_\theta} = -\beta\sigma(-z)<0\]

Therefore:

\[\frac{\partial L} {\partial\log\pi_\theta(y^+|x)}<0\]

\[\frac{\partial L} {\partial\log\pi_\theta(y^-|x)}>0\]

Gradient descent increases the preferred-response log-probability and decreases the rejected-response log-probability.

Length normalization changes:

\[\sum_t\log p(y_t)\]

into:

\[\frac{1}{T}\sum_t\log p(y_t)\]

These represent different objectives. The latter compares average token confidence and reduces the effect of response length; it is not algebraically equivalent to sequence likelihood.

For extreme=-1000, sigmoid underflows to zero and the naïve expression produces infinity. softplus(1000) remains a finite value near 1000.

Check answers:

  1. The reference establishes how much preference is already present. DPO trains the policy’s relative change while regularizing it implicitly toward the reference.

  2. Token log-probabilities are [B,T]; summing valid response tokens produces [B].

  3. The preference logit is zero: \[-\log\sigma(0)=\log 2\approx0.693\]

  4. Check whether reference inference was performed with gradients enabled or whether its computation graph is being retained.

  5. Larger \(\beta\) makes the logistic comparison sharper. Misranked pairs can receive larger gradients, while confidently correct pairs saturate more quickly.

Retrieval answers:

  • Autoregressive token log-probabilities are added to obtain the log-probability of the complete sequence.

  • Prompt and padding positions are context, not response targets; including them changes both the score and its gradient.
