🚀 Starting point

The problem: we want \(\nabla_\theta\,\mathbb E_{a\sim\pi_\theta}[R(a)]\), but sampling isn’t differentiable and \(R\) may not be differentiable at all. The score function \(\nabla_\theta\log\pi_\theta(a)\) solves this: it turns the gradient of an expectation into an expectation we can estimate from samples.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why can a sampled policy/reference log-ratio be negative even though its expectation is a KL divergence?

  2. What does subtracting an action-independent baseline change: the expected policy gradient, its variance, or both?

For a categorical policy:

\[\pi_\theta(a\mid s) = \operatorname{softmax}(z)_a, \qquad z\in\mathbb{R}^{A}\]

the expected reward is:

\[J(\theta) = \mathbb E_{a\sim\pi_\theta}[R(a)]\]

The score-function identity gives:

\[\nabla_\theta J = \mathbb E_{a\sim\pi_\theta} \left[ R(a)\nabla_\theta\log\pi_\theta(a) \right]\]

We minimize the sampled loss:

\[L_{\text{PG}} = -(R-b)\log\pi_\theta(a)\]

where:

\[A=R-b\]

is the advantage and \(b\) is a baseline that must not depend on the sampled action.

For categorical logits:

\[\nabla_z\log\pi(a) = \operatorname{onehot}(a)-\pi\]

Therefore the sampled loss gradient is:

\[\nabla_zL_{\text{PG}} = -(R-b) \left[ \operatorname{onehot}(a)-\pi \right]\]

The baseline does not change the expected gradient:

\[\mathbb E[b\nabla\log\pi(a)] = b\nabla\sum_a\pi(a) = 0\]

But a good baseline can substantially reduce variance. In actor–critic methods, the baseline is usually a learned value function and should be detached from the policy loss.

✏️ Derivation: REINFORCE, baselines, and the variance they remove

Step 1. \(\nabla J=\nabla\sum_a\pi_\theta(a)R(a)=\sum_a\pi_\theta(a)\nabla\log\pi_\theta(a)\,R(a)\), using \(\nabla\pi=\pi\nabla\log\pi\).

Step 2. So \(\nabla J=\mathbb E_{a\sim\pi}[R(a)\nabla\log\pi(a)]\), and one sample gives an unbiased estimate.

Step 3. Baselines are free: \(\mathbb E_\pi[b\nabla\log\pi]=b\sum_a\nabla\pi(a)=b\nabla1=0\) for any \(b\) independent of \(a\). So \((R-b)\nabla\log\pi\) has the same mean.

Step 4. Variance: \(\operatorname{Var}=\mathbb E[(R-b)^2\|\nabla\log\pi\|^2]-\|\nabla J\|^2\). Setting the derivative in \(b\) to 0 gives \(b^*=\frac{\mathbb E[R\|\nabla\log\pi\|^2]}{\mathbb E[\|\nabla\log\pi\|^2]}\), approximately \(\mathbb E[R]\).

Step 5. Softmax case: \(\nabla_z\log\pi(a)=\onehot(a)-\pi\). The loss to minimize is \(-(R-b)\log\pi(a)\), with \(R-b\) detached.

Step 6. Why the baseline can’t depend on \(a\): then step 3’s sum no longer factors, and the estimator becomes biased.

⚙️ Algorithm: REINFORCE with a running-mean baseline
Input: policy logits \(z_\theta\), baseline \(b\gets0\), rate \(\rho\)
for each batch do
sample \(a_i\sim\pi_\theta\); observe \(R_i\)
\(A_i\gets R_i-b\) ▷ detached
\(L\gets-\frac1n\sum_iA_i\log\pi_\theta(a_i)\); gradient step
\(b\gets\rho b+(1-\rho)\bar R\) ▷ update after computing \(A\)
end

Solution — open after attempting

probs = torch.softmax(logits, dim=-1)

expected_reward = (
    probs * reward_values
).sum()

exact_loss = -expected_reward

exact_gradient = torch.autograd.grad(
    exact_loss,
    logits,
)[0]

Monte Carlo estimator:

with torch.no_grad():
    actions = torch.multinomial(
        probs,
        num_samples=num_samples,
        replacement=True,
    )

    rewards = reward_values[actions]

    one_hot_actions = F.one_hot(
        actions,
        num_classes=A,
    ).float()

    score_gradients = (
        one_hot_actions - probs.detach()
    )

    baseline = expected_reward.detach()

    sample_gradients_no_baseline = (
        -rewards[:, None] * score_gradients
    )

    sample_gradients_with_baseline = (
        -(rewards - baseline)[:, None]
        * score_gradients
    )

    estimate_no_baseline = (
        sample_gradients_no_baseline.mean(dim=0)
    )

    estimate_with_baseline = (
        sample_gradients_with_baseline.mean(dim=0)
    )

Autograd estimator:

logits.grad = None

log_probs = F.log_softmax(logits, dim=-1)
selected_log_probs = log_probs[actions]

advantages = (
    rewards - expected_reward.detach()
).detach()

sampled_loss = -(
    advantages * selected_log_probs
).mean()

sampled_loss.backward()

An action has positive advantage when:

\[R(a)>\mathbb E[R]\]

For positive advantage:

\[L=-A\log\pi(a)\]

Gradient descent increases \(\log\pi(a)\), making that action more likely. Negative-advantage actions become less likely.

If expected_reward is not detached, the loss contains an additional path:

\[\theta\rightarrow b_\theta\rightarrow A\rightarrow L\]

That path is not part of the REINFORCE policy-gradient estimator. In actor–critic training, the critic receives its own value loss; the actor treats its predicted baseline as fixed.

Check answers:

  1. Sampling a categorical action is discrete and has no ordinary pathwise derivative. REINFORCE differentiates its log-probability instead.

  2. Because: \[\mathbb E[b\nabla\log\pi(a)] = b\nabla\sum_a\pi(a)=0\]

  3. Its advantage is zero, so it contributes zero policy gradient.

  4. An advantage baseline, learned critic, reward normalization, larger rollout batch, or generalized advantage estimation may help.

  5. Otherwise, the policy loss can optimize the reward or baseline computation itself through unintended paths instead of only changing action probabilities.

Retrieval answers:

  • A sampled log-ratio is one Monte Carlo term; only the correctly sampled expectation equals KL.

  • A good action-independent baseline preserves the expected gradient while reducing its variance.
