🚀 Starting point

At scale, training fails in a few recurring ways: attention logits explode, one head dumps all its attention on the first token, outputs grow without bound, and residual streams lose signal through depth. Each trick in this chapter targets one of these with a small piece of math.

✏️ Derivation: QK-norm, softcapping, z-loss and attention sinks

Step 1. QK-norm (Qwen3, Gemma 3/4, DeepSeek-V4): RMSNorm \(q\) and \(k\) per head before the dot product. A normalized vector has \(\|\hat x\|_2=\sqrt d\), so by Cauchy–Schwarz \(|q^\top k|\le d\,\max|\gamma_q|\max|\gamma_k|\): logits can’t grow just because the projection weights do.

Step 2. Logit softcapping (Gemma 2; Gemma 4 keeps a final cap of 30): \(z\mapsto c\tanh(z/c)\), bounded by \(\pm c\), with derivative \(1-\tanh^2(z/c)\approx1\) for \(|z|\ll c\). Gentle for normal logits, a hard ceiling for outliers.

Step 3. z-loss (PaLM): add \(\lambda(\LSE(z))^2\). Its gradient \(2\lambda\LSE(z)\,\operatorname{softmax}(z)\) pushes the log-normalizer toward 0, preventing slow drift of all logits upward.

Step 4. Attention sinks (gpt-oss, DeepSeek-V4): add one learned logit \(z'_h\) per head to the softmax denominator: \(a_{ij}=\frac{e^{z_{ij}}}{\sum_ke^{z_{ik}}+e^{z'_h}}\). Rows can now sum to less than 1, so a head with nothing useful to read can attend to “nothing” instead of piling onto token 0.

Softcapping (Gemma 4’s final cap \(c=30\)): almost the identity for normal logits, a hard ceiling for outliers.

✏️ Derivation: hyper-connections, and keeping them stable (mHC)

Step 1. Hyper-connections: widen the residual stream into \(n\) parallel copies, \(X\in\mathbb R^{n\times D}\). A layer reads a mix, writes back a mix, and the copies mix with each other: \(X_{l+1}=B_lX_l+C_l\,F_l(A_lX_l)\), with \(A_l\in\mathbb R^{1\times n}\), \(B_l\in\mathbb R^{n\times n}\), \(C_l\in\mathbb R^{n\times1}\).

Step 2. Problem: over \(L\) layers the stream is multiplied by \(B_L\cdots B_1\). If \(\|B_l\|>1\), signals explode exponentially in depth, and if \(<1\), they vanish.

Step 3. mHC (DeepSeek, used in V4 with \(n=4\)) constrains \(B_l\) to be doubly stochastic: entries \(\ge0\), every row and column sums to 1.

Step 4. Such a matrix is a convex combination of permutation matrices (Birkhoff), each with spectral norm 1, so \(\|B_l\|_2\le1\). Doubly stochastic matrices are closed under products, so \(\|B_L\cdots B_1\|_2\le1\) for any depth. Mixing can’t blow up.

Step 5. Getting one: Sinkhorn–Knopp. Start from \(M=e^{\tilde B}\) (positive), alternately divide by column sums and row sums. V4 runs 20 iterations (hc_sinkhorn_iters: 20); the check below reaches row and column sums of 1 and \(\|M\|_2=1.000\).

Step 6. Attention residuals (Kimi K3) take a different route along depth: each layer computes a softmax-weighted average over the outputs of earlier layers, \(h_l=\sum_{i<l}\alpha_{i\to l}v_i\), with weights from a learned per-layer query, done over 8 blocks of 12 layers to keep memory \(O(ND)\) instead of \(O(LD)\).

import torch

M = torch.exp(torch.randn(4, 4, dtype=torch.float64))   # positive start
for _ in range(20):                                      # Sinkhorn-Knopp
    M = M / M.sum(0, keepdim=True)                       # columns sum to 1
    M = M / M.sum(1, keepdim=True)                       # rows sum to 1
print(M.sum(1), M.sum(0), torch.linalg.matrix_norm(M, 2))  # ~1s, spectral norm ~1.0

Manifold-constrained hyper-connections in DeepSeek-V4: four parallel residual streams, mixed by a Sinkhorn-normalized matrix so the mixing can never amplify signals through depth.

✏️ Derivation: Muon: orthogonalize the momentum

Step 1. For a weight matrix with momentum \(M\) (SVD \(M=U\Sigma V^\top\)), Muon steps along \(O=UV^\top\): same singular directions, all singular values set to 1. It’s steepest descent under the spectral norm, so every direction in the update gets equal size.

Step 2. SVD is too slow, so apply an odd polynomial to the singular values: with \(X_0=M/\|M\|_F\) (singular values in \((0,1]\)), iterate \(X\gets aX+b(XX^\top)X+c(XX^\top)^2X\), which maps each \(\sigma\mapsto a\sigma+b\sigma^3+c\sigma^5\) without touching \(U,V\).

Step 3. Coefficients \((3.4445,-4.7750,2.0315)\) push small \(\sigma\) up quickly. DeepSeek-V4 then finishes with 2 steps of \((2,-1.5,0.5)\), which converge to exactly 1. The check below gives singular values in \([1.0000,1.0005]\).

Step 4. Update: \(W\gets W(1-\eta\lambda)-\eta\gamma\sqrt{\max(n,m)}\,O\). The \(\sqrt{\max(n,m)}\) factor matches AdamW’s typical update size, so learning rates transfer.

Step 5. QK-clip (Kimi K2’s MuonClip): if a head’s max logit \(S_{\max}\) exceeds \(\tau\), rescale \(W_Q\gets W_Q\sqrt{\tau/S_{\max}}\) and \(W_K\gets W_K\sqrt{\tau/S_{\max}}\). The logit \(q^\top k\) scales by exactly \(\tau/S_{\max}\). DeepSeek-V4 says it doesn’t need this because QK-norm already bounds logits.

import torch

G = torch.randn(64, 32, dtype=torch.float64)
X = G / G.norm()
for i in range(10):                                   # DeepSeek-V4's two-stage Newton-Schulz
    a, b, c = (3.4445, -4.7750, 2.0315) if i < 8 else (2, -1.5, 0.5)
    A = X @ X.T
    X = a * X + b * A @ X + c * A @ A @ X
print(torch.linalg.svdvals(X).aminmax())              # all singular values ~1
