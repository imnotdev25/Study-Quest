🚀 Starting point

Linear attention drops the softmax so attention becomes a running sum, and decoding needs a fixed-size state instead of a growing KV cache: \(O(1)\) memory per token. The price is a weaker memory. The delta rule and gating make that memory smarter, and hybrids keep a few full-attention layers for exact recall.

✏️ Derivation: linear attention is an RNN

Step 1. Causal attention with similarity \(\phi(q)^\top\phi(k)\) instead of \(e^{q^\top k}\): \(o_t=\sum_{s\le t}(q_t^\top k_s)v_s\) (taking \(\phi=\) identity, no normalizer).

Step 2. Rearrange: \(o_t=\Big(\sum_{s\le t}v_sk_s^\top\Big)q_t=S_t^\top q_t\) with \(S_t=\sum_{s\le t}k_sv_s^\top\in\mathbb R^{d_k\times d_v}\).

Step 3. Recurrence: \(S_t=S_{t-1}+k_tv_t^\top\). Each step costs \(O(d_kd_v)\), independent of \(t\). Training uses a chunked parallel form; both agree to \(10^{-15}\) (check below).

Step 4. Weakness: \(S\) only ever adds. Old associations are never removed, so after many tokens, retrieving \(S^\top q\) returns a blur.

✏️ Derivation: selective state spaces (Mamba)

Step 1. Continuous system \(h'(t)=Ah(t)+Bx(t)\), \(y=Ch\). Discretize with step \(\Delta\) (zero-order hold): \(\bar A=e^{\Delta A}\), \(\bar B\approx\Delta B\), so \(h_t=\bar Ah_{t-1}+\bar Bx_t\).

Step 2. With diagonal \(A<0\), \(\bar A\in(0,1)\) is a per-channel decay: a leaky memory.

Step 3. Selective: make \(\Delta,B,C\) functions of the current input \(x_t\). A large \(\Delta\) means “reset and write this token,” and a small \(\Delta\) means “ignore it and keep the state.”

Step 4. That’s the same structure as gated linear attention: \(S_t=\operatorname{diag}(\alpha_t)S_{t-1}+k_tv_t^\top\), with an input-dependent forget gate \(\alpha_t\).

✏️ Derivation: the delta rule is one step of online regression

Step 1. Treat the state as a linear memory that should return \(v_t\) when queried with key \(k_t\): minimize \(\mathcal L(S)=\frac12\|S^\top k_t-v_t\|^2\).

Step 2. Gradient: \(\nabla_S\mathcal L=k_t(S^\top k_t-v_t)^\top\).

Step 3. One gradient step with rate \(\beta_t\): \(S_t=S_{t-1}-\beta_tk_t(k_t^\top S_{t-1}-v_t^\top)=(I-\beta_tk_tk_t^\top)S_{t-1}+\beta_tk_tv_t^\top\). This is DeltaNet (verified below).

Step 4. Reading it: first erase what’s stored along \(k_t\) (the projection \(I-\beta kk^\top\)), then write \(v_t\). Overwriting, not piling up.

Step 5. Gated DeltaNet (used in Qwen3-Next and the Qwen3.8 “Next” line) adds a scalar decay: \(S_t=\alpha_t(I-\beta_tk_tk_t^\top)S_{t-1}+\beta_tk_tv_t^\top\).

Step 6. Kimi Delta Attention (Kimi Linear, then Kimi K3) makes the decay per channel: \(S_t=(I-\beta_tk_tk_t^\top)\operatorname{Diag}(\alpha_t)S_{t-1}+\beta_tk_tv_t^\top\), \(\alpha_t\in(0,1)^{d_k}\). In K3 the decay is bounded below: \(g=g_{\min}\sigma(e^{A_h}z)\), \(\alpha=e^g\in(e^{-5},1)\), so a 16-token chunk’s cumulative decay stays within BF16 range and the kernel can use tensor cores.

import torch

torch.manual_seed(0)
T, d = 10, 4
q, k, v = torch.randn(3, T, d, dtype=torch.float64)
parallel = torch.tril(q @ k.T) @ v                       # causal linear attention, all at once
S, rec = torch.zeros(d, d, dtype=torch.float64), []
for t in range(T):
    S = S + torch.outer(k[t], v[t])                       # S_t = S_{t-1} + k_t v_t^T
    rec.append(S.T @ q[t])
print((parallel - torch.stack(rec)).abs().max())          # ~1e-15

# Delta rule == one gradient step on 1/2 ||S^T k - v||^2
S0 = torch.randn(d, d, dtype=torch.float64, requires_grad=True)
kk = torch.nn.functional.normalize(torch.randn(d, dtype=torch.float64), dim=0)
vv, beta = torch.randn(d, dtype=torch.float64), 0.7
(0.5 * ((S0.T @ kk - vv) ** 2).sum()).backward()
delta = (torch.eye(d, dtype=torch.float64) - beta * torch.outer(kk, kk)) @ S0.detach() + beta * torch.outer(kk, vv)
print((delta - (S0.detach() - beta * S0.grad)).abs().max())  # ~1e-16

One step of Kimi Delta Attention. The state has a fixed size however long the sequence is. Gated DeltaNet uses a scalar \(\alpha_t\); plain DeltaNet has no decay box; plain linear attention has only the write box.

✏️ Derivation: hybrids: why keep some full attention

Step 1. A fixed state of size \(d_kd_v\) can store only about \(d_k\) independent key–value pairs exactly, while a KV cache stores all \(T\). Tasks like “find the phone number mentioned 200K tokens ago” need the cache.

Step 2. So modern long-context models interleave: MiniMax-01 uses 7 lightning (linear) layers per softmax layer; Qwen3-Next and Qwen3.8-Flash-Next use 3 Gated DeltaNet layers per gated full-attention layer; Kimi K3 uses 3 KDA layers per gated MLA layer (69 + 24).

Step 3. KV memory then grows only in the full-attention quarter (or eighth) of the layers, while the linear layers carry a constant-size state.

The 3:1 hybrid used by Qwen3-Next, Qwen3.8-Flash-Next (Gated DeltaNet) and Kimi K3 (KDA + gated MLA). MiniMax-01 uses 7:1.
