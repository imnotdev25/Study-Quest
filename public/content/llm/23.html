🚀 Starting point

Computation graph: each operation is a node, and each tensor is an edge. Two facts make backprop work. (1) Local derivatives: each node only needs to know its own derivative, e.g. \(\tanh'(h)=1-\tanh^2(h)\). (2) Branching: when a tensor feeds several nodes, its gradient is the sum over all paths, because \(L\) changes through each path at once.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Before reading further, recall from Session 1:

\[z=Xw+b\]

What are \(\partial L/\partial w\) and \(\partial L/\partial b\) if \(\delta=\partial L/\partial z\)?

Now consider a graph with a shared intermediate:

\[h=XW,\qquad a=\tanh(h)\]

Two branches consume \(a\):

\[L_{\text{main}}=\operatorname{mean}(av)\]

\[L_{\text{reg}}=\lambda\operatorname{mean}(a^2)\]

\[L=L_{\text{main}}+L_{\text{reg}}\]

Because \(a\) influences both branches, its total gradient is the sum:

\[\frac{\partial L}{\partial a} = \frac{\partial L_{\text{main}}}{\partial a} + \frac{\partial L_{\text{reg}}}{\partial a}\]

Then propagate backward:

\[\frac{\partial L}{\partial h} = \frac{\partial L}{\partial a} \odot(1-a^2)\]

\[\frac{\partial L}{\partial W} = X^\top\frac{\partial L}{\partial h}\]

Reverse-mode autodiff repeatedly computes vector–Jacobian products, without constructing full Jacobian matrices. This is why backpropagation is efficient when a large computation produces one scalar loss.

✏️ Derivation: a shared activation feeding two losses

Setup: \(h=XW\in\mathbb R^{B\times H}\), \(a=\tanh(h)\), \(L_{\text{main}}=\frac1B\sum_i(av)_i\), \(L_{\text{reg}}=\frac{\lambda}{BH}\sum_{ij}a_{ij}^2\).

Step 1. \(\tanh'\): \(\frac{d}{dh}\frac{e^h-e^{-h}}{e^h+e^{-h}}=\frac{(e^h+e^{-h})^2-(e^h-e^{-h})^2}{(e^h+e^{-h})^2}=1-\tanh^2h\).

Step 2. Main branch: \((av)_i=\sum_ja_{ij}v_j\), so \(\frac{\partial L_{\text{main}}}{\partial a_{ij}}=\frac{v_j}{B}\).

Step 3. Regularizer: \(\frac{\partial L_{\text{reg}}}{\partial a_{ij}}=\frac{2\lambda a_{ij}}{BH}\) (the mean is over all \(BH\) entries).

Step 4. Branching rule: \(\frac{\partial L}{\partial a}=\frac{\mathbf 1v^\top}{B}+\frac{2\lambda a}{BH}\).

Step 5. Elementwise node: \(\frac{\partial L}{\partial h}=\frac{\partial L}{\partial a}\odot(1-a^2)\).

Step 6. Linear node (Part 0 identity): \(\frac{\partial L}{\partial W}=X^\top\frac{\partial L}{\partial h}\).

Step 7. Why reverse mode: each step multiplied a gradient vector by a local derivative, and no \(BH\times BH\) Jacobian was ever built. That’s a vector–Jacobian product.

⚙️ Algorithm: reverse-mode automatic differentiation
Input: graph with nodes in topological order \(v_1,\dots,v_n=L\)
run the forward pass, saving what each node needs for its derivative
\(\bar v_n\gets1\); \(\bar v_k\gets0\) for \(k<n\) ▷ \(\bar v=\partial L/\partial v\)
for \(k=n\) down to \(1\) do
for each input \(u\) of node \(v_k\) do
\(\bar u\gets\bar u+\big(\tfrac{\partial v_k}{\partial u}\big)^\top\bar v_k\) ▷ VJP; \(+\) implements branching
end
end

2. PyTorch exercise — 10 minutes

Complete the manual backward pass.

import torch

torch.manual_seed(11)

B, D, H = 4, 3, 5
lam = 0.1

X = torch.randn(B, D, requires_grad=True)  # [B, D]
W = torch.randn(D, H, requires_grad=True)  # [D, H]
v = torch.randn(H)                         # [H]

# Forward graph
h = X @ W                                  # [B, H]
a = torch.tanh(h)                          # [B, H]

manual_dW = ...                            # TODO 6: [D, H]

3. Checks for understanding — 5 minutes

  1. Why are da_main and da_reg added instead of multiplied?

  2. What are the shapes of the conceptual Jacobians \(\partial a/\partial h\) and \(\partial h/\partial W\)? Why does PyTorch avoid materializing them?

  3. If tanh(h) is saturated near \(1\) or \(-1\), what happens to dh?

  4. Debugging: W.grad is finite, but its norm is almost zero. Name two plausible causes visible in this graph.

  5. Prediction: if main_loss changes from .mean() to .sum(), which gradient contribution changes, and by what factor?

Solution — open after attempting

d_scores = torch.ones_like(scores) / B

da_main = d_scores[:, None] * v[None, :]
da_reg = 2 * lam * a / a.numel()
da = da_main + da_reg

dh = da * (1 - a.square())
manual_dW = X.T @ dh
manual_dX = dh @ W.T

For the debugging extension, a.grad is initially None. By default, PyTorch stores gradients for leaf tensors such as X and W, but not intermediate non-leaf tensors such as a.

Use:

# Recompute the graph because the old graph was freed
h = X @ W
a = torch.tanh(h)
a.retain_grad()

scores = a @ v
loss = scores.mean() + lam * a.square().mean()

X.grad = None
W.grad = None
loss.backward()

print(torch.allclose(a.grad, da, atol=1e-6))

Check answers:

  1. Both branches independently influence the same value, so the multivariable chain rule sums their gradient contributions.

  2. The full Jacobians would be extremely large and mostly structured or sparse. Reverse-mode computes only the products needed to propagate the loss gradient.

  3. \(1-a^2\) approaches zero, producing vanishing gradients through the tanh.

  4. Likely causes include saturated tanh, small upstream values in v, cancellation between examples, or cancellation between the main and regularization branches.

  5. Only da_main changes. It becomes \(B\) times larger; the regularization gradient is unchanged.
