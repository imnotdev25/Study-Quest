🚀 Starting point

LLaMA (Touvron et al., 2023) fixed the template most open models still follow: pre-norm with RMSNorm, SwiGLU MLPs, RoPE positions (Session 24), no biases, and (from Llama 2 70B) grouped-query attention. Llama 3 (2024) kept it and scaled data to about 15T tokens with a 128K vocabulary.

One LLaMA block. Normalization sits inside each branch (pre-norm); the residual stream itself is never normalized.

✏️ Derivation: RMSNorm: LayerNorm without the mean

Step 1. \(\operatorname{RMSNorm}(x)=\gamma\odot\frac{x}{\operatorname{rms}(x)}\), with \(\operatorname{rms}(x)=\sqrt{\frac1D\sum_jx_j^2+\epsilon}\). No centering, no \(\beta\).

Step 2. Backward, with \(g=\partial L/\partial\hat x\) and \(\hat x=x/r\): \(\frac{\partial r}{\partial x_k}=\frac{x_k}{Dr}\), so \(\frac{\partial\hat x_j}{\partial x_k}=\frac{\delta_{jk}}{r}-\frac{x_jx_k}{Dr^3}\).

Step 3. VJP: \(\frac{\partial L}{\partial x}=\frac1r\big(g-\hat x\,\overline{g\odot\hat x}\big)\). Compare LayerNorm (Session 6): the \(-\overline g\) term is gone because there is no mean to remove.

Step 4. One reduction instead of two, and empirically just as stable.

✏️ Derivation: SwiGLU and the \(\tfrac23\) factor

Step 1. \(\operatorname{SwiGLU}(x)=W_2\big(\operatorname{SiLU}(xW_1)\odot xW_3\big)\), with \(\operatorname{SiLU}(z)=z\sigma(z)\). The second branch is a learned, input-dependent gate.

Step 2. Parameters: three \(D\times D_{\text{ff}}\) matrices \(=3DD_{\text{ff}}\), versus \(2D\cdot4D=8D^2\) for a GELU MLP.

Step 3. Match the budget: \(3DD_{\text{ff}}=8D^2\Rightarrow D_{\text{ff}}=\frac23\cdot4D\). For \(D=4096\): \(10{,}923\), rounded up to a multiple of 256: Llama 2 7B uses 11,008.

8 query heads sharing 8, 2 or 1 key/value heads. Only the orange squares are stored in the KV cache.

✏️ Derivation: grouped-query attention cuts the KV cache

Step 1. \(H\) query heads share \(n_{kv}<H\) key/value heads; each group of \(H/n_{kv}\) query heads reads the same \(K,V\). \(n_{kv}=H\) is MHA, \(n_{kv}=1\) is multi-query attention (MQA).

Step 2. KV cache per token per layer: \(2n_{kv}d_h\) numbers instead of \(2Hd_h\). A reduction of \(H/n_{kv}\).

Step 3. Llama 3 70B: 80 layers, 64 query heads, 8 KV heads, \(d_h=128\), BF16. Per token: \(2\cdot8\cdot128\cdot80\cdot2=327{,}680\) bytes \(=320\) KB, versus 2.5 MB with full MHA. An 8\(\times\) saving, so 8\(\times\) more concurrent context in the same memory.

Step 4. Attention FLOPs are unchanged (every query head still attends). GQA saves memory bandwidth, which is what limits decoding speed.
