🚀 Starting point

Backprop through a network is just Part 0’s identities applied layer by layer, from the loss backward: a linear layer passes \(GW^\top\) to its input and \(X^\top G\) to its weights, an elementwise layer multiplies by its derivative, and a bias sums over the batch.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. For softmax cross-entropy, what is \(\partial L/\partial Z\)?

  2. Why does each row of that logits gradient sum to zero?

Consider a two-layer classifier:

\[X\in\mathbb{R}^{B\times D}\]

\[Z_1=XW_1+b_1, \qquad W_1\in\mathbb{R}^{D\times H}\]

\[A_1=\operatorname{ReLU}(Z_1) \in\mathbb{R}^{B\times H}\]

\[Z_2=A_1W_2+b_2, \qquad W_2\in\mathbb{R}^{H\times C}\]

For mean cross-entropy:

\[\Delta_2 = \frac{\partial L}{\partial Z_2} = \frac{P-\operatorname{onehot}(y)}{B}\]

Backpropagate through the second linear layer:

\[\frac{\partial L}{\partial W_2} = A_1^\top\Delta_2 \in\mathbb{R}^{H\times C}\]

\[\frac{\partial L}{\partial b_2} = \sum_{i=1}^{B}\Delta_{2,i} \in\mathbb{R}^{C}\]

\[\frac{\partial L}{\partial A_1} = \Delta_2W_2^\top \in\mathbb{R}^{B\times H}\]

Then through ReLU:

\[\Delta_1 = \frac{\partial L}{\partial Z_1} = \frac{\partial L}{\partial A_1} \odot\mathbf1[Z_1>0]\]

Finally:

\[\frac{\partial L}{\partial W_1} = X^\top\Delta_1 \in\mathbb{R}^{D\times H}\]

\[\frac{\partial L}{\partial X} = \Delta_1W_1^\top \in\mathbb{R}^{B\times D}\]

The recurring pattern is:

upstream gradient → local derivative → parameter/input gradients
✏️ Derivation: a two-layer classifier, end to end

Step 1. Loss gradient at the output logits: \(\Delta_2=\frac{P-Y}{B}\) (Session 17).

Step 2. Layer 2, \(Z_2=A_1W_2+b_2\): \(\ \nabla W_2=A_1^\top\Delta_2\ (H\times C)\), \(\nabla b_2=\sum_i\Delta_{2,i}\), and the gradient passed down is \(\nabla A_1=\Delta_2W_2^\top\ (B\times H)\).

Step 3. ReLU, \(A_1=\max(0,Z_1)\): \(\Delta_1=\nabla A_1\odot\mathbb 1[Z_1>0]\). Units that were off pass no gradient.

Step 4. Layer 1, \(Z_1=XW_1+b_1\): \(\nabla W_1=X^\top\Delta_1\ (D\times H)\), \(\nabla b_1=\sum_i\Delta_{1,i}\).

Step 5. What to save from the forward pass: \(X\), \(Z_1\) (or its mask), \(A_1\), \(P\). Backward needs exactly these, which is why activations dominate training memory.

Step 6. Dead ReLUs: if a unit’s \(Z_1\le0\) for every example, its column of \(\Delta_1\) is 0, so its weights never change again.

⚙️ Algorithm: backprop through a two-layer MLP
Input: \(X,y\), \(W_1,b_1,W_2,b_2\)
forward: \(Z_1\gets XW_1+b_1\); \(A_1\gets\operatorname{ReLU}(Z_1)\); \(Z_2\gets A_1W_2+b_2\); \(P\gets\operatorname{softmax}(Z_2)\)
\(\Delta_2\gets(P-\onehot(y))/B\)
\(\nabla W_2\gets A_1^\top\Delta_2\); \(\nabla b_2\gets\mathbf 1^\top\Delta_2\)
\(\Delta_1\gets(\Delta_2W_2^\top)\odot\mathbb 1[Z_1>0]\)
\(\nabla W_1\gets X^\top\Delta_1\); \(\nabla b_1\gets\mathbf 1^\top\Delta_1\)

Solution — open after attempting

# Forward
Z1 = X @ W1 + b1
A1 = torch.relu(Z1)
logits = A1 @ W2 + b2

loss = F.cross_entropy(logits, targets)

# Manual cross-entropy backward
probs = torch.softmax(z2, dim=-1)

dZ2 = probs.clone()
dZ2[torch.arange(B), targets] -= 1
dZ2 /= B

# Second layer
manual_dW2 = a1.T @ dZ2
manual_db2 = dZ2.sum(dim=0)
dA1 = dZ2 @ w2.T

# ReLU
dZ1 = dA1 * (z1 > 0)

# First layer
manual_dW1 = x.T @ dZ1
manual_db1 = dZ1.sum(dim=0)
manual_dX = dZ1 @ w1.T

dA1 is the upstream gradient arriving from the second linear layer. dZ1 is the first gradient that incorporates the ReLU mask:

\[dZ_1=dA_1\odot\mathbf1[Z_1>0]\]

With a sufficiently negative first-layer bias, all ReLU outputs become zero:

\[A_1=0\]

Consequently:

  • W2.grad is zero because its input \(A_1\) is zero.

  • W1.grad and b1.grad are zero because ReLU blocks their gradients.

  • b2.grad can remain nonzero because logits still depend directly on \(b_2\).

Check answers:

  1. Each example contributes \(a_{1,i}^{\top}\Delta_{2,i}\); matrix multiplication sums these contributions across the batch.

  2. If \(W_2=0\), then \(dA_1=dZ_2W_2^\top=0\). Therefore W1, b1, and X receive zero gradients initially. W2 and b2 can still receive gradients.

  3. The hidden activations are probably all zero, detached, or otherwise not reaching the output projection.

  4. Every gradient becomes \(B\) times larger.

  5. Healthy gradients in later layers can dominate the global norm while an earlier layer has exactly zero gradients.

Retrieval answers:

\[\frac{\partial L}{\partial Z} = \frac{P-\operatorname{onehot}(y)}{B}\]

Each row sums to zero because both the probability vector and one-hot target sum to one.
