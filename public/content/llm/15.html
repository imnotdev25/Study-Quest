🚀 Starting point

Starting point. A 95% confidence interval is a procedure that, over repeated datasets, contains the true value 95% of the time. Any one interval either contains it or not. The only honest check of an interval formula is to simulate many datasets and count how often it covers.

Twenty intervals from twenty datasets. About one in twenty (red) misses.

✏️ Derivation: The z, t and Wilson intervals

Step 1. By the CLT, \(\frac{\bar X-\mu}{\sigma/\sqrt n}\approx N(0,1)\), so \(P(|\bar X-\mu|\le1.96\,\sigma/\sqrt n)\approx0.95\): the interval \(\bar X\pm1.96\,\sigma/\sqrt n\).

Step 2. With \(\sigma\) unknown, plugging in \(s\) adds extra randomness. For normal data \(\frac{\bar X-\mu}{s/\sqrt n}\) has a Student \(t_{n-1}\) distribution, with fatter tails: use \(t_{0.975,n-1}\) (2.78 for \(n=5\)) instead of 1.96. The z-version covers only 88% at \(n=5\).

Step 3. Proportions near 0 or 1: the Wald interval \(\hat p\pm1.96\sqrt{\hat p(1-\hat p)/n}\) collapses when \(\hat p\) is extreme (at \(\hat p=1\) its width is zero). The Wilson interval inverts the test instead, solving \(|\hat p-p|\le z\sqrt{p(1-p)/n}\) for \(p\): centre \(\frac{\hat p+z^2/2n}{1+z^2/n}\), half-width \(\frac{z\sqrt{\hat p(1-\hat p)/n+z^2/4n^2}}{1+z^2/n}\). At \(p=0.95,n=40\): Wald 87%, Wilson 95%.

Step 4. Bootstrap: resample the data with replacement many times, recompute the statistic each time, and take the 2.5% and 97.5% percentiles. It needs no formula, so it works for medians, pass@k and win rates (94% coverage for a median with \(n=60\)).

Step 5. Sample size: for half-width \(E\) on a proportion, \(n=z^2p(1-p)/E^2\le1.96^2/(4E^2)\). \(\pm2\) points needs 2,401 questions; \(\pm1\) point needs 9,604. Most benchmarks are too small to separate models one point apart.

"""Inference: confidence intervals and whether they really cover 95%."""
import math

import numpy as np

rng = np.random.default_rng(0)
T975 = {5: 2.776, 10: 2.262, 30: 2.045}                       # t quantiles for df = n - 1 (n = 5, 10, 30)

# 1. Mean of a normal, sigma unknown: z-interval with s undercovers for small n, t-interval is exact.
print("[ci] n    z-interval coverage   t-interval coverage   (target 0.95)")
for n in (5, 10, 30):
    x = rng.normal(0, 1, (100_000, n))
    m, s = x.mean(1), x.std(1, ddof=1)
    cz = np.mean(np.abs(m) <= 1.96 * s / math.sqrt(n))
    ct = np.mean(np.abs(m) <= T975[n] * s / math.sqrt(n))
    print(f"[ci] {n:2d}   {cz:.4f}                {ct:.4f}")

# 2. A proportion near 0 or 1 (eval accuracy 95% on 40 items): Wald undercovers, Wilson holds up.
p, n = 0.95, 40
k = rng.binomial(n, p, 200_000)
ph = k / n
wald = np.abs(ph - p) <= 1.96 * np.sqrt(ph * (1 - ph) / n)
z = 1.96
center = (ph + z**2 / (2 * n)) / (1 + z**2 / n)
half = z * np.sqrt(ph * (1 - ph) / n + z**2 / (4 * n**2)) / (1 + z**2 / n)
wilson = np.abs(center - p) <= half
print(f"[prop] p=0.95, n=40: Wald coverage {wald.mean():.4f}   Wilson coverage {wilson.mean():.4f}")

# 3. Bootstrap percentile interval for a median (no formula needed). Check coverage by repetition.
true_median = math.log(2)                                      # Exponential(1)
hits = 0
for _ in range(1000):
    x = rng.exponential(1, 60)
    boots = np.median(rng.choice(x, (2000, 60)), axis=1)
    lo, hi = np.percentile(boots, [2.5, 97.5])
    hits += lo <= true_median <= hi
print(f"[boot] percentile bootstrap CI for a median, n=60: coverage {hits / 1000:.3f}")

# 4. Sample size for a margin of error: n = z^2 p(1-p) / E^2.
for E in (0.05, 0.02, 0.01):
    print(f"[size] +-{E:.0%} at 95%, worst case p=0.5: n = {math.ceil(1.96**2 * 0.25 / E**2):,}")
