🚀 Starting point

Gradient-norm clipping limits the length of the update when gradients spike. Treat all parameters’ gradients as one long vector \(g\). If \(\|g\|_2>\tau\), rescale the whole vector to length \(\tau\). Its direction is unchanged.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why must mixed-precision gradients be unscaled before clipping?

  2. What error pattern should a finite-difference gradient check show as \(\epsilon\) decreases?

Treat all parameter gradients as one concatenated vector:

\[g= \begin{bmatrix} \operatorname{vec}(g_1)\\ \operatorname{vec}(g_2)\\ \vdots \end{bmatrix}\]

Its global \(L_2\) norm is:

\[\lVert g\rVert_2 = \sqrt{\sum_p\sum_i g_{p,i}^2}\]

Given threshold \(\tau\), global-norm clipping computes:

\[c= \min\left( 1,\frac{\tau}{\lVert g\rVert_2+\epsilon} \right)\]

\[g'_p=cg_p\]

Every parameter gradient receives the same coefficient. Therefore clipping preserves the direction of the complete gradient vector while reducing its magnitude.

For SGD:

\[\Delta\theta=-\eta g'\]

so:

\[\lVert\Delta\theta\rVert_2\leq\eta\tau\]

For Adam, clipping bounds the gradient entering the moment estimates, but does not directly bound the final adaptive parameter update.

Correct training order:

accumulate gradients
→ unscale AMP gradients
→ compute global norm
→ clip
→ optimizer step
→ clear gradients

Clipping every parameter independently is different: it changes the relative scale between layers and therefore changes the overall gradient direction.

✏️ Derivation: global clipping preserves direction, and per-tensor clipping doesn’t

Step 1. Global norm \(\|g\|=\sqrt{\sum_p\|g_p\|^2}\), and coefficient \(c=\min\big(1,\tau/(\|g\|+\epsilon)\big)\).

Step 2. Every tensor gets \(g'_p=cg_p\), so \(g'=cg\) is parallel to \(g\), and \(\|g'\|=\min(\|g\|,\tau)\).

Step 3. Example: \(g=(3,4)\), \(\|g\|=5\), \(\tau=1\): \(c=0.2\), \(g'=(0.6,0.8)\). Same direction, length 1.

Step 4. Per-tensor clipping: clip \((3)\) and \((4)\) separately to length 1, giving \((1,1)\), which points at \(45^\circ\) instead of \(53^\circ\). It changes the balance between layers.

Step 5. First-order effect: \(\Delta L\approx-\eta c\|g\|^2\le0\). Clipping only shortens the step, so it remains a descent direction.

Step 6. Clip once, after all accumulation and unscaling (Sessions 14, 16, 51).

⚙️ Algorithm: global gradient-norm clipping
Input: gradients \(g_1,\dots,g_P\) (after accumulation and unscaling), threshold \(\tau\)
\(n\gets\sqrt{\sum_p\|g_p\|_2^2}\) ▷ over all ranks if sharded
log \(n\) (the pre-clip norm)
\(c\gets\min(1,\tau/(n+10^{-6}))\); \(g_p\gets cg_p\) for every \(p\)

Solution — open after attempting

logits = model(X)

loss = 100.0 * F.cross_entropy(logits, targets)
loss.backward()

parameters = [
    p for p in model.parameters()
    if p.grad is not None

original_gradients = [
    p.grad.detach().clone()
    for p in parameters

squared_norms = [
    gradient.square().sum()
    for gradient in original_gradients

total_norm = torch.stack(squared_norms).sum().sqrt()

clip_coefficient = torch.clamp(
    max_norm / (total_norm + 1e-6),
    max=1.0,
)

manual_clipped = [
    gradient * clip_coefficient
    for gradient in original_gradients
]

Independent clipping:

independently_clipped = []

for gradient in original_gradients:
    local_norm = gradient.norm()

    local_coefficient = torch.clamp(
        max_norm / (local_norm + 1e-6),
        max=1.0,
    )

    independently_clipped.append(
        gradient * local_coefficient
    )

The cosine generally is not exactly one. Global clipping multiplies every gradient by one shared scalar. Independent clipping applies different scalars to different tensors, altering their relative contributions.

With error_if_nonfinite=True, PyTorch raises an error after detecting the non-finite norm. Continuing could feed nan into optimizer moments, after which future parameters and optimizer state may also become non-finite.

Check answers:

  1. The coefficient is one, so the gradients remain unchanged.

  2. Multiplication of every component by the same positive scalar changes magnitude but not direction.

  3. No. If clipping remains active, both the gradient and its norm scale by 100, causing the clipping coefficient to shrink by approximately \(1/100\).

  4. The values inspected before unscaling were still multiplied by the loss scale and were not the true gradients.

  5. The optimizer update should depend on the clipped sum of all microbatch gradients. Separately clipping microbatches changes both their relative weighting and final direction.

Retrieval answers:

  • AMP gradients must be unscaled because otherwise the clipping threshold is implicitly multiplied or divided by the loss scale.

  • Finite-difference error typically decreases, reaches a minimum, then increases as cancellation dominates.
