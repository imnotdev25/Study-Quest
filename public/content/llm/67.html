🚀 Starting point

Entropy \(H(p)=-\sum_ap_a\log p_a\) measures how spread out a distribution is: \(\log A\) for uniform over \(A\) actions, 0 for a certain one. Adding \(-c_HH\) to the loss (so minimizing the loss increases entropy) keeps the policy from becoming certain too early.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why must PPO critic targets use stored rollout values rather than current trainable values?

  2. When does clipped value loss produce a flat critic gradient?

For policy logits:

\[Z\in\mathbb{R}^{B\times T\times A}\]

the categorical probabilities and token-level entropy are:

\[P=\operatorname{softmax}(Z)\]

\[H_{bt} = -\sum_{a=1}^{A}P_{bta}\log P_{bta} \in\mathbb{R}^{B\times T}\]

Entropy is largest for a uniform policy:

\[H_{\max}=\log A\]

and zero for an exactly deterministic policy.

A simplified PPO loss is:

\[L_{\text{total}} = L_{\text{policy}} +c_VL_{\text{value}} -c_H\bar H\]

The negative sign is essential because optimizers minimize: minimizing \(-H\) encourages higher entropy.

When the policy and value head share a backbone, their gradients add:

\[\nabla_\theta L_{\text{total}} = \nabla_\theta L_{\text{policy}} +c_V\nabla_\theta L_{\text{value}} -c_H\nabla_\theta\bar H\]

An excessive entropy coefficient can oppose reward learning. Too little entropy pressure can cause premature policy collapse.

For language models, exact entropy requires summing across the full vocabulary:

\[H\in\mathbb{R}^{B\times T}, \qquad P,\log P\in\mathbb{R}^{B\times T\times V}\]

This can be expensive at large \(V\), and approximate entropy estimators should be treated as potentially biased metrics.

✏️ Derivation: the entropy gradient

Step 1. \(H=-\sum_ap_a\log p_a\), \(p=\operatorname{softmax}(z)\). Then \(\frac{\partial}{\partial p_a}(-p_a\log p_a)=-(\log p_a+1)\).

Step 2. Chain through softmax: \(\frac{\partial H}{\partial z_c}=-\sum_ap_a(\delta_{ac}-p_c)(\log p_a+1)\).

Step 3. Expand: \(=-\big[p_c(\log p_c+1)-p_c\sum_ap_a(\log p_a+1)\big]=-\big[p_c\log p_c+p_c-p_c(-H+1)\big]\).

Step 4. Simplify: \(\boxed{\frac{\partial H}{\partial z_c}=-p_c\big(\log p_c+H\big)}\).

Step 5. Reading it: for an action more likely than average in log terms (\(\log p_c>-H\)), the gradient is negative, so increasing \(H\) lowers that logit. Entropy pushes the most-confident actions down.

Step 6. Competition: the total gradient on \(z\) is \(\nabla L_\pi-c_H\nabla H\). When the policy gradient is small (advantages near 0), the entropy term dominates, and too large a \(c_H\) can stop the policy from ever committing.

⚙️ Algorithm: PPO loss with entropy bonus
Input: logits \(Z\), mask \(M\), coefficients \(c_V,c_H\)
\(\log P\gets\operatorname{log\_softmax}(Z)\); \(H_{bt}\gets-\sum_aP_{bta}\log P_{bta}\)
\(\bar H\gets\sum MH/\sum M\)
\(L\gets L_{\text{policy}}+c_VL_{\text{value}}-c_H\bar H\) ▷ minus sign: minimizing \(L\) raises entropy

def masked_mean_entropy(candidate_logits):
    candidate_logp = F.log_softmax(
        candidate_logits,
        dim=-1,
    )
    candidate_probs = candidate_logp.exp()

    entropy = -(
        candidate_probs * candidate_logp
    ).sum(dim=-1)

    return entropy[valid_mask].mean()

Solution — open after attempting

with torch.no_grad():
    old_log_probs = F.log_softmax(logits, dim=-1)

    old_selected_logp = old_log_probs.gather(
        dim=-1,
        index=actions.unsqueeze(-1),
    ).squeeze(-1)


log_probs = F.log_softmax(logits, dim=-1)
probs = log_probs.exp()

selected_logp = log_probs.gather(
    dim=-1,
    index=actions.unsqueeze(-1),
).squeeze(-1)

ratio = torch.exp(
    selected_logp - old_selected_logp
)

unclipped = ratio * advantages

clipped = (
    torch.clamp(
        ratio,
        1 - epsilon,
        1 + epsilon,
    )
    * advantages
)

policy_loss = -torch.minimum(
    unclipped,
    clipped,
)[valid_mask].mean()


token_entropy = -(
    probs * log_probs
).sum(dim=-1)

mean_entropy = token_entropy[valid_mask].mean()

entropy_loss = -entropy_coef * mean_entropy

total_loss = policy_loss + entropy_loss

At each position, adding the same constant to every logit leaves the categorical distribution—and therefore its entropy—unchanged. Consequently:

\[\sum_a \frac{\partial H}{\partial Z_a} =0\]

Gradient descent on:

\[L_H=-c_HH\]

moves the distribution toward greater entropy. Reversing the sign gives:

\[L_{\text{wrong}}=+c_HH\]

so minimization reduces entropy and sharpens the distribution.

At a uniform distribution, entropy is already maximal. Its gradient with respect to logits is therefore zero:

\[P_a=\frac1A \quad\Longrightarrow\quad \nabla_ZH=0\]

This does not mean entropy regularization is useless: once policy-gradient updates break uniformity, the entropy term supplies an opposing gradient.

Check answers:

  1. \(\log A\), achieved by assigning probability \(1/A\) to every action.

  2. Softmax is invariant to a common logit shift, so entropy has no gradient component in the all-ones direction.

  3. Zero, because uniform probability is the entropy maximum.

  4. The entropy coefficient may be too large relative to the policy-gradient scale.

  5. Prompt and padding positions are not sampled response decisions. Including them changes the weighting, consumes gradient budget, and can reward uncertainty on irrelevant tokens.

Retrieval answers:

  • Valid targets use: \[\hat R=A+V_{\text{old}}\] with rollout quantities detached.

  • Value clipping becomes flat when the prediction moves farther than \(\epsilon_V\) in a beneficial direction and the clipped-error branch is selected.
