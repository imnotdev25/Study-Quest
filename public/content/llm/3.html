🚀 Starting point

Starting point. A vector-valued map \(f:\mathbb R^n\to\mathbb R^m\) takes \(n\) numbers to \(m\) numbers. A layer of a network is one: \(x\mapsto\phi(Wx+b)\). Close to a point \(x_0\), every smooth map looks linear: \(f(x_0+\delta)\approx f(x_0)+J\delta\), where the Jacobian \(J_{ij}=\partial f_i/\partial x_j\) is an \(m\times n\) matrix. Row \(i\) is the gradient of output \(i\); column \(j\) says how all outputs move when input \(j\) moves. Real-life version: zoom far enough into a curved road map and the streets look straight. The Jacobian is that zoomed-in straight-line map.

✏️ Derivation: First- and second-order Taylor approximation

Step 1. One variable: \(g(t)=f(x_0+t\delta)\) for a fixed direction \(\delta\). Ordinary Taylor: \(g(1)=g(0)+g'(0)+\tfrac12g''(0)+O(\lVert\delta\rVert^3)\).

Step 2. Chain rule: \(g'(0)=\sum_j\frac{\partial f}{\partial x_j}\delta_j=\nabla f^\top\delta\), and \(g''(0)=\sum_{j,k}\frac{\partial^2f}{\partial x_j\partial x_k}\delta_j\delta_k=\delta^\top H\delta\), with \(H\) the Hessian.

Step 3. So for scalar \(f\): \(\boxed{f(x_0+\delta)=f(x_0)+\nabla f^\top\delta+\tfrac12\delta^\top H\delta+O(\lVert\delta\rVert^3)}\). For vector \(f\), apply step 2 to each output: the first-order term is \(J\delta\), and the error is \(O(\lVert\delta\rVert^2)\).

Step 4. Test it: shrinking \(\delta\) by 10 should shrink the first-order error by 100 and the second-order error by 1000. The output below shows exactly that.

The tangent line is good near the point; adding the curvature term keeps it good for longer.

Two Jacobians worth knowing

  • Polar coordinates \((r,\theta)\mapsto(r\cos\theta,r\sin\theta)\): \(J=\left(\begin{smallmatrix}\cos\theta&-r\sin\theta\\\sin\theta&r\cos\theta\end{smallmatrix}\right)\), \(\det J=r\). The determinant is how much the map stretches area, which is what change of variables in integrals uses.

  • Softmax: \(\partial p_i/\partial z_j=p_i(\delta_{ij}-p_j)\), i.e. \(J=\operatorname{diag}(p)-pp^\top\). It is also the Hessian of log-sum-exp. It is positive semi-definite with \(J\mathbf 1=0\): moving all logits together changes nothing, so LSE is convex but flat in that one direction.

Chain rule for maps. \(J_{g\circ f}(x)=J_g(f(x))\,J_f(x)\): Jacobians multiply. Backprop computes \(v^\top J_L\cdots J_1\) from the left, one vector–Jacobian product at a time, so no Jacobian is ever formed.

"""Math I: vector-valued maps, Jacobians and local (Taylor) approximation."""
import numpy as np

rng = np.random.default_rng(0)


def jac_num(f, x, h=1e-6):
    """Central-difference Jacobian: column j is (f(x + h e_j) - f(x - h e_j)) / 2h."""
    return np.stack([(f(x + h * e) - f(x - h * e)) / (2 * h) for e in np.eye(len(x))], axis=1)


# 1. Polar -> Cartesian, R^2 -> R^2. The Jacobian determinant r is the area-scaling factor.
polar = lambda u: np.array([u[0] * np.cos(u[1]), u[0] * np.sin(u[1])])
u = np.array([2.0, 0.7])
J = np.array([[np.cos(u[1]), -u[0] * np.sin(u[1])], [np.sin(u[1]), u[0] * np.cos(u[1])]])
print(f"[jac] polar map at r=2, theta=0.7: analytic == numeric {np.allclose(J, jac_num(polar, u))}, "
      f"det J = {np.linalg.det(J):.4f} (= r)")

# 2. A map R^2 -> R^3 and its linear approximation f(x0 + d) ~ f(x0) + J d. Error shrinks like |d|^2.
f = lambda x: np.array([np.sin(x[0]) * x[1], np.exp(x[0] - x[1]), x[0] ** 2 + x[1] ** 3])
x0 = np.array([0.3, -0.5])
J0 = jac_num(f, x0)
d = rng.normal(size=2); d /= np.linalg.norm(d)
print(f"[jac] f: R^2 -> R^3, Jacobian shape {J0.shape}")
for s in (1e-1, 1e-2, 1e-3):
    err = np.linalg.norm(f(x0 + s * d) - f(x0) - J0 @ (s * d))
    print(f"[taylor-1] |d| = {s:.0e}   error {err:.2e}   error / |d|^2 = {err / s**2:.3f}")

# 3. Second order for a scalar function: log-sum-exp. Gradient = softmax, Hessian = diag(p) - p p^T.
lse = lambda z: z.max() + np.log(np.exp(z - z.max()).sum())
softmax = lambda z: np.exp(z - lse(z))
z0 = rng.normal(size=4)
p = softmax(z0)
H = np.diag(p) - np.outer(p, p)
print(f"[hessian] LSE Hessian == diag(p) - pp^T: {np.allclose(H, jac_num(softmax, z0), atol=1e-8)}, "
      f"eigenvalues {np.round(np.linalg.eigvalsh(H), 4)}")
print(f"[hessian] H @ ones = {np.round(H @ np.ones(4), 12)}  (adding a constant to all logits changes nothing)")
d = rng.normal(size=4); d /= np.linalg.norm(d)
for s in (1e-1, 1e-2):
    e1 = abs(lse(z0 + s * d) - lse(z0) - p @ (s * d))
    e2 = abs(lse(z0 + s * d) - lse(z0) - p @ (s * d) - 0.5 * (s * d) @ H @ (s * d))
    print(f"[taylor-2] |d| = {s:.0e}   1st-order error {e1:.2e}   2nd-order error {e2:.2e}")

# 4. Chain rule for maps: J_{g o f}(x) = J_g(f(x)) J_f(x)   (2x3) @ (3x2) -> (2x2)
g = lambda y: np.array([y[0] * y[1], y[2] - y[0]])
print(f"[chain] J(g o f) == J_g J_f: {np.allclose(jac_num(lambda x: g(f(x)), x0), jac_num(g, f(x0)) @ J0, atol=1e-6)}")
