🚀 Starting point

LayerNorm rescales each example’s feature vector to mean 0 and variance 1, then applies a learned scale \(\gamma\) and shift \(\beta\): \(\operatorname{LN}(x)=\gamma\odot\hat x+\beta\) with \(\hat x=(x-\mu)/s\) and \(s=\sqrt{\sigma^2+\epsilon}\). A residual connection adds the input back: \(Y=X+F(X)\). The “+X” gives gradients a path that skips \(F\).

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. When a tensor feeds two downstream branches, how are their gradient contributions combined?

  2. What weight variance approximately preserves signal scale through a ReLU layer?

For \(X\in\mathbb{R}^{B\times D}\), LayerNorm normalizes each example across its \(D\) features:

\[\mu_i=\frac{1}{D}\sum_{j=1}^{D}X_{ij}\]

\[\sigma_i^2=\frac{1}{D}\sum_{j=1}^{D}(X_{ij}-\mu_i)^2\]

\[\hat X_{ij} = \frac{X_{ij}-\mu_i}{\sqrt{\sigma_i^2+\epsilon}}\]

Thus \(\mu,\sigma^2\in\mathbb{R}^{B\times1}\) and \(\hat X\in\mathbb{R}^{B\times D}\).

A pre-norm residual MLP block computes:

\[Y=X+F(\operatorname{LN}(X))\]

The backward pass contains two paths:

\[\frac{\partial L}{\partial X} = \underbrace{\frac{\partial L}{\partial Y}}_{\text{identity path}} + \underbrace{ \frac{\partial L}{\partial Y} \frac{\partial F(\operatorname{LN}(X))}{\partial X} }_{\text{learned branch}}\]

The identity path lets gradients bypass the nonlinear sublayer. This is a central reason residual networks—and later pre-norm Transformers—can train at substantial depth.

Research-engineering concern: \(\epsilon\) prevents division by zero when feature variance is tiny. Its value and computation precision matter in mixed-precision training.

✏️ Derivation: the LayerNorm backward formula

Let \(g=\partial L/\partial\hat x\) for one example (\(D\) features).

Step 1. \(\hat x_j=(x_j-\mu)/s\), and both \(\mu\) and \(s\) depend on every \(x_k\): \(\frac{\partial\mu}{\partial x_k}=\frac1D\).

Step 2. \(\sigma^2=\frac1D\sum_j(x_j-\mu)^2\Rightarrow\frac{\partial\sigma^2}{\partial x_k}=\frac2D(x_k-\mu)\) (the \(\mu\) terms cancel because \(\sum_j(x_j-\mu)=0\)). So \(\frac{\partial s}{\partial x_k}=\frac{1}{2s}\cdot\frac2D(x_k-\mu)=\frac{\hat x_k}{D}\).

Step 3. Quotient rule: \(\frac{\partial\hat x_j}{\partial x_k}=\frac{\delta_{jk}-\frac1D}{s}-\frac{x_j-\mu}{s^2}\cdot\frac{\hat x_k}{D}=\frac1s\Big(\delta_{jk}-\frac1D-\frac{\hat x_j\hat x_k}{D}\Big)\).

Step 4. VJP: \(\frac{\partial L}{\partial x_k}=\sum_jg_j\frac{\partial\hat x_j}{\partial x_k}=\boxed{\frac1s\Big(g_k-\overline{g}-\hat x_k\,\overline{g\odot\hat x}\Big)}\), where the bars mean averages over the \(D\) features.

Step 5. Reading it: LN removes the part of the gradient that would only shift the mean or change the scale, since those don’t affect \(\hat x\). Then divides by \(s\).

Step 6. Residual: \(Y=X+F(\operatorname{LN}(X))\Rightarrow\frac{\partial L}{\partial X}=\frac{\partial L}{\partial Y}+J_F^\top\frac{\partial L}{\partial Y}\). The first term is the identity path: even if \(J_F\) is tiny, the gradient reaches earlier layers undiminished.

⚙️ Algorithm: LayerNorm forward and backward (one row)
Input: \(x\in\mathbb R^D\), \(\gamma,\beta\), upstream \(\bar y=\partial L/\partial y\)
\(\mu\gets\overline{x}\); \(s\gets\sqrt{\overline{(x-\mu)^2}+\epsilon}\); \(\hat x\gets(x-\mu)/s\); \(y\gets\gamma\odot\hat x+\beta\)
\(\bar\gamma\gets\bar y\odot\hat x\); \(\bar\beta\gets\bar y\) ▷ summed over the batch
\(g\gets\bar y\odot\gamma\)
\(\bar x\gets\big(g-\overline g-\hat x\cdot\overline{g\odot\hat x}\big)/s\)

Solution — open after attempting

mean = X.mean(dim=-1, keepdim=True)
var = X.var(dim=-1, keepdim=True, unbiased=False)
X_norm = (X - mean) / torch.sqrt(var + eps)

hidden = F.gelu(X_norm @ W1 + b1)
branch = hidden @ W2 + b2

Y = X + branch
loss = Y.square().mean()

upstream = 2 * Y / Y.numel()

branch_dx = torch.autograd.grad(
    outputs=branch,
    inputs=X,
    grad_outputs=upstream,
    retain_graph=True,
)[0]

manual_dx = upstream + branch_dx
autograd_dx = torch.autograd.grad(loss, X)[0]

With:

Y_bug = X.detach() + branch

the skip-path gradient disappears because detach() treats that copy of \(X\) as a constant. Gradients can reach \(X\) only through the MLP branch.

For constant input, the variance is zero. With \(\epsilon>0\), the normalized result is finite zeros. Without \(\epsilon\), the expression becomes \(0/0\), producing nan.

Check answers:

  1. LayerNorm normalizes across the final feature dimension \(D\), independently for each batch item and token.

  2. Since \(Y=X+\text{branch}\), the local Jacobian of the skip path is the identity matrix.

  3. The branch no longer depends on \(X\), so branch_dx is zero; the identity-path gradient remains.

  4. Examples include detach(), conversion through NumPy, an accidental no_grad() region, replacing addition with only the branch output, or copying through a non-differentiable operation.

  5. LayerNorm needs the population variance of the current feature vector, not an unbiased estimate of variance from sampled observations.

Retrieval answers:

  • Gradients from downstream branches are added.

  • For ReLU, Kaiming initialization uses approximately:

\[\operatorname{Var}(W)=\frac{2}{\text{fan-in}}\]
