🚀 Starting point

Attention lets each token build its output as a weighted average of other tokens’ values. The weights come from comparing its query with their keys: a big dot product \(q^\top k\) means “relevant.” Softmax turns the scores into weights that are positive and sum to 1. A causal mask forbids looking at future tokens by setting their scores to \(-\infty\), since \(e^{-\infty}=0\).

Total: 20 minutes

Quick retrieval:

Given token representations:

\[X\in\mathbb{R}^{B\times T\times D}\]

attention creates queries, keys, and values:

\[Q=XW_Q\in\mathbb{R}^{B\times T\times d_k}\]

\[K=XW_K\in\mathbb{R}^{B\times T\times d_k}, \qquad V=XW_V\in\mathbb{R}^{B\times T\times d_v}\]

The attention scores are:

\[S=\frac{QK^\top}{\sqrt{d_k}} \in\mathbb{R}^{B\times T\times T}\]

Each row answers: “For this query token, how much should I read from every key token?”

\[A=\operatorname{softmax}(S,\text{dim}=-1)\]

\[O=AV\in\mathbb{R}^{B\times T\times d_v}\]

The factor \(1/\sqrt{d_k}\) keeps score magnitudes controlled. Without it, dot-product variance grows with \(d_k\), pushing softmax toward saturation and producing poor gradients.

For causal attention:

\[S_{ij}=-\infty\quad\text{when }j>i\]

so token \(i\) cannot access future tokens. Materializing \(S\) or \(A\) requires \(O(BT^2)\) memory per head—one motivation for fused attention kernels.

✏️ Derivation: why divide by \(\sqrt{d_k}\), and why the mask works

Step 1. Assume query and key entries are independent with mean 0 and variance 1. A score \(s=q^\top k=\sum_{i=1}^{d_k}q_ik_i\).

Step 2. Each term has mean 0 and variance \(\mathbb E[q_i^2]\mathbb E[k_i^2]=1\). Independent terms add variances: \(\operatorname{Var}(s)=d_k\). For \(d_k=64\), scores have std 8.

Step 3. Softmax of scores with std 8 is nearly one-hot: one weight \(\approx1\), others \(\approx0\). In that regime the softmax Jacobian \(\operatorname{diag}(a)-aa^\top\approx0\), so gradients vanish.

Step 4. Divide by \(\sqrt{d_k}\): \(\operatorname{Var}(s/\sqrt{d_k})=1\), whatever the head size.

Step 5. Shift invariance: \(\operatorname{softmax}(s+c)=\operatorname{softmax}(s)\) for any constant \(c\), because \(e^c\) cancels. So only score differences matter, and subtracting the row max is safe.

Step 6. Mask: with \(S_{ij}=-\infty\) for \(j>i\), \(A_{ij}=e^{-\infty}/Z=0\), so future values contribute nothing to \(O_i=\sum_jA_{ij}V_j\). In practice use a large negative finite number, so a fully masked row doesn’t produce \(0/0\).

⚙️ Algorithm: causal scaled dot-product attention
Input: \(X\in\mathbb R^{B\times T\times D}\), \(W_Q,W_K,W_V\)
\(Q\gets XW_Q\); \(K\gets XW_K\); \(V\gets XW_V\)
\(S\gets QK^\top/\sqrt{d_k}\) ▷ \(B\times T\times T\)
\(S_{ij}\gets-\infty\) for \(j>i\)
\(A\gets\operatorname{softmax}(S-\max_jS,\ \text{dim}=-1)\)
\(O\gets AV\)

3. Checks for understanding — 5 minutes

  1. Why does the score tensor have shape [B, T, T]?

  2. If \(d_k\) increases from 64 to 256, how does the scaling denominator change?

  3. Prediction: what happens to softmax probabilities and gradients when unscaled attention logits become extremely large?

  4. Debugging: training loss is suspiciously low, but validation generation fails. How could an incorrect causal mask cause this?

  5. If sequence length doubles, by what factor does the explicit attention-score matrix grow?

Solution — open after attempting

def causal_attention(X, mask_value=float("-inf")):
    Q = X @ W_Q
    K = X @ W_K
    V = X @ W_V

    scores = Q @ K.transpose(-2, -1)
    scores = scores / math.sqrt(d_k)

    causal_mask = torch.tril(
        torch.ones(T, T, dtype=torch.bool)
    )

    scores = scores.masked_fill(~causal_mask, mask_value)
    weights = torch.softmax(scores, dim=-1)
    output = weights @ V

    return output, weights, Q, K, V

The first query may attend only to the first key, so its attention row is:

\[[1,0,0,0]\]

Changing the final input token must not affect output positions 0, 1, or 2. Position 3 may change because it is allowed to attend to itself.

Replacing forbidden scores with zero is not sufficient because:

\[e^0=1\]

Those positions still receive nonzero softmax probability. Using \(-\infty\) makes their exponentiated contribution zero.

Check answers:

  1. Every one of the \(T\) queries is compared with every one of the \(T\) keys.

  2. The denominator changes from \(\sqrt{64}=8\) to \(\sqrt{256}=16\).

  3. Softmax becomes nearly one-hot. Most probabilities and corresponding gradients approach zero.

  4. During training, tokens could read the correct future targets, creating information leakage and unrealistically low loss.

  5. The matrix grows by \(2^2=4\), because explicit attention memory is quadratic in sequence length.

Retrieval answers:

  • The input receives the direct identity-path gradient plus the gradient through LayerNorm and the learned branch.

  • LayerNorm normalizes across the final feature dimension \(D\), independently for each token.
