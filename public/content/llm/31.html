🚀 Starting point

A decoder block has two residual updates. Attention mixes information across tokens, and the MLP processes each token independently: \(U=X+\operatorname{MHA}(\operatorname{LN}_1X)\), \(Y=U+\operatorname{MLP}(\operatorname{LN}_2U)\). “Pre-norm” means LN sits inside the branch, so the residual stream \(X\to U\to Y\) is never normalized directly.

Total: 20 minutes

A pre-norm decoder block combines causal attention and a position-wise MLP:

\[U=X+\operatorname{MHA}(\operatorname{LN}_1(X))\]

\[Y=U+\operatorname{MLP}(\operatorname{LN}_2(U))\]

The residual-stream shape remains constant:

\[X,U,Y\in\mathbb{R}^{B\times T\times D}\]

The MLP acts independently on every token:

\[[B,T,D] \rightarrow[B,T,D_{\mathrm{ff}}] \rightarrow[B,T,D]\]

Usually:

\[D_{\mathrm{ff}}\approx4D\]

Ignoring biases, attention has approximately \(4D^2\) parameters:

\[W_Q,W_K,W_V,W_O\]

The MLP has:

\[2DD_{\mathrm{ff}}=8D^2\]

Therefore, a standard block contains approximately:

\[12D^2\]

Attention mixes information across tokens. The MLP mixes features within each token.

✏️ Derivation: parameters and FLOPs of one block

Step 1. Attention: \(W_Q,W_K,W_V,W_O\in\mathbb R^{D\times D}\), giving \(4D^2\).

Step 2. MLP: \(W_1\in\mathbb R^{D\times D_{\text{ff}}}\), \(W_2\in\mathbb R^{D_{\text{ff}}\times D}\), giving \(2DD_{\text{ff}}=8D^2\) for \(D_{\text{ff}}=4D\).

Step 3. Total \(\approx12D^2\) per block (LN and biases are \(O(D)\)). Example: \(D=4096\) gives \(\approx201\)M parameters per block.

Step 4. A matrix multiply \((1\times D)(D\times D')\) costs \(DD'\) multiply-adds \(=2DD'\) FLOPs. So the forward pass costs \(\approx2\times12D^2=24D^2\) FLOPs per token for the weights, plus attention’s \(\approx4TD\) per token for \(QK^\top\) and \(AV\).

Step 5. Training \(\approx3\times\) forward (backward costs about twice the forward), giving the standard estimate of \(\approx6\times\) parameters FLOPs per token.

Step 6. Residual gradient: \(\frac{\partial L}{\partial X}=\frac{\partial L}{\partial U}\big(I+J_{\text{attn}}\big)\) and \(\frac{\partial L}{\partial U}=\frac{\partial L}{\partial Y}\big(I+J_{\text{mlp}}\big)\): the identity terms carry gradient straight down the stack.

⚙️ Algorithm: pre-norm decoder block
Input: residual stream \(X\in\mathbb R^{B\times T\times D}\)
\(U\gets X+\operatorname{MHA}_{\text{causal}}(\operatorname{LN}_1(X))\)
\(Y\gets U+W_2\,\phi\big(W_1\operatorname{LN}_2(U)\big)\) ▷ \(\phi\) = GELU or SwiGLU, applied per token
return \(Y\) ▷ same shape as \(X\); stack \(N\) blocks, then a final LN

class DecoderBlock(nn.Module):
    def __init__(self, d_model=16, n_heads=4, expansion=4):
        super().__init__()

        assert d_model % n_heads == 0

        self.d_model = d_model
        self.n_heads = n_heads
        self.d_head = d_model // n_heads

        self.ln1 = nn.LayerNorm(d_model)
        self.qkv = nn.Linear(d_model, 3 * d_model)
        self.out_proj = nn.Linear(d_model, d_model)

        self.ln2 = nn.LayerNorm(d_model)
        self.fc1 = nn.Linear(d_model, expansion * d_model)
        self.fc2 = nn.Linear(expansion * d_model, d_model)

    def attention(self, x):
        B, T, D = x.shape

        qkv = self.qkv(x)
        q, k, v = qkv.chunk(3, dim=-1)

        def split_heads(t):
            t = t.view(B, T, self.n_heads, self.d_head)
            return t.transpose(1, 2)

        q = split_heads(q)
        k = split_heads(k)
        v = split_heads(v)

        context = F.scaled_dot_product_attention(
            q,
            k,
            v,
            dropout_p=0.0,
            is_causal=True,
        )

        merged = (
            context.transpose(1, 2)
            .contiguous()
            .view(B, T, D)
        )

        return self.out_proj(merged)

    def forward(self, x):
        x = x + self.attention(self.ln1(x))

        hidden = F.gelu(self.fc1(self.ln2(x)))
        x = x + self.fc2(hidden)

        return x

Changing only the final input token must leave output positions 0 through T-2 unchanged. Only the final output may change.

Removing the attention residual connection eliminates:

  • the identity information path;

  • the direct identity-gradient path;

  • the ability for attention to behave as a refinement of the existing residual stream.

Check answers:

  1. Linear layers operate on the last dimension and treat [B,T] as leading batch dimensions.

  2. Attention has roughly \(4D^2\) parameters; the MLP has \(8D^2\). The MLP has about twice as many.

  3. Only the final output may change.

  4. Test causal invariance: changing future inputs must not affect earlier outputs.

  5. Residual paths can keep the total gradient nonzero even when a learned branch is detached, unused, or saturated. Inspect per-module gradients.

Retrieval answers:

  • The transpose makes token positions the attention matrix dimension inside each head.

  • Continuation position IDs should begin at the cached sequence length, adjusted for padding or packing.
