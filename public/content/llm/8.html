🚀 Starting point

Starting point. A continuous random variable has a density \(f\ge0\) with \(\int f=1\), and \(P(a<X\le b)=\int_a^bf(x)\,dx\). The CDF is \(F(x)=P(X\le x)\), so \(f=F'\). A density is not a probability: \(f(x)\) can exceed 1, and \(P(X=x)=0\) for every single point.

Example: the exponential. \(f(x)=\lambda e^{-\lambda x}\) for \(x\ge0\), \(F(x)=1-e^{-\lambda x}\), mean \(1/\lambda\). It is memoryless: \(P(X>s+t\mid X>s)=\frac{e^{-\lambda(s+t)}}{e^{-\lambda s}}=e^{-\lambda t}=P(X>t)\). Having waited does not shorten the remaining wait.

✏️ Derivation: Transforming a random variable

Step 1. Let \(Y=g(X)\) with \(g\) increasing. Then \(F_Y(y)=P(g(X)\le y)=P(X\le g^{-1}(y))=F_X(g^{-1}(y))\).

Step 2. Differentiate: \(\boxed{f_Y(y)=f_X(g^{-1}(y))\,\Big|\tfrac{d}{dy}g^{-1}(y)\Big|}\) (the absolute value covers decreasing \(g\)). In several variables the derivative becomes \(|\det J_{g^{-1}}|\), the area-scaling factor from the integration chapter.

Step 3. Example: \(X\sim U(0,1)\), \(Y=X^2\), \(g^{-1}(y)=\sqrt y\): \(f_Y(y)=\frac1{2\sqrt y}\) on \((0,1)\). Mass piles up near 0.

Step 4. Inverse-CDF sampling runs this backwards: if \(U\sim U(0,1)\), \(X=F^{-1}(U)\) has CDF \(F\), because \(P(F^{-1}(U)\le x)=P(U\le F(x))=F(x)\). For the exponential, \(X=-\ln(1-U)/\lambda\).

Step 5. Box–Muller: two uniforms, \(R=\sqrt{-2\ln U_1}\), \(\Theta=2\pi U_2\), give two independent \(N(0,1)\) as \((R\cos\Theta,R\sin\Theta)\). It is the polar Gaussian integral read as a sampler.

Two transforms used in deep learning

Gumbel-max. If \(G_i\) are independent Gumbel(0,1) (\(G=-\log(-\log U)\)), then \(\arg\max_i(z_i+G_i)\) is distributed exactly as \(\operatorname{softmax}(z)\). Replacing argmax by a softmax with a temperature gives the Gumbel-softmax relaxation.

Reparameterisation vs score function. To get \(\nabla_\mu\mathbb E_{x\sim N(\mu,1)}[f(x)]\) you can write \(x=\mu+\epsilon\) and differentiate through \(f\) (pathwise, used by VAEs and SAC), or use \(\mathbb E[f(x)\nabla_\mu\log p(x)]\) (score function, REINFORCE, which needs no derivative of \(f\), so it works for rewards from a judge or a unit test). Both are unbiased; the score-function estimator has much higher variance (3.6\(\times\) the standard deviation in the output), which is why policy gradients need baselines.

"""Probability: continuous random variables and transformations (inverse CDF, Box-Muller,
change of variables, Gumbel-max, and the reparameterisation vs score-function gradient)."""
import numpy as np

rng = np.random.default_rng(0)
N = 1_000_000

# 1. Exponential(rate 2): CDF 1 - e^{-2x}; memoryless P(X > s + t | X > s) = P(X > t).
x = rng.exponential(1 / 2, N)
print(f"[exp] P(X <= 0.5) sim {np.mean(x <= 0.5):.4f}  CDF {1 - np.exp(-1):.4f}")
print(f"[exp] memoryless: P(X > 1.3 | X > 1) = {np.mean(x[x > 1] > 1.3):.4f}  P(X > 0.3) = {np.mean(x > 0.3):.4f}")

# 2. Inverse-CDF sampling: if U ~ U(0,1) then F^{-1}(U) ~ F.  Exponential: -ln(1-U)/rate.
u = rng.random(N)
xi = -np.log(1 - u) / 2
print(f"[inverse-cdf] mean {xi.mean():.4f} (0.5)  var {xi.var():.4f} (0.25)")

# 3. Change of variables: Y = X^2 with X ~ U(0,1) has density f_Y(y) = 1 / (2 sqrt y).
y = rng.random(N) ** 2
edges = np.array([0.01, 0.1, 0.4, 0.9])
for lo, hi in zip(edges[:-1], edges[1:]):
    print(f"[transform] P({lo} < Y < {hi}): sim {np.mean((y > lo) & (y < hi)):.4f}  "
          f"integral of 1/(2 sqrt y) = sqrt(hi) - sqrt(lo) = {np.sqrt(hi) - np.sqrt(lo):.4f}")

# 4. Box-Muller: two uniforms -> two independent N(0,1), via the polar Jacobian.
u1, u2 = rng.random(N), rng.random(N)
r = np.sqrt(-2 * np.log(u1))
z1, z2 = r * np.cos(2 * np.pi * u2), r * np.sin(2 * np.pi * u2)
print(f"[box-muller] mean {z1.mean():+.4f}  var {z1.var():.4f}  corr(z1, z2) {np.corrcoef(z1, z2)[0, 1]:+.4f}"
      f"  P(|z|<1.96) {np.mean(np.abs(z1) < 1.96):.4f}")

# 5. Gumbel-max: argmax(logits + Gumbel noise) is an exact sample from softmax(logits).
logits = np.array([2.0, 1.0, 0.0, -1.0])
g = -np.log(-np.log(rng.random((N, 4))))
counts = np.bincount((logits + g).argmax(1), minlength=4) / N
print(f"[gumbel] frequencies {np.round(counts, 4)}  softmax {np.round(np.exp(logits) / np.exp(logits).sum(), 4)}")

# 6. Gradient of E_{x ~ N(mu, 1)}[x^2] = 2 mu, two ways (mu = 1.5 -> 3).
mu, n = 1.5, 1000
eps = rng.normal(size=(2000, n))
pathwise = (2 * (mu + eps)).mean(1)                    # reparameterise x = mu + eps, differentiate x^2
score = ((mu + eps) ** 2 * eps).mean(1)                # REINFORCE: f(x) d/dmu log p(x) = x^2 (x - mu)
print(f"[grad] pathwise estimate {pathwise.mean():.3f} +- {pathwise.std():.3f}   "
      f"score-function {score.mean():.3f} +- {score.std():.3f}   (true 3.000)")
