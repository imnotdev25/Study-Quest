🚀 Starting point

Shapes used throughout. \(B\) batch size, \(T\) sequence length, \(D\) model width, \(V\) vocabulary size, \(C\) number of classes, \(H\) heads, \(d_h=D/H\) head width. A matrix \(X\in\mathbb R^{B\times D}\) has one row per example.

A model is a function \(f_\theta\) with parameters \(\theta\). A loss is a single number \(L(\theta)\ge 0\) that is small when the model is good. Training means finding \(\theta\) that makes \(L\) small, using its gradient \(\nabla_\theta L\).

Derivatives of a scalar

For a scalar function \(L(\theta)\) of a vector \(\theta\in\mathbb R^P\), the gradient collects every partial derivative: \[\nabla_\theta L=\Big(\tfrac{\partial L}{\partial\theta_1},\dots,\tfrac{\partial L}{\partial\theta_P}\Big),\qquad L(\theta+\Delta)\approx L(\theta)+\nabla_\theta L^\top\Delta .\] The second form is the first-order Taylor expansion. It’s the reason gradient descent works: choosing \(\Delta=-\eta\nabla_\theta L\) gives \(L(\theta+\Delta)\approx L(\theta)-\eta\|\nabla_\theta L\|^2\), which is smaller than \(L(\theta)\) for a small enough \(\eta>0\).

The chain rule and why backprop goes backward

If \(L=\ell(z)\) and \(z=g(\theta)\) with \(z\in\mathbb R^m\), the Jacobian \(J=\partial z/\partial\theta\in\mathbb R^{m\times P}\) gives \[\nabla_\theta L=J^\top\nabla_zL .\] Backprop never builds \(J\). It computes the vector–Jacobian product \(J^\top v\) directly, starting from \(v=\nabla_zL\) at the loss and moving toward the inputs. Since the loss is one number, going backward costs about the same as one forward pass.

Branching rule: if a variable feeds several downstream paths, its gradient is the sum of the gradients along each path.

Four matrix identities used everywhere

For \(Z=XW\) with \(X\in\mathbb R^{B\times D}\), \(W\in\mathbb R^{D\times C}\), and upstream gradient \(G=\partial L/\partial Z\in\mathbb R^{B\times C}\): \[\frac{\partial L}{\partial W}=X^\top G\ \ (D\times C),\qquad \frac{\partial L}{\partial X}=GW^\top\ \ (B\times D).\] For a bias broadcast over rows, \(Z=XW+\mathbf 1b^\top\): \(\ \partial L/\partial b=\sum_iG_{i,:}\). For an elementwise function \(A=\phi(Z)\): \(\ \partial L/\partial Z=\partial L/\partial A\odot\phi'(Z)\).

✏️ Derivation: \(\partial L/\partial W=X^\top G\)

Step 1. One entry of \(Z\): \(Z_{ic}=\sum_dX_{id}W_{dc}\).

Step 2. \(W_{dc}\) appears in \(Z_{ic}\) for every row \(i\), and nowhere else. So \(\frac{\partial Z_{ic}}{\partial W_{dc}}=X_{id}\).

Step 3. Chain rule, summing over every \(Z_{ic}\) that \(W_{dc}\) touches: \(\frac{\partial L}{\partial W_{dc}}=\sum_iG_{ic}X_{id}\).

Step 4. That sum is the \((d,c)\) entry of \(X^\top G\). Shape check: \((D\times B)(B\times C)=D\times C\), the same shape as \(W\). Matching shapes is the fastest way to catch a transposed gradient.
