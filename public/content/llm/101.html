🚀 Starting point

Why decode is slow. A decode step reads all the weights to produce one token per sequence, and the GPU’s compute sits idle (the roofline). Verifying \(k\) proposed tokens in one pass costs about the same as generating one, because it’s the same weight read. Speculative decoding drafts several tokens cheaply, verifies them in one target pass, and keeps the longest correct prefix. With the right acceptance rule, the output distribution is exactly the target model’s.

✏️ Derivation: Speculative sampling is exact (Leviathan et al.; Chen et al., 2023)

Step 1. Draft \(x\sim q\). Accept with probability \(\min(1,p(x)/q(x))\). On rejection, sample from \(r(x)=\frac{(p(x)-q(x))_+}{\sum_y(p(y)-q(y))_+}\).

Step 2. Probability of outputting \(x\) by acceptance: \(q(x)\min(1,\tfrac{p(x)}{q(x)})=\min(p(x),q(x))\).

Step 3. Total acceptance probability: \(\beta=\sum_x\min(p,q)=1-\mathrm{TV}(p,q)\). The rejection mass is \(1-\beta=\sum_x(p-q)_+\).

Step 4. Probability of outputting \(x\) by rejection: \((1-\beta)\,r(x)=(p(x)-q(x))_+\).

Step 5. Sum: \(\min(p,q)+(p-q)_+=p(x)\). \(\boxed{\text{The output is distributed exactly as }p.}\) For greedy decoding this reduces to: accept a draft token iff it equals the target’s argmax.

✏️ Derivation: Expected speedup

Step 1. With per-token acceptance \(\alpha\) (assumed independent) and \(k\) drafts, token \(i\) is accepted only if all before it were: \(\Pr=\alpha^i\).

Step 2. Tokens per target pass, counting the one the target always adds (the correction or a bonus token): \(\mathbb E[N]=\sum_{i=0}^k\alpha^i=\frac{1-\alpha^{k+1}}{1-\alpha}\).

Step 3. If one draft step costs \(c\) of a target step, speedup \(=\frac{1-\alpha^{k+1}}{(1-\alpha)(1+ck)}\). It has an optimum in \(k\): long drafts waste work once \(\alpha^k\) is small. At \(\alpha=0.9\) and \(c=0.05\), \(k=13\) gives 4.7\(\times\).

⚙️ Algorithm: Speculative decoding loop (any drafter)
Input: target \(p\), drafter, max draft length \(k\)
loop
draft \(\tilde x_1..\tilde x_k\) with draft probabilities \(q_1..q_k\) ▷ a model, heads, n-grams, …
one target pass on \(\text{context}+\tilde x_{1..k}\) gives \(p_1..p_{k+1}\)
for \(i=1..k\) do
accept \(\tilde x_i\) with prob \(\min(1,p_i(\tilde x_i)/q_i(\tilde x_i))\); else sample from \((p_i-q_i)_+\), break
end
if all \(k\) accepted, also sample a bonus token from \(p_{k+1}\)
roll back the KV cache past the first rejection
end

The drafters

Method How it drafts Trade-off
Draft model a small model from the same family (e.g. 0.6B for 32B) needs a matching tokenizer and its own KV cache
Medusa extra heads on the target’s last hidden state, head \(i\) predicts token \(t+i\); a tree of candidates verified with a tree attention mask cheap, trained on target outputs; accuracy falls quickly with \(i\)
EAGLE / EAGLE-2 a one-layer drafter that runs autoregressively on the target’s features (second-to-top hidden states) plus the sampled token; EAGLE-2 grows the tree dynamically by draft confidence features are far easier to predict than tokens
EAGLE-3 drops the feature-prediction loss and predicts tokens directly; fuses low, middle and high-layer features; “training-time test” trains the drafter on its own multi-step outputs, as at inference acceptance keeps improving as drafter training data grows
MTP heads DeepSeek-V3 trains multi-token prediction modules with the model; at inference they act as a built-in drafter no separate training; fixed shallow depth
Prompt lookup / n-gram find the last \(n\) tokens earlier in the context, copy what followed free; great for editing, RAG and code, useless for novel text
SuffixDecoding a suffix tree over the current prompt and past outputs; drafts longest well-supported continuations, and adapts the draft length to how confident the match is model-free; very large speedups on repetitive agent workloads
Lookahead decoding Jacobi iteration: guess a window of future tokens, refine all in parallel, harvest n-grams that converge no drafter at all; lower acceptance
DFlash a block-diffusion drafter: proposes a whole block of tokens in one parallel denoising pass, conditioned on target features, instead of one draft token per step draft cost no longer grows with \(k\) (details not checked here; see the paper)

Trees

With top-2 candidates per level instead of one, a draft position counts as accepted if either candidate matches. If the top-1 matches 60% of the time and the top-2 another 20%, three levels of a chain accept \(0.6+0.6^2+0.6^3=1.18\) drafts on average, and a 2-ary tree accepts \(0.8+0.8^2+0.8^3=1.95\), for 14 candidate tokens verified in one pass with a tree attention mask (each node sees only its ancestors). Trees spend spare compute, so they help at small batch and hurt when the GPU is already compute-bound.

"""Inference ch. 'Speculative Decoding': exactness of speculative sampling, expected speedup,
tree drafts, and model-free drafting (prompt lookup vs suffix-tree style) on an agent-like workload."""
import random
from collections import defaultdict

import numpy as np

rng = np.random.default_rng(0)

# 1. Speculative sampling is exact: accept x~q with prob min(1, p/q), else resample from (p - q)+.
V = 8
p = rng.dirichlet(np.ones(V))                       # target
q = 0.6 * p + 0.4 * rng.dirichlet(np.ones(V))       # draft, close but not equal
N, out, acc = 200_000, np.zeros(V), 0
resid = np.maximum(p - q, 0); resid /= resid.sum()
for x in rng.choice(V, N, p=q):
    if rng.random() < min(1, p[x] / q[x]):
        out[x] += 1; acc += 1
    else:
        out[rng.choice(V, p=resid)] += 1
tv = 0.5 * np.abs(p - q).sum()
print(f"[exact] TV(empirical, target) = {0.5 * np.abs(out / N - p).sum():.4f}  (sampling noise ~0.003)")
print(f"[exact] acceptance {acc / N:.4f}  vs  1 - TV(p, q) = {1 - tv:.4f}")

# 2. Expected tokens per target pass with k drafts and per-token acceptance a: (1 - a^(k+1)) / (1 - a).
print("[speedup] a     k=1   k=3   k=5   k=8    best k (draft cost c = 0.05 of target)")
for a in (0.6, 0.75, 0.9):
    tok = {k: (1 - a ** (k + 1)) / (1 - a) for k in (1, 3, 5, 8)}
    sp = {k: (1 - a ** (k + 1)) / (1 - a) / (1 + 0.05 * k) for k in range(1, 16)}
    kb = max(sp, key=sp.get)
    print(f"[speedup] {a:.2f}  " + "  ".join(f"{tok[k]:4.2f}" for k in (1, 3, 5, 8))
          + f"    k={kb}, speedup {sp[kb]:.2f}x")

# 3. Tree drafts: top-2 candidates at each of 3 levels (Medusa / EAGLE-2 style). If the target token is
#    the draft's top-1 with prob 0.6 and its top-2 with prob 0.2, a chain accepts on top-1 only.
a1, a2, depth = 0.6, 0.2, 3
chain = sum(a1**i for i in range(1, depth + 1))
tree = sum((a1 + a2) ** i for i in range(1, depth + 1))
print(f"[tree] expected accepted drafts, depth {depth}: chain {chain:.2f}  tree (2 per level, "
      f"{2 + 4 + 8} nodes) {tree:.2f}")

# 4. Model-free drafting on an agent-like workload (characters as tokens, greedy target = the text).
random.seed(0)
tools = ["search", "read_file", "run_tests"]


def episode():
    s = ""
    for _ in range(6):
        t = random.choice(tools)
        arg = random.choice(["src/app.py", "tests/test_api.py", "README.md", "pricing bug", "login flow"])
        s += f'Thought: I should call {t}.\n{{"tool": "{t}", "args": {{"query": "{arg}"}}}}\n'
        s += random.choice(["Result: ok\n", "Result: 2 failures\n", "Result: found 3 matches\n"])
    return s


history = [episode() for _ in range(30)]


def run(text, draft_fn, k_max):
    """Count target passes to emit `text` when each pass verifies a draft and adds one free token."""
    i, passes, accepted = 0, 0, 0
    while i < len(text):
        d = draft_fn(text[:i], k_max)
        n = 0
        while n < len(d) and i + n < len(text) and d[n] == text[i + n]:
            n += 1
        i += n + 1; passes += 1; accepted += n
    return passes, accepted


def prompt_lookup(ctx, k, n=3):
    """Find the last earlier occurrence of the final n tokens in this request; copy what followed."""
    if len(ctx) < n:
        return ""
    j = ctx.rfind(ctx[-n:], 0, len(ctx) - 1)
    return ctx[j + n:j + n + k] if j >= 0 else ""


class SuffixIndex:
    """Suffix-decoding style: index past outputs by context; draft length grows with match length."""

    def __init__(self, texts, n=8):
        self.n, self.next = n, defaultdict(lambda: defaultdict(int))
        for t in texts:
            for i in range(len(t)):
                for m in range(1, n + 1):
                    if i - m >= 0:
                        self.next[t[i - m:i]][t[i]] += 1

    def draft(self, ctx, k_max):
        out = ""
        for _ in range(k_max):
            c = ctx + out
            for m in range(self.n, 0, -1):          # longest matching context wins
                nxt = self.next.get(c[-m:])
                if nxt:
                    tok, cnt = max(nxt.items(), key=lambda kv: kv[1])
                    if cnt / sum(nxt.values()) < 0.5 or m < 3:   # stop when the continuation is uncertain
                        return out
                    out += tok
                    break
            else:
                return out
        return out


idx = SuffixIndex(history[:20])
test = history[20:]
total = sum(len(t) for t in test)
for name, fn, k in (("none", lambda c, k: "", 0), ("prompt lookup", prompt_lookup, 8),
                    ("suffix index", idx.draft, 32)):
    passes = sum(run(t, fn, k)[0] for t in test)
    print(f"[model-free] {name:13s}: {total / passes:5.2f} tokens per target pass  ({passes} passes for {total} tokens)")

🔑 Key ideas

  • The empirical distribution matches the target to within sampling noise, and acceptance equals \(1-\mathrm{TV}(p,q)\) to three decimals. Speculation changes speed, never answers (in exact arithmetic).

  • On the agent-like workload, prompt lookup gives 2.5 tokens per pass, and a suffix index over past requests gives 21, because agents repeat tool-call boilerplate across requests. That is the SuffixDecoding argument in miniature; real gains are smaller since real text is less repetitive than this toy.

  • Speculation competes with batching for the same spare compute. At high load, \(B\) is large, decode moves toward compute-bound, and the speedup shrinks; engines lower \(k\) or turn speculation off under load.
