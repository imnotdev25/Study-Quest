🚀 Starting point

A reward model outputs one number per (prompt, response). It’s trained from comparisons, not absolute scores. Bradley–Terry models the probability that \(y^+\) beats \(y^-\) as \(\sigma(r^+-r^-)\), so only score differences have meaning.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why can the sampled PPO estimator \(k_1=-\log r\) be negative?

  2. Why is \(k_3=r-1-\log r\) nonnegative for every sample?

A reward model maps a prompt–response sequence to one scalar:

\[H\in\mathbb{R}^{B\times T\times D}\]

\[r_\phi(x,y)\in\mathbb{R}^{B}\]

For preferred and rejected responses:

\[r^+,r^-\in\mathbb{R}^{B}\]

the Bradley–Terry preference probability is:

\[P(y^+\succ y^-\mid x) = \sigma(r^+-r^-)\]

Define the margin:

\[\Delta=r^+-r^-\]

The pairwise loss is:

\[L_{\text{RM}} = -\log\sigma(\Delta) = \operatorname{softplus}(-\Delta)\]

Its score derivatives are:

\[\frac{\partial L}{\partial r^+} = -\sigma(-\Delta)\]

\[\frac{\partial L}{\partial r^-} = +\sigma(-\Delta)\]

Thus gradient descent raises the chosen score and lowers the rejected score.

Only score differences are identified:

\[(r^++c)-(r^-+c)=r^+-r^-\]

so adding the same constant to both scores changes nothing. Scale is not invariant: on separable data, margins can keep growing while accuracy is already perfect.

For decoder reward models, the score is commonly read from the final valid response token—not blindly from tensor position -1, which may be padding.

✏️ Derivation: the pairwise loss, its gradients, and identifiability

Step 1. NLL of the observed preference: \(L=-\log\sigma(\Delta)=\softplus(-\Delta)\), with \(\Delta=r^+-r^-\).

Step 2. \(\frac{dL}{d\Delta}=-\sigma(-\Delta)\). Chain: \(\frac{\partial L}{\partial r^+}=-\sigma(-\Delta)\) and \(\frac{\partial L}{\partial r^-}=+\sigma(-\Delta)\). Equal and opposite.

Step 3. Weight \(\sigma(-\Delta)\): \(\approx1\) for a wrongly ranked pair, \(\approx0\) for a confidently correct one.

Step 4. Identifiability: replace \(r(x,y)\) by \(r(x,y)+c(x)\). Then \(\Delta\) is unchanged, so the loss, every gradient, and every prediction are unchanged. The data can never determine \(c(x)\).

Step 5. Consequence: raw scores aren’t comparable across prompts, and their scale drifts. Before RL, normalize (e.g. subtract a per-prompt or global mean), and add a small \(\lambda\,\overline{(r^++r^-)^2}\) penalty if you want to pin the scale.

Step 6. Accuracy is \(P(\Delta>0)\) on held-out pairs. It says nothing about calibration or scale.

⚙️ Algorithm: pairwise reward-model training step
Input: pairs \((x,y^+,y^-)\), reward model \(r_\phi\) (score taken at the last real token)
\(\Delta\gets r_\phi(x,y^+)-r_\phi(x,y^-)\)
\(L\gets\operatorname{mean}\softplus(-\Delta)\); gradient step
log accuracy \(\operatorname{mean}\mathbb 1[\Delta>0]\) and the mean and std of raw scores

Solution — open after attempting

def terminal_hidden(hidden, mask):
    lengths = mask.sum(dim=-1)
    terminal_indices = lengths - 1

    batch_indices = torch.arange(
        hidden.shape[0],
        device=hidden.device,
    )

    return hidden[
        batch_indices,
        terminal_indices,
    ]


chosen_terminal = terminal_hidden(
    chosen_hidden,
    chosen_mask,
)

rejected_terminal = terminal_hidden(
    rejected_hidden,
    rejected_mask,
)

chosen_scores = (
    chosen_terminal @ reward_weight
    + reward_bias
)

rejected_scores = (
    rejected_terminal @ reward_weight
    + reward_bias
)

margin = chosen_scores - rejected_scores

per_pair_loss = F.softplus(-margin)
loss = per_pair_loss.mean()

For one pair:

\[L=\operatorname{softplus}(-\Delta)\]

At equal scores:

\[\Delta=0\]

\[L=\log 2\approx0.693\]

and:

\[\frac{\partial L}{\partial r^+} =-\sigma(0)=-\frac12\]

\[\frac{\partial L}{\partial r^-} =+\frac12\]

With batch-mean reduction, each derivative is additionally divided by \(B\).

For a badly misranked pair:

\[\Delta\ll0\]

\[\sigma(-\Delta)\approx1\]

so its gradient magnitude is large. For a confidently correct pair:

\[\Delta\gg0\]

\[\sigma(-\Delta)\approx0\]

and the gradient saturates.

The shared bias receives no gradient:

\[(r^++b)-(r^-+b)=r^+-r^-\]

This is another direct consequence of shift invariance.

Reading hidden[:, -1] scores padding positions whenever sequences have unequal lengths. The model can then learn artifacts associated with padded locations or length instead of response quality.

Check answers:

  1. Pairwise likelihood depends only on \(r^+-r^-\), so any common additive offset cancels.

  2. The loss is \(\log2\); derivatives are \(-1/2\) and \(+1/2\) before batch averaging.

  3. Check whether the scorer uses the last physical tensor position instead of the final valid response token, or whether padding enters mean pooling.

  4. The margin changes sign. Correct preferences become misranked examples, reversing the training signal.

  5. PPO uses reward magnitudes to construct returns and advantages. Rescaling rewards changes actor/critic gradient scales and the effective strength of KL penalties and clipping thresholds.

Retrieval answers:

  • \(k_1\) is a single Monte Carlo log-ratio term; only its old-policy expectation must be nonnegative.

  • \(k_3\ge0\) follows from: \[e^x\ge1+x\]
