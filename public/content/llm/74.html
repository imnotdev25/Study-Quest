🚀 Starting point

Shaped reward: the reward model gives one score \(R_b\) per response, while the KL penalty is naturally per token. Combine them as \(r_{bt}=-\beta k_{bt}+\mathbb 1[t=L_b-1]R_b\): a small cost at every token, and the score once, at the last real token. Return-to-go \(G_t=\sum_{k\ge t}r_k\) is what each token is credited with.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Under token-weighted policy loss, why do longer responses receive more aggregate gradient?

  2. How can a scalar loss equal zero while its parameter gradient remains nonzero?

In LLM reinforcement learning, a reward model commonly provides one score per response:

\[R\in\mathbb{R}^{B}\]

The policy and reference supply selected-token log-probabilities:

\[\ell_\pi,\ell_{\text{ref}} \in\mathbb{R}^{B\times T}\]

A sampled per-token KL penalty is:

\[k_{bt} = \ell_{\pi,bt}-\ell_{\text{ref},bt}\]

A common shaped reward is:

\[r_{bt}^{\text{shaped}} = -\beta k_{bt} + \mathbf 1[t=L_b-1]R_b\]

Thus:

  • every response token receives a local KL penalty;

  • the reward-model score is added only at the final valid response token;

  • padding receives neither reward nor policy gradient.

The return-to-go is:

\[G_{bt} = \sum_{j=t}^{L_b-1} \gamma^{j-t}r_{bj}^{\text{shaped}}\]

With \(\gamma=1\), terminal reward reaches every earlier response token equally. With \(\gamma<1\), earlier tokens receive a discounted signal.

Placing terminal reward at physical position T-1 instead of valid position \(L_b-1\) introduces length dependence. If the return recurrence crosses padding, the reward receives extra discounting; if padding resets the recurrence, the reward can disappear entirely.

In PPO, shaped rewards and returns are rollout data. They must be detached when optimizing the policy.

✏️ Derivation: what each token’s return contains

Step 1. With \(\gamma=1\): \(G_t=\sum_{k=t}^{L-1}r_k=-\beta\sum_{k=t}^{L-1}k_k+R\).

Step 2. So every token is credited with the full sequence score \(R\), plus the KL cost of itself and every token after it, not before.

Step 3. Backward recursion: \(G_{L-1}=-\beta k_{L-1}+R\), and \(G_t=r_t+G_{t+1}\). Padding beyond \(L-1\) must contribute 0.

Step 4. Placement bug: putting \(R\) on a padding position (index \(T-1\) instead of \(L_b-1\)) either drops it (if masked) or credits it to nonexistent tokens.

Step 5. Sum of KL penalties \(=-\beta\sum_tk_t\), which is \(-\beta\) times the sampled sequence KL \(\log\frac{\pi(y)}{\pi_{\text{ref}}(y)}\): token shaping implements the sequence-level KL objective.

⚙️ Algorithm: shaped rewards and return-to-go
Input: \(\ell_\pi,\ell_{\text{ref}}\) (detached), response lengths \(L_b\), scores \(R_b\), \(\beta\)
\(r_{bt}\gets-\beta(\ell_{\pi,bt}-\ell_{\text{ref},bt})\cdot M_{bt}\); \(r_{b,L_b-1}\gets r_{b,L_b-1}+R_b\)
\(G\gets0\)
for \(t=T-1\) down to \(0\) do
\(G_{bt}\gets M_{bt}(r_{bt}+G_{b,t+1})\)
end

Return-to-go:

def discounted_returns(rewards, gamma):
    returns = torch.zeros_like(rewards)

    running_return = torch.zeros(
        rewards.shape[0],
        dtype=rewards.dtype,
        device=rewards.device,
    )

    for t in reversed(range(rewards.shape[1])):
        running_return = (
            rewards[:, t]
            + gamma * running_return
        )

        returns[:, t] = running_return

    return returns

Policy loss:

policy_loss = -(
    new_selected_logp
    * masked_returns.detach()
)[response_mask].mean()

A positive terminal reward affects every preceding token through return-to-go:

\[G_t=r_t+\gamma r_{t+1}+\cdots\]

It does not affect only the terminal token.

A positive sequence score can still produce a negative return if accumulated KL penalties outweigh its discounted terminal contribution.

For a positive return:

\[L=-G_t\log\pi_\theta(a_t)\]

so:

\[\frac{\partial L} {\partial\log\pi_\theta(a_t)} =-G_t<0\]

Gradient descent therefore increases the selected action’s log-probability.

With the bug, a response of length \(L_b\) receives its terminal score at \(T-1\), adding:

\[T-L_b\]

artificial discount steps. Its contribution at valid token \(t\) becomes:

\[\gamma^{T-1-t}R_b\]

instead of:

\[\gamma^{L_b-1-t}R_b\]

Their ratio is:

\[\gamma^{T-L_b}\]

The shortest response has the most padding and therefore the strongest unintended attenuation. In implementations that reset return accumulation at padding, the misplaced reward may instead be removed completely.

Check answers:

  1. At index response_length - 1, the final valid response token.

  2. Every valid token receives the same return \(R\).

  3. Return-to-go includes all later shaped rewards, including later KL penalties.

  4. Check whether terminal reward is being written to [:, -1] rather than gathered/scattered using each response’s valid length.

  5. They define fixed rollout targets. Allowing gradients through their construction adds unintended paths and no longer implements the intended policy-gradient estimator.

Retrieval answers:

  • Token weighting assigns one contribution per valid action, so longer responses contain more contributing terms.

  • Loss terms can cancel in value while their derivatives with respect to different variables remain nonzero.
