🚀 Starting point

MLOps is version control for everything that changes: code (Git), data (DVC), experiments (MLflow), the environment (Docker), deployment (Kubernetes) and behaviour in production (Prometheus and Grafana). The rule: any result must be reproducible from a commit hash.

The service

A FastAPI app with input validation, a health check and Prometheus metrics, tested in-process. Note that it has no authentication: before exposing it beyond a cluster, put it behind an API gateway or add token auth, plus rate limiting.

"""Toolkit ch. 8: serve a model with FastAPI, expose Prometheus metrics, test it in-process."""
import time

import torch
from fastapi import FastAPI, HTTPException
from fastapi.testclient import TestClient
from prometheus_client import CONTENT_TYPE_LATEST, Counter, Histogram, generate_latest
from pydantic import BaseModel, Field
from starlette.responses import Response

torch.manual_seed(0)
model = torch.nn.Sequential(torch.nn.Linear(4, 16), torch.nn.ReLU(), torch.nn.Linear(16, 2)).eval()
MODEL_VERSION = "v1"

REQUESTS = Counter("predict_requests_total", "Prediction requests", ["status"])
LATENCY = Histogram("predict_latency_seconds", "Prediction latency")

app = FastAPI()


class Features(BaseModel):
    x: list[float] = Field(min_length=4, max_length=4)   # input validation at the boundary


@app.get("/health")
def health():
    return {"status": "ok", "model": MODEL_VERSION}


@app.post("/predict")
def predict(f: Features):
    t0 = time.perf_counter()
    try:
        with torch.no_grad():
            p = model(torch.tensor([f.x])).softmax(-1)[0]
    except Exception:
        REQUESTS.labels("error").inc()
        raise HTTPException(500, "inference failed")
    LATENCY.observe(time.perf_counter() - t0)
    REQUESTS.labels("ok").inc()
    return {"label": int(p.argmax()), "probs": [round(v, 4) for v in p.tolist()], "model": MODEL_VERSION}


@app.get("/metrics")
def metrics():
    return Response(generate_latest(), media_type=CONTENT_TYPE_LATEST)


if __name__ == "__main__":
    c = TestClient(app)
    print("[serve] GET /health ->", c.get("/health").json())
    r = c.post("/predict", json={"x": [0.1, -1.2, 0.3, 2.0]})
    print("[serve] POST /predict ->", r.status_code, r.json())
    print("[serve] bad input ->", c.post("/predict", json={"x": [1, 2]}).status_code)
    for _ in range(20):
        c.post("/predict", json={"x": [0.0, 0.0, 0.0, 1.0]})
    lines = [l for l in c.get("/metrics").text.splitlines()
             if l.startswith(("predict_requests_total{", "predict_latency_seconds_count"))]
    print("[serve] /metrics:", *lines, sep="\n  ")

The pipeline files

These configuration files were not run in this environment; they show the standard shape.

DVC pipeline (dvc.yaml): each stage declares inputs and outputs, so dvc repro reruns only what changed, and data lives in S3 under a hash.

stages:
  ingest:   {cmd: python src/ingest.py, deps: [src/ingest.py], outs: [data/raw]}
  features: {cmd: python src/features.py, deps: [data/raw, src/features.py], outs: [data/features]}
  train:
    cmd: python src/train.py
    deps: [data/features, src/train.py]
    params: [train.lr, train.epochs]
    outs: [models/model.pt]
    metrics: [{reports/metrics.json: {cache: false}}]

Docker image: slim base, pinned dependencies, non-root user.

FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY serve_app.py model.pt ./
RUN useradd -m app
USER app
EXPOSE 8000
CMD ["uvicorn", "serve_app:app", "--host", "0.0.0.0", "--port", "8000"]

CI (.github/workflows/ci.yml): test on every push, build and push the image on main.

on: {push: {branches: [main]}, pull_request: {}}
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: {python-version: "3.11"}
      - run: pip install -r requirements.txt pytest && pytest -q
  image:
    needs: test
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: docker build -t $REGISTRY/model-api:${{ github.sha }} .
      # then log in to the registry (ECR on AWS) and docker push

Kubernetes: a Deployment with probes on /health, resource limits, and annotations so Prometheus scrapes /metrics.

apiVersion: apps/v1
kind: Deployment
metadata: {name: model-api}
spec:
  replicas: 2
  selector: {matchLabels: {app: model-api}}
  template:
    metadata:
      labels: {app: model-api}
      annotations: {prometheus.io/scrape: "true", prometheus.io/port: "8000"}
    spec:
      containers:
        - name: api
          image: REGISTRY/model-api:COMMIT_SHA
          ports: [{containerPort: 8000}]
          readinessProbe: {httpGet: {path: /health, port: 8000}}
          livenessProbe:  {httpGet: {path: /health, port: 8000}, periodSeconds: 15}
          resources: {requests: {cpu: 250m, memory: 512Mi}, limits: {cpu: "1", memory: 1Gi}}
