🚀 Starting point

Starting point. A probability \(P\) assigns numbers in \([0,1]\) to events, with \(P(\Omega)=1\) and \(P(A\cup B)=P(A)+P(B)\) for disjoint \(A,B\). Everything else follows. Conditional probability \(P(A\mid B)=P(A\cap B)/P(B)\) is probability after learning that \(B\) happened. Real-life version: a weather forecast that updates as clouds roll in. Bayes’ rule is the update.

  • Complement: \(P(A^c)=1-P(A)\). Union: \(P(A\cup B)=P(A)+P(B)-P(A\cap B)\).

  • Product rule: \(P(A\cap B)=P(A\mid B)P(B)\). Independence: \(P(A\cap B)=P(A)P(B)\).

  • Total probability: if \(B_1,\dots,B_k\) partition \(\Omega\), \(P(A)=\sum_iP(A\mid B_i)P(B_i)\).

  • Bayes: \(P(B\mid A)=\dfrac{P(A\mid B)P(B)}{P(A)}\), i.e. posterior \(\propto\) likelihood \(\times\) prior.

✏️ Derivation: A 95%-accurate test, 1% prevalence

Step 1. \(P(+)=P(+\mid D)P(D)+P(+\mid D^c)P(D^c)=0.95\cdot0.01+0.05\cdot0.99=0.059\).

Step 2. \(P(D\mid+)=0.95\cdot0.01/0.059=0.161\). Only one positive in six is real: the false positives from the healthy 99% outnumber the true ones.

Step 3. A second independent positive: use 0.161 as the new prior. \(P(D\mid++)=0.785\). Updating one observation at a time gives the same answer as updating on all of them at once.

✏️ Derivation: Beta–Bernoulli: the conjugate update

Step 1. Prior on a coin’s bias \(\theta\): \(\text{Beta}(a,b)\), density \(\propto\theta^{a-1}(1-\theta)^{b-1}\).

Step 2. Likelihood of \(h\) heads and \(t\) tails: \(\theta^h(1-\theta)^t\).

Step 3. Posterior \(\propto\theta^{a+h-1}(1-\theta)^{b+t-1}\): \(\boxed{\text{Beta}(a+h,\,b+t)}\). The prior acts like \(a\) imaginary heads and \(b\) imaginary tails. Posterior mean \(\frac{a+h}{a+b+n}\) moves from the prior mean toward \(h/n\) as data accumulates, and the spread shrinks like \(1/\sqrt n\).

The posterior over a coin’s bias sharpens as flips arrive (the runs in the output below).

"""Probability: the rules, Bayes' theorem, and Bayesian updating."""
import numpy as np

rng = np.random.default_rng(0)

# 1. Bayes on a diagnostic test: P(disease | positive).
prev, sens, spec = 0.01, 0.95, 0.95
p_pos = sens * prev + (1 - spec) * (1 - prev)                 # law of total probability
post1 = sens * prev / p_pos
p_pos2 = sens * post1 + (1 - spec) * (1 - post1)
post2 = sens * post1 / p_pos2                                 # yesterday's posterior is today's prior
print(f"[bayes] P(+) = {p_pos:.4f}   P(D | +) = {post1:.4f}   after a second independent + : {post2:.4f}")
n = 2_000_000
d = rng.random(n) < prev
t = np.where(d, rng.random(n) < sens, rng.random(n) < 1 - spec)
print(f"[bayes] simulation of {n:,} people: P(D | +) = {d[t].mean():.4f}")

# 2. Beta-Bernoulli: prior Beta(a, b), after h heads and t tails the posterior is Beta(a + h, b + t).
a, b = 2.0, 2.0
flips = rng.random(40) < 0.7
for k in (0, 5, 20, 40):
    h = flips[:k].sum(); A, B = a + h, b + k - h
    mean, sd = A / (A + B), np.sqrt(A * B / ((A + B) ** 2 * (A + B + 1)))
    print(f"[beta] after {k:2d} flips ({h:2d} heads): Beta({A:.0f},{B:.0f})  mean {mean:.3f}  sd {sd:.3f}")
A_seq, B_seq = a, b
for f in flips:                                               # one flip at a time
    A_seq, B_seq = A_seq + f, B_seq + (1 - f)
print(f"[beta] sequential updates == one batch update: {(A_seq, B_seq) == (a + flips.sum(), b + 40 - flips.sum())}")

# 3. Grid posterior for the same coin (no conjugacy needed): prior x likelihood, normalise.
theta = np.linspace(0.001, 0.999, 999)
prior = theta ** (a - 1) * (1 - theta) ** (b - 1)
like = theta ** flips.sum() * (1 - theta) ** (40 - flips.sum())
post = prior * like; post /= post.sum()
print(f"[grid] posterior mean on a grid {(theta * post).sum():.4f}  vs conjugate {(a + flips.sum()) / (a + b + 40):.4f}")

# 4. Monty Hall: switching wins 2/3.
car, pick = rng.integers(3, size=100_000), rng.integers(3, size=100_000)
print(f"[monty] stay wins {(car == pick).mean():.3f}   switch wins {(car != pick).mean():.3f}")
