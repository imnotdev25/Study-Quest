🚀 Starting point

Label smoothing replaces the one-hot target with a slightly spread-out one: \(q^{(\epsilon)}=(1-\epsilon)\onehot(y)+\frac{\epsilon}{C}\mathbf 1\). The loss is still cross-entropy \(-\sum_cq_c\log p_c\), just against a softer target (Part 0: minimizing it means matching \(q^{(\epsilon)}\)).

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why can temperature scaling change confidence without changing top-1 predictions?

  2. Why can low aggregate ECE hide subgroup miscalibration?

For logits and labels:

\[Z\in\mathbb{R}^{B\times C}, \qquad y\in\{0,\ldots,C-1\}^{B}\]

ordinary cross-entropy uses one-hot targets \(q\):

\[L = -\frac1B\sum_{i,c}q_{ic}\log p_{ic}\]

\[p_{ic} = \operatorname{softmax}(Z_i)_c\]

Its key gradient is:

\[\frac{\partial L}{\partial Z_{ic}} = \frac{p_{ic}-q_{ic}}{B}\]

With hard labels:

\[q_{ic}=\mathbf1[c=y_i]\]

Label smoothing replaces this target with:

\[q_{ic}^{(\epsilon)} = (1-\epsilon)\mathbf1[c=y_i] + \frac{\epsilon}{C}\]

The correct-class target becomes:

\[1-\epsilon+\frac{\epsilon}{C}\]

while every other class receives \(\epsilon/C\).

This prevents training from continually demanding probability one for the observed class. For an extremely confident correct prediction, hard-label gradients approach zero; smoothed-label gradients can instead push confidence downward.

Practical consequences:

  • finite pressure against extreme logit gaps;

  • often less overconfidence;

  • changed gradients even when accuracy is already perfect;

  • potentially worse calibration or likelihood under distribution shift;

  • undesirable behavior when true labels genuinely should be nearly deterministic.

Label smoothing is a training objective—not a guaranteed calibration method.

✏️ Derivation: the gradient, and why logits stay finite

Step 1. \(\ell=-\sum_cq_c\log p_c=\LSE(z)\sum_cq_c-\sum_cq_cz_c=\LSE(z)-q^\top z\), since \(\sum q=1\).

Step 2. \(\nabla_z\ell=p-q\): the same “prediction minus target” form, with the soft target.

Step 3. Hard labels: \(p-\onehot(y)\) is never 0 for finite logits (\(p_y<1\) always), so the optimum pushes \(z_y-z_c\to\infty\): overconfidence is built in.

Step 4. Smoothed: the gradient is 0 when \(p=q^{(\epsilon)}\), so \(\frac{p_y}{p_c}=e^{z_y-z_c}=\frac{1-\epsilon+\epsilon/C}{\epsilon/C}\), a finite gap.

Step 5. Example: \(\epsilon=0.1\), \(C=10\): target \(0.91\) for the true class and \(0.01\) for the others, so the optimal logit gap is \(\ln91=4.51\).

Step 6. Decomposition: \(\ell=(1-\epsilon)\operatorname{CE}(\onehot,p)+\epsilon\operatorname{CE}(\text{uniform},p)\). The second term is a penalty for putting near-zero probability on any class.

⚙️ Algorithm: label-smoothed cross-entropy
Input: logits \(Z\in\mathbb R^{B\times C}\), labels \(y\), \(\epsilon\)
\(\log P\gets\operatorname{log\_softmax}(Z)\)
\(q\gets(1-\epsilon)\onehot(y)+\epsilon/C\)
\(L\gets-\frac1B\sum_{i,c}q_{ic}\log P_{ic}\) ▷ cross_entropy(..., label_smoothing=eps)

Solution — open after attempting

Forward computation:

log_probabilities = F.log_softmax(
    logits,
    dim=-1,
)

probabilities = log_probabilities.exp()

one_hot = F.one_hot(
    labels,
    num_classes=C,
).to(logits.dtype)

smoothed_targets = (
    (1.0 - epsilon) * one_hot
    + epsilon / C
)

hard_per_example = -log_probabilities.gather(
    dim=-1,
    index=labels[:, None],
).squeeze(-1)

smooth_per_example = -(
    smoothed_targets * log_probabilities
).sum(dim=-1)

hard_loss = hard_per_example.mean()
smooth_loss = smooth_per_example.mean()

Analytical gradients:

expected_hard_gradient = (
    probabilities.detach() - one_hot
) / B

expected_smooth_gradient = (
    probabilities.detach() - smoothed_targets
) / B

Unstable computation:

with torch.no_grad():
    exponentials = logits.exp()

    naive_probabilities = (
        exponentials
        / exponentials.sum(dim=-1, keepdim=True)
    )

    naive_log_probabilities = (
        naive_probabilities.log()
    )

For \(C=4\) and \(\epsilon=0.2\), the correct-class target is:

\[1-0.2+\frac{0.2}{4} = 0.85\]

The first example has \(p_y\approx1\). Therefore:

\[\frac{\partial L_{\text{smooth}}}{\partial z_y} = \frac{p_y-0.85}{B} >0\]

Gradient descent subtracts this positive gradient, reducing the correct-class logit and its excessive confidence.

The hard-label gradient is instead:

\[\frac{p_y-1}{B}\approx0\]

For the large logits, direct exponentiation computes values such as:

\[e^{1000}\]

which overflow to infinity. The subsequent division can produce \(\infty/\infty\), yielding NaN.

Softmax is invariant to a common row shift:

\[\frac{e^{z_c-a}}{\sum_j e^{z_j-a}} = \frac{e^{z_c}}{\sum_j e^{z_j}}\]

Choosing:

\[a=\max_jz_j\]

makes the largest exponent equal to one and prevents overflow. F.log_softmax performs this computation stably without first materializing potentially tiny probabilities.

A nonzero smoothed loss at perfect accuracy is expected: the target distribution assigns positive mass to non-target classes, so probability one on the correct class is not the optimum.
