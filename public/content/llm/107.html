How to reproduce an inference paper

Read for the claim, the workload and the baseline. Recreate the workload first (length distributions, arrival process, prefix sharing), then the baseline with its tuned settings, and only then the method. Profile both, run ablations to find which part gives the gain, and find the limits: the load, length or batch size where the gain disappears. Speculation, sparse attention and disaggregation all have such a crossover.

Capstone checklist

  1. Define the workload (lengths, rate, prefix sharing) and the SLO.

  2. Choose the model and the smallest GPU that fits weights plus the KV you need.

  3. Baseline with defaults: goodput at the SLO, latency curve.

  4. Profile prefill and decode; decide what bounds each.

  5. Optimise memory (utilisation, block size, prefix caching), then precision (FP8 weights and KV, measuring quality).

  6. Decide multi-GPU: replicas first; TP only if latency or model size demands it.

  7. Add routing (prefix-aware) and autoscaling.

  8. Failure-test: kill a replica, flood with long prompts, check admission control.

  9. Publish the workload, configs, numbers and the cost per million tokens.
