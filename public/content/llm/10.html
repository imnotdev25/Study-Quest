Distribution pmf / pdf Mean Variance Models
Bernoulli\((p)\) \(p^x(1-p)^{1-x}\) \(p\) \(p(1-p)\) one right/wrong answer
Binomial\((n,p)\) \(\binom nkp^k(1-p)^{n-k}\) \(np\) \(np(1-p)\) correct answers on \(n\) items
Geometric\((p)\) \((1-p)^{k-1}p\) \(1/p\) \((1-p)/p^2\) tries until first success
Poisson\((\lambda)\) \(e^{-\lambda}\lambda^k/k!\) \(\lambda\) \(\lambda\) request arrivals per second
Categorical\((p)\) \(p_k\) – – the next token
Uniform\((a,b)\) \(1/(b-a)\) \(\frac{a+b}2\) \(\frac{(b-a)^2}{12}\) random seeds
Exponential\((\lambda)\) \(\lambda e^{-\lambda x}\) \(1/\lambda\) \(1/\lambda^2\) gaps between arrivals
Normal\((\mu,\sigma^2)\) \(\frac1{\sqrt{2\pi\sigma^2}}e^{-(x-\mu)^2/2\sigma^2}\) \(\mu\) \(\sigma^2\) sums of many effects; init
Gamma\((k,\theta)\) \(\frac{x^{k-1}e^{-x/\theta}}{\Gamma(k)\theta^k}\) \(k\theta\) \(k\theta^2\) sums of exponentials
Beta\((a,b)\) \(\frac{x^{a-1}(1-x)^{b-1}}{B(a,b)}\) \(\frac a{a+b}\) \(\frac{ab}{(a+b)^2(a+b+1)}\) a probability itself
Laplace\((0,b)\) \(\frac1{2b}e^{-|x|/b}\) 0 \(2b^2\) heavy-ish tails; L1 prior

The normal: 68% within one standard deviation, 95% within 1.96.

How they connect. Bernoulli sums are binomial; \(\text{Binomial}(n,\lambda/n)\to\text{Poisson}(\lambda)\) as \(n\to\infty\) (the total-variation distance in the output falls 10\(\times\) per decade of \(n\)); exponential gaps between events make a Poisson count; sums of \(k\) exponentials are Gamma; sums of almost anything become normal (CLT, below); and the Beta is conjugate to the Bernoulli.

"""Probability: the standard discrete and continuous distributions, theory vs simulation."""
import math

import numpy as np

rng = np.random.default_rng(0)
N = 1_000_000

table = [  # name, sampler, theoretical mean, theoretical variance
    ("Bernoulli(0.3)", lambda: rng.random(N) < 0.3, 0.3, 0.21),
    ("Binomial(20, 0.3)", lambda: rng.binomial(20, 0.3, N), 6.0, 4.2),
    ("Geometric(0.25) trials", lambda: rng.geometric(0.25, N), 4.0, 12.0),
    ("Poisson(4)", lambda: rng.poisson(4, N), 4.0, 4.0),
    ("Uniform(2, 8)", lambda: rng.uniform(2, 8, N), 5.0, 3.0),
    ("Exponential(rate 0.5)", lambda: rng.exponential(2, N), 2.0, 4.0),
    ("Normal(1, 9)", lambda: rng.normal(1, 3, N), 1.0, 9.0),
    ("Gamma(k=3, theta=2)", lambda: rng.gamma(3, 2, N), 6.0, 12.0),
    ("Beta(2, 5)", lambda: rng.beta(2, 5, N), 2 / 7, 10 / (49 * 8)),
    ("Laplace(0, b=1)", lambda: rng.laplace(0, 1, N), 0.0, 2.0),
]
print("[dist] distribution              mean (theory)        variance (theory)")
for name, sample, m, v in table:
    s = sample().astype(float)
    print(f"[dist] {name:24s} {s.mean():7.4f} ({m:7.4f})   {s.var():8.4f} ({v:8.4f})")

# Poisson as the limit of Binomial(n, lam/n).
lam = 3.0
pois = np.array([math.exp(-lam) * lam**k / math.factorial(k) for k in range(40)])
for n in (10, 100, 1000):
    p = lam / n
    binom = np.array([math.comb(n, k) * p**k * (1 - p) ** (n - k) if k <= n else 0.0 for k in range(40)])
    print(f"[limit] Binomial({n}, 3/{n}) vs Poisson(3): total variation {0.5 * np.abs(binom - pois).sum():.5f}")

# Sums: Exponential sums are Gamma; Bernoulli sums are Binomial; Normal sums stay Normal.
s = rng.exponential(2, (N, 3)).sum(1)
print(f"[sums] sum of 3 Exponential(mean 2): mean {s.mean():.3f}, var {s.var():.3f}  -> Gamma(3, 2): 6, 12")
