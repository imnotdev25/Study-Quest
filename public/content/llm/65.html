🚀 Starting point

Reusing old samples: PPO collects actions with \(\pi_{\text{old}}\) and then takes several gradient steps. The importance ratio \(r=\pi_\theta(a)/\pi_{\text{old}}(a)\) reweights each old sample to estimate the new policy’s objective. The clip stops the policy from exploiting that estimate by moving too far.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Write the backward GAE recurrence.

  2. Why should a rollout truncation usually retain the bootstrap value while a true terminal state should not?

PPO reuses actions sampled from an old policy. For each selected action:

\[\ell_{\text{new}},\ell_{\text{old}},A \in\mathbb{R}^{B\times T}\]

The importance ratio is:

\[r_t(\theta) = \frac{\pi_\theta(a_t\mid s_t)} {\pi_{\text{old}}(a_t\mid s_t)} = \exp(\ell_{\text{new},t}-\ell_{\text{old},t})\]

The unclipped policy objective is:

\[r_tA_t\]

PPO uses the pessimistic surrogate:

\[J_t^{\text{clip}} = \min\left( r_tA_t,\; \operatorname{clip}(r_t,1-\epsilon,1+\epsilon)A_t \right)\]

and minimizes:

\[L_{\text{policy}} = -\frac{\sum_t M_tJ_t^{\text{clip}}} {\sum_t M_t}\]

The clipping is asymmetric because the sign of \(A_t\) determines which ratio movement is beneficial:

  • \(A_t>0\): increasing the selected action’s probability is beneficial; gradient vanishes beyond \(r_t>1+\epsilon\).

  • \(A_t<0\): decreasing its probability is beneficial; gradient vanishes beyond \(r_t<1-\epsilon\).

  • Harmful movements remain penalized even outside the interval.

PPO does not simply clamp every ratio. Nor does clipping guarantee bounded KL divergence or a bounded parameter update. In practice, monitor ratio statistics, clip fraction, approximate KL, and entropy—especially across multiple epochs on the same rollout.

✏️ Derivation: which gradients vanish under the clip

Step 1. Importance sampling: \(\mathbb E_{a\sim\pi_\theta}[A]=\mathbb E_{a\sim\pi_{\text{old}}}[rA]\), so \(rA\) is the surrogate. Its gradient at \(\theta=\theta_{\text{old}}\) is \(A\nabla\log\pi_\theta\): plain policy gradient.

Step 2. Per sample \(J=\min\big(rA,\operatorname{clip}(r,1-\epsilon,1+\epsilon)A\big)\). The min picks the smaller (more pessimistic) term.

Step 3. \(A>0\): if \(r>1+\epsilon\), the clipped term \((1+\epsilon)A\) is smaller and constant, so \(\partial J/\partial\theta=0\). If \(r<1+\epsilon\), \(J=rA\) and the gradient flows.

Step 4. \(A<0\): if \(r<1-\epsilon\), the clipped term \((1-\epsilon)A\) is smaller (more negative), so the gradient is 0. If \(r>1\), \(rA\) is smaller and the full penalty applies, unclipped.

Step 5. Summary: the gradient vanishes only when the ratio has already moved past the clip in the direction the advantage wants. Moves in the wrong direction are always penalized.

Step 6. \(\partial r/\partial\theta=r\nabla\log\pi_\theta\), so where it doesn’t vanish the gradient is \(rA\nabla\log\pi_\theta\). Compute \(r\) as \(\exp(\ell_{\text{new}}-\ell_{\text{old}})\) for stability.

⚙️ Algorithm: PPO clipped policy loss
Input: \(\ell_{\text{new}}\) (with gradient), \(\ell_{\text{old}},A\) (fixed), mask \(M\), \(\epsilon\)
\(r\gets\exp(\ell_{\text{new}}-\ell_{\text{old}})\)
\(J\gets\min\big(rA,\operatorname{clip}(r,1-\epsilon,1+\epsilon)A\big)\)
\(L\gets-\sum MJ/\sum M\)
log clip fraction \(\sum M\,\mathbb 1[|r-1|>\epsilon]/\sum M\)

For \(A>0,r=1.4\), the unclipped improvement exceeds the allowed surrogate improvement:

\[\min(1.4A,1.2A)=1.2A\]

The selected branch is constant with respect to the new log-probability, so its gradient is zero.

For \(A>0,r=0.6\):

\[\min(0.6A,0.8A)=0.6A\]

This is a harmful probability decrease, so PPO retains a gradient that pushes the ratio upward.

For \(A<0,r=0.6\):

\[\min(0.6A,0.8A)=0.8A\]

Because \(A\) is negative, \(0.8A\) is smaller. The beneficial probability reduction is clipped flat.

For \(A<0,r=1.3\):

\[\min(1.3A,1.2A)=1.3A\]

Increasing the probability of a negative-advantage action is harmful, so PPO continues penalizing it.

Directly clamping the ratio makes both sides flat regardless of advantage sign. It therefore removes corrective gradients for \(A>0,r<1-\epsilon\) and \(A<0,r>1+\epsilon\).

Check answers:

  1. The new policy assigns the sampled action more probability than the rollout policy did.

  2. Zero, assuming the clipped branch is strictly selected.

  3. That movement makes a below-baseline action more likely. Clipping is intended to limit excessive improvement, not protect harmful changes from correction.

  4. Repeated optimization is moving the current policy farther from the policy that generated the rollout, making the data increasingly stale.

  5. Clipping affects only selected-action surrogate terms. It does not constrain the complete action distribution, parameter-space movement, or accumulated changes across many optimizer steps.

Retrieval answers:

\[A_t=\delta_t+\gamma\lambda(1-d_t)A_{t+1}\]

A true terminal state has no valid successor value. A time-limit truncation still has a continuing state, so discarding its bootstrap value biases the advantage estimate.
