🚀 Starting point

Correlated samples carry less information than independent ones. Five rephrasings of the same question share its facts and difficulty, so they’re closer to one sample than five. The intra-cluster correlation \(\rho\) measures how alike items in the same cluster are.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why must paired model outcomes remain aligned during resampling?

  2. What uncertainty does a bootstrap interval fail to detect?

Suppose \(C\) underlying entities each have \(K\) prompt variants. For every variant, compute a paired model difference:

\[D\in\mathbb{R}^{C\times K}\]

Variants of the same entity share facts, phrasing, and difficulty, so they are correlated. The entity-balanced improvement is:

\[\hat\Delta = \frac{1}{C} \sum_{c=1}^{C} \left( \frac{1}{K}\sum_{k=1}^{K}D_{ck} \right)\]

Flattening \(D\) and bootstrapping \(CK\) rows assumes every variant is independent. This is pseudoreplication: it usually produces confidence intervals that are too narrow.

Instead, resample entity indices:

\[c_1^*,\ldots,c_C^* \sim \operatorname{Uniform}\{1,\ldots,C\}\]

and retain all variants belonging to each sampled entity.

For equal cluster size and within-cluster correlation \(\rho\), the approximate design effect is:

\[\text{DEFF}=1+(K-1)\rho\]

so the effective sample size is roughly:

\[N_{\text{eff}} \approx \frac{CK}{1+(K-1)\rho}\]

When \(\rho\approx1\), five paraphrases provide nearly one independent unit—not five.

For unequal variant counts, first decide the estimand:

  • Instance-weighted: entities with more variants receive more weight.

  • Entity-balanced: compute one mean per entity, then average those means.

✏️ Derivation: the design effect

Step 1. Cluster \(c\) has \(K\) items with variance \(\sigma^2\) and pairwise correlation \(\rho\). Its mean \(\bar D_c=\frac1K\sum_kD_{ck}\).

Step 2. \(\operatorname{Var}(\bar D_c)=\frac{1}{K^2}\Big[K\sigma^2+K(K-1)\rho\sigma^2\Big]=\frac{\sigma^2}{K}\big(1+(K-1)\rho\big)\).

Step 3. Over \(C\) independent clusters: \(\operatorname{Var}(\hat\Delta)=\frac{\sigma^2}{CK}\big(1+(K-1)\rho\big)\).

Step 4. Treating all \(CK\) items as independent predicts \(\frac{\sigma^2}{CK}\). The ratio \(\mathrm{DEFF}=1+(K-1)\rho\) is the design effect. Example: \(K=5\), \(\rho=0.5\) gives \(\mathrm{DEFF}=3\), so naive intervals are \(\sqrt3=1.7\times\) too narrow.

Step 5. Cluster bootstrap: resample whole clusters (entities), keeping all their variants together. That reproduces the correct variance automatically.

⚙️ Algorithm: cluster bootstrap
Input: differences \(D\in\mathbb R^{C\times K}\) (cluster \(\times\) variant), resamples \(B\)
\(\bar D_c\gets\) mean over variants for each cluster
for \(b=1,\dots,B\) do
draw \(C\) clusters with replacement; \(\hat\Delta_b\gets\) mean of their \(\bar D_c\)
end
return percentile interval of \(\{\hat\Delta_b\}\)

Solution — open after attempting

paired_differences = (
    entity_effect + variant_noise
)

entity_means = paired_differences.mean(dim=1)
estimated_improvement = entity_means.mean()

Naive bootstrap:

flat_differences = paired_differences.reshape(-1)

naive_estimates = flat_differences[
    naive_indices
].mean(dim=1)

naive_interval = torch.quantile(
    naive_estimates,
    quantiles,
)

Cluster bootstrap:

cluster_samples = paired_differences[
    cluster_indices
]

cluster_estimates = cluster_samples.mean(
    dim=(1, 2)
)

cluster_interval = torch.quantile(
    cluster_estimates,
    quantiles,
)

Analytical estimates:

naive_se = (
    flat_differences.std(unbiased=True)
    / (C * K) ** 0.5
)

cluster_se = (
    entity_means.std(unbiased=True)
    / C**0.5
)

The naive bootstrap treats the shared entity component as if it were independently redrawn for every variant. It therefore acts as though there are \(CK\) independent observations.

The cluster bootstrap redraws only \(C\) independent entities and keeps each entity’s correlated variants together. Variants can reduce uncertainty about that entity’s mean, but they do not create new independent entities.

If variant noise is zero:

\[D_{c1}=\cdots=D_{cK}\]

Duplicating each value \(K\) times adds no independent information. With \(\rho=1\):

\[\text{DEFF} = 1+(K-1) = K\]

so:

\[N_{\text{eff}} = \frac{CK}{K} = C\]

Retrieval answers:

  • Paired outcomes must remain aligned because their covariance determines the uncertainty of their difference.

  • Bootstrap intervals measure sampling variability under the observed data-generating setup; they do not reveal systematic judge bias, contamination, or dataset mismatch.
