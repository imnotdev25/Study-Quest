🚀 Starting point

Neuron: \(z_i=w^\top x_i+b\), a real number (the logit). Probability: \(p_i=\sigma(z_i)=1/(1+e^{-z_i})\in(0,1)\) is the model’s belief that \(y_i=1\). Loss: the Bernoulli negative log-likelihood (Part 0), averaged over the batch: \(L=\frac1B\sum_i\big[\softplus(z_i)-y_iz_i\big]\). It’s 0 when the model puts all its probability on the right label, and grows without bound when it’s confidently wrong.

Total: 20 minutes

1. Concept refresh — 4 minutes

For a batch of \(B\) examples with \(D\) features:

\[X\in\mathbb{R}^{B\times D},\quad w\in\mathbb{R}^{D},\quad b\in\mathbb{R}\]

A binary-classification neuron computes:

\[z=Xw+b,\qquad z\in\mathbb{R}^{B}\]

Using binary cross-entropy with logits:

\[L=\frac{1}{B}\sum_{i=1}^{B} \left[\operatorname{softplus}(z_i)-y_i z_i\right]\]

The backward pass is:

\[\delta=\frac{\partial L}{\partial z} =\frac{\sigma(z)-y}{B}\]

\[\frac{\partial L}{\partial w}=X^\top\delta \qquad \frac{\partial L}{\partial b}=\sum_i\delta_i\]

Think of backpropagation as:

  1. Compute the local error at the logits: \(\delta\).

  2. Send that error backward through each operation.

  3. Sum contributions whenever one value influences multiple downstream paths.

Research-engineering connection: binary_cross_entropy_with_logits combines sigmoid and BCE using a numerically stable formulation. Explicitly calculating log(sigmoid(z)) can overflow or produce -inf for large logits.

✏️ Derivation: every gradient of one neuron

Step 1. Per-example loss \(\ell_i=\softplus(z_i)-y_iz_i\). Since \(\softplus'(z)=\frac{e^z}{1+e^z}=\sigma(z)\): \(\ \frac{\partial\ell_i}{\partial z_i}=\sigma(z_i)-y_i\).

Step 2. Mean reduction: \(L=\frac1B\sum_i\ell_i\), and \(z_i\) only appears in \(\ell_i\), so \(\delta_i=\frac{\partial L}{\partial z_i}=\frac{\sigma(z_i)-y_i}{B}\).

Step 3. \(z_i=\sum_dX_{id}w_d+b\), so \(\frac{\partial z_i}{\partial w_d}=X_{id}\) and \(\frac{\partial z_i}{\partial b}=1\).

Step 4. Chain rule, summing over every example each parameter touches: \(\frac{\partial L}{\partial w_d}=\sum_i\delta_iX_{id}=(X^\top\delta)_d\), and \(\frac{\partial L}{\partial b}=\sum_i\delta_i\).

Step 5. Shape check: \(X^\top\in\mathbb R^{D\times B}\), \(\delta\in\mathbb R^B\), so \(X^\top\delta\in\mathbb R^D\), matching \(w\).

Step 6. Sanity check: if every prediction is perfect (\(\sigma(z_i)=y_i\)), then \(\delta=0\) and nothing changes. The gradient is “error times input,” summed.

⚙️ Algorithm: logistic neuron, one gradient step
Input: \(X\in\mathbb R^{B\times D}\), \(y\in\{0,1\}^B\), \(w,b\), learning rate \(\eta\)
\(z\gets Xw+b\)
\(L\gets\frac1B\sum_i\softplus(z_i)-y_iz_i\) ▷ stable form, never \(\log\sigma\)
\(\delta\gets(\sigma(z)-y)/B\)
\(\nabla_w\gets X^\top\delta\); \(\nabla_b\gets\sum_i\delta_i\)
\(w\gets w-\eta\nabla_w\); \(b\gets b-\eta\nabla_b\); clear gradients

3. Checks for understanding — 5 minutes

  1. Why does the factor \(1/B\) appear in delta?

  2. If every training example is duplicated and the loss still uses mean reduction, what happens to the gradient?

  3. Suppose z contains [1000, -1000]. Why is sigmoid(z) followed by manual logarithms risky?

  4. Debugging: the loss decreases, but w.grad is always None. Name two likely causes.

  5. If \(w\) changes from shape [D] to [D, 1], what are the resulting shapes of z and delta?

Spend the final minute explaining aloud:

Why is \(X^\top\delta\) the weight gradient?

Solution — open after attempting

z = X @ w + b

delta = (torch.sigmoid(z) - y) / X.shape[0]
manual_dw = X.T @ delta
manual_db = delta.sum()

The first repeated loss.backward() raises an error because the saved graph was freed. After recomputing the forward pass, another backward call succeeds—but adds the new gradient to the existing w.grad.

Clear gradients before the next step:

w.grad = None
b.grad = None

Check answers:

  1. BCE uses mean reduction, so each example contributes \(1/B\) of the batch gradient.

  2. The gradient remains unchanged because both the summed gradient and batch size double.

  3. Sigmoid can round to exactly 0 or 1, making subsequent logarithms produce infinities.

  4. Common causes include requires_grad=False, executing under torch.no_grad(), detaching the tensor, or checking a non-leaf tensor whose gradient was not retained.

  5. z and delta become [B, 1].

  6. Each weight affects every logit through its corresponding input feature. Multiplying \(X^\top\) by each example’s logit error sums those per-example contributions for every feature.
