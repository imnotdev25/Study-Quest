🚀 Starting point

Knowledge distillation trains a student to match a teacher’s full output distribution, not just its top answer. The teacher’s small probabilities for wrong-but-similar classes carry information (“dark knowledge”). Temperature \(T>1\) softens both distributions so those small probabilities are visible: \(p_T=\operatorname{softmax}(z^{(t)}/T)\), \(q_T=\operatorname{softmax}(z^{(s)}/T)\).

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Under label smoothing, what is the cross-entropy logit gradient?

  2. Why is log_softmax preferable to computing log(softmax(logits)) separately?

For teacher and student logits:

\[Z^{(t)},Z^{(s)}\in\mathbb{R}^{B\times C}\]

temperature-softened distributions are:

\[p_T = \operatorname{softmax} \left( \frac{Z^{(t)}}{T} \right)\]

\[q_T = \operatorname{softmax} \left( \frac{Z^{(s)}}{T} \right)\]

A distillation objective minimizes:

\[D_{\mathrm{KL}}(p_T\|q_T) = \sum_c p_{T,c} \left( \log p_{T,c}-\log q_{T,c} \right)\]

Higher \(T\) reveals relative probabilities among non-argmax classes—the teacher’s “dark knowledge.” But temperature also weakens gradients. Without compensation:

\[\frac{\partial L_{\mathrm{KD}}} {\partial Z^{(s)}} = \frac{q_T-p_T}{BT}\]

For large \(T\), the probability difference is itself approximately \(O(1/T)\), making the gradient roughly \(O(1/T^2)\).

The conventional correction is:

\[L_{\mathrm{KD}} = T^2D_{\mathrm{KL}}(p_T\|q_T)\]

which keeps gradient scale more comparable across temperatures.

A combined objective is commonly:

\[L = \alpha L_{\mathrm{hard}} + (1-\alpha)L_{\mathrm{KD}}\]

Teacher probabilities are fixed targets and should normally be detached.

✏️ Derivation: why the loss is multiplied by \(T^2\)

Step 1. Loss \(D_{\mathrm{KL}}(p_T\|q_T)=\sum_cp_{T,c}\log p_{T,c}-\sum_cp_{T,c}\log q_{T,c}\). Only the second term depends on the student: it’s cross-entropy with target \(p_T\).

Step 2. With \(u=z^{(s)}/T\): \(\nabla_u=q_T-p_T\) (Session 48, step 2). Chain rule: \(\nabla_{z^{(s)}}=\frac1T(q_T-p_T)\).

Step 3. For large \(T\), \(e^{z/T}\approx1+z/T\), so \(q_{T,c}\approx\frac1C+\frac{z^{(s)}_c-\bar z^{(s)}}{CT}\), and similarly for \(p_T\).

Step 4. Then \(\nabla_{z^{(s)}_c}\approx\frac1T\cdot\frac{(z^{(s)}_c-\bar z^{(s)})-(z^{(t)}_c-\bar z^{(t)})}{CT}=\frac{1}{CT^2}\big[(z^{(s)}_c-\bar z^{(s)})-(z^{(t)}_c-\bar z^{(t)})\big]\).

Step 5. The gradient shrinks like \(1/T^2\). Multiplying the distillation loss by \(T^2\) keeps its gradient scale roughly independent of \(T\), so mixing it with the hard-label loss doesn’t need retuning when \(T\) changes.

Step 6. Bonus: at high \(T\) the gradient is proportional to the difference in centered logits, so distillation approaches matching logits by squared error.

⚙️ Algorithm: distillation loss
Input: student logits \(Z^{(s)}\), teacher logits \(Z^{(t)}\) (no gradient), labels \(y\), \(T\), \(\alpha\)
\(\log q_T\gets\operatorname{log\_softmax}(Z^{(s)}/T)\); \(p_T\gets\operatorname{softmax}(Z^{(t)}/T)\)
\(L_{\text{KD}}\gets T^2\cdot\operatorname{mean}_i\sum_cp_{T,ic}(\log p_{T,ic}-\log q_{T,ic})\)
\(L\gets\alpha L_{\text{KD}}+(1-\alpha)\operatorname{CE}(Z^{(s)},y)\)

Temperature comparison:

def distillation_gradient_norm(
    teacher_logits,
    initial_student_logits,
    temperature,
    apply_t_squared,
):
    student = (
        initial_student_logits.detach()
        .clone()
        .requires_grad_()
    )

    teacher_probabilities = F.softmax(
        teacher_logits / temperature,
        dim=-1,
    ).detach()

    student_log_probabilities = F.log_softmax(
        student / temperature,
        dim=-1,
    )

    loss = F.kl_div(
        student_log_probabilities,
        teacher_probabilities,
        reduction="batchmean",
    )

    if apply_t_squared:
        loss = temperature**2 * loss

    gradient = torch.autograd.grad(
        loss,
        student,
    )[0]

    return gradient.norm()

At a fixed temperature:

\[L_{\mathrm{scaled}}=T^2L_{\mathrm{raw}}\]

so:

\[\nabla L_{\mathrm{scaled}} = T^2\nabla L_{\mathrm{raw}}\]

At \(T=4\), the exact gradient-norm ratio is therefore:

\[T^2=16\]

Multiplying by a positive constant does not change the minimizer. Both losses are minimized when:

\[q_T=p_T\]

The correction changes optimization scale, not the target distribution.

Without detachment, autograd differentiates through the teacher probabilities. If teacher and student are optimized together, the teacher can move toward the student, reducing KL without the student actually learning the intended target. It also retains the teacher computation graph, increasing memory and communication costs.

In an offline distillation pipeline, storing probabilities for a large vocabulary is expensive:

\[O(BTC)\]

Practical alternatives include storing teacher logits only for selected top-\(k\) classes, running the teacher online under torch.no_grad(), or distilling sequence-level behavior rather than the full token distribution.
