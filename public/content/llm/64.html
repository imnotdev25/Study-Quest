🚀 Starting point

A value function \(V(s)\) predicts the expected future return from state \(s\). The TD error \(\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)\) is the surprise: what actually happened over one step, plus the predicted future, minus what we predicted. GAE averages these surprises over many steps to estimate how much better an action was than expected.

Monte Carlo return from time \(t\) is:

\[G_t=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k}\]

It is unbiased when episodes are complete, but it can have high variance.

One-step temporal-difference error is:

\[\delta_t = r_t+\gamma(1-d_t)V(s_{t+1})-V(s_t)\]

where \(d_t=1\) means a genuine terminal transition. The factor \(1-d_t\) prevents bootstrapping beyond a terminal state.

Generalized Advantage Estimation uses:

\[A_t^{\mathrm{GAE}} = \delta_t+ \gamma\lambda(1-d_t)A_{t+1}^{\mathrm{GAE}}\]

Compute it backward through time.

For a batch of trajectories:

\[r,V,A,d\in\mathbb{R}^{B\times T}\]

while values commonly include one additional bootstrap value:

\[V_{\text{all}}\in\mathbb{R}^{B\times(T+1)}\]

The value-function target is:

\[\hat G_t=A_t+V(s_t)\]

Interpretation of \(\lambda\):

  • \(\lambda=0\): one-step TD advantage; lower variance, more bootstrap bias.

  • \(\lambda\approx1\): long-horizon return; lower bootstrap bias, higher variance.

A time-limit truncation is not necessarily a terminal state. Incorrectly setting done=True at every rollout boundary discards valid bootstrap information.

✏️ Derivation: from TD errors to GAE

Step 1. \(n\)-step advantage: \(A^{(n)}_t=r_t+\gamma r_{t+1}+\dots+\gamma^{n-1}r_{t+n-1}+\gamma^nV(s_{t+n})-V(s_t)\).

Step 2. Telescoping: substituting \(\delta_{t+k}\) gives \(A^{(n)}_t=\sum_{k=0}^{n-1}\gamma^k\delta_{t+k}\), since every intermediate \(V\) appears once with \(+\) and once with \(-\).

Step 3. GAE is the exponentially weighted mix: \(A^{\mathrm{GAE}}_t=(1-\lambda)\sum_{n\ge1}\lambda^{n-1}A^{(n)}_t\).

Step 4. Swap the sums: \(\delta_{t+k}\) appears in every \(A^{(n)}\) with \(n>k\), with total weight \((1-\lambda)\sum_{n>k}\lambda^{n-1}=\lambda^k\). So \(A^{\mathrm{GAE}}_t=\sum_k(\gamma\lambda)^k\delta_{t+k}\).

Step 5. Recursive form: \(A_t=\delta_t+\gamma\lambda(1-d_t)A_{t+1}\). \(\lambda=0\) gives \(\delta_t\) (low variance, biased by \(V\)), and \(\lambda=1\) gives \(G_t-V(s_t)\) (unbiased, high variance).

Step 6. The factor \((1-d_t)\) stops both bootstrapping and recursion at a true terminal step.

⚙️ Algorithm: GAE, computed backward
Input: rewards \(r_{0:T-1}\), values \(V_{0:T}\), dones \(d_{0:T-1}\), \(\gamma,\lambda\)
\(A\gets0\)
for \(t=T-1\) down to \(0\) do
\(\delta\gets r_t+\gamma(1-d_t)V_{t+1}-V_t\)
\(A\gets\delta+\gamma\lambda(1-d_t)A\); \(A_t\gets A\)
end
critic targets \(\hat R_t\gets A_t+V_t\)

Solution — open after attempting

def compute_gae(
    rewards,
    values,
    terminated,
    gamma,
    gae_lambda,
):
    B, T = rewards.shape

    advantages = torch.zeros_like(rewards)
    next_advantage = torch.zeros(
        B,
        dtype=rewards.dtype,
        device=rewards.device,
    )

    for t in reversed(range(T)):
        nonterminal = (
            ~terminated[:, t]
        ).to(rewards.dtype)

        delta = (
            rewards[:, t]
            + gamma
            * nonterminal
            * values[:, t + 1]
            - values[:, t]
        )

        next_advantage = (
            delta
            + gamma
            * gae_lambda
            * nonterminal
            * next_advantage
        )

        advantages[:, t] = next_advantage

    returns = advantages + values[:, :-1]
    return advantages, returns

For trajectory 0, the final transition is terminal:

\[1-d_{T-1}=0\]

Therefore:

\[\delta_{T-1} = r_{T-1}-V(s_{T-1})\]

and values[0, -1] is ignored.

Trajectory 1 is truncated but not terminal, so:

\[\delta_{T-1} = r_{T-1} +\gamma V(s_T) -V(s_{T-1})\]

Its bootstrap value matters.

The truncation bug changes the final TD error. Because GAE recursively includes later advantages:

\[A_t=\delta_t+\gamma\lambda A_{t+1}\]

that final error propagates backward, decaying approximately by a factor of \(\gamma\lambda\) at each step.

  2. It becomes: \[A_t=\delta_t\] the one-step TD error.

  3. No. The nonterminal factor becomes zero, cutting the recurrence at the terminal transition.

  5. Advantage normalization rescales the actor’s update for optimization stability. Value targets retain the reward scale because the critic must predict returns in that scale.
