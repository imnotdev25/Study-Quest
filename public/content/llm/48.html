🚀 Starting point

BERT (Devlin et al., 2018) is an encoder-only Transformer with no causal mask. Next-token prediction is impossible when every token can see the answer, so it’s trained by masked language modeling (MLM): hide 15% of tokens and predict them from both sides. BERT-base: 12 layers, \(D=768\), 12 heads, 110M parameters. BERT-large: 24 layers, \(D=1024\), 340M.

Masked language modeling: predict hidden tokens from context on both sides.

✏️ Derivation: the MLM loss and the 80/10/10 rule

Step 1. Choose a random set \(\mathcal M\) of about 15% of positions. Corrupt the input to \(\tilde x\), run the encoder, and get logits \(Z_t\) at every position.

Step 2. Loss = categorical NLL (Part 0), only over masked positions: \(L_{\text{MLM}}=-\frac{1}{|\mathcal M|}\sum_{t\in\mathcal M}\log p_\theta(x_t\mid\tilde x)\).

Step 3. If every chosen token became [MASK], the model would learn features only for [MASK] positions, yet [MASK] never appears at fine-tuning time. So of the chosen tokens: 80% become [MASK], 10% a random token, 10% stay unchanged.

Step 4. Because unchanged and random tokens are also predicted, the model can’t trust any visible token blindly, so it must build a good representation of every position.

Step 5. Signal per sequence: only 15% of positions produce a loss, versus 100% for next-token prediction. That’s MLM’s main inefficiency.

Step 6. BERT also used next-sentence prediction, a binary loss on [CLS]. RoBERTa (2019) showed removing it, training longer on 10\(\times\) more data, and re-sampling the mask every epoch (dynamic masking) works better.

✏️ Derivation: ELECTRA: a loss on every token

Step 1. A small generator \(G\) fills masked positions with plausible samples, giving \(\hat x\).

Step 2. The discriminator \(D\) predicts, for every position, whether the token was replaced: a Bernoulli output \(D(\hat x,t)=\sigma(z_t)\).

Step 3. Loss: binary cross-entropy (Part 0) summed over all \(T\) positions: \(L_D=\sum_t\big[\softplus(z_t)-y_tz_t\big]\), with \(y_t=\mathbb 1[\hat x_t\ne x_t]\).

Step 4. Total \(L=L_{\text{MLM}}(G)+\lambda L_D\) with \(\lambda=50\) in the paper. All \(T\) positions now give signal, which is why ELECTRA matches RoBERTa with a fraction of the compute.

ELECTRA: the discriminator gets a binary label at every position, not just the 15% that were masked.

⚙️ Algorithm: MLM masking
Input: token ids \(x_{1:T}\), mask rate \(0.15\)
\(\mathcal M\gets\) random 15% of positions (excluding special tokens)
for \(t\in\mathcal M\) do
with prob. 0.8: \(\tilde x_t\gets\texttt{[MASK]}\); with prob. 0.1: \(\tilde x_t\gets\) random token; else \(\tilde x_t\gets x_t\)
end
labels \(\gets x_t\) for \(t\in\mathcal M\), \(-100\) elsewhere; loss \(=\) cross-entropy on labels
