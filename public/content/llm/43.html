🚀 Starting point

An embedding is a lookup: token \(k\) is mapped to row \(E_k\) of a table \(E\in\mathbb R^{V\times D}\). Lookup is the same as multiplying a one-hot vector by \(E\): \(E_k=\onehot(k)^\top E\). Weight tying reuses \(E\) as the output layer, so logits are \(Z=HE^\top\), each logit being a dot product with a token’s embedding.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. When one tensor influences the loss through two branches, how are its gradients combined?

  2. Why can a global gradient norm hide a broken parameter path?

An embedding table is:

\[E\in\mathbb{R}^{V\times D}\]

where \(V\) is vocabulary size and \(D\) is model dimension. Token IDs:

\[X\in\{0,\ldots,V-1\}^{B\times T}\]

perform row lookups:

\[H=E[X]\in\mathbb{R}^{B\times T\times D}\]

If token \(k\) occurs several times, all occurrences contribute to the same embedding row:

\[\frac{\partial L}{\partial E_k} = \sum_{(b,t):X_{bt}=k} \frac{\partial L}{\partial H_{bt}}\]

Language models often tie the input embedding and output projection weights:

\[Z=HE^\top \in\mathbb{R}^{B\times T\times V}\]

Now \(E\) influences the loss through two paths:

  1. Input path: \(E\rightarrow H\rightarrow Z\rightarrow L\)

  2. Output path: \(E\rightarrow Z\rightarrow L\)

Therefore:

\[\frac{\partial L}{\partial E} = \left.\frac{\partial L}{\partial E}\right|_{\text{input}} + \left.\frac{\partial L}{\partial E}\right|_{\text{output}}\]

An embedding row absent from the input has zero input-path gradient. But it may still receive output-path gradient because every vocabulary logit participates in softmax.

Weight tying saves roughly \(VD\) parameters and forces input and output token representations to share geometry, but it also makes gradient debugging less obvious.

✏️ Derivation: gradients of a (tied) embedding

Step 1. \(H_{bt}=\onehot(X_{bt})^\top E\), so \(\frac{\partial H_{bt}}{\partial E_k}=\mathbb 1[X_{bt}=k]\,I\).

Step 2. Sum over all positions (branching rule): \(\frac{\partial L}{\partial E_k}=\sum_{(b,t):X_{bt}=k}\frac{\partial L}{\partial H_{bt}}\). A token that appears 3 times gets 3 contributions: a scatter-add, not an overwrite.

Step 3. Rows of tokens not in the batch get exactly 0 from the input side.

Step 4. Tied output: \(Z=HE^\top\) with \(\Delta=\partial L/\partial Z\) gives \(\frac{\partial L}{\partial E}\Big|_{\text{out}}=\Delta^\top H\in\mathbb R^{V\times D}\). Every row gets a gradient here, because softmax touches all \(V\) logits.

Step 5. Total for a tied matrix: \(\nabla E=\Delta^\top H_{\text{final}}+\text{scatter-add}\big(\tfrac{\partial L}{\partial H_{\text{input}}}\big)\). Both paths add into one tensor.

Step 6. Tying saves \(VD\) parameters: for \(V=50{,}000\), \(D=4096\), that’s 205M.

⚙️ Algorithm: embedding backward with tying
Input: token ids \(X\), table \(E\), upstream at the input \(\bar H_{\text{in}}\), output-logit gradient \(\Delta\), final hidden states \(H\)
\(\nabla E\gets\Delta^\top H\) ▷ output projection path
for each position \((b,t)\) do
\(\nabla E[X_{bt}]\gets\nabla E[X_{bt}]+\bar H_{\text{in},bt}\) ▷ index_add_, repeats accumulate
end

Solution — open after attempting

def tied_loss(E, input_path=True, output_path=True):
    lookup_weight = E if input_path else E.detach()
    output_weight = E if output_path else E.detach()

    hidden = lookup_weight[token_ids]
    logits = hidden @ output_weight.T

    return F.cross_entropy(
        logits.reshape(B * T, V),
        targets.reshape(B * T),
    )


full_loss = tied_loss(
    E,
    input_path=True,
    output_path=True,
)

full_gradient = torch.autograd.grad(
    full_loss, E
)[0]

input_loss = tied_loss(
    E,
    input_path=True,
    output_path=False,
)

input_gradient = torch.autograd.grad(
    input_loss, E
)[0]

output_loss = tied_loss(
    E,
    input_path=False,
    output_path=True,
)

output_gradient = torch.autograd.grad(
    output_loss, E
)[0]

combined_gradient = input_gradient + output_gradient

for token in range(V):
    count = (token_ids == token).sum().item()

    print(
        f"token={token}",
        f"input_count={count}",
        f"input_grad={input_gradient[token].norm().item():.6f}",
        f"output_grad={output_gradient[token].norm().item():.6f}",
        f"full_grad={full_gradient[token].norm().item():.6f}",
    )

Token 6 receives zero input-path gradient because it is never looked up:

\[\left. \frac{\partial L}{\partial E_6} \right|_{\text{input}} =0\]

It can receive a nonzero output-path gradient because cross-entropy affects every vocabulary logit:

\[\frac{\partial L}{\partial z_c} = p_c-\mathbf1[c=y]\]

For an incorrect token such as token 6, the gradient is \(p_6>0\). Gradient descent adjusts its output embedding to reduce that token’s logit in the current contexts.

The accidental detach removes the input path but leaves the output path active. The total embedding gradient therefore remains nonzero, making a simple grad is None or grad.norm() > 0 check insufficient.

Check answers:

  1. A lookup is shared use of one parameter row; reverse-mode autodiff sums every downstream contribution to that row.

  2. Every vocabulary item participates in the softmax denominator, including incorrect and absent tokens.

  3. Gradient descent should decrease its logits in those contexts.

  4. The lookup-side embedding may have been detached while the tied output projection still uses the trainable matrix.

  5. Separate input and output matrices require approximately \(2VD\) parameters; tying them requires \(VD\), saving \(VD\).

Retrieval answers:

  • Gradients from separate computation-graph branches are added.

  • A global norm can look healthy because gradients from functioning paths or later layers dominate the missing path.
