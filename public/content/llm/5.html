🚀 Starting point

Starting point. An integral is the limit of a sum. Cut \([a,b]\) into \(n\) pieces of width \(h\), take a height in each, add up \(f(x_i)h\). If the sum converges to the same number whichever heights you pick as \(h\to0\), that number is \(\int_a^bf\). In two variables, cut a region into small rectangles of area \(\Delta A\) and add \(f(x_i,y_j)\Delta A\): the result is the volume under the surface. Expectations, probabilities and normalising constants are all integrals of this kind.

A midpoint Riemann sum with 8 pieces. Its error falls like \(h^2\); left and right sums only like \(h\).

✏️ Derivation: Why the midpoint rule is an order better

Step 1. On one piece \([c-\tfrac h2,c+\tfrac h2]\), expand \(f(x)=f(c)+f'(c)(x-c)+\tfrac12f''(c)(x-c)^2+\dots\).

Step 2. Integrate: the linear term is odd around \(c\) and vanishes. \(\int f=hf(c)+\tfrac{h^3}{24}f''(c)+\dots\)

Step 3. Summing \(n=1/h\) pieces, the total error is \(\tfrac{h^2}{24}\int f''\): for \(f=x^2\), exactly \(h^2/12\), which is the \(-8.33\times10^{-4}\) at \(n=10\) in the output. A left sum keeps the linear term and has error \(O(h)\).

Iterated integrals and Fubini

For a continuous \(f\) on a region \(R\), the double integral equals an iterated one, in either order: \(\iint_Rf\,dA=\int\!\big(\int f\,dy\big)dx=\int\!\big(\int f\,dx\big)dy\). Only the limits change. On the triangle \(0\le y\le x\le1\) with \(f=xy\): \(\int_0^1\!\int_0^xxy\,dy\,dx=\int_0^1\tfrac{x^3}2dx=\tfrac18\), and \(\int_0^1\!\int_y^1xy\,dx\,dy=\int_0^1\tfrac{y(1-y^2)}2dy=\tfrac18\).

✏️ Derivation: Change of variables, and the Gaussian integral

Step 1. Under a map \(u\mapsto x=T(u)\), a small rectangle \(du_1du_2\) becomes a small parallelogram with area \(|\det J_T|\,du_1du_2\). So \(\iint f(x)\,dx=\iint f(T(u))\,|\det J_T(u)|\,du\).

Step 2. Let \(I=\int_{-\infty}^\infty e^{-x^2}dx\). Then \(I^2=\iint e^{-(x^2+y^2)}dx\,dy\).

Step 3. Polar coordinates, \(|\det J|=r\): \(I^2=\int_0^{2\pi}\!\int_0^\infty e^{-r^2}r\,dr\,d\theta=2\pi\cdot\tfrac12=\pi\).

Step 4. \(\boxed{\int e^{-x^2}dx=\sqrt\pi}\). Substituting \(x=t/\sqrt{2\sigma^2}\) gives the normal density’s constant \(1/\sqrt{2\pi\sigma^2}\). The same computation gives \(P(X^2+Y^2<1)=\int_0^1re^{-r^2/2}dr=1-e^{-1/2}\) for two independent standard normals.

Monte Carlo integration. \(\int_Rf=|R|\,\mathbb E[f(U)]\) for \(U\) uniform on \(R\), so averaging \(f\) at random points estimates any integral, with error \(\propto1/\sqrt N\) in any dimension. Grids need \(n^d\) points; that is why every high-dimensional expectation in ML (losses, policy gradients) is estimated by sampling.

"""Math I: Riemann sums, double integrals, Fubini, polar change of variables, Monte Carlo."""
import numpy as np

rng = np.random.default_rng(0)

# 1. From partitions to area: integral of x^2 on [0, 1] is 1/3.
f = lambda x: x**2
print("[riemann] n       left error   right error  midpoint error")
for n in (10, 100, 1000):
    x, h = np.linspace(0, 1, n + 1), 1 / n
    L, R, M = (f(x[:-1]) * h).sum(), (f(x[1:]) * h).sum(), (f((x[:-1] + x[1:]) / 2) * h).sum()
    print(f"[riemann] {n:5d}   {L - 1/3:+.2e}    {R - 1/3:+.2e}    {M - 1/3:+.2e}")

# 2. Volume: double midpoint sum of f(x, y) = x y over the unit square (exact 1/4).
n = 400
c = (np.arange(n) + 0.5) / n
Xg, Yg = np.meshgrid(c, c, indexing="ij")
print(f"[volume] sum over {n}x{n} cells of x*y*dA = {(Xg * Yg).sum() / n**2:.6f}  (exact 0.25)")

# 3. Fubini on the triangle 0 <= y <= x <= 1, f = x y: both orders give 1/8.
inner_y = lambda x: x * x**2 / 2                 # integral_0^x x y dy
inner_x = lambda y: y * (1 - y**2) / 2           # integral_y^1 x y dx
print(f"[fubini] dy then dx: {(inner_y(c) / n).sum():.6f}   dx then dy: {(inner_x(c) / n).sum():.6f}   (exact 0.125)")

# 4. The Gaussian integral via polar coordinates: double integral of exp(-(x^2+y^2)) = pi.
g = np.linspace(-6, 6, 1201); h = g[1] - g[0]
G = np.exp(-(g[:, None] ** 2 + g[None, :] ** 2)).sum() * h * h
print(f"[gauss] grid double integral {G:.6f} vs pi {np.pi:.6f}  -> integral of exp(-x^2) = sqrt(pi) = {np.sqrt(G):.6f}")

# 5. Monte Carlo: area of the unit disk = pi; error falls like 1/sqrt(N).
for N in (100, 10_000, 1_000_000):
    u = rng.uniform(-1, 1, (N, 2))
    est = 4 * ((u**2).sum(1) < 1).mean()
    print(f"[mc] N = {N:9,d}   pi estimate {est:.4f}   error {abs(est - np.pi):.4f}   1/sqrt(N) = {N**-0.5:.4f}")

# 6. Change of variables in a probability: P(X^2 + Y^2 < 1) for independent N(0,1) is 1 - e^{-1/2}.
z = rng.normal(size=(1_000_000, 2))
print(f"[polar] P(X^2+Y^2<1): simulated {((z**2).sum(1) < 1).mean():.4f}   exact {1 - np.exp(-0.5):.4f}")
