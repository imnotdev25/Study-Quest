🚀 Starting point

Curvature is how fast the gradient changes. Near a minimum, any smooth loss looks like a quadratic: \(L(\theta)\approx L^*+\frac12(\theta-\theta^*)^\top H(\theta-\theta^*)\), where \(H=\nabla^2L\) is the Hessian (the matrix of second derivatives). Its eigenvalues \(\lambda_i\) are the curvatures along its eigenvectors. Studying \(L=\frac12\theta^\top H\theta\) therefore tells us how gradient descent behaves near any minimum.

Now consider the quadratic loss:

\[L(\theta)=\frac{1}{2}\theta^\top H\theta\]

where:

\[\theta\in\mathbb{R}^{D}, \qquad H\in\mathbb{R}^{D\times D}\]

Its gradient is:

\[\nabla_\theta L=H\theta\]

Gradient descent updates:

\[\theta_{t+1} = \theta_t-\eta H\theta_t = (I-\eta H)\theta_t\]

Along an eigenvector of \(H\) with eigenvalue \(\lambda_i\):

\[\theta_{t+1}^{(i)} = (1-\eta\lambda_i)\theta_t^{(i)}\]

Therefore:

  • \(0<\eta\lambda_i<1\): smooth decay

  • \(1<\eta\lambda_i<2\): oscillating decay

  • \(\eta\lambda_i=2\): oscillation without decay

  • \(\eta\lambda_i>2\): divergence

Overall stability requires:

\[0<\eta<\frac{2}{\lambda_{\max}}\]

Large curvature constrains the learning rate. A badly conditioned loss has directions that learn at very different speeds—the familiar narrow-valley optimization problem.

✏️ Derivation: the learning-rate limit \(\eta<2/\lambda_{\max}\)

Step 1. Gradient of \(\frac12\theta^\top H\theta\) (symmetric \(H\)): \(\nabla L=H\theta\). Update: \(\theta_{t+1}=(I-\eta H)\theta_t\).

Step 2. Diagonalize: \(H=Q\Lambda Q^\top\) with orthonormal \(Q\). Rotate: \(\tilde\theta=Q^\top\theta\). Then \(\tilde\theta_{t+1}=(I-\eta\Lambda)\tilde\theta_t\): the coordinates are decoupled.

Step 3. Each coordinate evolves alone: \(\tilde\theta^{(i)}_t=(1-\eta\lambda_i)^t\,\tilde\theta^{(i)}_0\).

Step 4. It shrinks iff \(|1-\eta\lambda_i|<1\iff0<\eta\lambda_i<2\). This must hold for every \(i\), so \(0<\eta<2/\lambda_{\max}\).

Step 5. Best fixed step: minimize \(\max_i|1-\eta\lambda_i|\). The worst cases are the smallest and largest \(\lambda\), and they balance when \(1-\eta\lambda_{\min}=\eta\lambda_{\max}-1\), giving \(\eta^*=\frac{2}{\lambda_{\min}+\lambda_{\max}}\) and rate \(\frac{\kappa-1}{\kappa+1}\) with \(\kappa=\lambda_{\max}/\lambda_{\min}\).

Step 6. Example: \(\lambda=(1,10)\). \(\eta=0.15\): multipliers \((0.85,-0.5)\), stable with oscillation. \(\eta=0.25\): \((0.75,-1.5)\), diverges. \(\eta^*=2/11\): both have \(|\cdot|=9/11\approx0.82\) per step.

Step 7. Sum vs mean: \(L_{\text{sum}}=B\cdot L_{\text{mean}}\) has Hessian \(BH\), so switching to a sum multiplies every \(\lambda\) by \(B\), and the same \(\eta\) can now be unstable.

⚙️ Algorithm: gradient descent with a curvature check
Input: \(\theta_0\), learning rate \(\eta\), estimate of \(\lambda_{\max}\) (e.g. power iteration on Hessian–vector products)
if \(\eta\ge2/\lambda_{\max}\) then warn: this step size diverges along the sharpest direction
end
for \(t=0,1,\dots\) do
\(\theta_{t+1}\gets\theta_t-\eta\nabla L(\theta_t)\)
end

Solution — open after attempting

def train(lr, steps=15):
    theta = initial.clone().requires_grad_()
    history = []

    for step in range(steps):
        loss = 0.5 * theta @ H @ theta
        loss.backward()

        grad_norm = theta.grad.norm().item()
        history.append(
            (step, loss.item(), theta.detach().clone(), grad_norm)
        )

        with torch.no_grad():
            theta -= lr * theta.grad

        theta.grad = None

    return history

Expected dynamics:

  • lr=0.05: both coordinates decay smoothly.

  • lr=0.19: the low-curvature coordinate decays smoothly; the high-curvature coordinate oscillates while decaying.

  • lr=0.21: the high-curvature coordinate oscillates with increasing magnitude, causing divergence.

For lr=0.19:

\[1-\eta\lambda_1=1-0.19(1)=0.81\]

\[1-\eta\lambda_2=1-0.19(10)=-0.9\]

The second coordinate changes sign because its multiplier is negative.

If gradients are not cleared, each new gradient is added to all previous gradients. The update no longer represents ordinary gradient descent at the current parameter value.

Check answers:

  1. Stability requires \(\eta<2/10=0.2\). Exactly 0.2 does not converge along the high-curvature direction.

  2. The coordinate multipliers are 0.81 and -0.9.

  3. The negative gradient is a local direction. A step that is too large can cross the valley and reach a point with higher loss.

  4. Summing instead of averaging scales the gradient roughly with batch size, effectively increasing the learning rate.

  5. Otherwise, PyTorch records the update itself in the computation graph, increasing memory use and potentially causing incorrect graph dependencies.

Retrieval answers:

  1. Contributions from separate branches are added.

  2. \(\partial\tanh(h)/\partial h=1-\tanh^2(h)\).
