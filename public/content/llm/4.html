🚀 Starting point

Starting point. For a scalar \(L\) and a matrix \(X\), \(\partial L/\partial X\) is the matrix of the same shape with entries \(\partial L/\partial X_{ij}\). The fastest way to derive any identity is the differential: write \(dL\) to first order, massage it into \(dL=\operatorname{tr}(G^\top dX)=\sum_{ij}G_{ij}\,dX_{ij}\), and read off \(\partial L/\partial X=G\).

\(L\) \(\partial L/\partial(\cdot)\)
\(a^\top Xb\) \(ab^\top\)
\(x^\top Ax\) \((A+A^\top)x\) (\(=2Ax\) if symmetric)
\(\operatorname{tr}(AXB)\) \(A^\top B^\top\)
\(\log\det S\) \(S^{-\top}\)
\(\operatorname{tr}(S^{-1}A)\) \(-S^{-\top}A^\top S^{-\top}\)
\(\lVert XW-Y\rVert_F^2\) \(2X^\top(XW-Y)\) (w.r.t. \(W\))
✏️ Derivation: Three identities by differentials

Step 1. \(\operatorname{tr}(AXB)\): \(d\operatorname{tr}(AXB)=\operatorname{tr}(A\,dX\,B)=\operatorname{tr}(BA\,dX)\) (cyclic trace) \(=\operatorname{tr}((A^\top B^\top)^\top dX)\). So the gradient is \(A^\top B^\top\).

Step 2. \(\lVert XW-Y\rVert_F^2=\operatorname{tr}(R^\top R)\) with \(R=XW-Y\): \(d=2\operatorname{tr}(R^\top dR)=2\operatorname{tr}(R^\top X\,dW)\), gradient \(2X^\top R\). Setting it to zero gives the normal equations \(X^\top XW=X^\top Y\).

Step 3. \(\log\det S\): \(d\log\det S=\operatorname{tr}(S^{-1}dS)\) (Jacobi’s formula), gradient \(S^{-\top}\). And from \(S^{-1}S=I\): \(d(S^{-1})=-S^{-1}\,dS\,S^{-1}\), which gives the last identity. These two are the gradient of the Gaussian log-likelihood with respect to its covariance.

"""Math I: matrix calculus identities, each checked against autograd."""
import torch

torch.manual_seed(0)
D = torch.float64


def grad_of(fn, X):
    X = X.clone().requires_grad_(True)
    fn(X).backward()
    return X.grad


n, m = 4, 3
a, b, x = torch.randn(n, dtype=D), torch.randn(m, dtype=D), torch.randn(n, dtype=D)
X = torch.randn(n, m, dtype=D)
A = torch.randn(n, n, dtype=D)
B = torch.randn(m, n, dtype=D)
S = torch.randn(n, n, dtype=D); S = S @ S.T + n * torch.eye(n, dtype=D)       # symmetric positive definite
Xd, Y, W = torch.randn(20, n, dtype=D), torch.randn(20, 2, dtype=D), torch.randn(n, 2, dtype=D)

checks = {
    "d(a^T X b)/dX       = a b^T": (grad_of(lambda X: a @ X @ b, X), torch.outer(a, b)),
    "d(x^T A x)/dx       = (A + A^T) x": (grad_of(lambda x: x @ A @ x, x), (A + A.T) @ x),
    "d tr(A X B)/dX      = A^T B^T": (grad_of(lambda X: torch.trace(A @ X @ B), X), A.T @ B.T),
    "d log det S/dS      = S^-T": (grad_of(torch.logdet, S), torch.linalg.inv(S).T),
    "d tr(S^-1 A)/dS     = -S^-T A^T S^-T": (grad_of(lambda S: torch.trace(torch.linalg.inv(S) @ A), S),
                                             -torch.linalg.inv(S).T @ A.T @ torch.linalg.inv(S).T),
    "d |XW - Y|_F^2/dW   = 2 X^T (XW - Y)": (grad_of(lambda W: ((Xd @ W - Y) ** 2).sum(), W), 2 * Xd.T @ (Xd @ W - Y)),
}
for name, (auto, formula) in checks.items():
    print(f"[matcalc] {name:38s} {torch.allclose(auto, formula)}")

z = torch.randn(5, dtype=D)
p = z.softmax(0)
Jsm = torch.autograd.functional.jacobian(lambda z: z.softmax(0), z)
print(f"[matcalc] softmax Jacobian = diag(p) - p p^T       {torch.allclose(Jsm, torch.diag(p) - torch.outer(p, p))}")

# Setting the least-squares gradient to zero gives the normal equations X^T X W = X^T Y.
W_star = torch.linalg.solve(Xd.T @ Xd, Xd.T @ Y)
print(f"[lstsq] normal equations == torch.linalg.lstsq: {torch.allclose(W_star, torch.linalg.lstsq(Xd, Y).solution)}, "
      f"gradient there {grad_of(lambda W: ((Xd @ W - Y) ** 2).sum(), W_star).abs().max():.1e}")

[matcalc] d tr(A X B)/dX      = A^T B^T          True
[matcalc] d log det S/dS      = S^-T             True
