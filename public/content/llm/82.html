🚀 Starting point

Calibration: a model is calibrated if, among predictions made with confidence 0.8, about 80% are right. ECE measures the average gap between confidence and accuracy across confidence bins. Temperature scaling divides all logits by one learned \(T>0\): it softens (\(T>1\)) or sharpens (\(T<1\)) confidence without changing which class is predicted.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why can multiplying logits change selective coverage without changing top-1 accuracy?

  2. Why must selective risk be reported together with coverage?

A classifier is calibrated when predictions made with confidence \(q\) are correct approximately \(q\) of the time:

\[P(Y=\hat Y\mid S=q)\approx q\]

For logits:

\[Z\in\mathbb{R}^{N\times C}\]

define:

\[p_i=\operatorname{softmax}(Z_i),\qquad \hat y_i=\arg\max_c p_{ic},\qquad s_i=\max_c p_{ic}\]

Expected Calibration Error partitions confidence into \(B\) bins:

\[\operatorname{ECE} = \sum_{b=1}^{B} \frac{|I_b|}{N} \left| \operatorname{acc}(I_b) - \operatorname{conf}(I_b) \right|\]

where:

\[\operatorname{acc}(I_b) = \frac1{|I_b|} \sum_{i\in I_b}\mathbf1[\hat y_i=y_i]\]

\[\operatorname{conf}(I_b) = \frac1{|I_b|} \sum_{i\in I_b}s_i\]

Temperature scaling learns one positive scalar \(T\):

\[p_i(T)=\operatorname{softmax}\left(\frac{Z_i}{T}\right)\]

  • \(T>1\): softer, less confident probabilities.

  • \(T<1\): sharper, more confident probabilities.

  • Positive \(T\) preserves class ranking and therefore top-1 predictions.

Fit \(T\) on calibration data by minimizing negative log-likelihood, then evaluate it once on untouched test data. ECE itself is bin-dependent and nondifferentiable, so it is usually a diagnostic rather than the fitting objective.

✏️ Derivation: fitting the temperature

Step 1. Calibrated probabilities \(p=\operatorname{softmax}(z/T)\). Dividing by \(T>0\) doesn’t change the argmax, so accuracy is untouched.

Step 2. Fit \(T\) by minimizing validation NLL: \(\ell(T)=\LSE(z/T)-z_y/T\).

Step 3. Let \(u=z/T\), so \(\frac{\partial u_c}{\partial T}=-\frac{z_c}{T^2}\). With \(\frac{\partial\ell}{\partial u}=p-\onehot(y)\): \(\frac{d\ell}{dT}=\sum_c(p_c-\mathbb 1[c=y])\Big(-\frac{z_c}{T^2}\Big)=\frac{z_y-\mathbb E_p[z]}{T^2}\).

Step 4. The optimum sets the average of \(z_y-\mathbb E_p[z]\) over the validation set to 0: the true-class logit equals, on average, the model’s own expected logit. Overconfident models have \(z_y<\mathbb E_p[z]\) on average (the confident wrong answers), so \(d\ell/dT<0\) at \(T=1\) and \(T\) grows.

Step 5. ECE: \(\sum_b\frac{|I_b|}{N}|\operatorname{acc}_b-\operatorname{conf}_b|\). Example: two equal bins with (conf, acc) \((0.9,0.7)\) and \((0.6,0.6)\): ECE \(=0.5(0.2)+0.5(0)=0.10\).

⚙️ Algorithm: temperature scaling
Input: validation logits \(Z\), labels \(y\) (not used in training)
\(\log T\gets0\) ▷ optimize \(\log T\) so \(T>0\)
repeat
\(L\gets\operatorname{mean}_i\big(\LSE(Z_i/T)-Z_{i,y_i}/T\big)\); step on \(\log T\) (e.g. LBFGS)
until converged
apply \(\operatorname{softmax}(Z/T)\) at test time; report ECE before and after

ECE:

def expected_calibration_error(
    logits,
    labels,
    num_bins=10,
):
    probabilities = F.softmax(
        logits,
        dim=-1,
    )

    confidence, predictions = probabilities.max(
        dim=-1
    )

    correct = predictions.eq(labels).to(logits.dtype)

    edges = torch.linspace(
        0.0,
        1.0,
        num_bins + 1,
        device=logits.device,
    )

    bin_ids = torch.bucketize(
        confidence,
        edges[1:-1],
    )

    counts = torch.bincount(
        bin_ids,
        minlength=num_bins,
    ).to(logits.dtype)

    confidence_sum = torch.zeros(
        num_bins,
        device=logits.device,
    )

    accuracy_sum = torch.zeros_like(
        confidence_sum
    )

    confidence_sum.scatter_add_(
        dim=0,
        index=bin_ids,
        src=confidence,
    )

    accuracy_sum.scatter_add_(
        dim=0,
        index=bin_ids,
        src=correct,
    )

    safe_counts = counts.clamp_min(1.0)

    bin_confidence = (
        confidence_sum / safe_counts
    )

    bin_accuracy = (
        accuracy_sum / safe_counts
    )

    bin_weights = (
        counts / logits.shape[0]
    )

    ece = (
        bin_weights
        * (bin_accuracy - bin_confidence).abs()
    ).sum()

    return ece, bin_accuracy, bin_confidence, counts

The reported logits were constructed as:

\[Z_{\text{model}}=2.5Z_{\text{true}}\]

Dividing by \(T\approx2.5\) approximately recovers the data-generating probabilities:

\[\frac{Z_{\text{model}}}{2.5} = Z_{\text{true}}\]

Accuracy stays unchanged because division by a positive scalar preserves logit ordering. Confidence and threshold-based behavior do change.

ECE has several limitations:

  • it depends on the number and placement of bins;

  • large groups can hide severe errors in small subgroups;

  • positive and negative calibration errors within one bin are averaged;

  • a finite sample may leave high-confidence bins sparse;

  • low ECE says nothing about accuracy or distribution shift.

For safety-oriented evaluation, report reliability by important context and entity type, not only one aggregate ECE.

Check answers:

  1. Dividing every class logit by the same positive number preserves their ordering and argmax.

  2. All scaled logits approach zero, so softmax approaches the uniform distribution \(1/C\).

  3. Aggregate bins can hide subgroup, local, and high-confidence miscalibration.

  4. ECE is a discretized approximation whose result depends on bin boundaries and sample counts.

  5. Selecting \(T\) on the test set adapts the system to test labels, leaking evaluation information and producing optimistic calibration estimates.

Retrieval answers:

  • Logit scaling changes probability sharpness and therefore threshold crossings without changing the largest logit.

  • Selective risk alone rewards excessive abstention; coverage states how often the system actually answers.
