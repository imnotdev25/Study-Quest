🚀 Starting point

A language model assigns a probability to a whole token sequence by the chain rule of probability: \(p(x_1,\dots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t})\). The model only ever predicts one next token at a time. Training maximizes this likelihood on real text. The loss is the NLL from Part 0 with a categorical distribution over \(V\) tokens, applied at every position.

Total: 20 minutes

For token IDs:

\[X\in\mathbb{N}^{B\times T}\]

a causal language model produces:

\[Z\in\mathbb{R}^{B\times T\times V}\]

where \(V\) is vocabulary size. The logits at position \(t\) predict token \(x_{t+1}\):

\[p(x_{t+1}\mid x_{\leq t}) = \operatorname{softmax}(Z_t)\]

Therefore, training aligns:

\[Z[:,0:T-1,:] \quad\text{with}\quad X[:,1:T]\]

For valid target positions \(\mathcal V\):

\[L= -\frac{1}{|\mathcal V|} \sum_{(b,t)\in\mathcal V} \log p(x_{b,t+1}\mid x_{b,\leq t})\]

Padding and excluded tokens receive an ignore label, conventionally -100, and contribute neither loss nor gradient.

Practical concerns:

  • Unshifted labels let the model learn to reproduce the token already present in its residual stream.

  • Some model libraries shift labels internally; manually shifting again creates a double-shift bug.

  • cross_entropy operates directly on logits using a stable logsumexp.

  • Perplexity is \(\exp(L)\), but comparisons require compatible tokenization and masking.

✏️ Derivation: the next-token loss and the shift

Step 1. Log of the chain rule: \(\log p(x)=\sum_{t}\log p_\theta(x_{t+1}\mid x_{\le t})\). The product becomes a sum, one term per predicted token.

Step 2. The logits at position \(t\) have seen \(x_0,\dots,x_t\) (causal mask) and predict \(x_{t+1}\). So logits \(Z[:,t]\) pair with label \(X[:,t+1]\): logits[:, :-1] with tokens[:, 1:].

Step 3. Per-position loss: \(\ell_{bt}=\LSE(Z_{bt})-Z_{bt,\,x_{b,t+1}}\) (Part 0).

Step 4. Mask \(M_{bt}=1\) only where the label is real (not padding). Loss \(L=\frac{\sum M_{bt}\ell_{bt}}{\sum M_{bt}}\).

Step 5. Gradient at the logits: \(\frac{\partial L}{\partial Z_{bt}}=\frac{M_{bt}}{\sum M}\big(\operatorname{softmax}(Z_{bt})-\onehot(x_{b,t+1})\big)\). Masked positions get exactly 0.

Step 6. Without the shift: pairing \(Z[:,t]\) with \(X[:,t]\) asks the model to predict a token it can already see. Loss drops fast and the model learns nothing useful.

⚙️ Algorithm: causal language-model loss
Input: token ids \(X\in\mathbb N^{B\times T}\), pad mask
\(Z\gets f_\theta(X)\) ▷ \(B\times T\times V\)
\(\text{logits}\gets Z[:,0{:}T-1]\); \(\text{labels}\gets X[:,1{:}T]\); \(M\gets\) mask of \(\text{labels}\)
\(\ell\gets\LSE(\text{logits})-\text{logits}[\text{labels}]\) ▷ cross_entropy(..., reduction="none")
\(L\gets\sum M\ell/\sum M\)

Solution — open after attempting

shift_logits = logits[:, :-1, :]
shift_targets = input_ids[:, 1:]

shift_targets = shift_targets.clone()
shift_targets = shift_targets.masked_fill(
    shift_targets.eq(pad_id),
    ignore_index,
)

flat_logits = shift_logits.reshape(-1, V)
flat_targets = shift_targets.reshape(-1)

loss_sum = F.cross_entropy(
    flat_logits,
    flat_targets,
    ignore_index=ignore_index,
    reduction="sum",
)

valid_tokens = shift_targets.ne(ignore_index).sum()
loss = loss_sum / valid_tokens

There are six valid targets:

Row 1: 4, 2, 7, 3
Row 2: 8, 5

The last logit position is unused because there is no next token inside the supplied sequence. Ignored targets also produce zero gradients.

With unshifted labels, the representation at position \(t\) already includes the embedding of \(x_t\). The model can learn an identity-like mapping from that embedding to the same token, producing deceptively low training loss without learning next-token prediction.

Check answers:

  1. The first token provides context but has no previous position predicting it; the last input position has no subsequent target inside the sequence.

  2. Exactly zero.

  3. Approximately:

    \[e^2\approx7.39\]

  4. Check whether logits and labels were left unshifted. Also check whether a framework that shifts internally received already-shifted labels.

  5. Per-sequence averaging gives short and long sequences equal total weight. Token averaging gives every valid token equal weight, so longer sequences contribute more.

Retrieval answers:

\[U=X+\operatorname{MHA}(\operatorname{LN}_1(X))\]

\[Y=U+\operatorname{MLP}(\operatorname{LN}_2(U))\]

Attention mixes information across positions; the MLP transforms each position independently across features.
