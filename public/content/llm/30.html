🚀 Starting point

Permutation equivariance: a function \(f\) is equivariant if shuffling the inputs just shuffles the outputs the same way: \(f(PX)=Pf(X)\) for any permutation matrix \(P\). Attention without positions has this property, so “dog bites man” and “man bites dog” look the same up to order. Positional encodings add order information to each token.

1. Concept refresh — 5 minutes

For input embeddings:

\[X\in\mathbb{R}^{B\times T\times D}\]

self-attention has no inherent knowledge of token order. Without positional information, unmasked attention is permutation equivariant:

\[\operatorname{Attn}(PX)=P\operatorname{Attn}(X)\]

Reordering the input tokens merely reorders the corresponding outputs.

A causal mask blocks future information, but positional information is still needed to represent order-rich relationships. A classic sinusoidal encoding is:

\[\operatorname{PE}(p,2i) = \sin\left(\frac{p}{10000^{2i/D}}\right)\]

\[\operatorname{PE}(p,2i+1) = \cos\left(\frac{p}{10000^{2i/D}}\right)\]

Its shape is:

\[\operatorname{PE}\in\mathbb{R}^{T\times D}\]

It broadcasts across the batch:

\[X_{\text{model}} = X_{\text{token}}+\operatorname{PE}[None,:,:] \in\mathbb{R}^{B\times T\times D}\]

Practical concern: incorrect position IDs frequently cause generation errors with padding, sequence packing, and KV caching.

✏️ Derivation: attention is permutation-equivariant, and sinusoids encode offsets linearly

Step 1. Inputs shuffled: \(X\to PX\). Then \(Q\to PQ\), \(K\to PK\), \(V\to PV\).

Step 2. Scores: \((PQ)(PK)^\top=P\,QK^\top P^\top\): rows and columns permuted the same way.

Step 3. Row-wise softmax commutes with that: \(\operatorname{softmax}(PSP^\top)=P\operatorname{softmax}(S)P^\top\), since each row’s entries are just reordered.

Step 4. Output: \(PAP^\top\cdot PV=PA(P^\top P)V=PAV\), using \(P^\top P=I\). So \(\operatorname{Attn}(PX)=P\operatorname{Attn}(X)\).

Step 5. Sinusoids: for frequency \(\omega_i=10000^{-2i/D}\), the pair \(\big(\sin\omega_ip,\cos\omega_ip\big)\) at position \(p+k\) equals \(\begin{bmatrix}\cos\omega_ik&\sin\omega_ik\\-\sin\omega_ik&\cos\omega_ik\end{bmatrix}\begin{bmatrix}\sin\omega_ip\\\cos\omega_ip\end{bmatrix}\) (angle-addition formulas). A fixed linear map shifts any position by \(k\), so “\(k\) tokens back” is easy to learn.

Step 6. Multiple frequencies act like the hands of a clock: fast ones resolve nearby positions, slow ones distinguish far-apart ones.

⚙️ Algorithm: sinusoidal positional encoding
Input: positions \(p=0,\dots,T-1\) (offset by the cache length when decoding), width \(D\)
for \(i=0,\dots,D/2-1\) do
\(\omega_i\gets10000^{-2i/D}\)
\(\operatorname{PE}[p,2i]\gets\sin(\omega_ip)\); \(\operatorname{PE}[p,2i+1]\gets\cos(\omega_ip)\)
end
\(X\gets\operatorname{Embed}(\text{tokens})+\operatorname{PE}\)

def sinusoidal_positions(T, D, offset=0):
    assert D % 2 == 0

    positions = torch.arange(
        offset,
        offset + T,
        dtype=torch.float32,
    )[:, None]

    frequencies = torch.exp(
        -math.log(10000.0)
        * torch.arange(0, D, 2, dtype=torch.float32)
        / D
    )

    angles = positions * frequencies[None, :]

    pe = torch.zeros(T, D)
    pe[:, 0::2] = torch.sin(angles)
    pe[:, 1::2] = torch.cos(angles)

    return pe


def self_attention(x):
    q = x @ W_q
    k = x @ W_k
    v = x @ W_v

    scores = q @ k.transpose(-2, -1)
    scores = scores / math.sqrt(D)

    weights = torch.softmax(scores, dim=-1)
    return weights @ v
