🚀 Starting point

Monitoring drift: PPO needs to know how far \(\pi_\theta\) has moved from \(\pi_{\text{old}}\), measured as \(D_{\mathrm{KL}}(\pi_{\text{old}}\|\pi_\theta)\). The exact value needs the full \(V\)-way distribution at every token, which is expensive. Sampled estimators use only the log-probabilities of the tokens actually generated.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why should advantages be normalized over the complete rollout rather than separately per minibatch?

  2. What happens when a one-element minibatch is independently centered?

Let the rollout policy be \(p=\pi_{\text{old}}\), the current policy be \(q=\pi_\theta\), and:

\[a\sim p\]

For selected-action log-probabilities:

\[\ell_{\text{old}},\ell_{\text{new}} \in\mathbb{R}^{B\times T}\]

define:

\[x=\ell_{\text{new}}-\ell_{\text{old}}, \qquad r=e^x=\frac{q(a)}{p(a)}\]

A direct Monte Carlo estimator of the reverse KL is:

\[k_1=-x=\log p(a)-\log q(a)\]

because:

\[\mathbb E_{a\sim p}[k_1] = D_{\mathrm{KL}}(p\|q)\]

Individual values—and even a small-batch mean—can be negative.

A pointwise nonnegative alternative is:

\[k_3=(r-1)-\log r\]

Since \(e^x\ge1+x\):

\[k_3=e^x-1-x\ge0\]

Under exact old-policy sampling:

\[\mathbb E_p[r-1]=0\]

so \(k_1\) and \(k_3\) have the same expectation. For nearby policies:

\[k_3\approx\frac{x^2}{2}\]

The exact full-distribution KL is:

\[D_{\mathrm{KL}}(p\|q) = \sum_a p(a) \left[\log p(a)-\log q(a)\right]\]

Computing it requires full [B,T,A] distributions. Sampled diagnostics need only selected-action log-probabilities, which matters for large-vocabulary LMs.

✏️ Derivation: \(k_1\) and \(k_3\): same mean, different behaviour

Samples \(a\sim p=\pi_{\text{old}}\); \(q=\pi_\theta\); \(x=\log q(a)-\log p(a)\); \(r=e^x=q(a)/p(a)\).

Step 1. \(k_1=-x\): \(\mathbb E_p[k_1]=\sum_ap(a)\log\frac{p(a)}{q(a)}=D_{\mathrm{KL}}(p\|q)\). Unbiased, but negative whenever \(q(a)>p(a)\).

Step 2. \(\mathbb E_p[r]=\sum_ap(a)\frac{q(a)}{p(a)}=\sum_aq(a)=1\), so \(\mathbb E_p[r-1]=0\).

Step 3. \(k_3=(r-1)-x\): \(\mathbb E[k_3]=0+\mathbb E[k_1]=D_{\mathrm{KL}}(p\|q)\). Also unbiased.

Step 4. \(e^x\ge1+x\) for all \(x\) (the tangent line at 0 lies below a convex curve), so \(k_3=e^x-1-x\ge0\) pointwise.

Step 5. Small moves: \(e^x=1+x+\frac{x^2}{2}+\dots\), so \(k_3\approx\frac{x^2}{2}\). It’s quadratic, like the true KL, so its variance is small near \(p=q\).

Step 6. Example: \(x=0.1\): \(k_1=-0.100\), \(k_3=e^{0.1}-1.1=0.0052\).

⚙️ Algorithm: sampled PPO KL diagnostics
Input: selected-token \(\ell_{\text{new}},\ell_{\text{old}}\), mask \(M\)
\(x\gets\ell_{\text{new}}-\ell_{\text{old}}\)
\(\widehat{\mathrm{KL}}_1\gets\sum M(-x)/\sum M\); \(\widehat{\mathrm{KL}}_3\gets\sum M(e^x-1-x)/\sum M\)
log both; early-stop the epoch if \(\widehat{\mathrm{KL}}_3\) exceeds the target

with torch.no_grad():
    old_distribution = torch.distributions.Categorical(
        logits=old_logits
    )

    actions = old_distribution.sample(
        (num_samples,)
    )

    expanded_old_logp = old_logp.unsqueeze(0).expand(
        num_samples, -1, -1, -1
    )

    expanded_new_logp = new_logp.unsqueeze(0).expand(
        num_samples, -1, -1, -1
    )

    old_selected = expanded_old_logp.gather(
        dim=-1,
        index=actions.unsqueeze(-1),
    ).squeeze(-1)

    new_selected = expanded_new_logp.gather(
        dim=-1,
        index=actions.unsqueeze(-1),
    ).squeeze(-1)

    log_ratio = new_selected - old_selected
    ratio = torch.exp(log_ratio)

    k1 = -log_ratio
    k3 = ratio - 1.0 - log_ratio

    sampled_k1 = k1[:, valid_mask].mean()
    sampled_k3 = k3[:, valid_mask].mean()

    clip_fraction = (
        (ratio - 1.0).abs() > clip_epsilon
    )[:, valid_mask].float().mean()

If actions come from \(q\) while the measured term remains:

\[\log p(a)-\log q(a)\]

then:

\[\mathbb E_{a\sim q} [\log p(a)-\log q(a)] = -D_{\mathrm{KL}}(q\|p) \le0\]

The KL itself is not negative—the code is estimating the negative of the opposite KL direction.

For old-policy samples:

\[\mathbb E_p[k_3] = \mathbb E_p[r-1-\log r]\]

and:

\[\mathbb E_p[r] = \sum_a p(a)\frac{q(a)}{p(a)} = \sum_aq(a)=1\]

Therefore:

\[\mathbb E_p[k_3] = -\mathbb E_p[\log r] = D_{\mathrm{KL}}(p\|q)\]

Check answers:

  1. The old rollout policy.

  2. \(r=1\), \(k_1=0\), and \(k_3=0\).

  3. Individual log-ratio terms can be negative; only their old-policy expectation equals the nonnegative KL.

  4. Check whether actions were sampled from the new policy and whether the old/new log-ratio sign was reversed.

  5. Clip fraction observes ratios only for sampled actions. The policy can change substantially over unsampled or low-probability vocabulary entries, and PPO clipping is not a full-distribution trust-region constraint.

Retrieval answers:

  • Normalize advantages once over the complete valid rollout population; local normalization makes gradients depend on minibatch partitioning.

  • A one-element centered minibatch produces normalized advantage zero and therefore no policy-gradient contribution.
