🚀 Starting point

Selection is optimization. If a reward model scores \(R=U+\epsilon\) (true quality plus error), picking the highest-scoring of \(N\) candidates selects for high \(U\) and high \(\epsilon\). The winner’s curse: the winner’s score overstates its true quality, and the gap grows with \(N\).

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

  2. Why can a reward model’s ranking accuracy stay fixed while its score scale changes training behavior?

Suppose each prompt has \(G\) candidate responses:

\[U,R\in\mathbb{R}^{B\times G}\]

where \(U_{bg}\) is latent true quality and the reward-model score is:

\[R_{bg}=U_{bg}+\epsilon_{bg}\]

Best-of-\(N\) selects:

\[g_b^* = \arg\max_{g\le N}R_{bg}\]

Because selection explicitly maximizes \(R\), it selects both high quality and favorable reward-model error:

\[R_{b,g_b^*} = U_{b,g_b^*} + \epsilon_{b,g_b^*}\]

Typically:

\[\mathbb E[\epsilon_{b,g_b^*}]>0\]

This is the winner’s curse. As \(N\) grows:

  • selected proxy reward usually rises;

  • selected true quality may rise more slowly or plateau;

  • the proxy–true gap generally grows;

  • generated data moves farther from the reward model’s training distribution.

A reward model can therefore have good held-out pairwise accuracy but still fail under strong optimization. Standard validation measures average performance on ordinary samples; best-of-\(N\) probes performance on examples selected specifically to exploit the model’s errors.

Practical evaluation should track both the optimized reward and an independent signal: human preference, a held-out reward model, task success, or targeted safety metrics.

✏️ Derivation: the selected error is positive

Step 1. Let \(U_g,\epsilon_g\) be independent, with \(\mathbb E[\epsilon]=0\). Choose \(g^*=\arg\max_gR_g\).

Step 2. Unselected, \(\mathbb E[\epsilon_g]=0\). But \(g^*\) is more likely to be a candidate with large \(\epsilon\), since large \(\epsilon\) raises \(R\). So \(\mathbb E[\epsilon_{g^*}]>0\).

Step 3. Pure noise (\(U\) equal for all): \(\mathbb E[\epsilon_{g^*}]=\sigma\,\mathbb E[\max_{g\le N}Z_g]\) with standard normals \(Z\), about \(1.03\sigma\) at \(N=4\) and \(1.77\sigma\) at \(N=16\). An upper bound is \(\sigma\sqrt{2\ln N}\).

Step 4. So \(\mathbb E[R_{g^*}]-\mathbb E[U_{g^*}]=\mathbb E[\epsilon_{g^*}]>0\): the selected score is biased upward, and an independent judge is needed to measure the true gain.

Step 5. KL cost: best-of-\(N\) moves the output distribution by \(D_{\mathrm{KL}}=\log N-\frac{N-1}{N}\) nats from the base policy. More selection means more drift and more exploited error.

⚙️ Algorithm: best-of-\(N\) with an honest estimate
Input: prompts, policy, reward model \(\hat r\), independent judge \(u\), \(N\)
for each prompt do
sample \(N\) responses; pick \(g^*=\arg\max_g\hat r\)
record \(\hat r(g^*)\) and \(u(g^*)\) ▷ judge on the selected one only
end
report the mean of \(u\) as the gain; \(\overline{\hat r-u}\) estimates the winner’s curse

At \(N=1\), there is no selection among alternatives. The chosen reward noise is therefore ordinary zero-mean noise:

\[\mathbb E[\epsilon]\approx0\]

For \(N>1\), selection favors candidates whose proxy score is high partly because their error is positive:

\[g^*=\arg\max_g(U_g+\epsilon_g)\]

Consequently:

\[\mathbb E[\epsilon_{g^*}]>0\]

The optimized reward rises faster than latent quality because it includes this selected error.

The independent evaluator has unrelated noise:

\[R_{\text{heldout}} = U+\epsilon'\]

with:

\[\epsilon'\perp\epsilon\]

Selection based on \(\epsilon\) does not directly select positive \(\epsilon'\), so the held-out evaluator more closely tracks the selected candidate’s true-quality improvement.

The leaked evaluator reuses exactly the same error:

\[R_{\text{leaked}}=U+\epsilon=R_{\text{proxy}}\]

It therefore reproduces the optimized model’s selection bias and provides no independent evidence.

Check answers:

  1. Maximization preferentially selects candidates with positive reward-model errors.

  2. It approaches zero because proxy reward approaches true quality.

  3. Best-of-64 concentrates evaluation on extreme proxy scores, where rare modeling errors and distribution shift become important.

  4. Check whether both evaluators share weights, training labels, prompts, preprocessing, judge templates, or cached scores.

  5. Optimization changes the response distribution toward regions favored by the reward model. Evaluation must measure performance on that shifted distribution.

  • Excessive KL should increase \(\beta\), strengthening the penalty.

  • Reward scale controls the relative magnitude of policy, value, clipping, and KL terms even when ranking order is unchanged.
