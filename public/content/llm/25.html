🚀 Starting point

Momentum keeps a running sum of past gradients, \(v_t=\beta v_{t-1}+g_t\), and steps along it: \(\theta_{t+1}=\theta_t-\eta v_t\). The state \(v\) is part of the optimizer and must persist across steps. \(\beta\in[0,1)\) controls how much memory it has.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

First, retrieve from Session 3:

  1. For curvature eigenvalue \(\lambda_i\), what multiplier does plain gradient descent apply each step?

  2. Why can changing a loss from .mean() to .sum() destabilize training?

Plain SGD uses only the current gradient:

\[\theta_{t+1}=\theta_t-\eta g_t, \qquad g_t=\nabla_\theta L(\theta_t)\]

Momentum maintains a gradient accumulator:

\[v_t=\beta v_{t-1}+g_t\]

\[\theta_{t+1}=\theta_t-\eta v_t\]

For \(\theta,g,v\in\mathbb{R}^{D}\):

  • \(\eta\): learning rate

  • \(\beta\): momentum coefficient, commonly near \(0.9\)

  • \(v_t\): optimizer state with the same shape as \(\theta\)

Intuition: momentum acts like a low-pass filter. Consistent gradient directions accumulate, while rapidly changing directions partially cancel. This can accelerate movement through shallow directions of an ill-conditioned loss, although excessive momentum can produce oscillation.

Optimizer state has practical costs. Momentum adds roughly one parameter-sized state tensor; Adam generally adds two. With billions of parameters, optimizer state can consume more memory than the model weights.

✏️ Derivation: what momentum does on a constant slope and on a quadratic

Step 1. Unroll: \(v_t=g_t+\beta g_{t-1}+\beta^2g_{t-2}+\dots=\sum_{k\ge0}\beta^kg_{t-k}\).

Step 2. Constant gradient \(g\): \(v_t\to g\sum_k\beta^k=\frac{g}{1-\beta}\). The effective learning rate is \(\frac{\eta}{1-\beta}\): \(10\eta\) for \(\beta=0.9\).

Step 3. Quadratic \(L=\frac12\lambda\theta^2\), \(g_t=\lambda\theta_t\). From the update, \(v_{t-1}=(\theta_{t-1}-\theta_t)/\eta\). Substitute: \(\theta_{t+1}=\theta_t-\eta\lambda\theta_t+\beta(\theta_t-\theta_{t-1})\).

Step 4. Try \(\theta_t=r^t\): \(r^2-(1+\beta-\eta\lambda)r+\beta=0\).

Step 5. Both roots satisfy \(|r|<1\) iff \(|\beta|<1\) and \(|1+\beta-\eta\lambda|<1+\beta\) (the Jury test for quadratics), i.e. \(0<\eta\lambda<2(1+\beta)\).

Step 6. Compare: plain GD needs \(\eta\lambda<2\). With \(\beta=0.9\), momentum tolerates \(\eta\lambda<3.8\), and in flat directions it accelerates by up to \(1/(1-\beta)\).

Step 7. Why the state must persist: resetting \(v\) each step makes \(v_t=g_t\), which is plain SGD.

⚙️ Algorithm: SGD with momentum
Input: \(\theta\), \(\eta\), \(\beta\); state \(v\gets0\) created once
for each step do
\(g\gets\nabla_\theta L\)
\(v\gets\beta v+g\)
\(\theta\gets\theta-\eta v\)
end

Solution — open after attempting

def train(beta, lr=0.04, steps=50, reset_velocity=False):
    theta = initial.clone().requires_grad_()
    velocity = torch.zeros_like(theta)
    history = []

    for step in range(steps):
        loss = 0.5 * theta @ H @ theta
        loss.backward()

        if reset_velocity:
            velocity.zero_()

        with torch.no_grad():
            velocity.mul_(beta).add_(theta.grad)
            theta.add_(velocity, alpha=-lr)

        history.append({
            "step": step,
            "loss": loss.item(),
            "theta": theta.detach().clone(),
            "velocity": velocity.clone(),
        })

        theta.grad = None

    return history

The high-curvature coordinate tends to oscillate more because its gradient changes sharply as it crosses the minimum. Momentum should accelerate progress along the consistently sloped, low-curvature coordinate.

Resetting velocity makes every update:

\[v_t=\beta(0)+g_t=g_t\]

so the optimizer becomes ordinary SGD regardless of the supplied nonzero \(\beta\).

Check answers:

  1. With \(\beta=0\), \(v_t=g_t\), giving \(\theta_{t+1}=\theta_t-\eta g_t\).

  2. Momentum tracks one accumulated value per parameter element; mismatched devices or shapes make the update invalid.

  3. The limiting velocity is:

    \[v_\infty=\frac{g}{1-\beta}\]

  4. The optimizer checkpoint may be missing its momentum buffers. Scheduler and gradient-scaler state are other possibilities.

  5. One parameter-sized velocity requires approximately another 4 GB in the same precision.

Retrieval answers:

  1. The multiplier is \(1-\eta\lambda_i\).

  2. Summation scales gradients with the number of elements, effectively increasing the learning rate unless compensated.
