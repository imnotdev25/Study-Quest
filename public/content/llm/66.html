🚀 Starting point

The critic is trained by regression: predict the return target \(\hat R_t\). That’s MSE, the Gaussian NLL from Part 0. Both \(\hat R_t=A_t+V_{\text{old}}(s_t)\) and \(V_{\text{old}}\) are fixed numbers from the rollout. Only \(V_{\text{new}}\) carries gradient. Value clipping optionally limits how far \(V_{\text{new}}\) can move from \(V_{\text{old}}\) in one update.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. For which two combinations of advantage sign and probability ratio does PPO’s policy gradient become flat?

  2. Why is directly clamping the importance ratio different from PPO’s pessimistic minimum?

GAE produces a fixed critic target:

\[\hat R_t=A_t^{\text{GAE}}+V_{\text{old}}(s_t)\]

For a rollout batch:

\[V_{\text{old}},V_{\text{new}},A,\hat R \in\mathbb{R}^{B\times T}\]

The ordinary critic loss is:

\[L_V = \frac{1}{2} \left(V_{\text{new}}-\hat R\right)^2\]

Both the return target and old value prediction must be treated as fixed rollout data.

PPO implementations may restrict value-prediction movement:

\[V_{\text{clip}} = V_{\text{old}} + \operatorname{clip} \left( V_{\text{new}}-V_{\text{old}}, -\epsilon_V,\epsilon_V \right)\]

The pessimistic loss is:

\[L_V^{\text{clip}} = \frac{1}{2} \max\left[ (V_{\text{new}}-\hat R)^2, (V_{\text{clip}}-\hat R)^2 \right]\]

The max matters:

  • An excessively large beneficial movement becomes flat.

  • An excessively large harmful movement remains penalized.

  • Simply clamping \(V_{\text{new}}\) before MSE would incorrectly flatten both.

Unlike the policy ratio, value errors have reward units. Therefore \(\epsilon_V\) interacts strongly with reward scaling and normalization. Monitor value loss, explained variance, prediction scale, and value-clip fraction.

✏️ Derivation: the clipped value loss and when its gradient is zero

Step 1. Plain loss \(\frac12(V-\hat R)^2\), gradient \(V-\hat R\).

Step 2. Clipped prediction \(V_c=V_{\text{old}}+\operatorname{clip}(V-V_{\text{old}},-\epsilon,\epsilon)\). Inside the band, \(V_c=V\); outside, \(V_c\) is constant.

Step 3. Loss \(L=\frac12\max\big((V-\hat R)^2,(V_c-\hat R)^2\big)\). The max is pessimistic, like PPO’s min.

Step 4. Outside the band, if \((V_c-\hat R)^2\) is the larger term, \(L\) is constant in \(V\), so the gradient is 0. That happens when \(V\) has moved past the band boundary toward \(\hat R\): \(V\) has already moved “enough” this update.

Step 5. If \(V\) moved away from \(\hat R\), the unclipped term is larger and the full gradient pulls it back.

Step 6. Scale warning: \(\epsilon\) is in return units. With returns around 100 and \(\epsilon=0.2\), \(V\) can only move 0.2 per update, so normalize returns or scale \(\epsilon\).

⚙️ Algorithm: PPO critic loss
Input: \(V_{\text{new}}\) (with gradient), fixed \(V_{\text{old}},\hat R\), mask \(M\), \(\epsilon_v\)
\(V_c\gets V_{\text{old}}+\operatorname{clip}(V_{\text{new}}-V_{\text{old}},-\epsilon_v,\epsilon_v)\)
\(L_V\gets\frac12\sum M\max\big((V_{\text{new}}-\hat R)^2,(V_c-\hat R)^2\big)/\sum M\)

For target \(2\), prediction \(0.5\):

\[(0.5-2)^2=2.25\]

\[(0.2-2)^2=3.24\]

The clipped branch is larger and locally constant, so the gradient is zero.

For target \(2\), prediction \(-0.5\):

\[(-0.5-2)^2=6.25\]

\[(-0.2-2)^2=4.84\]

The harmful, unclipped prediction has the larger loss, so it retains a gradient toward the target.

The two negative-target cases are symmetric. Prediction \(-0.5\) is beneficial and clipped flat; prediction \(0.5\) is harmful and remains penalized.

With the broken target:

\[\hat R_{\text{bad}} = A+V_{\text{new}}\]

Therefore:

\[V_{\text{new}}-\hat R_{\text{bad}} = V_{\text{new}}-(A+V_{\text{new}}) = -A\]

The prediction cancels from the error, producing zero critic gradient. Correct targets use stored rollout values and are detached:

\[\hat R=A+V_{\text{old}}\]

Check answers:

  1. The actor maximizes a conservative improvement estimate, so it chooses the smaller objective. The critic minimizes a conservative error estimate, so it chooses the larger loss.

  2. The clipped-value branch becomes worse than the improved prediction and is selected, producing a flat region.

  3. The target may have been recomputed as advantage + current_value without detaching the current value.

  4. Value differences have reward units. Rescaling rewards also rescales returns and prediction errors, but a fixed \(\epsilon_V\) does not rescale automatically.

  5. Critic gradients also update the shared backbone. An oversized critic term can dominate representation learning and interfere with the policy objective.

Retrieval answers:

  • Policy clipping is flat for \(A>0,r>1+\epsilon\) and \(A<0,r<1-\epsilon\).

  • Direct clamping suppresses both beneficial and harmful out-of-range gradients; PPO suppresses only excessive beneficial movement.
