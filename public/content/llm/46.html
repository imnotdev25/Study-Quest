🚀 Starting point

Perplexity is the exponential of the average per-token NLL: \(\operatorname{PPL}=\exp(L_{\text{token}})\). Read it as the effective number of equally likely choices the model is torn between at each step. A model that spreads probability uniformly over \(V\) tokens has \(\operatorname{PPL}=V\), and a perfect model has \(\operatorname{PPL}=1\).

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. For mean softmax cross-entropy, what is the gradient with respect to logits?

  2. Why must ignored or padded tokens be excluded from the loss denominator?

For language-model logits and labels:

\[Z\in\mathbb{R}^{B\times T\times V}, \qquad Y\in\{0,\ldots,V-1\}^{B\times T}\]

the negative log-likelihood of each valid token is:

\[\ell_{bt}=-\log p_\theta(Y_{bt}\mid Y_{b,<t})\]

If \(M_{bt}\in\{0,1\}\) indicates valid target tokens:

\[L_{\text{token}} = \frac{\sum_{b,t}M_{bt}\ell_{bt}} {\sum_{b,t}M_{bt}}\]

Perplexity is:

\[\operatorname{PPL}=\exp(L_{\text{token}})\]

It is the exponential of average token NLL—not average sequence loss and not average batch perplexity.

For distributed or microbatched evaluation, accumulate two quantities:

\[S=\sum_{\text{valid tokens}}\ell_{bt}\]

\[N=\sum_{b,t}M_{bt}\]

Then calculate once:

\[L=\frac{S}{N}, \qquad \operatorname{PPL}=e^{S/N}\]

Averaging batch means is incorrect when batches contain different valid-token counts:

\[\frac{1}{K}\sum_k\frac{S_k}{N_k} \neq \frac{\sum_kS_k}{\sum_kN_k}\]

Research-engineering implication: evaluation results should not change merely because examples were packed or batched differently.

✏️ Derivation: what perplexity is, and how to aggregate it

Step 1. \(\exp\Big(-\frac1N\sum_t\log p_t\Big)=\Big(\prod_tp_t\Big)^{-1/N}\): the inverse geometric mean of the probabilities given to the true tokens.

Step 2. If every \(p_t=1/k\), then \(\operatorname{PPL}=k\). So \(\operatorname{PPL}=7.39\) (NLL \(2.0\)) is “as uncertain as choosing among about 7 tokens.”

Step 3. Aggregating across batches: accumulate \(\sum\) NLL and \(\sum\) tokens, divide once, then exponentiate. Batches with more tokens must count more.

Step 4. Averaging batch perplexities is wrong: \(\exp\) is convex, so by Jensen \(\frac1K\sum_ke^{L_k}\ge e^{\frac1K\sum_kL_k}\). Example: batch NLLs 1 and 3 with equal tokens: true \(\operatorname{PPL}=e^2=7.39\), but the mean of \(e^1\) and \(e^3\) is \(11.40\).

Step 5. Perplexity depends on the tokenizer: different tokenizations of the same text give different \(N\), so only compare models with the same tokenizer (or use bits per byte).

⚙️ Algorithm: corpus perplexity
Input: evaluation batches with logits, labels and masks
\(S\gets0\); \(N\gets0\)
for each batch do
\(S\gets S+\sum_{b,t}M_{bt}\ell_{bt}\); \(N\gets N+\sum_{b,t}M_{bt}\) ▷ sum, don’t average
end
return \(\operatorname{PPL}=\exp(S/N)\) ▷ all-reduce \(S,N\) across ranks first

Solution — open after attempting

def loss_sum_and_count(logits, labels):
    flat_logits = logits.reshape(-1, V)
    flat_labels = labels.reshape(-1)

    token_losses = F.cross_entropy(
        flat_logits,
        flat_labels,
        ignore_index=ignore_index,
        reduction="none",
    )

    valid = flat_labels != ignore_index

    loss_sum = token_losses[valid].sum()
    valid_count = valid.sum()

    return loss_sum, valid_count


full_sum, full_count = loss_sum_and_count(
    logits,
    labels,
)

full_mean = full_sum / full_count
full_ppl = torch.exp(full_mean)

total_count = torch.tensor(0)

aggregated_mean = total_sum / total_count
aggregated_ppl = torch.exp(aggregated_mean)

The first microbatch contains only three valid tokens, while the second contains nine. wrong_mean assigns both microbatches 50% of the final metric, so each token in the first receives three times as much influence as each token in the second.

Pure rebatching does not alter the model, examples, labels, or token probabilities. A metric that changes after rebatching is therefore aggregating containers—batches or sequences—instead of the intended token-level observations.

Check answers:

  1. The final dimension \(V\). Cross-entropy normalizes across vocabulary entries for each [b,t] position.

  2. The global mean is: \[\frac{\sum_r S_r}{\sum_r N_r}\] Averaging worker means incorrectly weights workers equally when their valid-token counts differ.

  3. Nothing changes: \[\exp\left(\frac{2S}{2N}\right)=\exp(S/N)\]

  4. The implementation is probably averaging batch-level losses or perplexities instead of aggregating token-loss sums and counts.

  5. Sequences have different lengths, and exponentiation is nonlinear. Averaging sequence perplexities weights sequences equally and does not equal: \[\exp\left( \frac{\text{total token NLL}} {\text{total valid tokens}} \right)\]

Retrieval answers:

\[\frac{\partial L}{\partial Z} = \frac{P-\operatorname{onehot}(Y)} {N_{\text{valid}}}\]

Ignored tokens contribute neither loss nor gradient and must not enlarge the mean-reduction denominator.
