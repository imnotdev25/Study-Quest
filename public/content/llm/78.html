🚀 Starting point

An evaluation is an estimate. Scores on \(N\) prompts are a sample, and a different sample would give a different number. The standard error is the typical size of that sample-to-sample variation. Pairing means scoring both models on the same prompts, so prompt difficulty, which affects both equally, cancels out of the difference.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why should best-of-\(N\) evaluation use an independent quality signal?

  2. Why does reward-model error become positively biased after selecting the maximum-scoring response?

Suppose baseline and updated models are evaluated on the same \(N\) prompts:

\[Y^{\text{base}},Y^{\text{new}} \in\{0,1\}^{N}\]

Define the prompt-level difference:

\[D_i=Y_i^{\text{new}}-Y_i^{\text{base}}\]

The estimated improvement is:

\[\hat\Delta = \frac1N\sum_{i=1}^{N}D_i\]

Its paired standard error is:

\[\operatorname{SE}_{\text{paired}} = \frac{s_D}{\sqrt N}\]

Equivalently:

\[\operatorname{Var}(\hat\Delta) = \frac{ \operatorname{Var}(Y^{\text{new}}) + \operatorname{Var}(Y^{\text{base}}) - 2\operatorname{Cov}(Y^{\text{new}},Y^{\text{base}}) }{N}\]

When models tend to succeed and fail on the same prompts, covariance is positive and pairing reduces uncertainty.

An unpaired calculation omits the covariance:

\[\operatorname{SE}_{\text{unpaired}} = \sqrt{ \frac{s_{\text{new}}^2}{N} + \frac{s_{\text{base}}^2}{N} }\]

For a paired bootstrap, resample prompt indices and keep both model outcomes together. Independently resampling the two arms destroys the pairing.

Confidence intervals quantify sampling uncertainty. They do not detect judge bias, benchmark contamination, reward hacking, or a systematically unrepresentative prompt set.

✏️ Derivation: why pairing shrinks the error

Step 1. \(\hat\Delta=\frac1N\sum_iD_i\) with \(D_i=Y_i^{\text{new}}-Y_i^{\text{base}}\). For independent prompts, \(\operatorname{Var}(\hat\Delta)=\operatorname{Var}(D)/N\).

Step 2. \(\operatorname{Var}(D)=\operatorname{Var}(Y^{\text{new}})+\operatorname{Var}(Y^{\text{base}})-2\operatorname{Cov}(Y^{\text{new}},Y^{\text{base}})\).

Step 3. Hard prompts are hard for both models, so the covariance is large and positive. The \(-2\operatorname{Cov}\) term removes that shared variation.

Step 4. Unpaired (independent samples) drops the covariance term: a larger variance for the same \(N\).

Step 5. SE and interval: \(\operatorname{SE}=s_D/\sqrt N\); an approximate 95% interval is \(\hat\Delta\pm1.96\,\operatorname{SE}\).

Step 6. Bootstrap: resample prompt indices with replacement, recompute \(\hat\Delta\), and take the 2.5th and 97.5th percentiles. It makes no normality assumption, but it must resample pairs (both models’ scores on the same prompt together).

⚙️ Algorithm: paired bootstrap confidence interval
Input: per-prompt differences \(D_1..D_N\), resamples \(B\) (e.g. 10,000)
for \(b=1,\dots,B\) do
draw \(N\) indices with replacement; \(\hat\Delta_b\gets\) mean of the drawn \(D\)
end
return \(\bar D\) and the 2.5% and 97.5% percentiles of \(\{\hat\Delta_b\}\)

Solution — open after attempting

baseline_correct = (
    shared_uniform < baseline_probability
).float()

updated_correct = (
    shared_uniform < updated_probability
).float()

paired_difference = (
    updated_correct - baseline_correct
)

estimated_improvement = paired_difference.mean()

paired_se = (
    paired_difference.std(unbiased=True)
    / N**0.5
)

unpaired_se = torch.sqrt(
    updated_correct.var(unbiased=True) / N
    + baseline_correct.var(unbiased=True) / N
)

Paired bootstrap:

    bootstrap_indices

    torch.tensor([0.025, 0.975]),

Incorrect unpaired bootstrap:

unpaired_bootstrap_estimates = (
    updated_correct[updated_indices].mean(dim=1)
    - baseline_correct[baseline_indices].mean(dim=1)
)

unpaired_interval = torch.quantile(
    unpaired_bootstrap_estimates,
    torch.tensor([0.025, 0.975]),
)

The correct bootstrap resamples:

\[(Y_i^{\text{base}},Y_i^{\text{new}})\]

as one prompt-level pair. It retains the covariance caused by common prompt difficulty.

Independent resampling estimates a different experiment in which the baseline and updated models were evaluated on unrelated prompts. It discards:

\[-2\operatorname{Cov} \left( Y^{\text{new}}, Y^{\text{base}} \right)\]

and therefore generally produces a wider interval when the covariance is positive.

Shuffling the updated predictions does not alter either marginal mean:

\[\frac1N\sum_iY_i^{\text{new}} \quad\text{or}\quad \frac1N\sum_iY_i^{\text{base}}\]

so their mean difference remains unchanged. But it breaks the prompt-level correspondence and changes the variance of:

\[Y_i^{\text{new}}-Y_i^{\text{base}}\]

This commonly occurs when result files are joined by row position rather than a stable example ID.

Check answers:

  1. One prompt together with all model outcomes associated with that prompt.

  2. Zero: every paired difference is exactly zero.

  3. It ignores positive within-prompt correlation, treating shared prompt difficulty as independent noise.

  4. Check for duplicated, missing, reordered, or incorrectly joined example IDs.

  5. The interval measures sampling variability conditional on the judge and dataset. A biased judge can produce an extremely precise but invalid estimate.

Retrieval answers:

  • Best-of-\(N\) should be checked with an evaluator whose errors are independent of the optimized reward model.

  • Maximization preferentially selects candidates with favorable reward-model errors, making selected error positively biased.
