🚀 Starting point

Reduction defines the objective. When one advantage per response is copied to every token, the choice of denominator decides how much each token, and each response, counts. Token-mean gives every token equal weight. Sequence-mean gives every response equal weight, so tokens of long responses count less.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why does an equal-reward response group produce zero group-relative advantages?

  2. Why can tiny within-group reward variance create order-one normalized advantages?

Suppose each prompt has \(G\) responses, each padded to \(T\) tokens:

\[A\in\mathbb{R}^{B\times G},\qquad M,\ell_{\text{new}},\ell_{\text{old}} \in\mathbb{R}^{B\times G\times T}\]

with response length:

\[L_{bg}=\sum_t M_{bgt}\]

and importance ratio:

\[r_{bgt} = \exp\left( \ell_{\text{new},bgt}-\ell_{\text{old},bgt} \right)\]

When a sequence-level advantage \(A_{bg}\) is broadcast to every response token, the reduction determines the effective training objective.

Token-weighted objective:

\[J_{\text{token}} = \frac{ \sum_{b,g,t}M_{bgt}r_{bgt}A_{bg} }{ \sum_{b,g,t}M_{bgt} }\]

A response with twice as many tokens contributes roughly twice as much total gradient.

Sequence-balanced objective:

\[J_{\text{sequence}} = \frac1{BG} \sum_{b,g} \frac1{L_{bg}} \sum_t M_{bgt}r_{bgt}A_{bg}\]

Every response receives equal aggregate weight, but short responses receive larger gradients per token.

At \(r=1\), for minimized loss \(L=-J\):

\[\frac{\partial L_{\text{token}}} {\partial\ell_{bgt}} = -\frac{M_{bgt}A_{bg}}{N_{\text{tokens}}}\]

\[\frac{\partial L_{\text{sequence}}} {\partial\ell_{bgt}} = -\frac{M_{bgt}A_{bg}}{BG\,L_{bg}}\]

Neither reduction is universally correct. Token weighting treats each generated action equally; sequence weighting treats each sampled completion equally. The implementation must match the intended estimand.

✏️ Derivation: per-token gradient weights under each reduction

Responses \((b,g)\) of length \(L_{bg}\), advantage \(A_{bg}\), and \(N=\sum_{b,g}L_{bg}\) tokens in total.

Step 1. Token-mean: \(J=\frac1N\sum_{bgt}M_{bgt}r_{bgt}A_{bg}\). Each token’s weight is \(\frac{A_{bg}}{N}\), and response \((b,g)\)’s total weight is \(\frac{L_{bg}A_{bg}}{N}\): proportional to its length.

Step 2. Sequence-mean: \(J=\frac{1}{BG}\sum_{bg}\frac{1}{L_{bg}}\sum_tM_{bgt}r_{bgt}A_{bg}\). Each token’s weight is \(\frac{A_{bg}}{BG\,L_{bg}}\), and every response totals \(\frac{A_{bg}}{BG}\), whatever its length.

Step 3. Length bias of sequence-mean: a long wrong response (\(A<0\)) spreads its penalty over many tokens, so each token is barely discouraged, and long wrong answers become cheap.

Step 4. True gradient: \(\nabla\mathbb E[R]=\mathbb E[A\sum_t\nabla\log\pi(y_t)]\), a sum over tokens. Dividing by a constant (e.g. \(BG\cdot L_{\max}\)) matches it up to scale.

Step 5. Example: lengths 5 and 20, \(A=\pm1\), \(G=2\): sequence-mean per-token weights \(\pm0.1\) and \(\mp0.025\); token-mean \(\pm0.04\) for both.

⚙️ Algorithm: choosing and applying a reduction
Input: per-token objective \(J_{bgt}\), mask \(M\), mode
if mode \(=\) token then \(J\gets\sum MJ/\sum M\)
else if mode \(=\) sequence then \(J\gets\operatorname{mean}_{bg}\big(\sum_tMJ/\sum_tM\big)\)
else \(J\gets\sum MJ/(BG\cdot L_{\max})\) ▷ constant normalizer
end
keep the mode fixed for a run; log mean response length

def compute_gradient(reduction):
    new_logp = torch.zeros(
        B, G, T,
        requires_grad=True,
    )

    ratio = torch.exp(
        new_logp - old_logp
    )

    token_advantages = advantages.detach().unsqueeze(-1)

    if reduction == "token":
        objective = (
            ratio * token_advantages
        )[response_mask].mean()

    elif reduction == "sequence":
        mask_float = response_mask.to(ratio.dtype)
        lengths = mask_float.sum(dim=-1)

        response_objectives = (
            ratio
            * token_advantages
            * mask_float
        ).sum(dim=-1) / lengths

        objective = response_objectives.mean()

    else:
        raise ValueError(reduction)

    loss = -objective

    gradient = torch.autograd.grad(
        loss,
        new_logp,
    )[0]

    return loss.detach(), gradient

Padding bug:

bad_loss = -(

Under token weighting, every valid token has gradient magnitude:

\[\frac{|A_{bg}|}{N_{\text{tokens}}}\]

Therefore, aggregate response influence is:

\[\frac{L_{bg}|A_{bg}|}{N_{\text{tokens}}}\]

The length-six positive response has three times the total influence of the length-two positive response.

Under sequence balancing, aggregate influence is:

\[\frac{|A_{bg}|}{BG}\]

regardless of length. Its per-token magnitude is:

\[\frac{|A_{bg}|}{BG\,L_{bg}}\]

so the shortest response has the largest per-token gradient.

The sequence-balanced loss is initially zero because three \(+1\) and three \(-1\) response objectives cancel. Its gradients do not cancel elementwise: positive-advantage log-probabilities must increase, while negative-advantage log-probabilities must decrease.

The broken reduction includes padding as if it represented sampled actions. Consequently:

  • padded log-probabilities receive gradients;

  • changing padded width changes the denominator;

  • shorter responses acquire more artificial padded contributions;

  • loss and gradient scale depend on T, not just real responses.

Check answers:

  1. Its aggregate contribution approximately doubles.

  2. Each token’s gradient is halved, leaving aggregate sequence influence unchanged.

  3. A zero value may result from cancellation between terms whose individual derivatives are nonzero.

  4. Padding is probably included in the objective or reduction denominator.

  5. Token weighting is appropriate when each valid generated action is intended to be one equally weighted training observation, particularly with meaningful token-level advantages or rewards.

Retrieval answers:

  • Equal rewards equal the group mean, so every centered group-relative advantage is zero.

  • Dividing tiny centered differences by a tiny standard deviation removes their small absolute scale and can promote noise to order-one advantages.
