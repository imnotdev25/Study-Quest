🚀 Starting point

Attention backward chains three steps: the matrix product \(O=AV\), the row-wise softmax \(A=\operatorname{softmax}(S)\), and the scaled product \(S=QK^\top/\sqrt d\). The only new piece is the softmax VJP, which can be computed without forming the \(T\times T\) Jacobian of each row.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. For \(Z=XW\), how do you compute \(dW\) and \(dX\)?

  2. For softmax cross-entropy, why does each logits-gradient row sum to zero?

Consider single-head attention:

\[Q,K,V\in\mathbb{R}^{B\times T\times d}\]

\[S=\frac{QK^\top}{\sqrt d} \in\mathbb{R}^{B\times T\times T}\]

\[A=\operatorname{softmax}(S,\text{dim}=-1)\]

\[O=AV\in\mathbb{R}^{B\times T\times d}\]

Given upstream gradient:

\[G=\frac{\partial L}{\partial O}\]

backpropagate through \(O=AV\):

\[\frac{\partial L}{\partial V}=A^\top G\]

\[\frac{\partial L}{\partial A}=GV^\top\]

For one softmax row \(a=\operatorname{softmax}(s)\), its vector–Jacobian product is:

\[\frac{\partial L}{\partial s} = a\odot \left( g_a-\sum_j g_{a,j}a_j \right)\]

This avoids constructing the full softmax Jacobian.

Finally:

\[\frac{\partial L}{\partial Q} = \frac{1}{\sqrt d} \frac{\partial L}{\partial S}K\]

\[\frac{\partial L}{\partial K} = \frac{1}{\sqrt d} \left(\frac{\partial L}{\partial S}\right)^\top Q\]

For masked positions, \(A_{ij}=0\), so their score gradients should also be zero.

Practical concern: ordinary attention backward may retain \(A:[B,T,T]\), which is expensive at long sequence lengths. Fused attention implementations reduce this memory traffic and may recompute intermediate quantities during backward.

✏️ Derivation: gradients of \(Q\), \(K\) and \(V\)

Upstream \(G=\partial L/\partial O\in\mathbb R^{T\times d}\) (one batch element).

Step 1. \(O=AV\) (Part 0 identities): \(\nabla V=A^\top G\), \(\nabla A=GV^\top\).

Step 2. One softmax row \(a=\operatorname{softmax}(s)\), upstream \(g=\nabla a\): \(\frac{\partial L}{\partial s_j}=\sum_ig_i\,a_i(\delta_{ij}-a_j)=a_j\Big(g_j-\sum_ig_ia_i\Big)\).

Step 3. All rows at once: \(\nabla S=A\odot\big(\nabla A-\operatorname{rowsum}(\nabla A\odot A)\big)\). Cost \(O(T^2)\), no \(T^3\) Jacobians.

Step 4. \(S=QK^\top/\sqrt d\): \(\nabla Q=\frac{1}{\sqrt d}\nabla S\,K\) and \(\nabla K=\frac{1}{\sqrt d}(\nabla S)^\top Q\).

Step 5. Masked entries: \(A_{ij}=0\Rightarrow(\nabla S)_{ij}=0\) by step 2, so future tokens receive no gradient, as they should.

Step 6. Memory: steps 1–3 need \(A\) (\(T^2\) per head). Fused kernels (FlashAttention) store only the per-row \(\LSE\) and recompute \(A\) block by block during backward.

⚙️ Algorithm: attention backward (one head)
Input: saved \(Q,K,V,A\); upstream \(G\)
\(\nabla V\gets A^\top G\); \(\nabla A\gets GV^\top\)
\(c_i\gets\sum_j(\nabla A)_{ij}A_{ij}\) for each row \(i\)
\(\nabla S\gets A\odot(\nabla A-c\mathbf 1^\top)\)
\(\nabla Q\gets\nabla S\,K/\sqrt d\); \(\nabla K\gets(\nabla S)^\top Q/\sqrt d\)

Solution — open after attempting

# Forward
scores = (
    Q @ K.transpose(-2, -1)
) / math.sqrt(d)

masked_scores = scores.masked_fill(
    ~causal_mask,
    float("-inf"),
)

A = torch.softmax(masked_scores, dim=-1)
O = A @ V

loss = (O * G).sum()

# Backward through O = A @ V
manual_dV = a.transpose(-2, -1) @ G
dA = G @ v.transpose(-2, -1)

# Softmax backward
row_inner_product = (
    dA * a
).sum(dim=-1, keepdim=True)

dS = a * (dA - row_inner_product)

# Score backward
manual_dQ = (dS @ k) / math.sqrt(d)

manual_dK = (
    dS.transpose(-2, -1) @ q
) / math.sqrt(d)

Forbidden score gradients are zero because their attention probabilities are zero:

\[dS_{ij} = A_{ij} \left( dA_{ij}-\sum_k dA_{ik}A_{ik} \right) =0\]

Each score-gradient row sums to zero:

\[\sum_j dS_j = \sum_j A_jdA_j - \left(\sum_jA_j\right) \left(\sum_kA_kdA_k\right) =0\]

Removing \(1/\sqrt d\) makes manual_dQ and manual_dK approximately \(\sqrt d\) times too large.

Check answers:

  1. One value vector can influence every query that attends to it, so backward sums contributions from all those query outputs.

  2. Softmax is invariant to adding a constant to an entire score row; the gradient therefore has no component in that all-ones direction.

  3. Its probability is exactly one. Because changing its only allowed score cannot change the distribution, its score gradient is zero.

  4. Attention may be extremely saturated or effectively one-hot. The output still depends on selected values, while small changes to queries and keys barely change the probabilities.

  5. Explicit probabilities require storing [B,H,T,T]; fused kernels can avoid returning that quadratic tensor and manage backward intermediates internally.

Retrieval answers:

\[dW=X^\top dZ,\qquad dX=dZW^\top\]

Cross-entropy logits-gradient rows sum to zero because probabilities and one-hot targets both sum to one.
