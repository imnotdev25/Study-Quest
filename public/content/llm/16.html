🚀 Starting point

A hypothesis test asks: if there were no real difference (the null hypothesis), how surprising would data at least this extreme be? That probability is the p-value. It is not the probability that the null is true. This chapter is the one you need most for reading ML papers and leaderboards.

✏️ Derivation: Paired comparison on one eval set

Step 1. Models A and B answer the same \(n\) questions: correctness \(a_i,b_i\in\{0,1\}\). Let \(d_i=a_i-b_i\).

Step 2. \(\operatorname{Var}(\bar a-\bar b)=\frac1n\big(\operatorname{Var}a+\operatorname{Var}b-2\operatorname{Cov}(a,b)\big)\). Questions that are easy for one model tend to be easy for the other, so \(\operatorname{Cov}>0\).

Step 3. The unpaired standard error ignores the covariance and overstates the noise. The paired one, \(\operatorname{sd}(d)/\sqrt n\), uses it. In the output the same data gives \(p=0.052\) unpaired and \(p=0.037\) paired.

Step 4. A permutation test needs no normal approximation: under the null, A and B are interchangeable on each question, so flip the sign of each \(d_i\) at random many times and see how often the mean is as extreme as observed.

Multiple comparisons

Test 20 benchmarks where nothing differs, each at the 5% level, and the chance that at least one comes out “significant” is \(1-0.95^{20}=64\%\). Bonferroni (test each at \(\alpha/m\)) brings it back to 5%, at the cost of power. Report every comparison you ran, not just the ones that crossed the line.

Concentration: Hoeffding’s inequality

For \(n\) independent variables in \([0,1]\), \(P(|\bar X-\mu|\ge\epsilon)\le2e^{-2n\epsilon^2}\), with no other assumptions. Setting the right side to \(\delta\): \(n\ge\frac{\ln(2/\delta)}{2\epsilon^2}\), 4,612 questions for \(\pm2\) points at 95%. The normal approximation needs 2,401 because it uses the actual variance. Hoeffding-type bounds are what PAC learning and bandit algorithms (UCB in the RL book) are built on.

Monte Carlo and importance sampling

✏️ Derivation: Importance sampling, and why PPO clips

Step 1. \(\mathbb E_p[f(X)]=\int f\,p=\int f\,\frac pq\,q=\mathbb E_q\big[f(X)w(X)\big]\) with \(w=p/q\). Sample from \(q\), reweight by \(w\).

Step 2. Good \(q\) puts samples where \(f\,p\) is large. For \(P(Z>4)=3.2\times10^{-5}\), naive sampling sees about 3 hits in 100,000; sampling from \(N(4,1)\) and reweighting gets the answer to 0.5%.

Step 3. Bad \(q\): the weights’ variance explodes when \(p\) and \(q\) drift apart. The effective sample size \((\sum w)^2/\sum w^2\) for Gaussians shifted by \(\Delta\) is about \(Ne^{-\Delta^2}\): 37% of the samples at \(\Delta=1\), under 2% at \(\Delta=2\). (At \(\Delta=2\) and 3 the measured ESS exceeds the theory: the weights are so heavy-tailed that 10,000 samples rarely contain the largest ones, so the estimate itself becomes unreliable. That is the failure mode.)

Step 4. Off-policy RL is importance sampling with \(w=\pi_\theta/\pi_{\text{old}}\). PPO’s clip, GSPO’s sequence ratio and the truncated weights of IMPALA and asynchronous RL all exist to keep \(w\) near 1 so the effective sample size doesn’t collapse.

"""Inference: comparing two models on one eval set, multiple comparisons, Hoeffding, importance sampling."""
import math

import numpy as np

rng = np.random.default_rng(0)
Phi = lambda z: 0.5 * math.erfc(-z / math.sqrt(2))

# 1. Two models on the same 500 questions. Their correctness is correlated (shared easy/hard items).
n = 500
difficulty = rng.normal(size=n)
a = rng.random(n) < 1 / (1 + np.exp(-(difficulty + 0.75)))
b = rng.random(n) < 1 / (1 + np.exp(-(difficulty + 0.45)))
diff = a.astype(float) - b
se_unpaired = math.sqrt(a.var(ddof=1) / n + b.var(ddof=1) / n)
se_paired = diff.std(ddof=1) / math.sqrt(n)
z_u, z_p = diff.mean() / se_unpaired, diff.mean() / se_paired
print(f"[ab] accuracy A {a.mean():.3f}  B {b.mean():.3f}  gap {diff.mean():+.3f}")
print(f"[ab] unpaired SE {se_unpaired:.4f}  z {z_u:.2f}  p {2 * (1 - Phi(abs(z_u))):.4f}")
print(f"[ab] paired   SE {se_paired:.4f}  z {z_p:.2f}  p {2 * (1 - Phi(abs(z_p))):.4f}   (same data, smaller SE)")

# Permutation test: under H0 the A/B labels are exchangeable within each question, so flip signs.
flips = rng.choice([-1, 1], size=(20_000, n))
null = (flips * diff).mean(1)
print(f"[perm] paired sign-flip permutation p-value {np.mean(np.abs(null) >= abs(diff.mean())):.4f}")

# 2. Multiple comparisons: 20 benchmarks, no real difference anywhere.
trials = 5_000
pvals = rng.random((trials, 20))                              # p-values are uniform under H0
print(f"[multi] P(at least one p < 0.05 among 20 null tests) = {np.mean((pvals < 0.05).any(1)):.3f} "
      f"(theory {1 - 0.95**20:.3f});  with Bonferroni (p < 0.0025): {np.mean((pvals < 0.05 / 20).any(1)):.3f}")

# 3. Hoeffding: P(|mean - mu| >= eps) <= 2 exp(-2 n eps^2). Questions needed for +-2 points at 95%.
eps, delta = 0.02, 0.05
print(f"[hoeffding] n >= ln(2/delta) / (2 eps^2) = {math.ceil(math.log(2 / delta) / (2 * eps**2)):,} questions "
      f"(no assumptions); normal approximation at p=0.5: {math.ceil(1.96**2 * 0.25 / eps**2):,}")

# 4. Importance sampling: P(Z > 4) for Z ~ N(0,1) = 3.17e-5.
exact = 1 - Phi(4)
z = rng.normal(size=100_000)
w_samples = rng.normal(4, 1, 100_000)                         # proposal q = N(4, 1)
w = np.exp(-w_samples**2 / 2) / np.exp(-(w_samples - 4) ** 2 / 2)   # p/q
is_est = np.mean((w_samples > 4) * w)
print(f"[is] exact {exact:.3e}   naive MC (100k) {np.mean(z > 4):.3e}   importance sampling (100k) {is_est:.3e}")
for shift in (0.5, 1.0, 2.0, 3.0):                            # policy drift -> effective sample size collapses
    s = rng.normal(0, 1, 10_000)
    ww = np.exp(-(s - shift) ** 2 / 2 + s**2 / 2)             # target N(shift,1), samples from N(0,1)
    print(f"[ess] target shifted by {shift}: ESS = (sum w)^2 / sum w^2 = {ww.sum()**2 / (ww**2).sum():7.0f} of 10,000"
          f"   (theory {10_000 * math.exp(-shift**2):.0f})")

🔑 Key ideas

  • On a shared eval set, always compare models with a paired test.

  • A 2-point gap on 500 questions is usually inside the noise; quote intervals, not single numbers.

  • Importance weights are the mathematical link between statistics and off-policy RL: watch the effective sample size.
