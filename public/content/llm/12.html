🚀 Starting point

Starting point. \(\operatorname{Cov}(X,Y)=\mathbb E[(X-\mu_X)(Y-\mu_Y)]=\mathbb E[XY]-\mu_X\mu_Y\): positive when the two tend to be above their means together. Correlation \(\rho=\operatorname{Cov}/(\sigma_X\sigma_Y)\) removes the units.

✏️ Derivation: \(|\rho|\le1\), and what correlation can’t see

Step 1. For any \(t\), \(0\le\operatorname{Var}(Y-tX)=\sigma_Y^2-2t\operatorname{Cov}+t^2\sigma_X^2\).

Step 2. A quadratic in \(t\) that is never negative has discriminant \(\le0\): \(4\operatorname{Cov}^2-4\sigma_X^2\sigma_Y^2\le0\), so \(|\rho|\le1\), with equality only if \(Y\) is exactly linear in \(X\).

Step 3. \(\rho(aX+b,cY+d)=\operatorname{sign}(ac)\,\rho(X,Y)\): scale-free.

Step 4. Independent \(\Rightarrow\) uncorrelated, but not conversely. \(Y=Z^2\) with \(Z\sim N(0,1)\): \(\operatorname{Cov}(Z,Z^2)=\mathbb E[Z^3]=0\), yet \(Y\) is a function of \(Z\). Correlation measures linear association only; mutual information sees all of it.

Covariance matrices

For a random vector, \(\Sigma=\mathbb E[(X-\mu)(X-\mu)^\top]\). It is symmetric and positive semi-definite, because \(v^\top\Sigma v=\operatorname{Var}(v^\top X)\ge0\). Its eigenvectors are the principal axes of the data (PCA) and its eigenvalues are the variances along them. Any linear combination has \(\operatorname{Var}(a^\top X)=a^\top\Sigma a\); in particular \(\operatorname{Var}(X_1+X_2)=\Sigma_{11}+\Sigma_{22}+2\Sigma_{12}\).

Contours of \(N(0,\Sigma)\) with \(\Sigma=\left(\begin{smallmatrix}4&2.4\\2.4&9\end{smallmatrix}\right)\): ellipses along the eigenvectors, eigenvalues 3.03 and 9.97 (drawn at half scale).

✏️ Derivation: Gaussian combinations

Step 1. Sampling: factor \(\Sigma=LL^\top\) (Cholesky). If \(z\sim N(0,I)\), \(x=\mu+Lz\) has covariance \(L\,I\,L^\top=\Sigma\).

Step 2. Linear maps: \(AX+b\sim N(A\mu+b,\,A\Sigma A^\top)\). Sums of jointly Gaussian variables are Gaussian.

Step 3. Conditioning: partition \(x=(x_1,x_2)\). Then \(x_1\mid x_2\sim N\big(\mu_1+\Sigma_{12}\Sigma_{22}^{-1}(x_2-\mu_2),\ \Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}\big)\). The mean moves along the regression line; the variance shrinks by a fixed amount whatever \(x_2\) is (the Schur complement). This is the core of Gaussian processes and the Kalman filter.

Step 4. Fusing two measurements \(N(m_1,v_1)\) and \(N(m_2,v_2)\) of the same quantity: precisions add, \(1/v=1/v_1+1/v_2\), and the mean is the precision-weighted average \(m=v(m_1/v_1+m_2/v_2)\).

"""Joint RVs: covariance matrices and Gaussian combinations (sums, linear maps, conditioning)."""
import numpy as np

rng = np.random.default_rng(0)
N = 1_000_000

# 1. Sum of independent normals: means add, variances add.
s = rng.normal(1, 2, N) + rng.normal(-3, 1.5, N)
print(f"[sum] N(1,4) + N(-3,2.25): mean {s.mean():.3f} (-2), var {s.var():.3f} (6.25)")

# 2. Correlated sum: Var(X + Y) = Var X + Var Y + 2 Cov(X, Y).
Sigma = np.array([[4.0, 2.4, 0.0], [2.4, 9.0, -1.5], [0.0, -1.5, 1.0]])
L = np.linalg.cholesky(Sigma)                                  # Sigma = L L^T
mu = np.array([1.0, 0.0, 2.0])
Z = mu + rng.normal(size=(N, 3)) @ L.T                         # x = mu + L z
print(f"[mvn] sample covariance from Cholesky sampling:\n{np.round(np.cov(Z.T), 2)}")
print(f"[mvn] Var(X1 + X2) = {np.var(Z[:, 0] + Z[:, 1]):.3f}   formula 4 + 9 + 2(2.4) = {4 + 9 + 4.8}")

# 3. Linear map: AX + b ~ N(A mu + b, A Sigma A^T).
A = np.array([[1.0, -1.0, 0.0], [0.5, 0.5, 2.0]])
Y = Z @ A.T
print(f"[linear] cov(AX) sample vs A Sigma A^T  max diff {np.abs(np.cov(Y.T) - A @ Sigma @ A.T).max():.3f}")

# 4. Eigen-decomposition: principal axes of the density ellipse; PSD means all eigenvalues >= 0.
ev, V = np.linalg.eigh(Sigma[:2, :2])
print(f"[eig] Sigma[:2,:2] eigenvalues {np.round(ev, 3)}, principal axis {np.round(V[:, 1], 3)}")

# 5. Conditioning: X1 | X2 = x2 ~ N(mu1 + S12/S22 (x2 - mu2), S11 - S12^2/S22).
x2 = 3.0
cm = mu[0] + Sigma[0, 1] / Sigma[1, 1] * (x2 - mu[1])
cv = Sigma[0, 0] - Sigma[0, 1] ** 2 / Sigma[1, 1]
near = Z[np.abs(Z[:, 1] - x2) < 0.05, 0]
print(f"[cond] E[X1 | X2=3] formula {cm:.3f}, sample {near.mean():.3f}   Var formula {cv:.3f}, sample {near.var():.3f}")

# 6. Product of Gaussian densities (combining two noisy measurements): precision-weighted average.
m1, v1, m2, v2 = 10.0, 4.0, 14.0, 1.0
v = 1 / (1 / v1 + 1 / v2); m = v * (m1 / v1 + m2 / v2)
print(f"[fuse] N(10, 4) x N(14, 1) -> N({m:.2f}, {v:.2f})   (the precise sensor gets 4x the weight)")
