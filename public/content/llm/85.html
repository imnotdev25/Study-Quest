🚀 Starting point

Variable token counts: in language models, each microbatch holds a different number of valid (unmasked) tokens. The target objective is still the mean over all valid tokens in the full batch, \(L=S/N\), where \(S\) is the total loss sum and \(N\) the total valid count. Session 14’s rule applies with “elements” meaning valid tokens.

Total: 20 minutes

1. Retrieval + concept refresh — 5 minutes

Quick retrieval:

  1. Why does distillation conventionally multiply KL loss by \(T^2\)?

  2. Why should teacher probabilities normally be detached?

For token features, targets, and a validity mask:

\[X\in\mathbb{R}^{B\times T\times D}, \qquad Y,M\in\mathbb{R}^{B\times T}\]

suppose token losses are:

\[\ell_{bt}(\theta)\]

The correct valid-token mean is:

\[L = \frac{ \sum_{b,t}M_{bt}\ell_{bt} }{ \sum_{b,t}M_{bt} } = \frac{S}{N}\]

Gradient accumulation divides the batch into \(K\) microbatches. If microbatch \(k\) has loss sum \(S_k\) and \(N_k\) valid tokens:

\[L = \frac{\sum_k S_k}{\sum_kN_k}\]

A common implementation instead computes:

\[L_{\text{wrong}} = \frac1K \sum_k\frac{S_k}{N_k}\]

This weights every microbatch equally. A microbatch containing 10 valid tokens receives the same aggregate influence as one containing 1,000.

Correct implementations either:

\[\text{backward}\left(\frac{S_k}{N_{\text{global}}}\right)\]

for each microbatch, or weight every local mean by:

\[\frac{N_k}{N_{\text{global}}}\]

This matters for variable-length LLM batches, packing, ignored labels, gradient accumulation, and distributed training.

✏️ Derivation: the wrong and right scaling with masks

Step 1. Correct: \(L=\frac{\sum_kS_k}{\sum_kN_k}\), so microbatch \(k\) backpropagates \(S_k/N\).

Step 2. Common bug: \(L_{\text{wrong}}=\frac1K\sum_k\frac{S_k}{N_k}\). A token in microbatch \(k\) gets weight \(\frac{1}{KN_k}\) instead of \(\frac1N\).

Step 3. Ratio of weights: \(\frac{N}{KN_k}\). A microbatch with half the average token count has its tokens counted twice as much.

Step 4. With data parallelism, \(N\) must be the global count across ranks. Each rank computes local \(S_k\), but divides by the all-reduced \(N\). DDP then averages gradients over \(W\) ranks, so multiply by \(W\) (or divide by \(N/W\)) to keep the sum correct.

Step 5. Test: the accumulated gradient must match a single full-batch backward to float precision, whatever the microbatch split.

⚙️ Algorithm: token-exact accumulation with data parallelism
Input: \(W\) ranks, \(K\) microbatches per rank, masks
\(N\gets\operatorname{all\_reduce\_sum}\big(\sum_{k}\sum M_k\big)\) ▷ before any backward
for \(k=1,\dots,K\) do
\(S_k\gets\sum M_k\ell_k\); backward on \(W\cdot S_k/N\) ▷ \(W\) cancels DDP’s averaging
end
optimizer step; verify once against a single-batch reference

Solution — open after attempting

Full-batch computation:

def token_loss(weight, x, y):
    predictions = x @ weight

    return 0.5 * (
        predictions - y
    ).square()


full_token_losses = token_loss(
    full_weight,
    features,
    targets,
)

full_loss = full_token_losses[
    valid_mask
].mean()

Naive accumulation:

naive_weight = (
    initial_weight.clone()
    .requires_grad_()
)

for start, end in microbatches:
    local_losses = token_loss(
        naive_weight,
        features[start:end],
        targets[start:end],
    )

    local_mask = valid_mask[start:end]

    local_mean = local_losses[
        local_mask
    ].mean()

    scaled_local_mean = (
        local_mean / len(microbatches)
    )

    scaled_local_mean.backward()

Correct accumulation:

correct_weight = (
    initial_weight.clone()
    .requires_grad_()
)

global_valid_count = valid_mask.sum()

for start, end in microbatches:
    local_losses = token_loss(
        correct_weight,
        features[start:end],
        targets[start:end],
    )

    local_mask = valid_mask[start:end]

    local_sum = local_losses[
        local_mask
    ].sum()

    normalized_local_sum = (
        local_sum / global_valid_count
    )

    normalized_local_sum.backward()

Effective weights:

correct_weights = (
    local_counts / local_counts.sum()
)

naive_weights = torch.full_like(
    local_counts,
    1.0 / len(microbatches),
)

The correct microbatch weights are:

\[\left[ \frac3{12}, \frac9{12} \right] = [0.25,0.75]\]

The naive calculation instead uses:

\[[0.5,0.5]\]

It therefore doubles the aggregate influence of the three-token microbatch and reduces the nine-token microbatch’s influence.

Dividing each local mean by the number of accumulation steps works when all microbatches have equal effective denominators—for example, equal numbers of valid tokens. Equal tensor shapes are insufficient if padding or ignored labels differ.

For distributed data parallelism, rank-local gradients are commonly averaged. If rank \(r\) computes:

\[\frac{S_r}{N_r}\]

then averaging ranks weights each rank equally, not each token equally. Correct global normalization requires the global valid-token count:

\[N_{\text{global}}=\sum_rN_r\]

and consistent handling of the framework’s gradient averaging factor.

Check answers:

  1. Each microbatch mean has denominator \(N_k\); averaging those means assigns equal weight to unequal token populations.

  2. A token in the one-token microbatch receives 1,000 times the influence of a token in the other microbatch.

  3. When every microbatch has the same number of effective observations, or when local means are explicitly weighted by their counts.

  4. Inspect whether independently normalized microbatch losses are averaged instead of accumulating numerators under one global denominator.

  5. Rank-local averaging weights ranks equally and can overrepresent ranks with fewer valid tokens.

Retrieval answers:

  • \(T^2\) compensates for the approximate \(1/T^2\) reduction in distillation-gradient magnitude.

  • Detachment prevents the teacher from moving toward the student and avoids retaining an unnecessary teacher computation graph.
