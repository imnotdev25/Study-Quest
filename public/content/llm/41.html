🚀 Starting point

A directional derivative is how fast \(L\) changes when \(\theta\) moves along a unit vector \(v\): \(D_vL=\lim_{\epsilon\to0}\frac{L(\theta+\epsilon v)-L(\theta)}{\epsilon}=\nabla L^\top v\). A gradient check computes the right side with autograd and the left side numerically. If they disagree, the backward pass has a bug.

Total: 20 minutes

For parameters:

\[\theta\in\mathbb{R}^{P}, \qquad g=\nabla_\theta L\in\mathbb{R}^{P}\]

checking every coordinate is expensive. Instead, choose a unit direction \(v\in\mathbb{R}^{P}\) and compare the autograd directional derivative:

\[D_vL=g^\top v\]

with a central finite difference:

\[D_vL \approx \frac{L(\theta+\epsilon v)-L(\theta-\epsilon v)} {2\epsilon}\]

Central differences have \(O(\epsilon^2)\) truncation error, but \(\epsilon\) cannot be arbitrarily small:

  • Large \(\epsilon\): poor local approximation.

  • Tiny \(\epsilon\): floating-point cancellation.

  • Intermediate \(\epsilon\): usually the best agreement.

Use relative error:

\[\text{relative error} = \frac{|g^\top v-D_v^{FD}L|} {\max(1,|g^\top v|,|D_v^{FD}L|)}\]

For reliable checks:

  • Use float64.

  • Disable dropout and other randomness.

  • Avoid checking exactly at ReLU kinks.

  • Compare the same scalar loss and reduction.

  • Test several directions and \(\epsilon\) values.

✏️ Derivation: why central differences, and how to choose \(\epsilon\)

Step 1. Taylor in direction \(v\): \(L(\theta\pm\epsilon v)=L\pm\epsilon L'+\frac{\epsilon^2}{2}L''\pm\frac{\epsilon^3}{6}L'''+O(\epsilon^4)\), with \(L'=D_vL\).

Step 2. Subtract: \(\frac{L(\theta+\epsilon v)-L(\theta-\epsilon v)}{2\epsilon}=L'+\frac{\epsilon^2}{6}L'''+O(\epsilon^4)\). The even terms cancel, so the truncation error is \(O(\epsilon^2)\). A forward difference keeps \(\frac{\epsilon}{2}L''\), which is \(O(\epsilon)\).

Step 3. Roundoff: each \(L\) has error about \(u|L|\) (\(u\approx10^{-16}\) in float64, \(10^{-7}\) in float32). Dividing by \(2\epsilon\) gives error \(\approx u|L|/\epsilon\).

Step 4. Total \(\approx\frac{\epsilon^2}{6}|L'''|+\frac{u|L|}{\epsilon}\). Minimizing over \(\epsilon\) gives \(\epsilon^*\propto u^{1/3}\): about \(5\times10^{-6}\) in float64. In float32, \(\epsilon^*\approx5\times10^{-3}\) and the best achievable error is about \(10^{-5}\) relative, which is too coarse. Check in float64.

Step 5. Compare with a relative error \(\frac{|a-b|}{\max(|a|,|b|,10^{-12})}\), and expect \(\lesssim10^{-7}\) in float64.

⚙️ Algorithm: directional gradient check
Input: \(L(\theta)\) in float64, deterministic (no dropout), \(\epsilon\approx10^{-6}\)
\(g\gets\) autograd gradient; draw random \(v\), normalize \(\|v\|=1\)
\(a\gets g^\top v\)
\(b\gets\big(L(\theta+\epsilon v)-L(\theta-\epsilon v)\big)/(2\epsilon)\)
pass iff \(|a-b|/\max(|a|,|b|)<10^{-6}\); repeat for several \(v\)

Solution — open after attempting

def unpack(theta):
    offset = 0

    W1 = theta[offset:offset + D * H].view(D, H)
    offset += D * H

    b1 = theta[offset:offset + H]
    offset += H

    W2 = theta[offset:offset + H * C].view(H, C)
    offset += H * C

    b2 = theta[offset:offset + C]

    return W1, b1, W2, b2


def loss_fn(theta, detach_hidden=False):
    W1, b1, W2, b2 = unpack(theta)

    hidden = torch.tanh(X @ W1 + b1)

    if detach_hidden:
        hidden = hidden.detach()

    logits = hidden @ W2 + b2
    return F.cross_entropy(logits, targets)


loss = loss_fn(theta)
gradient = torch.autograd.grad(loss, theta)[0]

direction = torch.randn_like(theta)
direction = direction / direction.norm()

analytic = (gradient * direction).sum()


def central_difference(theta, direction, epsilon, detach_hidden=False):
    with torch.no_grad():
        loss_plus = loss_fn(
            theta + epsilon * direction,
            detach_hidden=detach_hidden,
        )
        loss_minus = loss_fn(
            theta - epsilon * direction,
            detach_hidden=detach_hidden,
        )

    return (loss_plus - loss_minus) / (2 * epsilon)

The expected error is roughly U-shaped:

  • At large \(\epsilon\), the approximation is not sufficiently local.

  • At moderate \(\epsilon\), numerical and analytic derivatives agree closely.

  • At extremely small \(\epsilon\), subtracting nearly equal losses causes cancellation.

For the detach bug, the forward value of hidden still changes when the first-layer parameters change. Finite differences therefore observe a change in the loss.

Autograd, however, treats the detached hidden tensor as constant:

\[\frac{\partial\,\text{hidden.detach()}} {\partial\theta_{\text{first}}} =0\]

This mismatch is exactly the kind of silent broken-gradient path that gradient checking can expose.

Check answers:

  1. It requires only two additional forward evaluations, rather than roughly \(2P\) evaluations for all coordinates.

  2. FP64 reduces rounding and cancellation error, allowing a much more informative comparison.

  3. Error generally decreases, reaches a minimum, and then increases again due to floating-point cancellation.

  4. The positive and negative perturbations are being evaluated with different random dropout masks. Disable randomness or restore identical RNG state.

  5. ReLU is not differentiable at zero. Autograd selects a convention, while finite differences may cross between two different linear regions.

Retrieval answers:

\[dS=A\odot \left(dA-\sum_j dA_jA_j\right)\]

Saturated or nearly one-hot attention can preserve value gradients while making query/key gradients extremely small.
