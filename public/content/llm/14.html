🚀 Starting point

Starting point. The likelihood \(L(\theta)=\prod_ip(x_i\mid\theta)\) is the probability of the observed data as a function of the parameter. The maximum-likelihood estimate (MLE) picks the \(\theta\) that makes the data most probable. Part 0 showed that every standard loss (cross-entropy, BCE, MSE) is a negative log-likelihood, so training a network is MLE.

✏️ Derivation: Two MLEs

Step 1. Bernoulli: \(\ell(p)=h\log p+(n-h)\log(1-p)\). \(\ell'(p)=\frac hp-\frac{n-h}{1-p}=0\Rightarrow\hat p=h/n\).

Step 2. Gaussian: \(\ell(\mu,\sigma^2)=-\frac n2\log(2\pi\sigma^2)-\frac1{2\sigma^2}\sum(x_i-\mu)^2\). \(\partial_\mu=0\Rightarrow\hat\mu=\bar x\); \(\partial_{\sigma^2}=0\Rightarrow\hat\sigma^2=\frac1n\sum(x_i-\bar x)^2\), the biased-low divisor from the last chapter.

✏️ Derivation: Fisher information and the Cramér–Rao bound

Step 1. The score is \(s(\theta)=\partial_\theta\log p(x\mid\theta)\). It has mean zero: \(\mathbb E[s]=\int\partial_\theta p=\partial_\theta\int p=0\).

Step 2. Fisher information \(I(\theta)=\operatorname{Var}(s)=-\mathbb E[\partial^2_\theta\log p]\): how sharply the log-likelihood curves around the truth. For a Bernoulli, \(I(p)=\frac1{p(1-p)}\).

Step 3. Cramér–Rao: any unbiased estimator from \(n\) samples has \(\operatorname{Var}\hat\theta\ge\frac1{nI(\theta)}\), and the MLE reaches it as \(n\) grows: \(\hat\theta\approx N\big(\theta,\frac1{nI(\theta)}\big)\). For \(p=0.3,n=200\): \(0.00105\), matched by simulation.

Step 4. In several parameters, \(I\) is a matrix, and the standard errors are \(\sqrt{\operatorname{diag}(H^{-1})}\) with \(H\) the Hessian of the negative log-likelihood at the MLE. The Fisher matrix is also the metric behind natural gradients and TRPO’s KL constraint (\(\mathrm{KL}\approx\tfrac12\delta^\top I\delta\)).

MAP: the prior as a regulariser

The maximum a posteriori estimate maximises \(\log p(\text{data}\mid\theta)+\log p(\theta)\). A Beta\((a,b)\) prior on a coin gives \(\hat p_{\text{MAP}}=\frac{h+a-1}{n+a+b-2}\): three heads in three flips gives 1.0 by MLE but 0.64 with a Beta(5,5) prior. A Gaussian prior on weights gives L2 weight decay; a Laplace prior gives L1.

Logistic regression by Newton’s method

The negative log-likelihood of logistic regression is binary cross-entropy. Gradient \(X^\top(p-y)\), Hessian \(X^\top\operatorname{diag}(p(1-p))X\) (positive definite, so the problem is convex). Newton’s method (iteratively reweighted least squares) converges quadratically: the gradient norm goes from 22 to \(10^{-4}\) in three steps, and the inverse Hessian gives the standard errors for free.

"""Inference: maximum likelihood, Fisher information, MAP, and logistic regression by Newton's method."""
import numpy as np

rng = np.random.default_rng(0)

# 1. Bernoulli MLE = sample mean; Gaussian MLE = sample mean and the 1/n variance.
x = rng.random(200) < 0.3
grid = np.linspace(0.01, 0.99, 9801)
ll = x.sum() * np.log(grid) + (len(x) - x.sum()) * np.log(1 - grid)
print(f"[mle] Bernoulli: grid argmax {grid[ll.argmax()]:.4f}  closed form mean {x.mean():.4f}")
g = rng.normal(5, 2, 500)
print(f"[mle] Gaussian: mu-hat {g.mean():.4f}  sigma2-hat (1/n) {((g - g.mean())**2).mean():.4f}  true 5, 4")

# 2. Fisher information and the sampling spread of the MLE: Var(p-hat) ~ 1 / (n I(p)), I(p) = 1/(p(1-p)).
p, n = 0.3, 200
est = (rng.random((20_000, n)) < p).mean(1)
print(f"[fisher] Var of MLE across 20,000 datasets {est.var():.6f}   Cramer-Rao 1/(n I) = {p * (1 - p) / n:.6f}")

# 3. Exponential rate MLE 1/mean is biased in small samples: E = n/(n-1) lam.
lam = 2.0
for n in (5, 50):
    e = 1 / rng.exponential(1 / lam, (200_000, n)).mean(1)
    print(f"[bias] n={n:2d}: mean of rate MLE {e.mean():.4f}   theory n/(n-1) lam = {n / (n - 1) * lam:.4f}")

# 4. MAP with a Beta(a, b) prior = (h + a - 1) / (n + a + b - 2): shrinks small samples toward the prior.
a = b = 5
for h, n in ((3, 3), (30, 50), (300, 500)):
    print(f"[map] {h:3d}/{n:3d} heads: MLE {h / n:.3f}   MAP {(h + a - 1) / (n + a + b - 2):.3f}")

# 5. Logistic regression: NLL = binary cross-entropy. Gradient X^T (p - y), Hessian X^T diag(p(1-p)) X.
X = np.c_[np.ones(1000), rng.normal(size=(1000, 2))]
w_true = np.array([-0.5, 2.0, -1.0])
y = (rng.random(1000) < 1 / (1 + np.exp(-X @ w_true))).astype(float)
w = np.zeros(3)
for it in range(8):
    pr = 1 / (1 + np.exp(-X @ w))
    grad, H = X.T @ (pr - y), X.T @ (X * (pr * (1 - pr))[:, None])
    w -= np.linalg.solve(H, grad)
    nll = -(y * np.log(pr) + (1 - y) * np.log(1 - pr)).mean()
    if it in (0, 1, 2, 5, 7):
        print(f"[logreg] Newton iter {it}: mean BCE {nll:.6f}  |grad| {np.linalg.norm(grad):.2e}")
se = np.sqrt(np.diag(np.linalg.inv(H)))
print(f"[logreg] w-hat {np.round(w, 3)}  true {w_true}  standard errors from the inverse Hessian {np.round(se, 3)}")
