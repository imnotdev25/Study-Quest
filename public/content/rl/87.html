🧩 Analogy: asking several experts about an unfamiliar case

Ask five doctors about a common illness and they’ll agree. Ask about something none of them has seen and their guesses scatter. That scatter is useful: it says “we don’t know.” Train several FQE critics differently, and their disagreement flags values the logs never pinned down.

2. Bellman regression cannot determine an unseen action’s value

Suppose logs contain no transition for \((s,a)\). FQE receives no direct regression gradient for:

\[Q(s,a)\]

Its value is determined by initialization, regularization and neural-network generalization—not observed evidence.

An ensemble fits \(M\) critics with different initialization or bootstrap data:

\[\hat Q_1,\ldots,\hat Q_M\]

Each produces a target-policy value:

\[\hat V_m(s) = \sum_a\pi(a\mid s)\hat Q_m(s,a)\]

Measure disagreement:

\[\bar V(s) = \frac1M\sum_m\hat V_m(s)\]

\[\sigma_V(s) = \sqrt{ \frac1M\sum_m \left( \hat V_m(s)-\bar V(s) \right)^2 }\]

If an unsupported action receives substantial target-policy probability, its disagreement propagates backward through Bellman targets.

A heuristic pessimistic score is:

\[V_{\text{pess}} = \bar V-\beta\sigma_V\]

This is not automatically a statistically valid confidence bound. Ensembles can agree because they share the same architecture, data, regularization or modeling error.

Also report unsupported target mass:

\[u(s) = \sum_a \pi(a\mid s) \mathbf1[N(s,a)=0]\]

Tensor shapes:

  • ensemble \(Q\)-tables: [M, S, A]

  • transition targets: [M, N]

  • policy values: [M]

  • coverage counts: [S, A]

For LLM agents, exact actions rarely repeat. Coverage must therefore be examined through meaningful abstractions such as tool type, argument schema, prompt family, turn depth and policy likelihood—not raw token identity alone.

A DPO policy may remain close to its reference in KL while still increasing probability on poorly covered tool trajectories. Preference proximity does not prove environmental support.

🔍 Deeper: pessimistic ensemble value

Train \(M\) FQE critics with different seeds and bootstrap resamples of the logs. Report \(\bar V\) and \(\mathrm{sd}_m(V_m)\), and decide on \(\bar V-k\cdot\mathrm{sd}\). Disagreement propagates: an unsupported \(Q(s',a')\) enters the target of every earlier state that leads to \(s'\), so uncertainty flows backward through the Bellman backups. Not calibrated: the spread is a warning signal, not a confidence interval.

🔑 Key ideas

  • Let plausible critics disagree where the logs say nothing.

  • Treat disagreement as a warning, not a guarantee.

🚶 Walkthrough: five critics at an unsupported action

\(Q_m(s',R)=(4.0,-1.0,2.5,0.5,3.0)\), mean 1.8, sd 2.0. At the supported action \(L\): \((1.0,1.1,0.9,1.0,1.0)\), sd 0.07. Pessimistic value with \(k=1\): \(1.8-2.0=-0.2\) for \(R\). The ensemble is effectively saying “don’t rely on this action.”

Common mistakes

  • Same seed and same data for all members.

  • Averaging away the disagreement and reporting only \(\bar V\).

  • Treating \(\pm2\)sd as a 95% interval.

Hints

  • target_tables[:, fit_next_states, :] has shape [M, N, A].

  • Broadcast target-policy probabilities with a leading model dimension.

  • Predictions use q_tables[:, fit_states, fit_actions].

  • Evaluate each model with target_policy[0].

  • Ensemble standard deviation is across dimension 0.

  • An unseen pair has coverage count zero.

  • Multiply the zero-coverage indicator by the target-policy table.

Debugging experiments

  • Give every critic identical initialization. Missing-action disagreement can falsely become zero.

  • Apply strong weight decay. All unsupported values may collapse toward the same number without gaining evidence.

  • Compute variance across actions instead of across models. That measures action-value differences, not epistemic uncertainty.

  • Forget the terminal mask. Random terminal values create artificial ensemble disagreement.

  • Multiply rewards by 100 without rescaling \(\beta\). Pessimism changes purely because reward units changed.

  • Interpret high disagreement as proof that an action is bad. It means evidence is weak, not that the true value is low.

  • Interpret agreement as proof of correctness. Shared misspecification can make every critic wrong in the same direction.

Coverage diagnostics:

def coverage_table(
    table_states,
    table_actions,
):
    pair_ids = (
        table_states * num_actions
        + table_actions
    )

    return torch.bincount(
        pair_ids,
        minlength=(
            num_states * num_actions
        ),
    ).reshape(
        num_states,
        num_actions,
    )


full_coverage = coverage_table(
    states,
    actions,
)

gap_coverage = coverage_table(
    states[support_gap_mask],
    actions[support_gap_mask],
)

full_unsupported_mass = (
    target_policy
    * (
        full_coverage == 0
    ).to(torch.float64)
).sum(dim=-1)[:2]

gap_unsupported_mass = (
    target_policy
    * (
        gap_coverage == 0
    ).to(torch.float64)
).sum(dim=-1)[:2]

With complete coverage, every relevant critic should approach:

\[Q^\pi = \begin{bmatrix} 1&2.43\\ 0&3\\ *&* \end{bmatrix}\]

so:

\[V^\pi(0)=2.144\]

and ensemble disagreement should be nearly zero.

With (state=1, action=1) absent, its target-policy unsupported mass is:

\[u(1)=\pi(1\mid1)=0.9\]

That missing value affects its predecessor:

\[Q(0,1) = 0.9[ 0.1Q(1,0)+0.9Q(1,1) ]\]

Therefore, initialization-dependent uncertainty propagates into the reported initial value even though the observed Bellman loss can be almost zero.

Check answers

  1. Observed state-action pairs receive repeated regression gradients; sufficiently optimized tabular values lose their initialization dependence.

  2. It is the probability that the target policy assigns to actions with no logged coverage in a state.

  3. Members are correlated and may share data, architectures and errors. Their empirical spread has no automatic frequentist coverage guarantee.

  4. Report ensemble spread by state or turn, target mass on rare actions, visitation counts, initialization and bootstrap diversity, Bellman residuals, reward scale, terminal masking and sensitivity to architecture and regularization.

Retrieval answers

  1. Bellman loss only tests logged state-action pairs; unsupported counterfactual values can still dominate the target-policy expectation.

  2. Using max applies the Bellman optimality operator and evaluates an implied greedy policy rather than the fixed target policy.

Takeaway: when logs do not constrain an action, different plausible critics should be allowed to disagree. Treat that disagreement as a warning signal, not a calibrated guarantee—and never let a small training loss hide missing support.
