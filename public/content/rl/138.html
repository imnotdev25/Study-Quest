2. Combine FQE with occupancy-ratio corrections

Suppose FQE provides a value model:

\[\hat V_t(s) = \underbrace{ \sum_a\pi(a\mid s)\hat Q_t(s,a) }_{\text{modelled target-policy return}}\]

For each logged transition, calculate its TD residual:

\[\delta_t = \underbrace{R_t}_{\text{observed reward}} + \underbrace{ \gamma(1-D_t)\hat V_{t+1}(S_{t+1}) }_{\text{modelled future return}} - \underbrace{ \hat Q_t(S_t,A_t) }_{\text{modelled return before transition}}\]

Marginalized doubly robust evaluation corrects these residuals using occupancy ratios:

\[\hat V_{\mathrm{MDR}} = \underbrace{ \frac1N\sum_i\hat V_0(S_0^{(i)}) }_{\text{FQE baseline}} + \sum_{t=0}^{T-1} \underbrace{\gamma^t}_{\text{discount}} \frac1N\sum_i \underbrace{ \frac{d_t^\pi(S_t^{(i)},A_t^{(i)})} {d_t^\mu(S_t^{(i)},A_t^{(i)})} }_{\text{marginal occupancy correction}} \underbrace{\delta_t^{(i)}}_{\text{observed model error}}\]

It has two rescue routes:

  • Correct occupancy ratios make the residuals repair an incorrect \(Q\)-model.

  • A correct \(Q\)-model gives:

\[E[\delta_t\mid S_t,A_t] = \underbrace{0}_{\text{no systematic correction}}\]

even if the ratios are incorrect.

If both are wrong, the estimator can be confidently biased. Marginalization reduces variance; it does not create missing support.

For LLM agents, \(\hat Q\) must estimate future task return—not merely the current reward-model score. DPO supplies neither this trajectory-value model nor deployment occupancy ratios.

Tensor shapes:

  • trajectories: [R, N, T]

  • \(Q\)-values: [T, S, A]

  • \(V\)-values: [T+1, S]

  • occupancy ratios: [T, S, A]

  • repeated estimates: [R]

The model recursion is:

\[\hat Q_t(s,a) = \underbrace{\hat r(s,a)}_{\text{modelled immediate reward}} + \underbrace{ \gamma\hat V_{t+1}(s\oplus a) }_{\text{modelled future after XOR transition}}\]

\[\hat V_t(s) = \underbrace{ \sum_a\pi(a\mid s)\hat Q_t(s,a) }_{\text{target-policy expectation}}\]

  • Initialize \(V_T=0\).

  • Sample rewards from reward_probability_table[state, action].

  • Index time-dependent tensors with time_indices.

  • Add the residual correction to the initial baseline.

  • Do not multiply the initial baseline by an importance weight.

  • In a variable-length batch, multiply the next value by 1 - done.

Value models:

def build_value_model(reward_model):
    q_values = torch.zeros(
        horizon,
        num_states,
        num_actions,
    )

    v_values = torch.zeros(
        horizon + 1,
        num_states,
    )

    for time in reversed(range(horizon)):
        for state in range(num_states):
            for action in range(num_actions):
                next_state = state ^ action

                q_values[
                    time,
                    state,
                    action,
                ] = (
                    reward_model[state, action]
                    + gamma
                    * v_values[
                        time + 1,
                        next_state,
                    ]
                )

        v_values[time] = (
            target_policy
            * q_values[time]
        ).sum(dim=-1)

    return q_values, v_values

    actions[..., time] = sampled_actions

    next_state = (
        current_states ^ sampled_actions

    next_states[..., time] = next_state

    reward_probabilities = (
        reward_probability_table[
            current_states,
            sampled_actions,

    rewards[..., time] = (
        torch.rand(
            num_repetitions,
            episodes_per_repetition,
        )
        < reward_probabilities
    ).to(torch.float64)

    current_states = next_state

mis_estimates = (

def marginalized_dr(
    q_model,
    v_model,
    weights,
):
    logged_q_values = q_model[
        time_indices,
        states,
        actions,
    ]

    next_time_indices = torch.arange(
        1,
        horizon + 1,
    ).view(1, 1, horizon)

    next_values = v_model[
        next_time_indices,
        next_states,
    ]

    td_residuals = (
        rewards
        + gamma * next_values
        - logged_q_values
    )

    corrections = (
        discounts
        * weights
        * td_residuals
    ).sum(dim=-1).mean(dim=1)

    return (
        v_model[0, 0]
        + corrections
    )


mdr_exact_model_exact_ratios = marginalized_dr(

Check answers

  1. Either the occupancy ratios are correct or the trajectory \(Q\)-model is correct.

  2. It importance-weights residual surprises rather than full rewards; a useful model removes predictable reward variation.

  3. Real \(Q\)-models are not exact. Incorrect ratios expose any remaining systematic model error.

  4. It prevents nuisance models from fitting the same random reward noise later used to assess their corrections.

  5. No. Neither a value model nor a density-ratio model can identify an outcome absent from the logs.

Retrieval answers

  1. MIS conditions cumulative history ratios on the current state–action pair, averaging away irrelevant differences between histories that merged.

  2. A complete autoregressive prefix nearly identifies its history, leaving few alternative trajectories to average over.

Takeaway: the strongest offline estimator is not automatically the one with the smallest variance. MDR is reliable when at least one nuisance component is credible—and dangerously precise when both are wrong.
