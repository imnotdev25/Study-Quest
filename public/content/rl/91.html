🧩 Analogy: judging a diet by weight change

To judge a diet, you look at each person’s weight change, not their final weight. Their starting weight explains most of the variation and has nothing to do with the diet. CUPED does the same: subtract the part of each prompt’s outcome that its difficulty already predicted.

2. An experimental baseline works like a policy-gradient baseline

Some prompts are intrinsically easier than others. Randomization prevents systematic bias, but a small canary may accidentally send more easy prompts to one arm, increasing variance.

Let \(X_i\) be a pre-treatment difficulty signal correlated with outcome \(Y_i\). CUPED constructs:

\[Y_i^{\text{adj}} = Y_i-\theta(X_i-\bar X)\]

The variance-minimizing coefficient is:

\[\theta^* = \frac{\operatorname{Cov}(Y,X)} {\operatorname{Var}(X)}\]

Then estimate the policy effect using adjusted outcomes:

\[\hat\Delta_{\text{CUPED}} = \bar Y_{\text{candidate}}^{\text{adj}} - \bar Y_{\text{control}}^{\text{adj}}\]

This resembles subtracting a baseline in REINFORCE:

  • the baseline explains predictable variation;

  • it should not change the expected policy effect;

  • removing predictable variation lowers estimator variance.

With optimal \(\theta\), the approximate variance reduction is:

\[\frac{ \operatorname{Var}(Y^{\text{adj}}) }{ \operatorname{Var}(Y) } = 1-\rho_{Y,X}^2\]

A correlation of \(0.8\) removes roughly 64% of outcome variance.

The covariate must be measured before policy assignment. Valid examples include:

  • historical user success;

  • a frozen prompt-difficulty score;

  • prompt family or domain;

  • control-policy predicted success before generating a response.

Post-treatment quantities—response length, tool count, latency, judge score—may be changed by the candidate. Adjusting for them can remove part of the treatment effect or introduce bias.

Tensor shapes:

  • repeated experiments: outcomes and covariates [R, N]

  • assignment mask: [R, N]

  • raw and adjusted effects: [R]

  • estimator diagnostics: [2]

Estimate \(\theta\) from independent pilot data, or use cross-fitted predictions. If a neural baseline is used, persist detached predictions; evaluation must not train the baseline on its own held-out outcomes.

For context-dependent adaptive routing, CUPED alone does not correct assignment imbalance. Combine outcome modeling with the logged propensities—an augmented inverse-propensity estimator.

DPO may create the candidate policy, but DPO loss is not a valid pre-treatment covariate. A prompt-only reward prediction can be; a score computed from the candidate response cannot.

🔍 Deeper: control variates

With a pre-treatment covariate \(X\) (e.g. the baseline model’s score on that prompt): \(Y^{\text{adj}}=Y-\theta(X-\bar X)\), with \(\theta=\operatorname{Cov}(X,Y)/\operatorname{Var}(X)\) estimated on pooled data. \(\operatorname{Var}[Y^{\text{adj}}]=(1-\rho^2)\operatorname{Var}[Y]\), where \(\rho=\operatorname{corr}(X,Y)\). The treatment effect estimate stays unbiased because \(X\) is fixed before assignment. This is the same trick as a policy-gradient baseline: subtract something predictable and uncorrelated with the decision.

🔑 Key ideas

  • Prompt difficulty is predictable noise, so subtract it.

  • Freeze the covariate before the experiment.

🚶 Walkthrough: how much sample size it buys

\(\rho=0.8\): variance factor \(1-0.64=0.36\). The same precision now needs only 36% of the samples, about a 2.8\(\times\) speed-up.

Common mistakes

  • A covariate measured after treatment (e.g. the candidate’s own score).

  • Estimating \(\theta\) separately in each arm.

  • “Adjusting away” behaviour the candidate itself caused.

Hints

  • Center pilot tensors by subtracting their means.

  • The covariance and variance denominators cancel in the ratio for \(\theta\).

  • Use torch.corrcoef for the pilot correlation.

  • Center difficulty independently within every simulated experiment.

  • Apply the same frozen \(\theta\) to both arms.

  • Standard error combines arm-specific sample variances divided by their counts.

Debugging experiments

  • Estimate separate \(\theta\) values for candidate and control using the same evaluation outcomes.

  • Use a difficulty model trained on every evaluation outcome without cross-fitting.

  • Adjust for tool calls or latency produced after assignment.

  • Forget to freeze or detach neural baseline predictions.

  • Apply ordinary CUPED to context-dependent routing without propensity correction.

  • Standardize reward values but retain an old, differently scaled \(\theta\).

Solutions

Pilot coefficient:

centered_pilot_difficulty = (
    pilot_difficulty
    - pilot_difficulty.mean()
)

centered_pilot_outcomes = (
    pilot_outcomes
    - pilot_outcomes.mean()
)

theta_hat = (
    (
        centered_pilot_difficulty
        * centered_pilot_outcomes
    ).sum()
    / centered_pilot_difficulty
    .square()
    .sum()
)

pilot_correlation = torch.corrcoef(
    torch.stack([
        pilot_difficulty,
        pilot_outcomes,
    ])
)[0, 1]

expected_variance_ratio = (
    1.0 - pilot_correlation.square()
)

Raw estimates:

raw_candidate_means = masked_mean(
    outcomes,
    assignment,
)

raw_control_means = masked_mean(
    outcomes,
    control_assignment,
)

raw_effects = (
    raw_candidate_means
    - raw_control_means
)

CUPED estimates:

centered_difficulty = (
    difficulty
    - difficulty.mean(
        dim=1,
        keepdim=True,
    )
)

adjusted_outcomes = (
    outcomes
    - theta_hat
    * centered_difficulty
)

adjusted_candidate_means = masked_mean(
    adjusted_outcomes,
    assignment,
)

adjusted_control_means = masked_mean(
    adjusted_outcomes,
    control_assignment,
)

cuped_effects = (
    adjusted_candidate_means
    - adjusted_control_means
)

Estimator diagnostics:

mean_effects = all_effects.mean(
    dim=0
)

biases = (
    mean_effects - true_effect
)

standard_deviations = (
    all_effects.std(
        dim=0,
        correction=1,
    )
)

rmses = (
    (
        all_effects - true_effect
    )
    .square()
    .mean(dim=0)
    .sqrt()
)

empirical_variance_ratio = (
    cuped_effects.var(
        correction=1
    )
    / raw_effects.var(
        correction=1
    )
)

Standard errors:

candidate_counts = assignment.sum(
    dim=1
)

control_counts = (
    control_assignment.sum(dim=1)
)

raw_standard_errors = torch.sqrt(
    masked_variance(
        outcomes,
        assignment,
    ) / candidate_counts
    +
    masked_variance(
        outcomes,
        control_assignment,
    ) / control_counts
)

cuped_standard_errors = torch.sqrt(
    masked_variance(
        adjusted_outcomes,
        assignment,
    ) / candidate_counts
    +
    masked_variance(
        adjusted_outcomes,
        control_assignment,
    ) / control_counts
)

mean_raw_standard_error = (
    raw_standard_errors.mean()
)

mean_cuped_standard_error = (
    cuped_standard_errors.mean()
)

Ignoring the small treatment contribution, the outcome variance is:

\[\operatorname{Var}(Y) = 1.5^2\operatorname{Var}(X)+1^2 = 3.25\]

The population correlation is:

\[\rho = \frac{1.5}{\sqrt{3.25}} \approx0.832\]

Therefore:

\[1-\rho^2 = 1-\frac{2.25}{3.25} \approx0.308\]

CUPED should retain only about 31% of the raw estimator’s variance.

With roughly 250 episodes per arm, the raw standard deviation is approximately:

\[\sqrt{ \frac{3.25}{250} + \frac{3.25}{250} } \approx0.161\]

After removing prompt difficulty, residual variance is near one:

\[\sqrt{ \frac1{250} + \frac1{250} } \approx0.089\]

Both estimators remain centered near the true effect 0.10; CUPED reaches substantially lower variance and RMSE.

Check answers

  1. Randomization balances any pre-treatment quantity in expectation, so the expected candidate/control difference in the subtracted baseline is zero.

  2. Both subtract predictable variation that is unrelated to the parameter’s expectation, reducing noise without intentionally changing the signal.

  3. A post-treatment variable may mediate the policy’s real effect. Conditioning on it can remove that effect or introduce collider bias.

  4. If routing probabilities vary with context or history, use logged propensities. Combine a cross-fitted outcome baseline with propensity correction when both imbalance and outcome noise matter.

Retrieval answers

  1. Context-dependent assignment gives candidate and control different prompt populations, so their raw means target different context mixtures.

  2. Use the exact conditional probability that the deployed router assigned that episode to its observed arm—not a later reconstruction or average traffic fraction.

Takeaway: prompt difficulty is experimental noise you can often predict before generation. Subtract it like a policy-gradient baseline—but freeze it before evaluation and never “control away” behavior caused by the candidate itself.
