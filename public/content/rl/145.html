2. A ratio needs covariance-aware uncertainty

SNIS is a ratio of two sample means:

\[\hat V = g(\hat A,\hat B) = \underbrace{ \frac{\hat A}{\hat B} }_{\text{self-normalized estimate}}\]

where:

\[\hat A = \underbrace{\frac1N\sum_iw_iR_i}_{\text{mean weighted reward}}, \qquad \hat B = \underbrace{\frac1N\sum_iw_i}_{\text{mean raw weight}}\]

Think of \(g(A,B)=A/B\) as a surface. Its local slopes are:

\[\nabla g(A,B) = \left[ \underbrace{\frac1B}_{\text{sensitivity to numerator}}, \underbrace{-\frac{A}{B^2}}_{\text{sensitivity to denominator}} \right]\]

The delta method uses these slopes to approximate how sampling noise moves the ratio:

\[\operatorname{Var}(\hat V) \approx \underbrace{ g_A^2\operatorname{Var}(\hat A) }_{\text{numerator uncertainty}} + \underbrace{ g_B^2\operatorname{Var}(\hat B) }_{\text{denominator uncertainty}} + \underbrace{ 2g_Ag_B\operatorname{Cov}(\hat A,\hat B) }_{\text{shared movement}}\]

An equivalent per-episode influence score is:

\[\phi_i = \underbrace{ \frac{w_i(R_i-\hat V)} {\hat B} }_{\text{episode's first-order effect on the ratio}}\]

giving:

\[\widehat{SE}_{\mathrm{delta}} = \underbrace{ \frac{\operatorname{SD}(\phi_1,\ldots,\phi_N)} {\sqrt N} }_{\text{standard error from independent episodes}}\]

Treating \(\hat B\) as fixed ignores its covariance with the numerator. That can produce badly calibrated intervals.

For SNDR, replace \(R_i\) with residual \(e_i\) and add baseline variation:

\[\phi_i^{\mathrm{SNDR}} \approx \underbrace{m_i-\bar m}_{\text{baseline variation}} + \underbrace{ \frac{w_i(e_i-\hat c)} {\bar w} }_{\text{normalized-correction variation}}\]

where \(\hat c=\sum_iw_ie_i/\sum_iw_i\).

This measures sampling uncertainty only. It does not repair model bias, missing support or an invalid reward model.

Hints

SNIS is:

numerator_terms.mean(dim=1) / importance_weights.mean(dim=1)

The influence score is:

importance_weights * (
    rewards - snis_estimates[:, None]
) / mean_weights[:, None]

Its row mean should be approximately zero—in exact arithmetic, the weighted residuals sum to zero.

For the bootstrap, resample complete episode indices from one repetition. Do not resample numerator and denominator independently.

Debugging experiments

  • Bootstrap weighted rewards and weights using different episode indices.

  • Calculate std(w * reward) / sqrt(N) and ignore denominator randomness.

  • Divide the influence-score standard deviation by \(N\) instead of \(\sqrt N\).

  • Build intervals from individual tokens belonging to correlated trajectories.

  • Allow gradients through propensities or frozen nuisance predictions.

  • Multiply long token-level ratios directly; use log-ratios and logsumexp for numerical stability.

  • Interpret delta-method coverage as evidence that the reward or propensity models are valid.

Solutions

Logged data:

actions = (
    torch.rand(
        num_repetitions,
        episodes_per_repetition,
    )
    < behavior_policy[1]
).to(torch.long)

rewards = reward_by_action[actions]

importance_weights = (
    target_policy[actions]
    / behavior_policy[actions]
)

numerator_terms = (
    importance_weights * rewards
)

exact_target_value = (
    target_policy * reward_by_action
).sum()

SNIS:

mean_numerators = (
    numerator_terms.mean(dim=1)
)

mean_weights = (
    importance_weights.mean(dim=1)
)

snis_estimates = (
    mean_numerators
    / mean_weights.clamp_min(1e-12)
)

Naive standard error:

naive_standard_errors = (
    numerator_terms.std(
        dim=1,
        correction=1,
    )
    / (
        math.sqrt(episodes_per_repetition)
        * mean_weights.clamp_min(1e-12)
    )
)

Delta-method standard error:

influence_scores = (
    importance_weights
    * (
        rewards
        - snis_estimates[:, None]
    )
    / mean_weights[
        :,
        None,
    ].clamp_min(1e-12)
)

maximum_influence_mean_error = (
    influence_scores.mean(dim=1)
    .abs()
    .max()
)

delta_standard_errors = (
    influence_scores.std(
        dim=1,
        correction=1,
    )
    / math.sqrt(episodes_per_repetition)
)

empirical_standard_error = (
    snis_estimates.std(correction=1)
)

Coverage:

naive_lower_bounds = (
    snis_estimates
    - z_value * naive_standard_errors
)

naive_upper_bounds = (
    snis_estimates
    + z_value * naive_standard_errors
)

delta_lower_bounds = (
    snis_estimates
    - z_value * delta_standard_errors
)

delta_upper_bounds = (
    snis_estimates
    + z_value * delta_standard_errors
)

naive_coverage = (
    (
        (naive_lower_bounds <= exact_target_value)
        & (
            exact_target_value
            <= naive_upper_bounds
        )
    )
    .to(torch.float64)
    .mean()
)

delta_coverage = (
    (
        (delta_lower_bounds <= exact_target_value)
        & (
            exact_target_value
            <= delta_upper_bounds
        )
    )
    .to(torch.float64)
    .mean()
)

centered_numerators = (
    numerator_terms
    - mean_numerators[:, None]
)

centered_weights = (
    importance_weights
    - mean_weights[:, None]
)

numerator_weight_covariances = (
    (
        centered_numerators
        * centered_weights
    ).sum(dim=1)
    / (episodes_per_repetition - 1)
)

Episode bootstrap:

bootstrap_indices = torch.randint(
    low=0,
    high=episodes_per_repetition,
    size=(
        num_bootstrap_samples,
        episodes_per_repetition,
    ),
)

bootstrap_weights = (
    importance_weights[0][bootstrap_indices]
)

bootstrap_rewards = (
    rewards[0][bootstrap_indices]
)

bootstrap_estimates = (
    (
        bootstrap_weights
        * bootstrap_rewards
    ).sum(dim=1)
    / bootstrap_weights.sum(
        dim=1
    ).clamp_min(1e-12)
)

bootstrap_standard_error = (
    bootstrap_estimates.std(
        correction=1
    )
)

Typical results:

  • mean SNIS estimate: approximately 0.494;

  • empirical estimator SD: approximately 0.061;

  • mean delta-method SE: approximately 0.059;

  • bootstrap SE: usually near 0.06;

  • delta-method 95% coverage: approximately 95%;

  • naive mean SE: approximately 0.106;

  • naive coverage: approximately 99.5%.

The naive interval is too wide because the numerator and denominator rise together. In the delta variance:

\[2 \underbrace{\frac1B}_{g_A>0} \underbrace{\left(-\frac A{B^2}\right)}_{g_B<0} \underbrace{\operatorname{Cov}(\hat A,\hat B)}_{>0} <0\]

so the covariance term subtracts uncertainty.

Check answers

  1. Positive: rare action observations increase both the weighted reward and total weight.

  2. It reduces variance because the two derivatives have opposite signs.

  3. Too wide in this example; it ignores the stabilizing covariance.

  4. Yes, when overlap and sample size make the linear approximation reasonable.

  5. No. Standard errors describe variation around the estimator’s expectation, not its bias from self-normalization or model misspecification.

Retrieval answers

  1. Normalize only the importance-weighted residual correction; average the model baseline normally.

  2. The required residual is never observed, so weighting or normalization cannot correct that model error.

Takeaway: a ratio estimator’s numerator and denominator move together. Use an influence-function or paired bootstrap calculation that preserves this covariance—then separately audit support and estimator bias.
