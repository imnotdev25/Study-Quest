🧩 Analogy: curving a class where everyone scored 79–81

If every student scores between 79 and 81, a curve that standardizes scores turns an 81 into an “A” and a 79 into an “F.” The 2-point difference might be pure luck, but standardization blows it up to the same size as a real gap. That’s the risk of dividing GRPO advantages by a tiny group standard deviation.

2. Centering and scaling do different jobs

For responses sampled for prompt \(i\), group centering gives:

\[A_{i,j}^{\text{centered}} = R_{i,j}-\mu_i\]

where:

\[\mu_i=\frac1G\sum_jR_{i,j}\]

Centering says whether a response is above or below its group average.

Group standardization additionally divides by the group standard deviation:

\[\sigma_i = \sqrt{ \frac1G \sum_j (R_{i,j}-\mu_i)^2 }\]

\[A_{i,j}^{\text{standardized}} = \frac{R_{i,j}-\mu_i} {\sigma_i+\epsilon}\]

This makes groups with different raw reward scales more comparable.

For a positive affine reward transformation:

\[R' = cR+d,\qquad c>0\]

ideal standardization gives approximately:

\[\frac{R'-\mu'}{\sigma'} = \frac{c(R-\mu)}{c\sigma} = \frac{R-\mu}{\sigma}\]

So adding 10 or multiplying rewards by 100 should barely change standardized advantages.

The dangerous side

Suppose rewards are:

[0.490, 0.500, 0.510, 0.500]

The differences may be scorer noise, but standardization expands them to order-one advantages. Standardization removes units; it does not prove that tiny differences are meaningful.

Other practical cases:

  • zero group variance produces zero centered advantages;

  • omitting epsilon produces division by zero;

  • large epsilon dampens low-variance groups;

  • global normalization mixes prompt difficulty with response quality;

  • reward normalization changes the effective balance with KL, entropy and auxiliary losses.

Tensor shapes:

  • group rewards and advantages: [prompts, group]

  • group mean and standard deviation: [prompts, 1]

  • policy logits and gradients: [prompts, group]

DPO uses preference pairs and a \(\beta\)-scaled log-ratio objective. It does not require online group-reward normalization, though its own scale hyperparameters still affect update strength.

🔍 Deeper: scale invariance cuts both ways

\(\hat A_i=(r_i-\bar r)/(\sigma+\varepsilon)\) is unchanged when \(r\to ar+c\) with \(a>0\). That’s useful: prompts with different reward scales become comparable. But the same invariance means a group whose rewards differ by \(0.001\) of pure noise gets advantages as large as a group with a real, clear winner.

Bernoulli case: \(\sigma=\sqrt{p(1-p)}\), so dividing by it upweights prompts that are almost always right or almost always wrong by \(1/\sqrt{p(1-p)}\). This is one argument behind Dr. GRPO’s choice to drop the std division.

Practical: log the raw within-group std, set a floor on \(\varepsilon\), and check whether near-zero-std groups dominate the update.

🔑 Key ideas

  • Standardization equalizes scales, and it also equalizes signal with noise.

  • Inspect raw group variance before trusting normalized advantages.

🚶 Walkthrough: tiny differences become big advantages

\(r=(0.80,0.81,0.79,0.80)\). Mean \(0.80\), sample std \(0.0082\). \(\hat A=(0,+1.22,-1.22,0)\). A 0.01 difference, possibly judge noise, gets as large an advantage as a real success vs failure.

Common mistakes

  • \(\varepsilon\) too small (\(10^{-8}\)) for continuous judge scores.

  • Not logging the raw within-group std.

  • Assuming std-normalization is harmless because it “just rescales.”

Debugging experiments

Remove epsilon:

standardized_advantages = (
    centered_advantages / group_stds
)

The all-zero group divides 0 by 0 and produces nan.

Next, normalize globally:

global_advantages = (
    rewards - rewards.mean()
) / (
    rewards.std(unbiased=False) + epsilon
)

The prompt with rewards [1,2,3,4] now dominates the common scale, while prompt difficulty and reward magnitude leak into comparisons across prompts.

Finally, set:

epsilon = 0.1

The tiny-difference group is strongly dampened because its standard deviation is much smaller than epsilon. Epsilon is therefore not only a numerical detail when reward variance is small.

  4. Does reward standardization eliminate the need to monitor raw rewards?

Solutions

Group statistics:

group_means = rewards.mean(
    dim=1,
    keepdim=True,
)

group_stds = rewards.std(
    dim=1,
    keepdim=True,
    unbiased=False,
)

Advantages:

centered_advantages = (
    rewards - group_means
)

standardized_advantages = (
    centered_advantages
    / (
        group_stds + epsilon
    )
)

Transformed rewards:

scaled_standardized_advantages = (
    scaled_rewards - scaled_means
) / (
    scaled_stds + epsilon
)

Gradients:

centered_gradient = ascent_gradient(
    centered_advantages
)

standardized_gradient = ascent_gradient(
    standardized_advantages
)

Scale-invariance error:

scale_invariance_error = (
    standardized_advantages
    - scaled_standardized_advantages
).abs().max()

The all-zero group has:

\[R_j-\mu=0 \quad\forall j\]

so every advantage and policy gradient is zero.

The small-difference group has standard deviation around 0.007, so rewards separated by only 0.01 become order-one standardized signals. This makes its gradient magnitude comparable to groups whose raw reward gaps are much larger.

Centered gradients retain reward units. The [1,2,3,4] group therefore produces a much larger gradient than the [0.49,0.50,0.51,0.50] group. Standardization largely removes this scale difference.

Check answers

  1. Both the centered numerator and standard deviation are multiplied by the same positive constant, which cancels.

  2. It can convert evaluator noise or insignificant score differences into large policy updates.

  3. No sampled response is better or worse than another according to the supplied reward.

  4. No. Log raw means, standard deviations, extrema, zero-variance-group rate and reward components alongside normalized advantages.

Retrieval answers

  1. The current reward appears inside its own baseline, partially subtracting its correlation with the score-function gradient.

  2. Centering produces zero advantages for every response, so the prompt contributes no policy-learning signal.

Takeaway: group standardization makes prompt-level reward scales comparable, but it also treats tiny reliable differences and tiny noisy differences alike. Always inspect raw group variance before trusting normalized advantages.
