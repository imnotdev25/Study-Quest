🧩 Analogy: live win-probability on a sports broadcast

During a match, the broadcast shows “Team A: 62% to win.” After a goal it jumps to 80%. The model doesn’t wait for the final whistle. It updates its guess using its next guess. That’s TD learning: learn from “a guess, updated toward a better guess.”

Neuroscience twist: dopamine neurons fire on surprise (the TD error), not on reward itself.

TD looks one step ahead and trusts its own estimate. MC follows the real trajectory to the end.

2. Temporal-difference learning

Suppose you are travelling to a new city. You originally estimate that reaching the destination will take five hours.

After one hour, the navigation system says four hours remain. You can update your original estimate immediately—you do not need to finish the journey first.

That is the idea behind temporal-difference learning.

TD(0) uses this one-step target:

\[Y_t = R_{t+1}+\gamma V(S_{t+1})\]

For a terminal transition:

\[Y_t=R_{t+1}\]

The TD error is:

\[\delta_t = R_{t+1} +\gamma(1-D_t)V(S_{t+1}) -V(S_t)\]

where \(D_t=1\) when the transition truly terminates the episode.

The tabular update is:

\[V(S_t) \leftarrow V(S_t)+\alpha\delta_t\]

Interpret the sign:

  • \(\delta_t>0\): the transition was better than predicted, so increase \(V(S_t)\).

  • \(\delta_t<0\): it was worse than predicted, so decrease \(V(S_t)\).

  • \(\delta_t\approx0\): prediction and one-step target agree.

Monte Carlo versus TD

Property Monte Carlo TD(0)
Property Monte Carlo TD(0)
Target Complete \(G_t\) \(R_{t+1}+\gamma V(S_{t+1})\)
Wait for termination Yes No
Bootstraps No Yes
Typical target variance Higher Lower
Target bias during learning Lower Higher

TD’s target depends on an imperfect estimate, so it can initially be biased. But it avoids waiting for a noisy complete outcome.

Connection to slopes and SGD

For a critic with parameters \(\theta\), define:

\[L(\theta) = \frac12 \left( V_\theta(S_t)-Y_t \right)^2\]

The loss’s slope tells us how changing the prediction changes the error. SGD follows that slope to move \(V_\theta(S_t)\) toward \(Y_t\).

The target is normally treated as fixed:

\[Y_t = R_{t+1} +\gamma V_{\bar\theta}(S_{t+1})\]

The bar means: do not differentiate through the next-state estimate during this update. In PyTorch, we use .detach() or torch.no_grad().

This is called a semi-gradient TD update.

LLM connection

A critic can estimate the value of each generated prefix:

\[V(x,y_{<t})\]

After generating the next token, TD can use the next prefix’s estimated value. This supplies denser learning signals than waiting only for a final response reward, although errors in the critic can propagate backward.

🔍 Deeper: how TD relates to MC

TD error: \(\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)\). The update is \(V(s_t)\leftarrow V(s_t)+\alpha\delta_t\).

Telescoping identity (holding \(V\) fixed within an episode): \[G_t-V(s_t)=\sum_{k=0}^{T-t-1}\gamma^k\delta_{t+k}.\] So the MC error is just the discounted sum of future TD errors. TD uses only the first term, which gives lower variance but adds bias whenever \(V(s_{t+1})\) is wrong.

Semi-gradient view: TD minimizes \(\tfrac12\big(\text{sg}[r+\gamma V(s')]-V(s)\big)^2\), where sg means stop-gradient: the target is treated as a fixed label.

Simulated on the classic 5-state random walk (Sutton & Barto Example 6.2, 100 runs). TD learns faster here, and a larger \(\alpha\) learns fast but plateaus noisier.

🔑 Key ideas

  • TD = bootstrap: the target uses your own current guess.

  • MC: unbiased, high variance. TD: biased, low variance, learns mid-episode.

🚶 Walkthrough: value spreads one step per episode

Chain \(A\to B\to\)end with reward 1 at the end. \(\alpha=0.5\), \(\gamma=1\), \(V=0\).

  • Episode 1: at \(A\), \(\delta=0+V(B)-V(A)=0\). At \(B\), \(\delta=1-0=1\), so \(V(B)=0.5\).

  • Episode 2: at \(A\), \(\delta=0.5\), so \(V(A)=0.25\). At \(B\), \(V(B)=0.75\).

MC would update \(A\) toward 1 in the very first episode. TD needs the news to travel back through \(B\).

Common mistakes

  • Bootstrapping from a terminal state (\(V(\text{end})\) must be 0).

  • Letting gradients flow through the target in the neural version.

  • Updating \(V(s')\) first and then using the new value in \(V(s)\)’s target without meaning to.

⚙️ Algorithm: TD(0) prediction
Input: policy \(\pi\), step size \(\alpha\), discount \(\gamma\)
\(V(s)\gets0\) for every state
for each episode do
\(s\gets\) initial state
while \(s\) is not terminal do
take \(a\sim\pi(\cdot|s)\); observe \(r,s'\) and done flag \(d\)
\(\delta\gets r+\gamma(1-d)V(s')-V(s)\) ▷ TD error
\(V(s)\gets V(s)+\alpha\,\delta\) ▷ update now, mid-episode
\(s\gets s'\)
end
end

Solutions

import torch

gamma = 0.9
alpha = 0.2

states = torch.tensor([0, 1])
next_states = torch.tensor([1, 2])
rewards = torch.tensor([0.0, 5.0])
dones = torch.tensor([0.0, 1.0])

values = torch.nn.Parameter(torch.zeros(3))
optimizer = torch.optim.SGD([values], lr=alpha)

for step in range(100):
    predictions = values[states]

    with torch.no_grad():
        targets = (
            rewards
            + gamma
            * (1.0 - dones)
            * values[next_states]
        )

    errors = predictions - targets
    loss = 0.5 * errors.pow(2).sum()

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

print(values.detach())

Approximate final result:

tensor([4.5000, 5.0000, 0.0000])

These satisfy:

\[V(1)=5\]

\[V(0)=0+0.9V(1)=4.5\]

First two updates

Initially:

V = [0, 0, 0]
targets = [0, 5]

With \(\alpha=0.2\):

V after step 1 ≈ [0, 1, 0]

The next targets become:

target(state 0) = 0 + 0.9(1) = 0.9
target(state 1) = 5

So the second update gives approximately:

V after step 2 ≈ [0.18, 1.8, 0]

Reward information moves backward one transition through bootstrapping.

Check answers

  1. Its target needs only the immediate reward and estimated value of the next state.

  2. It indicates whether the current state was undervalued or overvalued relative to the one-step target.

  3. No future rewards exist after genuine termination, so bootstrapping would introduce fictitious value.

  4. The target should supervise the current prediction. Without detaching, gradients also alter the value used to construct that target.

  5. No. If the underlying process could continue beyond an artificial time limit, it is usually appropriate to bootstrap from the truncated next state.

Retrieval answers

  1. The complete sampled return \(G_t\).

  2. Using an existing value estimate to construct the target for another value estimate.

Takeaway: Monte Carlo asks, “What eventually happened?” TD asks, “What happened now, plus what do I currently predict happens next?”
