2. Correcting stale trajectories — 5 minutes

Distributed agents often collect trajectories while the learner continues updating. By training time, the behavior policy \(\mu\) that generated an action may differ from the current policy \(\pi\).

The raw importance ratio is:

\[\underbrace{\rho_t}_{\text{policy mismatch}} = \exp\left( \underbrace{\log\pi(a_t|s_t)}_{\text{current log-probability}} - \underbrace{\log\mu(a_t|s_t)}_{\text{stored behavior log-probability}} \right)\]

Large ratios correct distribution mismatch but can create extreme variance. V-trace clips them in two different places:

\[\underbrace{\bar{\rho}_t}_{\text{local correction weight}} = \min(\rho_{\max},\rho_t) \qquad \underbrace{c_t}_{\text{trace propagation weight}} = \min(c_{\max},\rho_t)\]

  • \(\bar{\rho}_t\) controls the immediate TD correction.

  • \(c_t\) controls how far later corrections travel backward.

  • Usually \(c_{\max}\leq\rho_{\max}\).

The corrected TD error is:

\[\underbrace{\delta_t^{V}}_{\text{clipped off-policy correction}} = \underbrace{\bar{\rho}_t}_{\text{local importance weight}} \left[ \underbrace{r_t+\gamma(1-d_t)V(s_{t+1})}_{\text{one-step target}} - \underbrace{V(s_t)}_{\text{current estimate}} \right]\]

The V-trace value target is:

\[\underbrace{v_s}_{\text{corrected value target}} = \underbrace{V(s_s)}_{\text{baseline}} + \sum_{t=s}^{T-1} \underbrace{\gamma^{t-s}}_{\text{discount}} \underbrace{\left(\prod_{i=s}^{t-1}c_i\right)}_{\text{trace survival}} \underbrace{\delta_t^V}_{\text{weighted TD evidence}}\]

Clipping trades variance for bias. It does not reconstruct the exact fully off-policy return, but it prevents a few stale transitions from dominating training.

At truncation, bootstrap from the final observation. At true termination, set the bootstrap term to zero.

Shapes:

  • rewards, ratios, termination and valid masks: [B, T]

  • values: [B, T+1]

  • V-trace targets and policy advantages: [B, T]

  • actor and critic losses: scalar []

DPO distinction: DPO learns from fixed preference pairs. It does not correct stale online rollouts generated by a behavior policy, so V-trace is not part of ordinary DPO training.

⚙️ Algorithm: V-trace targets for stale (off-policy) rollouts
Input: trajectory from behaviour \(\mu\), target \(\pi\), values \(V(s_0),\dots,V(s_T)\), caps \(\bar\rho\ge\bar c\)
\(v_T\gets V(s_T)\)
for \(t=T-1\) down to \(0\) do
\(\rho_t\gets\min\big(\bar\rho,\ \pi(a_t|s_t)/\mu(a_t|s_t)\big)\); \(c_t\gets\min\big(\bar c,\ \pi(a_t|s_t)/\mu(a_t|s_t)\big)\)
\(\delta_t\gets\rho_t\big(r_{t+1}+\gamma V(s_{t+1})-V(s_t)\big)\)
\(v_t\gets V(s_t)+\delta_t+\gamma c_t\big(v_{t+1}-V(s_{t+1})\big)\)
end
critic targets \(v_t\); actor advantage \(\rho_t\big(r_{t+1}+\gamma v_{t+1}-V(s_t)\big)\)

Solutions

ratios = torch.exp(current_logp - behavior_logp)

clipped_rho = ratios.clamp(max=rho_max)
trace_c = ratios.clamp(max=c_max)

vtrace = torch.zeros(B, T)
policy_advantages = torch.zeros(B, T)
next_correction = torch.zeros(B)

for t in reversed(range(T)):
    td_error = (
        rewards[:, t]
        + gamma * bootstrap[:, t] * values[:, t + 1]
        - values[:, t]
    )

    local_correction = clipped_rho[:, t] * td_error

    corrected_next_value = (
        values[:, t + 1] + next_correction
    )

    policy_advantages[:, t] = (
        rewards[:, t]
        + gamma * bootstrap[:, t] * corrected_next_value
        - values[:, t]
    ) * valid[:, t]

    next_correction = (
        local_correction
        + gamma
        * bootstrap[:, t]
        * trace_c[:, t]
        * next_correction
    ) * valid[:, t]

    vtrace[:, t] = (
        values[:, t] + next_correction
    ) * valid[:, t]

actor_weights = (
    clipped_rho.detach()
    * policy_advantages.detach()
)

actor_loss = -(
    actor_weights * current_logp * valid
).sum() / valid.sum()

critic_loss = (
    (values[:, :-1] - vtrace.detach()).square()
    * valid
).sum() / valid.sum()

4. Checks — 3 minutes

  1. Why use separate \(\rho_{\max}\) and \(c_{\max}\)?
    Local correction and long-range propagation have different variance risks. A smaller \(c_{\max}\) prevents one stale event from affecting many earlier states.

  2. Why detach vtrace in the critic loss?
    The target is constructed using current value estimates, but critic regression should treat it as fixed—a semi-gradient update.

  3. What is the cost of clipping?
    Reduced variance but added bias. The result is more stable, not exactly unbiased.

  4. Why does truncation still bootstrap?
    The environment did not terminate; only collection stopped. The final observation still has future value.

  5. Debugging prediction: what if behavior log-probabilities are accidentally recomputed using the current policy?
    Ratios become approximately one, hiding rollout staleness and disabling off-policy correction.

Retrieval answers

  1. The ratio measures how much more or less likely the recorded action is under the current policy than under the behavior policy.

  2. Different masks change the normalized action space, making the ratio incomparable.

  3. Yes. Bootstrap from the final pre-reset observation because the underlying task could continue.

Takeaway: V-trace turns stale actor trajectories into bounded learning signals. Clip local corrections, clip trace propagation more aggressively, preserve rollout masks and behavior log-probabilities, and bootstrap correctly at truncation.
