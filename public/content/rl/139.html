2. Train nuisances without the row they will score

A doubly robust score for logged example \(i\) is:

\[\psi_i = \underbrace{ \sum_a\pi(a\mid x_i)\hat q(x_i,a) }_{\text{model-based baseline}} + \underbrace{ \frac{\pi(a_i\mid x_i)} {\mu(a_i\mid x_i)} \left[ R_i-\hat q(x_i,a_i) \right] }_{\text{weighted correction}}\]

The argument that the correction repairs model error treats \(\hat q\) as fixed relative to \(R_i\). If a flexible model memorizes that same outcome:

\[\hat q(x_i,a_i)=R_i\]

then:

\[R_i-\hat q(x_i,a_i) = \underbrace{0}_{\text{importance correction disabled by memorization}}\]

Cross-fitting prevents this:

  1. Divide independent units into folds \(I_1,\dots,I_K\).

  2. Fit nuisance models without fold \(I_k\).

  3. Score only \(I_k\) with those models.

  4. Join all out-of-fold scores.

The estimator is:

\[\hat V_{\mathrm{CFDR}} = \frac1n \sum_{k=1}^{K} \sum_{i\in I_k} \left[ \underbrace{ \sum_a\pi(a\mid x_i) \hat q^{(-k)}(x_i,a) }_{\text{prediction trained without fold }k} + \underbrace{ \frac{\pi(a_i\mid x_i)} {\hat\mu^{(-k)}(a_i\mid x_i)} \left( R_i-\hat q^{(-k)}(x_i,a_i) \right) }_{\text{out-of-fold residual correction}} \right]\]

Cross-fitting reduces own-sample overfitting bias. It does not repair missing support, invalid rewards, judge bias or jointly misspecified nuisance models.

For sequential LLM-agent data, split complete episodes, users or prompt clusters—not individual tokens from the same trajectory. DPO remains preference optimization; cross-fitting only protects a subsequent evaluation from label reuse.

Tensor shapes:

  • actions and rewards: [R, N]

  • nuisance action values: [R, A]

  • per-example DR scores: [R, N]

  • repeated estimates: [R]

Hints

The true target value is:

\[V^\pi = \underbrace{0.20(0.20)}_{\text{action 0 contribution}} + \underbrace{0.80(0.80)}_{\text{action 1 contribution}} = 0.68\]

The importance weight is:

\[w_i = \underbrace{ \frac{\pi(A_i)} {\mu(A_i)} }_{\text{target-to-behavior action probability}}\]

  • Create leaky_q_values with shape [R, N, 2].

  • Scatter with indices and sources shaped [R, N, 1].

  • Estimate each action mean using only the opposite fold.

  • Every row must be scored exactly once.

  • Use .clamp_min(1) on fold-specific action counts.

  • The fold-specific baseline has shape [R, 1] and broadcasts.

Solutions

Logged data:

actions = (
    torch.rand(
        num_repetitions,
        examples_per_repetition,
    )
    < behavior_policy[1]
).to(torch.long)

reward_probabilities = true_action_values[
    actions
]

rewards = (
    torch.rand(
        num_repetitions,
        examples_per_repetition,
    )
    < reward_probabilities
).to(torch.float64)

exact_target_value = (
    target_policy
    * true_action_values
).sum()

Weights and leaky model:

importance_weights = (
    target_policy[actions]
    / behavior_policy[actions]
)

leaky_q_values = torch.zeros(
    num_repetitions,
    examples_per_repetition,
    2,
)

leaky_q_values.scatter_(
    dim=2,
    index=actions[..., None],
    src=rewards[..., None],
)

leaky_baselines = (
    leaky_q_values
    * target_policy
).sum(dim=-1)

leaky_logged_predictions = (
    leaky_q_values
    .gather(
        dim=2,
        index=actions[..., None],
    )
    .squeeze(-1)
)

leaky_dr_estimates = (
    leaky_baselines
    + importance_weights
    * (
        rewards
        - leaky_logged_predictions
    )
).mean(dim=1)

Cross-fitting:

fold_ids = (
    torch.arange(examples_per_repetition)
    % num_folds
)

cross_fitted_scores = torch.zeros_like(
    rewards
)

cross_fitted_direct_scores = torch.zeros_like(
    rewards
)

for fold in range(num_folds):
    training_mask = fold_ids != fold
    evaluation_mask = fold_ids == fold

    training_actions = actions[
        :,
        training_mask,
    ]

    training_rewards = rewards[
        :,
        training_mask,
    ]

    action_value_estimates = []

    for action in range(2):
        action_mask = (
            training_actions == action
        )

        estimated_value = (
            (
                training_rewards
                * action_mask
            ).sum(dim=1)
            / action_mask.sum(dim=1)
            .clamp_min(1)
        )

        action_value_estimates.append(
            estimated_value
        )

    action_value_estimates = torch.stack(
        action_value_estimates,
        dim=1,
    )

    evaluation_actions = actions[
        :,
        evaluation_mask,
    ]

    evaluation_rewards = rewards[
        :,
        evaluation_mask,
    ]

    model_baseline = (
        action_value_estimates
        * target_policy
    ).sum(dim=1, keepdim=True)

    logged_predictions = (
        action_value_estimates.gather(
            dim=1,
            index=evaluation_actions,
        )
    )

    evaluation_weights = (
        target_policy[evaluation_actions]
        / behavior_policy[evaluation_actions]
    )

    cross_fitted_scores[
        :,
        evaluation_mask,
    ] = (
        model_baseline
        + evaluation_weights
        * (
            evaluation_rewards
            - logged_predictions
        )
    )

    cross_fitted_direct_scores[
        :,
        evaluation_mask,
    ] = model_baseline


cross_fitted_dr_estimates = (
    cross_fitted_scores.mean(dim=1)
)

cross_fitted_dm_estimates = (
    cross_fitted_direct_scores.mean(dim=1)
)

ips_estimates = (
    importance_weights
    * rewards
).mean(dim=1)

Diagnostics:

means = all_estimates.mean(dim=0)

biases = means - exact_target_value

standard_deviations = all_estimates.std(
    dim=0,
    correction=1,
)

rmses = (
    (
        all_estimates
        - exact_target_value
    )
    .square()
    .mean(dim=0)
    .sqrt()

The leaky estimator has the smallest standard deviation while being catastrophically wrong. Its residuals are exactly zero, so importance weighting cannot repair its counterfactual predictions.

Check answers

  1. The model copies \(R_i\), making \(R_i-\hat q(x_i,a_i)=0\); the corrective term disappears.

  2. Each scored outcome is excluded from the data used to produce its nuisance predictions.

  3. Split the largest plausibly dependent unit: usually complete episodes, users, conversations or prompt families.

  4. No. It controls own-sample overfitting; structural misspecification and missing support remain.

  5. A model trained and frozen on genuinely independent data already provides the needed separation, assuming its selection did not use evaluation outcomes.

Retrieval answers

  1. MDR is consistent if either its occupancy ratios are correct or its trajectory \(Q\)-model is correct.

  2. Small variance measures repeatability around the estimator’s own expectation—not closeness of that expectation to truth.

Takeaway: an evaluator should never grade an outcome it was allowed to memorize. Cross-fitting preserves data efficiency while ensuring every residual is genuinely out of sample.
