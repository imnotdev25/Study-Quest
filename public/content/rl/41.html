🧩 Analogy: comparing yourself to an average that includes you

If you’re judged against the class average and you’re in the class, then your own score pulls the average toward you. The better you do, the higher the bar rises, partly cancelling your success. In a class of 4, that’s a big distortion. Leave-one-out compares you only with everyone else.

Rewards \((1,0,0,0)\). Including yourself in the baseline shrinks every advantage by the factor \((G-1)/G=3/4\).

2. A subtle small-group bias

REINFORCE uses:

\[\hat g = \frac1B\sum_i (R_i-b_i) \nabla_\theta\log\pi_\theta(A_i)\]

For the baseline to leave the expected gradient unchanged, it must not depend on the current sampled action \(A_i\).

A common implementation subtracts the group mean:

\[\bar R = \frac1G\sum_{j=1}^G R_j\]

\[\hat A_i=R_i-\bar R\]

But \(\bar R\) contains \(R_i\), so the sample partly baselines itself. Without standard-deviation normalization, the expected estimator becomes:

\[\mathbb E[\hat g_{\text{group mean}}] = \left(1-\frac1G\right) \nabla_\theta J\]

For group size \(G=2\), the expected gradient is scaled by one-half. Its direction remains correct, but its magnitude is biased.

Leave-one-out baseline

Exclude the current response:

\[b_i^{\text{LOO}} = \frac1{G-1} \sum_{j\ne i}R_j\]

\[\hat A_i^{\text{LOO}} = R_i-b_i^{\text{LOO}}\]

Other samples were generated independently from the current action, so this restores the usual unbiased-baseline argument.

For \(G=2\):

\[\hat A_1=R_1-R_2,\qquad \hat A_2=R_2-R_1\]

Practical limits:

  • LOO requires \(G>1\).

  • It does not guarantee lower variance for every problem.

  • Small groups still produce noisy baselines.

  • GRPO often also divides by the group standard deviation and uses PPO ratios, so its estimator is not simply vanilla REINFORCE with an unbiased baseline.

  • Group-relative normalization can still be useful even though it changes gradient scale and sometimes the effective objective.

Tensor shapes:

  • actions and rewards: [groups, G]

  • group means and LOO baselines: [groups, G] after broadcasting

  • policy logits and gradients: [actions]

DPO does not estimate sampled reward baselines; it differentiates a fixed chosen-versus-rejected preference loss.

🔍 Deeper: the exact relationship

Leave-one-out mean: \(\bar r_{-i}=\frac{1}{G-1}\sum_{j\ne i}r_j\). Group mean: \(\bar r=\frac1G\big(r_i+(G-1)\bar r_{-i}\big)\). Then \[r_i-\bar r=r_i-\tfrac1Gr_i-\tfrac{G-1}{G}\bar r_{-i}=\frac{G-1}{G}\big(r_i-\bar r_{-i}\big).\] So the mean baseline is just a scaled-down LOO advantage. \(\bar r_{-i}\) doesn’t depend on action \(i\), which makes it a valid baseline. \(\bar r\) contains \(r_i\), so it’s slightly correlated with action \(i\), and the expected gradient is shrunk by \((G-1)/G\). This is the RLOO estimator. The gap matters most for small groups.

🔑 Key ideas

  • Don’t use a sample as its own baseline.

  • Mean-baseline advantage \(=\frac{G-1}{G}\times\) LOO advantage.

🚶 Walkthrough: mean baseline vs LOO

\(r=(1,0,0,0)\), \(G=4\). Mean baseline: \((0.75,-0.25,-0.25,-0.25)\). LOO: \((1,-\tfrac13,-\tfrac13,-\tfrac13)\). Ratio \(0.75/1=3/4=(G-1)/G\). (checks out)

Common mistakes

  • LOO with \(G=1\) (division by zero, so you need \(G\ge2\)).

  • Mixing LOO and std-normalization without noting the scale change.

  • Computing the baseline over the whole batch instead of per prompt.

⚙️ Algorithm: Leave-one-out (RLOO) advantages
Input: \(G\ge2\) rewards \(r_1,\dots,r_G\) for the same prompt
\(S\gets\sum_jr_j\)
for \(i=1,\dots,G\) do
\(b_i\gets(S-r_i)/(G-1)\) ▷ everyone else’s mean
\(A_i\gets r_i-b_i\)
end
return \(A_1,\dots,A_G\) for the policy-gradient update

\[\text{scale} = \frac{g_{\text{observed}}^\top g_{\text{exact}}} {g_{\text{exact}}^\top g_{\text{exact}}}\]

Debugging experiments

Use:

group_size = 1

The self-including advantage becomes exactly zero:

\[R_i-\bar R=R_i-R_i=0\]

LOO is undefined because there are no other samples.

Next, omit .detach() when advantages come from a learned critic. The actor loss can then update the critic through the policy term, mixing two intended optimization paths.

Finally, normalize by a nearly zero group standard deviation without epsilon. Identical group rewards will produce nan or inf; zero-variance groups need explicit numerical handling.

Solutions

Advantages:

no_baseline_advantages = rewards
group_means = rewards.mean(
    dim=1,
    keepdim=True,
)

self_including_advantages = (
    rewards - group_means
)

Leave-one-out baseline:

group_reward_sums = rewards.sum(
    dim=1,
    keepdim=True,
)

leave_one_out_baselines = (
    group_reward_sums - rewards
) / (
    group_size - 1
)

leave_one_out_advantages = (
    rewards
    - leave_one_out_baselines
)

Estimated gradients:

no_baseline_gradient = (
    estimate_ascent_gradient(
        no_baseline_advantages
    )
)

self_including_gradient = (
    estimate_ascent_gradient(
        self_including_advantages
    )
)

leave_one_out_gradient = (
    estimate_ascent_gradient(
        leave_one_out_advantages
    )
)

Observed scale:

observed_scale = (
    self_including_gradient
    @ exact_ascent_gradient
) / (
    exact_ascent_gradient
    @ exact_ascent_gradient
)

Both the no-baseline and leave-one-out estimates should approach:

\[\nabla J\]

The self-including estimator should approach:

\[\left(1-\frac1G\right)\nabla J\]

With \(G=2\):

\[\mathbb E[\hat g_{\text{self}}] = 0.5\nabla J\]

It normally points in the correct direction, but its magnitude is approximately halved. As \(G\) grows, the factor approaches one:

\[1-\frac1G\rightarrow1\]

Check answers

  1. Its value contains the current reward, which depends directly on the current sampled action.

  2. No. A positive constant preserves direction, although it changes the effective learning rate and interacts with clipping, Adam and other loss terms.

  3. Most groups may contain identical failures, while the few groups containing a success produce large relative signals.

  4. Otherwise, an apparent optimization change may come entirely from deterministic rescaling rather than improved credit assignment.

Retrieval answers

  1. For an action-independent baseline \(b\):

\[\mathbb E[ b\nabla\log\pi(A) ] = b\nabla\sum_a\pi(a) = 0\]

  1. Exact differentiation, central finite differences and sampled REINFORCE.

Takeaway: a group mean that contains the current reward partially cancels that sample’s own policy-gradient signal. Leave-one-out baselines restore action independence, which matters most for small response groups.
