2. Normalize weights into a weighted average

Ordinary importance sampling is:

\[\hat V_{\mathrm{IPS}} = \underbrace{ \frac1N\sum_{i=1}^{N}w_iR_i }_{\text{mean weighted reward}}, \qquad w_i=\frac{\pi(A_i)}{\mu(A_i)}\]

Self-normalized importance sampling—also called weighted IS—uses:

\[\bar w_i = \underbrace{ \frac{w_i}{\sum_{j=1}^{N}w_j} }_{\text{weight normalized across the dataset}}\]

\[\hat V_{\mathrm{SNIS}} = \underbrace{ \sum_{i=1}^{N}\bar w_iR_i }_{\text{convex weighted average of observed rewards}} = \frac{\sum_iw_iR_i}{\sum_iw_i}\]

Because \(\bar w_i\ge0\) and \(\sum_i\bar w_i=1\), SNIS stays within the observed reward range. One huge weight cannot produce an estimate above the largest observed reward.

But it is biased in finite samples:

\[E\!\left[ \frac{\sum_iw_iR_i}{\sum_iw_i} \right] \ne \underbrace{ \frac{E[\sum_iw_iR_i]} {E[\sum_iw_i]} }_{V^\pi}\]

The expectation of a ratio is not generally the ratio of expectations.

Under adequate support and regularity, it is consistent:

\[\frac1N\sum_iw_iR_i \longrightarrow \underbrace{E_\mu[wR]}_{V^\pi}\]

\[\frac1N\sum_iw_i \longrightarrow \underbrace{E_\mu[w]}_{1}\]

so:

\[\hat V_{\mathrm{SNIS}} \longrightarrow \underbrace{\frac{V^\pi}{1}}_{\text{target-policy value}}\]

Unlike fixed weight clipping, its bias normally shrinks with more data. It still cannot recover a target-relevant action that was never observed.

For diagnostics, always report the raw:

\[\bar w = \underbrace{\frac1N\sum_iw_i}_{\text{should approach }1}\]

before normalization. SNIS forces normalized weights to sum to one and can otherwise hide poor realized overlap.

DPO reference log-ratios are not automatically valid deployment importance weights. Similarly, PPO advantage normalization and PPO ratio clipping are different operations from SNIS evaluation.

Hints

Use a binomial distribution to avoid creating a large episode tensor:

torch.distributions.Binomial(
    total_count=sample_size,
    probs=behavior_policy[1],
)

The sufficient statistics are:

\[K = \underbrace{\text{number of rare episodes}}_{\text{binomial random variable}}\]

\[\sum_iw_iR_i = \underbrace{K\,w_{\mathrm{rare}}}_{R_{\mathrm{rare}}=1}\]

\[\sum_iw_i = \underbrace{K\,w_{\mathrm{rare}}}_{\text{rare episodes}} + \underbrace{(N-K)w_{\mathrm{common}}}_{\text{common episodes}}\]

Use .clamp_min(1e-12) on the denominator for numerical safety.

Solutions

Policy ratios:

common_weight = (
    target_policy[0]
    / behavior_policy[0]
)

rare_weight = (
    target_policy[1]
    / behavior_policy[1]
)

Inside the loop:

rare_counts = (
    torch.distributions.Binomial(
        total_count=sample_size,
        probs=behavior_policy[1],
    ).sample((num_repetitions,))
)

common_counts = (
    sample_size - rare_counts
)

Numerator and denominator:

weighted_reward_sums = (
    rare_counts
    * rare_weight
    * reward_by_action[1]
)

weight_sums = (
    rare_counts * rare_weight
    + common_counts * common_weight
)

mean_raw_weights = (
    weight_sums / sample_size
)

Estimators:

ips_estimates = (
    weighted_reward_sums
    / sample_size
)

snis_estimates = (
    weighted_reward_sums
    / weight_sums.clamp_min(1e-12)
)

clipped_rare_weight = min(
    rare_weight.item(),
    clip_threshold,
)

clipped_ips_estimates = (
    rare_counts
    * clipped_rare_weight
    * reward_by_action[1]
    / sample_size
)

Diagnostics:

estimates = torch.stack([
    ips_estimates,
    snis_estimates,
    clipped_ips_estimates,
], dim=1)

means = estimates.mean(dim=0)

biases = means - exact_target_value

standard_deviations = estimates.std(
    dim=0,
    correction=1,
)

rmses = (
    (
        estimates
        - exact_target_value
    )
    .square()
    .mean(dim=0)
    .sqrt()
)

statistics = torch.stack([
    means,
    biases,
    standard_deviations,
    rmses,
], dim=1)

all_results.append(statistics)

zero_event_fractions.append(
    (rare_counts == 0)
    .to(torch.float64)
    .mean()
)

one_rare_numerator = (
    rare_weight
    * reward_by_action[1]
)

one_rare_denominator = (
    rare_weight
    + (sample_size - 1)
    * common_weight
)

one_event_snis_values.append(
    one_rare_numerator
    / one_rare_denominator
)

At \(N=100\), one rare episode gives:

\[\hat V_{\mathrm{SNIS}} = \frac{ \underbrace{50}_{\text{weighted rare reward}} }{ \underbrace{50}_{\text{rare weight}} + \underbrace{99(0.505)}_{\text{common weights}} } \approx0.50\]

But no rare episode gives:

\[\hat V_{\mathrm{SNIS}} = \underbrace{0}_{\text{no observed positive reward}}\]

which occurs about 36.6% of the time at \(N=100\).

The fixed clipped estimator converges to 0.30, not 0.50, because its clipping bias does not disappear. SNIS approaches 0.50 as the rare-action count becomes representative.

Check answers

  1. Yes. A single rare contribution produces IPS 0.50; several can make it exceed 1.0.

  2. No. With nonnegative normalized weights, it is a convex combination of observed rewards.

  3. No. Its random numerator and denominator create finite-sample ratio bias.

  4. Zero; normalization cannot invent the missing reward-bearing action.

  5. Fixed clipping. Under adequate support, SNIS bias shrinks with increasing sample size.

Retrieval answers

  1. Weight clipping exchanges unbiasedness for lower variance.

  2. Those rare rows can represent much more target-policy probability than logging-data frequency suggests.

Takeaway: SNIS turns importance weighting into a stable weighted average and is often useful when raw IPS is explosive. Its bounded output is not a guarantee of correctness—retain raw overlap diagnostics and treat absent target-relevant behavior as a data-collection problem.
