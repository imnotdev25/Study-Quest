2. Combine a trajectory model with per-step corrections

Suppose a value model predicts what remains under target policy \(\pi\):

\[\hat V(s) = \underbrace{ \sum_a \pi(a\mid s)\hat Q(s,a) }_{\text{predicted target-policy return from state }s}\]

After observing one transition, calculate its temporal-difference residual:

\[\delta_t = \underbrace{R_t}_{\text{observed reward}} + \underbrace{ \gamma(1-D_t)\hat V(S_{t+1}) }_{\text{predicted future; zero after termination}} - \underbrace{ \hat Q(S_t,A_t) }_{\text{prediction before observing the transition}}\]

Here \(D_t=1\) means the episode terminated.

Sequential doubly robust evaluation begins with the model prediction and corrects every unexpected transition:

\[\hat V_{\mathrm{SDR}} = \frac1N\sum_{i=1}^{N} \left[ \underbrace{ \hat V(S_0^{(i)}) }_{\text{model-based starting estimate}} + \sum_{t=0}^{T-1} \underbrace{\gamma^t}_{\text{discount}} \underbrace{\rho_{0:t}^{(i)}}_{\text{off-policy history correction}} \underbrace{\delta_t^{(i)}}_{\text{model error observed at step }t} \right]\]

It has two rescue routes:

  • Correct behavior probabilities make the residual corrections repair an incorrect value model.

  • A correct \(Q\)-model gives:

\[E[\delta_t\mid S_t,A_t] = \underbrace{0}_{\text{no systematic residual}}\]

so incorrect propensity estimates cannot systematically shift the result.

If both components are wrong, the estimate can be biased. In practice, learned models should be fitted on separate data or with cross-fitting.

For an LLM agent, states include conversation and tool history, while actions may be tool calls or tokens. DPO optimizes preferences offline; it does not supply the behavior propensities or transition-aware \(Q\)-model required here.

Tensor shapes:

  • actions, rewards and cumulative ratios: [R, N, T]

  • \(Q\)-model: [T, A]

  • \(V\)-model: [T+1]

  • TD residuals: [R, N, T]

  • repeated estimates: [R]

For the value model:

\[\hat Q_t(a) = \underbrace{\hat r(a)}_{\text{predicted current reward}} + \underbrace{\gamma\hat V_{t+1}}_{\text{predicted remaining return}}\]

Importance ratios:

def cumulative_ratios(
    assumed_action_one_probability,
):
    assumed_behavior_policy = torch.tensor([
        1.0 - assumed_action_one_probability,
        assumed_action_one_probability,
    ])

    step_ratios = (
        target_policy[actions]
        / assumed_behavior_policy[actions]
    )

    return step_ratios.cumprod(dim=-1)


correct_ratios = cumulative_ratios(
    behavior_action_one_probability
)

wrong_ratios = cumulative_ratios(
    wrong_behavior_action_one_probability
)

Value models:

def build_value_model(immediate_reward_model):
    q_values = torch.zeros(
        horizon,
        2,
    )

    v_values = torch.zeros(
        horizon + 1
    )

    for time in reversed(range(horizon)):
        q_values[time] = (
            immediate_reward_model
            + gamma * v_values[time + 1]
        )

        v_values[time] = (
            target_policy
            * q_values[time]
        ).sum()

    return q_values, v_values


exact_q, exact_v = build_value_model(
    true_reward_means
)

bad_q, bad_v = build_value_model(
    bad_reward_model
)

PDIS and sequential DR:

pdis_estimates = (
    correct_ratios
    * discounts
    * rewards
).sum(dim=-1).mean(dim=1)


def sequential_dr(
    q_model,
    v_model,
    cumulative_weights,
):
    time_indices = torch.arange(
        horizon
    ).view(1, 1, horizon)

    logged_q_values = q_model[
        time_indices,
        actions,
    ]

    next_state_values = v_model[
        1:
    ].view(1, 1, horizon)

    td_residuals = (
        rewards
        + gamma * next_state_values
        - logged_q_values
    )

    corrections = (
        cumulative_weights
        * discounts
        * td_residuals
    ).sum(dim=-1)

    return (
        v_model[0]
        + corrections.mean(dim=1)
    )


sdr_exact_model_correct_ratios = sequential_dr(
    exact_q,
    exact_v,
    correct_ratios,
)

sdr_bad_model_correct_ratios = sequential_dr(
    bad_q,
    bad_v,
    correct_ratios,
)

sdr_exact_model_wrong_ratios = sequential_dr(
    exact_q,
    exact_v,
    wrong_ratios,
)

sdr_bad_model_wrong_ratios = sequential_dr(

The exact value is:

\[V^\pi = \underbrace{0.65}_{\text{mean reward}} \underbrace{ (1+0.9+\cdots+0.9^5) }_{4.68559} \approx3.046\]

Check answers

  1. PDIS transports complete rewards; sequential DR transports only residual surprises left after model prediction.

  2. Its TD residual has conditional mean zero, so action-dependent weighting cannot create a systematic correction.

  3. Correct ratios transform residuals to the target trajectory distribution, where the corrections telescope from the incorrect baseline to the true return.

  4. Give padded steps ratio 1 and correction mask 0; set the next-state value to zero after genuine termination.

  5. No. Poor support, long horizons, learned-model misspecification and high-stakes promotion decisions still favor fresh target-policy rollouts.

Retrieval answers

  1. Reward \(R_t\) depends only on decisions through time \(t\); future action ratios add variance without correcting its distribution.

  2. Either the outcome model is correct or the behavior propensity model is correct, assuming adequate support and valid estimation procedures.

Takeaway: use the model to predict the route, then importance-weight only its observed mistakes. Sequential DR can dramatically reduce variance, but “doubly robust” still means one component may fail—not both.
