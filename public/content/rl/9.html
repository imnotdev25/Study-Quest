🧩 Analogy: recognizing faces

You don’t memorize a separate entry for every face in every lighting condition; you learn features (eyes, shape, smile) that generalize. A Q-table is pure memorization. A neural Q-function learns features, so learning about one state changes its guesses about similar states. That’s great until learning something new overwrites something old, like how learning Spanish can make your French a bit wobbly.

2. Why tables stop working

Tabular Q-learning stores one number for every state-action pair:

\[Q\in\mathbb{R}^{|\mathcal S|\times|\mathcal A|}\]

This works for three positions, but not for images, continuous measurements, or every possible LLM prefix.

Instead, use a neural network:

\[Q_\theta(s)\rightarrow \begin{bmatrix} Q_\theta(s,a_0) & \cdots & Q_\theta(s,a_{A-1}) \end{bmatrix}\]

For a batch:

  • states: [B, state_features]

  • network output: [B, actions]

  • selected actions: [B]

  • selected Q-values: [B]

The network shares parameters across states. Learning about one state can therefore affect similar states. This is generalization, but unwanted changes to other predictions are interference.

Q-learning as regression

For one transition, construct a fixed target:

\[Y_t= R_{t+1} + \gamma(1-D_t)\max_{a'}Q_\theta(S_{t+1},a')\]

Then minimize:

\[L(\theta) = \frac12 \left(Q_\theta(S_t,A_t)-Y_t\right)^2\]

This connects directly to slope and SGD. Let \(q=Q_\theta(S_t,A_t)\):

\[\frac{\partial L}{\partial q}=q-Y_t\]

  • If \(q<Y_t\), the derivative is negative; gradient descent raises \(q\).

  • If \(q>Y_t\), the derivative is positive; gradient descent lowers \(q\).

The target must be detached. Otherwise, optimization can move both the prediction and the value supplying its target.

This version uses correlated online transitions and a moving target, so it is deliberately fragile. Replay buffers and target networks will stabilize it in upcoming sessions.

LLM connection

An LLM critic cannot store a table containing every prefix. It learns:

\[V_\phi(x,y_{<t})\]

from a prefix representation. Parameter sharing lets related prefixes share evidence, but a critic update for one response can also disturb predictions for unrelated responses.

🔍 Deeper: semi-gradient Q-learning and the deadly triad

Loss with a stop-gradient target: \(\mathcal L(\theta)=\tfrac12\big(y-Q_\theta(s,a)\big)^2\), where \(y=\text{sg}\big[r+\gamma\max_{a'}Q_\theta(s',a')\big]\). Then \[\theta\leftarrow\theta+\alpha\,\big(y-Q_\theta(s,a)\big)\,\nabla_\theta Q_\theta(s,a).\] Why updates leak: after one step, the change at another state \(\tilde s\) is about \(\Delta Q(\tilde s,\tilde a)\approx\alpha\,\delta\,\nabla_\theta Q(\tilde s,\tilde a)^\top\nabla_\theta Q(s,a)\). Similar gradients mean shared learning. That’s generalization, and also interference.

The deadly triad: function approximation + bootstrapping + off-policy data can diverge, even for linear models (Baird’s counterexample). DQN’s replay buffer and target network (next two topics) are practical patches for exactly this.

🔑 Key ideas

  • Q-learning becomes regression on a moving, self-generated label.

  • Generalization and interference are the same mechanism.

🚶 Walkthrough: one update, two states change

Linear \(Q=w^\top\phi\), with \(w=(0.5,0.5)\). State 1: \(\phi_1=(1,1)\), so \(Q_1=1.0\). State 2: \(\phi_2=(1,0)\), so \(Q_2=0.5\). Target for state 1: \(y=2\), with \(\alpha=0.1\). Then \(w\gets w+0.1(2-1)\phi_1=(0.6,0.6)\). New values: \(Q_1=1.2\), and \(Q_2=0.6\) changed too, although it was never trained. That is generalization (or interference).

Common mistakes

  • Not detaching the target \(y\).

  • Gathering the wrong action’s \(Q\) (forgetting .gather(1, a)).

  • Missing \((1-d)\) at terminal transitions.

⚙️ Algorithm: Online semi-gradient Q-learning with a neural network
Input: network \(Q_\theta\), learning rate \(\eta\), discount \(\gamma\), exploration \(\epsilon\)
for each environment step do
\(a\gets\epsilon\text{-greedy}(Q_\theta,s)\); take \(a\); observe \(r,s',d\)
\(y\gets r+\gamma(1-d)\max_{a'}Q_\theta(s',a')\) ▷ no gradient through \(y\)
\(\theta\gets\theta-\eta\,\nabla_\theta\tfrac12\big(y-Q_\theta(s,a)\big)^2\)
\(s\gets s'\) (reset if \(d=1\))
end

The nonterminal greedy actions should normally be:

state 0: right
state 1: right
state 2: right

The approximate optimal right-action values are:

\[Q^*(2,\text{right})=1\]

\[Q^*(1,\text{right})=-0.01+0.95(1)=0.94\]

\[Q^*(0,\text{right})=-0.01+0.95(0.94)=0.883\]

The learned values need not match these exactly. Online samples are correlated, exploration continues, and the same network supplies both predictions and moving targets.

The terminal row is not necessarily zero because the network generalizes to it even though no terminal action is trained. Its values are irrelevant as long as terminal transitions correctly disable bootstrapping.

Check answers

  1. It shares information across large or continuous state spaces instead of storing every state-action pair separately.

  2. Only the action actually taken should be trained toward this transition’s target.

  3. The target should supervise the current prediction, not move through the same gradient update.

  4. Exploration keeps producing different transitions, and each shared-parameter update can change several state predictions.

Retrieval answers

  1. \(R_{t+1}+\gamma(1-D_t)\max_{a'}Q(S_{t+1},a')\).

  2. An exploratory behaviour policy generates experience; a greedy target policy defines the update.

Takeaway: A Q-table remembers each situation separately. A neural Q-function shares what it learns—but sharing creates both useful generalization and potentially unstable interference.
