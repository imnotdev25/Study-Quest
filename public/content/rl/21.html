🧩 Analogy: two mechanics’ quotes

Getting your car fixed, you ask two mechanics and budget for the higher quote. That protects you from one person’s optimistic guess. SAC trains two critics and uses the more pessimistic one, which fights the winner’s curse from Q-learning. Meanwhile the entropy bonus keeps the policy from deciding too early that it knows the one true way to drive.

Twin critics, a pessimistic min, and an entropy-seeking actor, all trained off-policy from replay.

2. SAC’s core idea

Soft Actor-Critic combines:

  • an actor that remains stochastic;

  • off-policy replay;

  • bootstrapped soft Q-functions;

  • target networks;

  • usually two critics to reduce overestimation.

Ordinary Q-learning uses:

\[Y_t = R_{t+1} +\gamma(1-D_t)\max_{a'}Q(S_{t+1},a')\]

SAC replaces the hard maximum with a soft value:

\[V_{\text{soft}}(s) = \mathbb E_{a\sim\pi} \left[ \min(Q_1(s,a),Q_2(s,a)) -\alpha\log\pi(a\mid s) \right]\]

The critic target becomes:

\[Y_t = R_{t+1} +\gamma(1-D_t)V_{\text{soft,target}}(S_{t+1})\]

The actor minimizes:

\[L_\pi = \mathbb E_{s,a\sim\pi} \left[ \alpha\log\pi(a\mid s) -\min(Q_1(s,a),Q_2(s,a)) \right]\]

Interpretation:

  • the \(Q\) term pushes the actor toward rewarding actions;

  • the \(\alpha\log\pi\) term discourages premature collapse;

  • the smaller of two critics gives a conservative value estimate.

Why SAC is off-policy

Transitions are sampled from replay, possibly generated by older policies. The critic learns from those stored transitions, while the current actor supplies actions for the soft next-state value.

This makes SAC sample-efficient compared with strictly on-policy algorithms such as PPO.

Discrete versus continuous SAC

Today’s small action space allows exact summation:

\[V_{\text{soft}}(s) = \sum_a \pi(a\mid s) \left[ \min(Q_1,Q_2)-\alpha\log\pi(a\mid s) \right]\]

Canonical continuous-action SAC cannot sum over every action. It samples a differentiable, reparameterized action from a squashed Gaussian policy.

LLM connection

SAC itself is uncommon for full-vocabulary LLM training because summing or optimizing over enormous sequence action spaces is difficult. Its central idea—optimizing reward while preserving policy entropy—still appears throughout LLM post-training.

🔍 Deeper: the three SAC losses

Critic target (soft Bellman): \(y=r+\gamma(1-d)\big(\min_{j}Q_{\bar\phi_j}(s',a')-\alpha\log\pi_\theta(a'|s')\big)\) with \(a'\sim\pi_\theta(\cdot|s')\). In the discrete case (your exercise), average exactly: \(V(s')=\sum_{a'}\pi(a'|s')\big[\min_jQ(s',a')-\alpha\log\pi(a'|s')\big]\).

Actor: minimize \(\mathbb E_s\mathbb E_{a\sim\pi}\big[\alpha\log\pi(a|s)-\min_jQ_{\phi_j}(s,a)\big]\). For continuous actions, sample with the reparameterization \(a=\tanh(\mu+\sigma\xi)\) and correct the log-probability for the squash: \(\log\pi(a|s)=\log\mathcal N(u;\mu,\sigma)-\sum_i\log(1-\tanh^2u_i)\).

Temperature: \(\mathcal L(\alpha)=\mathbb E\big[-\alpha(\log\pi(a|s)+\bar{\mathcal H})\big]\). This raises \(\alpha\) when entropy drops below the target \(\bar{\mathcal H}\), and lowers it when entropy is above.

🔑 Key ideas

  • SAC = off-policy replay + twin-critic pessimism + entropy.

  • Auto-tuning \(\alpha\) keeps entropy near a target instead of guessing a fixed bonus.

🚶 Walkthrough: one discrete SAC target

Two actions. \(\pi(\cdot|s')=(0.8,0.2)\). Target critics: \(Q_1=(3.0,1.0)\), \(Q_2=(2.5,1.5)\), so \(\min=(2.5,1.0)\). \(\alpha=0.2\). \(V(s')=0.8(2.5+0.2\cdot0.223)+0.2(1.0+0.2\cdot1.609)=2.036+0.264=2.300\). With \(r=1,\gamma=0.99,d=0\): \(y=1+0.99\cdot2.300=3.277\).

Common mistakes

  • Taking \(\min\) after averaging over actions, instead of per action.

  • Using the online critics in the target.

  • Forgetting the tanh log-probability correction in the continuous version.

⚙️ Algorithm: Soft Actor-Critic (discrete actions)
Input: critics \(Q_{\phi_1},Q_{\phi_2}\), targets \(\bar\phi_1,\bar\phi_2\), actor \(\pi_\theta\), temperature \(\alpha\), target entropy \(\bar{\mathcal H}\), buffer \(\mathcal D\)
for each step do
\(a\sim\pi_\theta(\cdot|s)\); step the environment; store \((s,a,r,s',d)\) in \(\mathcal D\)
sample a minibatch from \(\mathcal D\)
\(V(s')\gets\sum_{a'}\pi_\theta(a'|s')\big[\min_jQ_{\bar\phi_j}(s',a')-\alpha\log\pi_\theta(a'|s')\big]\)
\(y\gets r+\gamma(1-d)V(s')\); update each critic on \(\big(Q_{\phi_j}(s,a)-y\big)^2\)
update actor on \(\sum_a\pi_\theta(a|s)\big[\alpha\log\pi_\theta(a|s)-\min_jQ_{\phi_j}(s,a)\big]\)
update \(\alpha\) on \(-\alpha\big(\sum_a\pi_\theta(a|s)\log\pi_\theta(a|s)+\bar{\mathcal H}\big)\)
\(\bar\phi_j\gets\tau\phi_j+(1-\tau)\bar\phi_j\) for \(j=1,2\)
end

Debugging experiment

Remove .detach() from the critic values used in the actor loss. After actor_loss.backward(), inspect:

print(q1.grad, q2.grad)

The actor update now produces critic gradients. Those gradients are not used by actor_optimizer, but they accumulate and confuse debugging unless cleared. More importantly, a combined optimizer could accidentally update critics using the wrong objective.

Then remove (1.0 - dones) from the critic target. Arbitrary Q-values at the dummy next state leak into terminal targets.

Solutions

Next-policy quantities:

next_log_probs = F.log_softmax(
    actor_logits[next_states],
    dim=-1,
)

next_probs = next_log_probs.exp()

Conservative target values:

target_min_q = torch.minimum(
    target_q1[next_states],
    target_q2[next_states],
)

Soft next-state value:

next_soft_values = (
    next_probs
    * (
        target_min_q
        - alpha * next_log_probs
    )
).sum(dim=-1)

Critic targets:

targets = (
    rewards
    + gamma
    * (1.0 - dones)
    * next_soft_values
)

Actor objective:

conservative_q = torch.minimum(
    q1,
    q2,
).detach()

actor_loss = (
    probs
    * (
        alpha * log_probs
        - conservative_q
    )
).sum(dim=-1).mean()

Target updates:

target_q1.mul_(1.0 - tau).add_(
    tau * q1
)

target_q2.mul_(1.0 - tau).add_(
    tau * q2
)

The policy should strongly prefer action 1 in both states, while retaining a small probability for action 0.

At state 1:

\[Q(1,1)\approx1, \qquad Q(1,0)\approx0\]

At state 0, action 1 receives no immediate reward but leads to state 1:

\[Q(0,1) \approx \gamma V_{\text{soft}}(1)\]

so it becomes much more valuable than terminating immediately.

Terminal targets remain exactly their immediate rewards because (1 - dones) removes all bootstrapping.

Check answers

  1. Taking the minimum reduces positive bias when one noisy critic overestimates an action.

  2. The next-state value contains \(-\alpha\log\pi(a'\mid s')\).

  3. Its critic is off-policy and learns from stored transitions rather than requiring every sample to come from the current actor.

  4. Environmental reward dominates the fixed entropy term, so the policy becomes effectively more reward-greedy.

Retrieval answers

  1. \(J=\mathbb E[R]+\alpha\mathcal H(\pi)\).

  2. \(\pi^*(a\mid s)\propto\exp(Q(s,a)/\alpha)\).

Takeaway: SAC combines replay-based sample efficiency, conservative twin critics and entropy-preserving policy improvement. Reward says where to go; entropy prevents the actor from becoming certain too early.
