2. Combine model predictions with human corrections

Suppose a reward model predicts every episode, but humans audit only a selected subset.

Two basic estimators can fail differently:

  • outcome modeling predicts every label but is biased if the model is wrong;

  • inverse-probability weighting is unbiased with correct audit propensities but can have high variance.

The doubly robust estimator combines them:

\[\hat\mu_{\text{DR}} = \frac1N\sum_{i=1}^N \left[ m(X_i) + \frac{S_i}{\pi_i} \bigl(Y_i-m(X_i)\bigr) \right]\]

where:

  • \(m(X_i)\) predicts the human outcome;

  • \(S_i\) indicates whether episode \(i\) was audited;

  • \(\pi_i=P(S_i=1\mid X_i)\);

  • \(Y_i-m(X_i)\) is the audited residual.

Think of \(m(X_i)\) as a rough map of every house. Human audits measure selected houses and correct the map’s errors.

The estimator is consistent if either:

  1. the outcome model \(m\) is correct, or

  2. the propensity model \(\pi\) is correct.

If both are wrong, double robustness provides no protection.

Tensor shapes:

  • features, outcomes, audit masks and propensities: [N]

  • model predictions and residual corrections: [N]

  • final estimate: scalar

In production, cross-fit the nuisance models: train \(m\) or \(\pi\) on other folds, then compute corrections on held-out rows. Freeze or detach() their predictions during evaluation.

A reward model can supply \(m(X)\) for an RLHF or DPO checkpoint. Doubly robust estimation can improve evaluation from targeted human labels; it does not make DPO an online RL algorithm or repair preferences that corrupted training.

4. Checks for understanding

  1. Why can a wrong outcome model be corrected by accurate propensities?

  4. Why should nuisance predictions be cross-fitted and detached?

Solutions

Population and audit:

high_risk = (
    torch.rand(num_episodes)
    < high_risk_probability
)

true_incident_probabilities = torch.where(
    high_risk,
    torch.tensor(
        high_risk_incident_probability
    ),
    torch.tensor(
        low_risk_incident_probability
    ),
)

true_incidents = (
    torch.rand(num_episodes)
    < true_incident_probabilities
).to(torch.float64)
audit_probabilities = torch.where(
    high_risk,
    torch.tensor(
        high_risk_audit_probability
    ),
    torch.tensor(
        low_risk_audit_probability
    ),
)

audited = (
    torch.rand(num_episodes)
    < audit_probabilities
)

observed_incidents = torch.where(
    audited,
    true_incidents,
    torch.zeros_like(true_incidents),
)

Nuisance models:

# Oracle-quality model, used only to demonstrate
# the doubly robust identity.
correct_outcome_predictions = (
    true_incident_probabilities.detach()
)

wrong_outcome_predictions = torch.full(
    (num_episodes,),
    0.15,
)

correct_propensities = (
    audit_probabilities.detach()
)

marginal_audit_rate = (
    audited
    .to(torch.float64)
    .mean()
    .detach()
)

wrong_propensities = torch.full_like(
    audit_probabilities,
    marginal_audit_rate,
)

Basic estimators:

oracle_rate = true_incidents.mean()

naive_audit_rate = (
    observed_incidents[audited].mean()
)

outcome_only_correct = (
    correct_outcome_predictions.mean()
)

outcome_only_wrong = (
    wrong_outcome_predictions.mean()
)

ipw_correct = (
    audited.to(torch.float64)
    * observed_incidents
    / correct_propensities
).mean()

ipw_wrong = (
    audited.to(torch.float64)
    * observed_incidents
    / wrong_propensities
).mean()

Doubly robust estimator:

def doubly_robust(
    outcome_predictions,
    propensities,
):
    residual_corrections = torch.where(
        audited,
        (
            observed_incidents
            - outcome_predictions
        ) / propensities,
        torch.zeros_like(
            outcome_predictions
        ),
    )

    estimate = (
        outcome_predictions
        + residual_corrections
    ).mean()

    return estimate


dr_both_correct = doubly_robust(
    correct_outcome_predictions,
    correct_propensities,
)

dr_correct_propensity = doubly_robust(
    wrong_outcome_predictions,
    correct_propensities,
)

dr_correct_outcome = doubly_robust(
    correct_outcome_predictions,
    wrong_propensities,
)

dr_both_wrong = doubly_robust(
    wrong_outcome_predictions,
    wrong_propensities,
)

Diagnostics:

ipw_weights = torch.where(
    audited,
    1.0 / correct_propensities,
    torch.zeros_like(
        correct_propensities
    ),
)

effective_sample_size = (
    ipw_weights.sum().square()
    / ipw_weights.square().sum()
)

maximum_weight = ipw_weights.max()

The deployment incident rate is:

\[\mu = 0.8(0.02)+0.2(0.30) = 0.076\]

The expected audit rate is:

\[0.8(0.02)+0.2(0.60) = 0.136\]

The expected incident rate among audited episodes is:

\[\frac{ 0.8(0.02)(0.02) + 0.2(0.60)(0.30) }{ 0.136 } \approx0.267\]

Expected behavior:

  • correct outcome model: near 0.076;

  • correct-propensity IPW: near 0.076;

  • wrong outcome plus correct propensity DR: near 0.076;

  • correct outcome plus wrong propensity DR: near 0.076;

  • both wrong: near the biased audit rate, approximately 0.267.

Low-risk audited episodes receive weight:

\[1/0.02=50\]

so the effective sample size will be far below the raw audit count.

Check answers

  1. Correct propensities expand each audited residual back to its deployment frequency, making the average correction unbiased.

  2. If \(m(X)=E[Y\mid X]\), its residual has conditional mean zero; incorrect propensity scaling still averages zero in expectation.

  3. No. The guarantee requires at least one nuisance model to be correctly specified. Two small, correlated errors can still create meaningful bias.

  4. Cross-fitting reduces overfitting bias. Detaching prevents an evaluation calculation from silently training the models whose validity it is meant to assess.

Retrieval answers

  1. Targeted samples have a different mixture from deployment. Weighting each audited row by \(1/\pi_i\) restores its population representation.

  2. No. Zero inclusion probability creates missing support; weighting cannot manufacture unseen human outcomes.

Takeaway: predict every episode, then use properly weighted human residuals to correct the predictions. Doubly robust does not mean assumption-free—it means one of two carefully validated nuisance models may fail, but not both.
