2. Which tool call deserves the outcome? — 5 minutes

Consider an agent trajectory:

search → open page → calculate → answer → reward

If only the final answer receives reward, earlier tool calls still influenced it. We therefore propagate later outcomes backward using a return-to-go.

\[\underbrace{G_t}_{\text{credit from step }t} = \underbrace{\sum_{k=t}^{T-1}\gamma^{\,k-t}r_k}_{\text{current and future rewards}}\]

Annotations:

  • \(r_k\): reward emitted after step \(k\)

  • \(\gamma\in[0,1]\): discount factor

  • \(G_t\): credit assigned to the action taken at step \(t\)

With rewards \([0,0,0,1]\) and \(\gamma=0.9\):

\[G=[0.9^3,\;0.9^2,\;0.9,\;1]\]

The final answer receives full credit. Earlier tool calls receive progressively discounted credit.

But this is only temporal credit—it does not prove which tool call caused success. A useless search before a correct answer can still receive positive return. A value baseline reduces variance:

\[\underbrace{A_t}_{\text{action quality above expectation}} = \underbrace{G_t}_{\text{observed return}} - \underbrace{V_\phi(s_t)}_{\text{expected return before acting}}\]

The masked actor loss is:

\[L_{\text{actor}} = -\frac{ \sum_{b,t} \underbrace{m_{b,t}}_{\text{valid trajectory step}} \underbrace{\operatorname{stopgrad}(A_{b,t})}_{\text{fixed credit}} \underbrace{\log\pi_\theta(a_{b,t}\mid s_{b,t})}_{\text{chosen action log-probability}} }{ \underbrace{\sum_{b,t}m_{b,t}}_{\text{number of real steps}} }\]

Padding must not receive rewards, returns, losses, or diagnostic statistics.

The critic learns with:

\[L_{\text{value}} = \frac{ \sum_{b,t}m_{b,t} \left( \underbrace{V_\phi(s_{b,t})}_{\text{prediction}} - \underbrace{\operatorname{stopgrad}(G_{b,t})}_{\text{return target}} \right)^2 }{ \sum_{b,t}m_{b,t} }\]

Shapes:

  • rewards, returns, values, advantages, step mask: [B, T]

  • policy logits: [B, T, A]

  • selected actions and log-probabilities: [B, T]

  • actor and value losses: scalar []

Practical limitation: a final scalar reward broadcasts coarse credit across the whole trajectory. Tool-level rewards, process supervision, counterfactual evaluation or learned critics can improve attribution—but can also introduce new reward-hacking surfaces.

Predict before running:

  1. Should the first action of trajectory 0 receive positive return?

  2. Can trajectory 2’s failed answer action receive negative immediate reward but positive return?

  3. Should any padded logit or value receive a gradient?

Hints

  • Backward recurrence:

    \[G_t=r_t+\gamma G_{t+1}\]

  • Multiply the updated running return by the mask for step \(t\).

  • Use (returns - values).detach() for actor advantages.

  • Divide masked losses by step_mask.sum(), not B*T.

  • Detach only the target side of the critic loss.

Solutions

returns = torch.zeros_like(rewards)
running_return = torch.zeros(batch_size)

for t in reversed(range(max_steps)):
    running_return = rewards[:, t] + gamma * running_return
    running_return = running_return * step_mask[:, t]
    returns[:, t] = running_return

advantages = (returns - values).detach()

distribution = torch.distributions.Categorical(logits=logits)
chosen_log_probs = distribution.log_prob(actions)

actor_loss = -(
    advantages * chosen_log_probs * step_mask
).sum() / step_mask.sum()

value_loss = (
    (values - returns.detach()).square() * step_mask
).sum() / step_mask.sum()

Check answers

  1. Yes. Its search action preceded the eventual success, so return-to-go assigns discounted positive credit.

  2. Yes. At trajectory 2, step 3:

    \[G_3=-0.2+0.9(1.0)=0.7\]

    The later success outweighs the immediate penalty.

  3. No. Padding is not part of the environment trajectory and must contribute neither loss nor gradient.

  4. Return-to-go is imperfect because temporal precedence is not causality. Irrelevant tool calls can inherit reward from later success.

Retrieval answers

  1. Masking after softmax leaves invalid actions inside the normalization and can produce a probability vector whose allowed entries sum to less than one.

  2. A PPO ratio must compare the same recorded decision under both policies. Changing the mask changes the action space itself.

  3. Training reward rises while an independent audit peaks, stagnates or falls.

Takeaway: propagate outcomes backward with return-to-go, subtract expected value for lower-variance credit, and mask padding everywhere—not only in the final loss.
