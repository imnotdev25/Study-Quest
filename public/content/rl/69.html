🧩 Analogy: knowing when to hand back the wheel

A good assistant knows when a task is done and returns control. One who checks in every five seconds is useless, and so is one who never stops. Learned option termination faces exactly this: without care, options collapse into one-step actions or never end.

Positive values mean “terminate more.” The cost \(\xi\) shifts the line so small disadvantages don’t trigger a switch.

2. The agent must learn when to return control

A hierarchical agent needs a termination rule:

\[\beta_\psi(s,o) = P(\text{terminate option }o\mid s)\]

If termination probability is always high, every option lasts one step and hierarchy disappears. If it is always low, the agent remains trapped in an unsuitable routine.

Define the current option’s advantage over switching:

\[A_\Omega(s,o) = Q_\Omega(s,o)-V_\Omega(s)\]

Interpretation:

  • \(A_\Omega>0\): the current option is better than switching; continue.

  • \(A_\Omega<0\): alternatives are better; terminate.

  • \(A_\Omega\approx0\): the decision is uncertain.

A simple termination loss is:

\[L_\beta = \mathbb E[ \beta_\psi(s,o) A_\Omega(s,o) ]\]

Gradient descent reduces \(\beta\) when the advantage is positive and increases it when the advantage is negative.

Frequent switching may itself have a cost: rebuilding context, issuing another model call or losing cached state. With deliberation cost \(\eta>0\):

\[L_\beta = \mathbb E[ \beta_\psi(s,o) (A_\Omega(s,o)+\eta) ]\]

The option now terminates only when switching is sufficiently better:

\[A_\Omega<-\eta\]

Detach the option advantage during the termination update. Apply this loss only where termination is actually learnable—not on padding, forced episode endings or invalid option states.

Tensor shapes:

  • termination logits and probabilities: [B, T] or [N];

  • option advantages: matching shape;

  • valid termination mask: matching Boolean shape;

  • reduced termination loss: scalar.

DPO may learn preferences for shorter or longer traces, but it does not explicitly estimate option advantages or interactively learn a termination rule.

🔍 Deeper: the termination gradient

Option-critic (Bacon et al., 2017) updates the termination parameters \(\vartheta\) with \(\vartheta\gets\vartheta-\alpha\,\nabla_\vartheta\beta_\vartheta(s')\,\big(A_\Omega(s',o)+\xi\big)\).

  • \(A_\Omega<0\): continuing \(o\) is worse than average, so increase \(\beta\) (stop).

  • \(\xi>0\) (deliberation cost): switching must be better by at least \(\xi\), which discourages one-step options.

  • Forced boundaries (episode end, truncation) are not decisions to terminate. Mask them out of this gradient.

🔑 Key ideas

  • Terminate when switching is meaningfully better.

  • Mask forced boundaries and watch average option length.

🚶 Walkthrough: the sign flips with \(\xi\)

\(Q_\Omega(s',o)=1.0\), \(V_\Omega(s')=1.3\), so \(A=-0.3\). Without cost, \(A+\xi=-0.3<0\): terminate more. With \(\xi=0.5\): \(A+\xi=+0.2>0\): continue, since the gain from switching doesn’t cover the switching cost.

Common mistakes

  • Not detaching \(A_\Omega\).

  • Counting truncation as a learned termination.

  • Never logging average option duration.

⚙️ Algorithm: Option-critic update at one step
Input: current option \(o\), transition \((s,a,r,s')\), critics \(Q_\Omega,Q_U\), deliberation cost \(\xi\)
\(U\gets(1-\beta_o(s'))Q_\Omega(s',o)+\beta_o(s')\max_{o'}Q_\Omega(s',o')\) ▷ value on arrival
update \(Q_U(s,o,a)\) toward \(r+\gamma U\) (detached)
intra-option policy: \(\theta_o\gets\theta_o+\alpha\nabla\log\pi_o(a|s)\,Q_U(s,o,a)\)
if \(s'\) is not a forced boundary then
termination: \(\vartheta\gets\vartheta-\alpha\nabla\beta_o(s')\big(Q_\Omega(s',o)-V_\Omega(s')+\xi\big)\)
end
with probability \(\beta_o(s')\), pick a new option with the policy over options

Debugging experiments

Remove .detach() from the option advantages when they come from a critic. The termination loss can then change the critic merely to make termination decisions look easier.

Remove the validity mask. The padded advantage of 99 drives its termination probability toward zero and contaminates aggregate diagnostics.

Reverse the loss sign. Good options learn to terminate while bad options continue.

Increase the deliberation cost above 1.0. Even the state with advantage -1 may stop terminating, creating excessively long options.

Solutions

Termination probabilities and effective advantages:

probabilities = torch.sigmoid(
    logits
)

effective_advantages = (
    option_advantages.detach()
    + switching_cost
)

per_state_loss = (
    probabilities
    * effective_advantages
)

Masked mean:

loss = (
    per_state_loss
    * valid_mask.to(
        per_state_loss.dtype
    )
).sum() / valid_mask.sum()

Initial gradient:

initial_gradient = torch.autograd.grad(
    initial_loss,
    termination_logits_no_cost,
)[0]

Optimization:

(
    loss_no_cost
    + loss_with_cost
).backward()

optimizer_no_cost.step()
optimizer_with_cost.step()

At zero logits:

\[\beta=\sigma(0)=0.5\]

and:

\[\frac{\partial\beta}{\partial z} = \beta(1-\beta) = 0.25\]

Therefore, ignoring the batch-mean factor:

\[\frac{\partial L_\beta}{\partial z} = 0.25(A_\Omega+\eta)\]

Gradient descent lowers the termination logit when this quantity is positive and raises it when negative.

Expected behavior:

  • \(A=2\): termination approaches zero.

  • \(A=-1\): termination approaches one.

  • \(A=-0.2\), no cost: termination approaches one.

  • \(A=-0.2\), \(\eta=0.3\): effective advantage is \(0.1\), so termination approaches zero.

  • Padding remains near its initial probability because its gradient is masked.

Check answers

  1. Continuing the current option has greater expected value than returning control to the high-level policy.

  2. It introduces a threshold against unnecessary switching, generally producing longer options.

  3. Padding, forced terminal states, states outside the option’s domain and positions where termination was not sampled.

  4. Log option-length histograms, one-step-option rate, maximum-length rate, termination probabilities, switching frequency and success per option.

Retrieval answers

  1. The next high-level choice occurs \(k\) primitive transitions later.

  2. Once—at the state where the high-level policy selected that option.

Takeaway: terminate when switching is meaningfully better. Mask forced boundaries, detach critic estimates and monitor whether options collapse toward one step or never return control.
