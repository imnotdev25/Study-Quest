2. GAE for both reward and cost

One-step TD errors provide short-range credit:

\[\delta_t^R = \underbrace{r_t+\gamma m_tV_R(s_{t+1})}_{\text{reward target}} - \underbrace{V_R(s_t)}_{\text{current prediction}}\]

\[\delta_t^C = \underbrace{c_t+\gamma m_tV_C(s_{t+1})}_{\text{cost target}} - \underbrace{V_C(s_t)}_{\text{current prediction}}\]

Here \(m_t=0\) after termination and \(1\) otherwise.

GAE propagates each TD error backward:

\[\hat A_t^R = \underbrace{\delta_t^R}_{\text{current surprise}} + \underbrace{\gamma\lambda_Rm_t\hat A_{t+1}^R}_{\text{later reward surprises}}\]

\[\hat A_t^C = \underbrace{\delta_t^C}_{\text{current cost surprise}} + \underbrace{\gamma\lambda_Cm_t\hat A_{t+1}^C}_{\text{later cost surprises}}\]

The actor receives:

\[\hat A_t^{\text{actor}} = \underbrace{\hat A_t^R}_{\text{reward credit}} - \underbrace{\nu}_{\text{safety price}} \underbrace{\hat A_t^C}_{\text{cost credit}}\]

Do not confuse the coefficients:

Symbol Meaning Behaviour
Symbol Meaning Behaviour
\(\lambda_{\text{GAE}}\in[0,1]\) Trace length Fixed hyperparameter
\(\nu\ge0\) Safety multiplier Learns from constraint violation
\(\beta_{\text{DPO}}\) DPO reference strength Fixed offline-loss coefficient

The GAE extremes are:

\[\lambda_{\text{GAE}}=0 \Rightarrow \underbrace{\hat A_t=\delta_t}_{\text{one-step TD; lower variance}}\]

\[\lambda_{\text{GAE}}=1 \Rightarrow \underbrace{\hat A_t+V(s_t)=G_t}_{\text{full return for terminal trajectories}}\]

Larger \(\lambda_{\text{GAE}}\) propagates terminal outcomes farther but usually increases variance. It does not automatically make the policy safer.

For LLM rollouts, a sequence-level reward or safety cost can therefore influence earlier generated tokens. Prompt and padding tokens must remain masked.

Shapes:

  • signals and advantages: [B, T]

  • critic values including the next state: [B, T+1]

  • valid and continuation masks: [B, T]

  • safety multiplier: scalar []

Predict before running:

  1. Should both identity errors be near zero?

  2. Can an early action receive negative actor advantage because of a later cost?

  3. What happens if the continuation mask stays 1 across an episode boundary?

  4. Does increasing \(\lambda_{\text{GAE}}\) increase the safety penalty \(\nu\)?

Hints

  • TD error: signal + gamma * continuation * next_value - current_value.

  • Multiply TD errors by the valid mask.

  • Reverse recursion: delta + gamma * lambda * continuation * running.

  • Reset the running result to zero on padding.

  • Critic target: (advantage + current_value).detach().

  • Combine reward and cost advantages before any optional normalization.

Debugging checks

  • Reverse the trajectory along the batch dimension instead of time.

  • Use only valid_mask and bootstrap through terminal states.

  • Use only continuation_mask and train on padded positions.

  • Normalize reward and cost advantages separately, silently changing the meaning of \(\nu\).

  • Let critic-target gradients flow back through the GAE recursion.

  • Treat prompt tokens as generated actions in an LLM policy loss.

4. Checks for understanding

  1. Why might cost GAE need a long trace when safety cost appears only at sequence end?

  2. Why should the dual update still use raw episode cost?

  3. What does \(\lambda_{\text{GAE}}=0\) depend on most strongly?

  4. When does \(\lambda_{\text{GAE}}=1\) fail to equal a pure Monte Carlo return?

Solutions

TD errors:

deltas = (
    signals
    + gamma
    * continuation_mask
    * next_values.detach()
    - current_values
) * valid_mask

Reverse recursion:

running_advantage = (
    deltas[:, t]
    + gamma
    * trace_lambda
    * continuation_mask[:, t]
    * running_advantage
)

running_advantage = (
    running_advantage
    * valid_mask[:, t]
)

advantages[:, t] = running_advantage

Critic targets:

return_targets = (
    advantages + current_values
).detach() * valid_mask

Combined actor advantage:

actor_advantages = (
    reward_advantages
    - safety_multiplier
    * cost_advantages
).detach() * valid_mask

Direct return recursion:

running_return = (
    signals[:, t]
    + gamma
    * continuation_mask[:, t]
    * running_return
)

running_return = (
    running_return
    * valid_mask[:, t]
)

returns[:, t] = running_return

Both diagnostic errors should be at floating-point zero:

\[\lambda_{\text{GAE}}=0 \Rightarrow \underbrace{\hat A_t-\delta_t}_{\text{identity error}} \approx0\]

\[\lambda_{\text{GAE}}=1 \Rightarrow \underbrace{\hat A_t+V_t-G_t}_{\text{return identity error}} \approx0\]

All padded actor advantages should also be exactly zero.

Check answers

  1. Long cost traces propagate delayed safety consequences to the earlier actions that helped cause them.

  2. GAE centers cost around critic predictions. The dual variable instead needs absolute constraint violation.

  3. The one-step critic estimate; inaccurate bootstrapping therefore creates more bias.

  4. For truncated nonterminal rollouts, it ends with a bootstrapped value rather than an observed terminal return.

Retrieval answers

  1. The multiplier changes during training. Separate critics remain meaningful and expose reward and cost diagnostics independently.

  2. Accurate TD errors average near zero even when the critic correctly predicts an excessive total cost.

Takeaway: propagate reward and cost credit separately, then combine them using the learned safety price. GAE’s trace parameter controls credit length—not how strongly safety is enforced.
