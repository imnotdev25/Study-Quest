2. Reward scale changes the optimization problem

An LLM PPO rollout may combine task reward with reference-KL cost:

\[R_i^{\text{shaped}} = \underbrace{R_i^{\text{task}}}_{\text{reward model or verifier}} - \underbrace{\beta K_i}_{\text{reference-drift penalty}}\]

If task rewards are multiplied by \(c\), but \(\beta\) is unchanged:

\[cR_i^{\text{task}}-\beta K_i = c\left( R_i^{\text{task}} - \underbrace{\frac{\beta}{c}}_{\text{weaker effective KL price}} K_i \right)\]

Thus reward scaling is not harmless: multiplying rewards by ten makes the KL penalty ten times weaker relative to task reward.

To preserve the trade-off, scale both:

\[\underbrace{ cR_i^{\text{task}}-c\beta K_i }_{\text{scaled task and KL}} = c \underbrace{ \left(R_i^{\text{task}}-\beta K_i\right) }_{\text{same preference ordering}}\]

The critic produces an advantage:

\[A_i = \underbrace{ R_i^{\text{shaped}}-V_\phi(x_i) }_{\text{return above expected return}}\]

PPO commonly normalizes advantages:

\[\widehat A_i = \underbrace{ \frac{A_i-\mu_A} {\sqrt{\sigma_A^2+\epsilon}} }_{\text{approximately zero mean and unit variance}}\]

This improves optimizer conditioning and prevents one reward outlier from setting the entire gradient scale. But it also makes learning batch-relative. It does not repair a miscalibrated or exploitable reward model.

Keep these quantities distinct:

  • critic targets remain in the raw shaped-return scale;

  • actor advantages may be normalized;

  • safety dual updates use raw costs;

  • logged rewards should include both raw and normalized statistics.

For binary verifiable rewards, a batch containing all successes or all failures has zero reward variance. Whitening then produces no relative learning signal. Always monitor success diversity and std.

DPO does not consume scalar rewards to whiten. Its preference margin and \(\beta_{\text{DPO}}\) determine the loss scale; DPO remains offline preference optimization.

Shapes:

  • task rewards, KL costs, returns and advantages: [B]

  • token log-probabilities and masks: [B, T]

  • logits: [B, T, V]

  • reward mean, standard deviation and \(\beta\): scalar []

Hints

  • Shaped return: task_reward - beta * kl_cost.

  • Use variance = mean((x - mean) ** 2).

  • Detach actor advantages and critic targets.

  • Actor loss is negative advantage times sequence log-probability.

  • Per-sequence gradient norm: gradient.flatten(1).norm(dim=1).

  • Outlier share is its norm divided by the sum of all sequence norms.

  • Normalize constants with the same mean/variance formula and epsilon.

Debugging checks

  • Normalize rewards but train the critic against normalized targets without intending to change its scale.

  • Rescale reward-model output while leaving KL and cost coefficients unchanged.

  • Divide by standard deviation without an epsilon or finite-value check.

  • Hide reward collapse by logging only normalized advantages.

  • Update a safety multiplier from whitened costs.

  • Treat advantage whitening as protection against reward hacking.

4. Checks for understanding

  1. Why does multiplying all task rewards change their trade-off with KL?

  2. Does subtracting a baseline change which sampled actions receive positive versus negative credit?

  3. Why should critic targets normally remain in raw shaped-return units?

  4. Why can a zero-variance verifier batch provide no relative learning signal?

Solutions

Reward construction:

shaped_returns = (
    task_rewards
    - kl_coefficient
    * reference_kl_costs
)

task_only_scaled_returns = (
    reward_scale * task_rewards
    - kl_coefficient
    * reference_kl_costs
)

co_scaled_returns = (
    reward_scale * task_rewards
    - reward_scale
    * kl_coefficient
    * reference_kl_costs
)

co_scaling_identity_error = (
    co_scaled_returns
    - reward_scale * shaped_returns
).abs().max()

Advantages:

raw_advantages = (
    shaped_returns
    - critic_values
).detach()

advantage_mean = raw_advantages.mean()

advantage_variance = (
    raw_advantages
    - advantage_mean
).square().mean()

advantage_std = torch.sqrt(
    advantage_variance + epsilon
)

normalized_advantages = (
    (
        raw_advantages
        - advantage_mean
    )
    / advantage_std
).detach()

critic_targets = shaped_returns.detach()

Actor loss:

def actor_loss(advantages):
    return -(
        advantages.detach()
        * sequence_log_probabilities
    ).mean()

Gradient diagnostics:

gradient_scaling_error = (
    scaled_gradient
    - reward_scale * raw_gradient
).abs().max()

raw_gradient_norms = (
    raw_gradient.flatten(1).norm(dim=1)
)

normalized_gradient_norms = (
    normalized_gradient
    .flatten(1)
    .norm(dim=1)
)

raw_outlier_share = (
    raw_gradient_norms[-1]
    / raw_gradient_norms.sum()
)

normalized_outlier_share = (
    normalized_gradient_norms[-1]
    / normalized_gradient_norms.sum()
)

Constant-advantage diagnostic:

constant_mean = constant_advantages.mean()

constant_variance = (
    constant_advantages
    - constant_mean
).square().mean()

constant_normalized = (
    constant_advantages
    - constant_mean
) / torch.sqrt(
    constant_variance + epsilon
)

The co-scaling identity error and gradient-scaling error should both be near floating-point zero:

\[\underbrace{ 10R-10\beta K }_{\text{co-scaled objective}} = 10 \underbrace{ (R-\beta K) }_{\text{original objective}}\]

Multiplying detached advantages by ten similarly multiplies the policy gradient by ten. This changes optimizer step size unless learning rate, clipping and other loss coefficients are adjusted.

Whitening substantially reduces the extreme response’s control over gradient magnitude, but it also changes the batch’s absolute reward interpretation.

Check answers

  1. Reward becomes larger relative to KL, so the effective KL coefficient becomes \(\beta/c\).

  2. A baseline shifts the credit threshold. Samples above it become positive; samples below it become negative. A valid action-independent baseline preserves the expected policy gradient while reducing variance.

  3. The critic must predict the deployed return scale. Moving normalization statistics can otherwise make its target nonstationary and diagnostics difficult to interpret.

  4. The batch contains no information about which completion is better. After centering, every relative advantage is zero.

Retrieval answers

  1. Broadcasting uses one outcome as credit for all actions that preceded it. Repeating the reward changes the return and counts the outcome multiple times.

  2. Length normalization applies a different \(1/L_i\) weight to each sequence, altering their relative gradient contributions.

Takeaway: reward units are part of the algorithm. Normalize detached actor advantages for conditioning when useful, but retain raw returns for critics and diagnostics—and rescale KL or safety prices whenever the reward scale changes.
