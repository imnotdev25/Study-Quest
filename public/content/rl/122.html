2. \(\lambda\) chooses how much you trust the critic

GAE begins with TD residuals:

\[\delta_t = r_t+\gamma V(s_{t+1})-V(s_t)\]

and combines them:

\[A_t^{\text{GAE}} = \sum_{k=0}^{H-1-t} (\gamma\lambda)^k\delta_{t+k}\]

The extremes are:

  • \(\lambda=0\): one-step TD; relies heavily on the critic;

  • \(\lambda=1\): Monte Carlo-like credit; uses the complete sampled outcome.

The approximate trace horizon is:

\[\frac{1}{1-\gamma\lambda}\]

If \(\gamma=1,\lambda=0.95\), that is about 20 tokens.

A low \(\lambda\) is effective when the critic recognizes consequences early. If the critic cannot distinguish the states created by a good versus bad action, the early TD residual can be zero. Terminal evidence is then attenuated by:

\[(\gamma\lambda)^{H-1}\]

A larger \(\lambda\) repairs this bias but imports more terminal-reward noise. This is the GAE bias–variance tradeoff.

Tensor shapes:

  • rewards and values: [N, H], [N, H + 1]

  • candidate \(\lambda\) values: [G]

  • first-step advantages and gradient samples: [N, G]

Advantages must be detached before actor backpropagation. Episode-boundary masks must stop the recursion; otherwise another response’s reward can leak backward.

DPO has no critic, TD residual or GAE parameter. Its chosen/rejected sequence gradients come directly from fixed preference pairs.

3. PyTorch exercise — a blind critic erases delayed credit

At token zero, the policy chooses action 0 or 1:

\[P(R=1\mid a=0)=0.2,\qquad P(R=1\mid a=1)=0.8\]

The exact policy gradient at \(p=0.5\) is:

\[p(1-p)(0.8-0.2)=0.15\]

Compare:

  • a blind critic that predicts 0.5 after either action;

  • an informed critic that predicts 0.2 or 0.8 after observing the action.

GAE recursion:

def first_step_gae(
    rewards,
    values,
):
    td_residuals = (
        rewards
        + gamma * values[:, 1:]
        - values[:, :-1]
    )

    running_advantages = torch.zeros(
        num_episodes,
        num_lambdas,
    )

    for token_index in reversed(
        range(horizon)
    ):
        running_advantages = (
            td_residuals[
                :, token_index
            ][:, None]
            + gamma
            * lambdas[None, :]
            * running_advantages
        )

    return running_advantages

For the blind critic:

\[\hat g_\lambda = \lambda^{19}(0.15)\]

Therefore, the expected gradients are approximately:

\(\lambda\) Terminal multiplier Blind gradient Informed gradient
\(\lambda\) Terminal multiplier Blind gradient Informed gradient
0.00 0.0000 0.0000 0.1500
0.80 0.0144 0.0022 0.1500
0.95 0.3774 0.0566 0.1500
1.00 1.0000 0.1500 0.1500

The informed critic creates an immediate TD residual:

\[\delta_0 = \mu_a-0.5\]

Its score-weighted value is always:

\[(a-0.5)(\mu_a-0.5)=0.15\]

Later terminal noise has conditional mean zero. Increasing \(\lambda\) therefore retains the same expected gradient but adds more terminal-reward variance.

Check answers

  1. It predicts the same next-state value after both actions, so the first TD residual contains no information about which action was better.

  2. Its next-state value already encodes the action-dependent expected reward; one-step TD contains the complete expected policy-gradient signal.

  3. It adds increasingly distant TD residuals—here, mostly terminal Bernoulli noise.

  4. Log value loss, explained variance, calibration by timestep/action, TD-residual variance, advantage variance and gradient signal-to-noise ratio.

  5. No. \(\lambda\) changes the estimator’s reliance on bootstrapping versus sampled returns; unlike \(\gamma\), it does not define the underlying discounted-return objective.

Retrieval answers

  1. It exponentially weakens credit for earlier tokens and therefore implicitly favors shorter responses or tokenizations.

  2. A token cost assigns a direct, linear price to length; discounting produces nonlinear position-dependent attenuation.

Takeaway: tune \(\lambda\) together with critic quality and sequence length. Low \(\lambda\) is excellent when the critic recognizes action consequences; when it does not, the terminal learning signal can vanish exponentially before reaching the decision that caused it.
