🧩 Analogy: a speed limit in the wrong units

A speed limit of “0.2” is sensible in km per second and absurd in km per hour. PPO’s value clipping caps how far \(V\) can move per update. With \(\epsilon=0.2\) and returns around 1, that’s a gentle cap. With returns around 500, the critic is nearly frozen, and that’s a units problem, not a learning problem.

2. Prevent abrupt critic updates

PPO usually updates the actor and critic on the same rollout batch. The critic can overfit that batch or change sharply, destabilizing advantages used by later updates.

Let:

  • \(V_{\text{old}}(s_t)\): value prediction stored during rollout;

  • \(V_\phi(s_t)\): current prediction;

  • \(\hat R_t\): fixed return target.

Clip the change in prediction:

\[V_{\text{clip}} = V_{\text{old}} + \operatorname{clip} \left( V_\phi-V_{\text{old}}, -\epsilon_v,\epsilon_v \right)\]

The PPO-style value loss is:

\[L_V = \frac12 \mathbb E \left[ \max \left( (V_\phi-\hat R)^2, (V_{\text{clip}}-\hat R)^2 \right) \right]\]

The max is deliberate. The critic is not allowed to report the optimistic smaller error produced by an excessively large update.

This is analogous to actor clipping:

  • actor clipping limits probability-ratio improvement;

  • value clipping limits prediction movement from rollout-time values.

Important limitations:

  • clipping can slow necessary critic adaptation;

  • \(\epsilon_v\) depends on reward and return scale;

  • stored old values and return targets must be detached;

  • clipping does not make incorrect bootstrap targets correct;

  • low value loss still does not imply high explained variance.

Tensor shapes:

  • old/current values, returns and masks: [B, T]

  • value deltas and loss elements: [B, T]

  • final masked value loss: scalar

DPO ordinarily has no critic and therefore no value-clipping objective.

🔍 Deeper: the clipped value loss

\[L^V=\max\Big((V_\phi-\hat G)^2,\ \big(V_{\text{old}}+\operatorname{clip}(V_\phi-V_{\text{old}},-\epsilon,\epsilon)-\hat G\big)^2\Big).\]

\(V_{\text{old}}=0\), target \(\hat G=1\), \(\epsilon=0.2\). Past \(V=0.2\) the loss is flat at 0.64, so the gradient is zero even though \(V\) is still far from the target.

Implications: the critic can close at most about \(\epsilon\) of the gap per rollout. If \(|\hat G-V_{\text{old}}|\gg\epsilon\), it needs many iterations. Normalize returns, or scale \(\epsilon\) to the return scale, and track the value clip fraction.

🔑 Key ideas

  • The critic can have its own trust region, measured in return units.

  • Track the value clip fraction, raw errors and explained variance together.

🚶 Walkthrough: how slow can the critic be?

\(V_{\text{old}}=0\), target \(1\), \(\epsilon_v=0.2\): one update reaches at most \(0.2\), so the gap closes in about 5 rollouts. Same setup with returns \(\times100\) (target \(100\)): about 500 rollouts. Normalize returns.

Common mistakes

  • One \(\epsilon\) shared by the policy and value clips with unnormalized returns.

  • Clipping around the current \(V_\phi\) instead of rollout-time \(V_{\text{old}}\).

  • Using \(\min\) instead of \(\max\) (that makes the critic optimistic, not pessimistic).

⚙️ Algorithm: PPO critic update with value clipping
Input: new predictions \(V_\phi(s_t)\), rollout-time values \(V_{\text{old}}(s_t)\), targets \(\hat R_t\), clip \(\epsilon_v\), mask \(m_t\)
\(V_{\text{clip}}\gets V_{\text{old}}+\operatorname{clip}(V_\phi-V_{\text{old}},-\epsilon_v,\epsilon_v)\)
\(L_V\gets\frac12\sum_tm_t\max\big((V_\phi-\hat R_t)^2,(V_{\text{clip}}-\hat R_t)^2\big)\big/\sum_tm_t\)
gradient step on \(L_V\)
log the value clip fraction \(\operatorname{mean}_t\,\mathbb 1[|V_\phi-V_{\text{old}}|>\epsilon_v]\) and explained variance

Hints

  • Delta is current - old.

  • Clamp delta to [-0.2, 0.2].

  • Both errors compare a prediction against the same detached return.

  • Multiply by the mask before dividing by valid-token count.

  • The clipped branch is selected where its squared error is larger.

Debugging experiments

Use minimum instead of maximum:

value_loss_elements = torch.minimum(
    unclipped_errors,
    clipped_errors,
)

The critic can now benefit from whichever branch looks better, defeating the conservative clipping rule.

Next, accidentally use current predictions as old values:

old_values = current_values.detach()

Every delta becomes zero, so value clipping never detects movement from the actual rollout critic.

Finally, scale returns by 100 while retaining epsilon_v=0.2. The permitted update becomes tiny relative to the target scale, potentially freezing useful critic learning.

4. Checks for understanding

  1. Why must rollout-time old values remain fixed?

  2. Can value clipping produce zero gradients for badly predicted states?

  3. Why should value clip fraction be logged with explained variance?

  4. When might disabling value clipping be reasonable?

Solutions

Value changes:

value_deltas = (
    current_values - old_values
)

Clipped predictions:

clipped_deltas = value_deltas.clamp(
    -value_clip_epsilon,
    value_clip_epsilon,
)

clipped_values = (
    old_values + clipped_deltas
)

Squared errors:

unclipped_errors = (
    current_values
    - returns.detach()
).square()

clipped_errors = (
    clipped_values
    - returns.detach()
).square()

Masked value loss:

value_loss_elements = torch.maximum(
    unclipped_errors,
    clipped_errors,
)

value_loss = 0.5 * (
    value_loss_elements * mask
).sum() / mask.sum()

Diagnostics:

delta_clip_fraction = (
    value_deltas[valid].abs()
    > value_clip_epsilon
).to(
    current_values.dtype
).mean()

clipped_branch_fraction = (
    clipped_errors[valid]
    > unclipped_errors[valid]
).to(
    current_values.dtype
).mean()

The valid deltas are:

+0.1, +0.5, -0.5, +0.1

The middle two exceed the allowed magnitude 0.2.

For the prediction 0.5 with target 1.0:

\[(0.5-1)^2=0.25\]

but its clipped prediction is 0.2:

\[(0.2-1)^2=0.64\]

The loss selects 0.64, preventing the critic from claiming the improvement produced by moving farther than the clipping range.

In this simplified example, the selected clipped branch is constant outside the clamp and can produce zero gradient. Real shared-network parameters may still receive gradients from other tokens and loss terms.

All padded positions must have zero gradient despite their extreme value 99.

Check answers

  1. Otherwise, both sides move together and the delta no longer measures change from the policy that generated the rollout.

  2. Yes. When the constant clipped branch supplies the maximum loss, that sample may contribute no direct value gradient.

  3. A large clip fraction may explain stalled critic learning or poor EV even when the reported clipped loss appears stable.

  4. When reward scales change rapidly, the critic is severely underfit, or careful learning-rate control and monitoring provide sufficient stability.

Retrieval answers

  1. Its residuals vary more than the returns themselves; predicting a constant return mean would perform better.

  2. MSE has squared reward units. Multiplying rewards and predictions by \(c\) multiplies MSE by \(c^2\), even if relative prediction quality is unchanged.

Takeaway: PPO constrains not only the actor but often the critic. Value clipping can stabilize training, yet its threshold is reward-scale dependent and can suppress necessary learning. Track clip fraction, raw value errors and explained variance together.
