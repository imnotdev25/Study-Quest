🧩 Analogy: a lazy weather forecaster

A forecaster in a mild city who always predicts “20\(^\circ\)C” gets a small average error, because the weather rarely moves far from 20. But they’re useless: they never tell you whether tomorrow is warmer or colder. A critic that predicts the average return everywhere has the same flaw: a low loss, and no information.

2. A critic must predict variation, not merely small numbers

PPO’s critic predicts expected return:

\[V_\phi(s_t)\approx \hat R_t\]

Its masked regression loss is usually:

\[L_V = \frac{ \sum_{i,t} M_{i,t} \left[ V_\phi(s_{i,t})-\hat R_{i,t} \right]^2 }{ \sum_{i,t}M_{i,t} }\]

Value loss alone can be misleading:

  • if returns are tiny, a useless critic can have tiny MSE;

  • multiplying rewards by 100 multiplies MSE by roughly 10,000;

  • padding can make loss appear smaller if included in the denominator;

  • a critic predicting only the mean may reduce loss without ranking good and bad states.

A scale-relative diagnostic is explained variance:

\[\operatorname{EV} = 1- \frac{ \operatorname{Var}(\hat R-V_\phi) }{ \operatorname{Var}(\hat R) }\]

Interpretation:

  • \(1\): perfect predictions;

  • \(0\): no better than predicting a constant mean;

  • \(<0\): worse than that constant baseline.

EV does not replace value loss. It becomes unstable when return variance is nearly zero, so log both the return variance and EV.

Tensor shapes:

  • critic inputs: [B, T, features]

  • predicted values, returns and mask: [B, T]

  • masked value loss and explained variance: scalar

Return and advantage targets should be detached from critic backpropagation. DPO ordinarily has no value critic because it optimizes fixed preference comparisons rather than online return estimates.

🔍 Deeper: explained variance

\[\mathrm{EV}=1-\frac{\operatorname{Var}[G-V]}{\operatorname{Var}[G]} .\] EV \(=1\) is perfect. EV \(=0\) is no better than predicting the mean. EV \(<0\) is worse than a constant. Why loss alone misleads: the MSE of the constant critic equals \(\operatorname{Var}[G]\). If returns barely vary, that’s tiny, yet EV \(=0\). Compute everything over masked (real) response tokens, with detached targets, and also log the raw scale of returns. A critic that’s 90% accurate on a scale of 0.01 still might not help.

🔑 Key ideas

  • Low value loss doesn’t mean a useful critic.

  • Track explained variance alongside loss.

🚶 Walkthrough: explained variance

Returns \(G=(1,2,3,4)\), \(\operatorname{Var}=1.25\). Critic \(V=(1.2,1.9,3.1,3.8)\): residuals \((-0.2,0.1,-0.1,0.2)\), \(\operatorname{Var}=0.025\), so EV \(=0.98\). Constant critic \(V=2.5\): residual variance \(=1.25\), so EV \(=0\).

Common mistakes

  • Including padding positions.

  • Using different variance conventions in numerator and denominator.

  • Computing EV on normalized targets but reporting raw loss.

Hints

Debugging experiments

Include padding in the loss:

value_loss = (
    predictions - returns
).square().mean()

The critic now trains on positions that do not correspond to generated tokens. If padded returns are zeros, enough padding can make a zero predictor look deceptively good.

Next, remove target detachment after constructing returns from a differentiable reward or advantage pipeline. The critic can then alter the target-producing network rather than simply fitting a fixed target.

Finally, make all valid returns identical. Target variance becomes zero, so EV is undefined in principle. The epsilon prevents division by zero but does not make EV informative.

4. Checks for understanding

  1. Why is value MSE difficult to compare across reward scales?

  2. What does negative explained variance mean?

  3. Can a high EV guarantee unbiased advantages?

  4. Which critic diagnostics should be logged together?

Solutions

Mask:

mask = (
    positions < lengths[:, None]
)

Metrics:

mse = residuals.square().mean()

target_variance = valid_targets.var(
    unbiased=False
)

residual_variance = residuals.var(
    unbiased=False
)

explained_variance = (
    1.0
    - residual_variance
    / (
        target_variance + 1e-8
    )
)

Training:

for step in range(200):
    predictions = critic(
        features
    ).squeeze(-1)

    value_loss = (
        predictions[mask]
        - returns[mask].detach()
    ).square().mean()

    optimizer.zero_grad()
    value_loss.backward()
    optimizer.step()

Scaled quantities:

scaled_returns = (
    100.0 * returns
)

scaled_predictions = (
    100.0 * final_predictions
)

The trained parameters should approach:

\[w\approx2,\qquad b\approx-0.5\]

with small deviations due to noise.

A constant predictor equal to the target mean has residual variance approximately equal to target variance:

\[\operatorname{EV}\approx0\]

The reversed predictor is actively wrong, so its residual variance exceeds the target variance and EV becomes negative.

When targets and predictions are both multiplied by 100:

\[\mathrm{MSE}'=100^2\mathrm{MSE}\]

but:

\[\operatorname{EV}'=\operatorname{EV}\]

because numerator and denominator variances scale by the same factor.

Check answers

  1. MSE has squared reward units, so reward rescaling changes its magnitude even when relative prediction quality is unchanged.

  2. The critic’s errors vary more than the returns themselves; predicting the constant mean would be better.

  3. No. A critic may explain variation while remaining systematically biased, and incorrect bootstrapping can still corrupt advantages.

  4. Log masked MSE, explained variance, return variance, prediction mean and spread, target mean and spread, correlation, and errors by response position and prompt category.

Retrieval answers

  1. The current policy has moved far from the rollout policy, often because of too many epochs, a high learning rate or stale rollouts; many samples may be clipped.

  2. PPO’s ratio must compare the current policy against the fixed policy that generated the actions. Allowing the denominator to move invalidates that comparison.

Takeaway: critic loss measures absolute squared error; explained variance asks whether the critic captures meaningful return variation. Monitor both with the correct response mask, detached targets and raw return-scale diagnostics.
