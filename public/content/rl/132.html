2. PPO changes the distribution being evaluated

Suppose a reward model was calibrated on outputs from behavior policy \(\mu\), where only 5% of outputs were unusual. After optimization, target policy \(\pi\) may produce unusual outputs 40% of the time.

The relevant target risk is:

\[R_\pi = \underbrace{ E_{y\sim d_\pi}[\ell(y)] }_{\text{expected reward-model error on new-policy outputs}}\]

An unweighted validation set instead estimates:

\[R_\mu = \underbrace{ E_{y\sim d_\mu}[\ell(y)] }_{\text{error on old-policy outputs}}\]

These are different estimands.

If the target distribution is supported by the behavior distribution, define:

\[w(y) = \underbrace{ \frac{d_\pi(y)}{d_\mu(y)} }_{\text{how much more often the new policy generates }y}\]

Then estimate target risk from behavior-policy data:

\[\hat R_\pi = \underbrace{ \frac{\sum_i w_i\ell_i} {\sum_i w_i} }_{\text{self-normalized importance-weighted risk}}\]

For an autoregressive LLM:

\[w(y\mid x) = \underbrace{ \frac{\pi(y\mid x)}{\mu(y\mid x)} }_{\text{sequence probability ratio}} = \exp\left( \underbrace{ \sum_{t=1}^{T} \left[ \log\pi(y_t\mid x,y_{<t}) - \log\mu(y_t\mid x,y_{<t}) \right] }_{\text{sum only over generated, unmasked tokens}} \right)\]

Long sequences can produce enormous or tiny ratios. Compute in log space and confirm that behavior log-probabilities correspond to the actual temperature, masking and sampling filters.

For selective prediction:

\[\hat C_\pi(\tau) = \underbrace{ \frac{\sum_i w_i a_i(\tau)} {\sum_i w_i} }_{\text{estimated target-policy coverage}}\]

\[\hat R_\pi(\tau) = \underbrace{ \frac{\sum_i w_i a_i(\tau)\ell_i} {\sum_i w_i a_i(\tau)} }_{\text{target risk among accepted outputs}}\]

Importance weighting can have high variance. Its effective sample size is:

\[\operatorname{ESS} = \underbrace{ \frac{(\sum_i w_i)^2} {\sum_i w_i^2} }_{\text{independent, equal-weight sample equivalent}}\]

Weight clipping increases stability but introduces bias:

\[\tilde w_i = \underbrace{ \min(w_i,c) }_{\text{bounded weight; lower variance but changed target}}\]

DPO is offline preference optimization, but evaluation of the resulting DPO policy still requires fresh generations or valid off-policy correction. Reference-policy log-ratios inside the DPO loss do not automatically correct outcome evaluation.

Solutions

Batch generation:

def generate_batch(
    num_examples,
    tail_probability,
):
    tail_examples = (
        torch.rand(num_examples)
        < tail_probability
    )

    true_rewards = torch.randn(
        num_examples
    )

    error_standard_deviations = torch.where(
        tail_examples,
        torch.tensor(tail_error_sd),
        torch.tensor(ordinary_error_sd),
    )

    predicted_rewards = (
        true_rewards
        + error_standard_deviations
        * torch.randn(num_examples)
    )

    uncertainty = (
        torch.where(
            tail_examples,
            torch.tensor(0.60),
            torch.tensor(0.20),
        )
        + 0.15
        * torch.randn(num_examples)
    ).clamp_min(0.0)

    accepted = (
        uncertainty
        <= acceptance_threshold
    )

    return (
        true_rewards,
        predicted_rewards,
        uncertainty,
        tail_examples,
        accepted,
    )

def weighted_selective_risk(
    losses,
    accepted,
    weights,
):
    accepted_weights = (
        weights
        * accepted.to(torch.float32)
    )

    return (
        accepted_weights * losses
    ).sum() / accepted_weights.sum().clamp_min(
        1e-12
    )

Exact importance weighting reconstructs the target mixture but reduces the effective sample fraction to roughly:

\[\underbrace{0.28}_{\text{about 14,000 equal-weight samples from 50,000 logs}}\]

Clipping raises the ESS fraction to roughly 0.68, but only by underrepresenting the target tail. It is more stable because it estimates a different, easier distribution.

Check answers

  1. PPO changes which completions are common; reward error can depend strongly on completion style or region.

  2. Every target-policy output with positive probability must also have positive behavior-policy probability.

  3. Sequence ratios multiply token ratios, so small per-token differences compound exponentially with length.

  4. It reduces variance and increases effective sample size while introducing bias toward the behavior distribution.

  5. Prefer fresh rollouts when ratios are highly variable, support is weak, decoding changed, or promotion decisions are high stakes.

Retrieval answers

  1. Coverage is the automatically accepted fraction; selective risk is error conditional on acceptance.

  2. An overconfident failure can receive lower uncertainty than correct examples, so stricter filtering may concentrate rather than remove failures.

Takeaway: reward-model calibration belongs to a policy distribution. Once PPO, GRPO, best-of-\(N\), or DPO changes that distribution, either evaluate fresh outputs or quantify the shift—old validation accuracy does not travel automatically.
