2. An ensemble can expose uncertainty—not truth

Let \(M\) reward models score completion \(y\):

\[\hat r_1(y),\ldots,\hat r_M(y)\]

Compute their mean and disagreement:

\[\mu(y)=\frac1M\sum_{m=1}^M\hat r_m(y)\]

\[s(y)= \sqrt{ \frac1M\sum_{m=1}^M \left(\hat r_m(y)-\mu(y)\right)^2 }\]

A simple pessimistic selection score is:

\[q_\kappa(y)=\mu(y)-\kappa s(y)\]

Think of five inspectors. Agreement raises confidence; disagreement is a warning. Increasing \(\kappa\) makes selection more conservative.

If model errors are independent with variance \(\sigma^2\), averaging reduces noise:

\[\operatorname{Var}[\mu]\approx\frac{\sigma^2}{M}\]

But suppose every model shares the same blind spot \(b(y)\):

\[\hat r_m(y)=r(y)+b(y)+\epsilon_m(y)\]

Then:

\[\mu(y)\approx r(y)+b(y)\]

while \(s(y)\) measures only differences among models. All models can confidently agree on the same mistake.

Therefore, \(\mu-\kappa s\) is a risk-sensitive proxy—not automatically a calibrated confidence bound. Calibration requires held-out, preferably adversarial, human or verifiable outcomes.

Tensor shapes:

  • true rewards and exploit flags: [B, N]

  • member predictions: [B, N, M]

  • ensemble means and standard deviations: [B, N]

  • selected candidate IDs: [B, 1]

In PPO, freeze and detach reward-model outputs before constructing advantages. Also calibrate member scales: disagreement is meaningless if one model merely emits numerically larger scores.

DPO has no separate scalar reward model during training, but can still exploit shared shortcuts in preference data. An ensemble can audit DPO outputs; it does not turn DPO into online RL.

Solutions

Candidate construction:

ordinary_true_rewards = torch.randn(
    num_prompts,
    num_candidates,
)

exploit_flags = (
    torch.rand(
        num_prompts,
        num_candidates,
    )
    < exploit_probability
)

true_rewards = torch.where(
    exploit_flags,
    torch.full_like(
        ordinary_true_rewards,
        exploit_true_reward,
    ),
    ordinary_true_rewards,
)

Reward-model ensembles:

member_noise = (

Selection metrics:

def selection_metrics(score, disagreement):
    selected_indices = score.argmax(
        dim=1,
        keepdim=True,
    )

    selected_scores = score.gather(
        dim=1,
        index=selected_indices,
    ).squeeze(1)

    selected_true_rewards = true_rewards.gather(
        dim=1,
        index=selected_indices,
    ).squeeze(1)

    selected_exploits = exploit_flags.gather(
        dim=1,
        index=selected_indices,
    ).squeeze(1).to(torch.float32)

    selected_disagreement = disagreement.gather(
        dim=1,
        index=selected_indices,
    ).squeeze(1)

    oracle_true_rewards = true_rewards.max(
        dim=1
    ).values

    oracle_regret = (
        oracle_true_rewards
        - selected_true_rewards
    )

    return torch.stack([
        selected_scores.mean(),
        selected_true_rewards.mean(),
        selected_exploits.mean(),
        selected_disagreement.mean(),
        oracle_regret.mean(),
    ])

Disagreement audit:

any_exploit_rate = (
    exploit_flags.any(dim=1)
    .to(torch.float32)
    .mean()

theoretical_any_exploit_rate = (
    1.0
    - (
        1.0
        - exploit_probability

)

Typical behavior is approximately:

Selection rule Selected true reward Exploit rate Interpretation
Selection rule Selected true reward Exploit rate Interpretation
Single vulnerable model below 0 near 0.72 One model gives exploits a huge bonus
Heterogeneous ensemble mean near 0 around 0.60 Averaging helps, but the mean remains vulnerable
Heterogeneous pessimistic score around 2.5 near 0 Large disagreement suppresses exploits
Shared-bias pessimistic score below 0 near 0.72 Agreement hides the shared failure
Oracle around 2.6 0 Selects by true reward

For ordinary candidates, expected disagreement is roughly 0.34. The heterogeneous exploit bonuses produce disagreement near 3.75, making the exploit detectable.

With a shared bonus, both honest and exploit candidates have disagreement near 0.34. The uncertainty penalty therefore provides no warning: every model agrees on the same wrong answer.

Check answers

  1. Independent errors partially cancel in the ensemble mean, reducing variance approximately as \(1/M\).

  2. Members are correlated, their training data are finite, and their score scales may be uncalibrated. Standard deviation alone supplies no coverage guarantee.

  3. A shared blind spot caused by common data, architecture, labelers or evaluation shortcuts.

  4. Selection becomes more conservative about disagreement, but may reject genuinely valuable novel behavior and changes the optimized objective.

  5. An evaluator independent of the reward ensemble—preferably humans, verifiable outcomes or a separately governed audit system.

Retrieval answers

  1. Maximization conditions on unusually positive errors, so selected errors are no longer centered at zero.

  2. The probability is \(1-(1-p)^N\).

Takeaway: ensemble disagreement can reveal “the models do not know,” but not “the models agree and are wrong.” Penalize uncertainty only as one defense; independently test the optimized reward tail for shared blind spots.
