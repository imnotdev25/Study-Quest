2. Replace an arbitrary penalty with an adaptive multiplier

Constrained RL asks:

\[\max_\theta \underbrace{J_R(\theta)}_{\text{expected reward}} \qquad \text{subject to} \qquad \underbrace{J_C(\theta)\le d}_{\text{expected cost below limit}}\]

Here, cost could mean unsafe responses, excessive tool calls, latency or policy violations.

Introduce a nonnegative Lagrange multiplier:

\[\mathcal L(\theta,\lambda) = \underbrace{J_R(\theta)}_{\text{reward}} - \underbrace{ \lambda\left(J_C(\theta)-d\right) }_{\text{adaptive constraint penalty}} + \underbrace{\beta\mathcal H(\pi_\theta)}_{\text{optional entropy}}\]

with:

\[\lambda\ge0\]

The actor maximizes the Lagrangian:

\[\theta \leftarrow \underbrace{ \theta+\eta_\theta \nabla_\theta\mathcal L(\theta,\lambda) }_{\text{reward ascent penalized by cost}}\]

The multiplier follows:

\[\lambda \leftarrow \underbrace{ \left[ \lambda+ \eta_\lambda \left(J_C(\theta)-d\right) \right]_+ }_{\text{increase penalty when cost exceeds limit}}\]

The sign is important:

  • if \(J_C>d\), increase \(\lambda\);

  • if \(J_C<d\), decrease \(\lambda\);

  • projection \([\cdot]_+\) prevents negative safety penalties.

At a constrained optimum:

\[\underbrace{\lambda\ge0}_{\text{valid multiplier}}, \qquad \underbrace{J_C-d\le0}_{\text{feasible policy}}, \qquad \underbrace{\lambda(J_C-d)=0}_{\text{complementary slackness}}\]

Thus an active constraint usually ends near \(J_C=d\).

A fixed penalty such as \(J_R-0.5J_C\) is not automatically equivalent to a constraint. Its correct coefficient depends on reward scale, cost scale and the environment.

DPO’s \(\beta\) regulates movement from a reference policy; it is not an automatically adjusted safety multiplier. DPO remains offline preference optimization unless coupled to an environment interaction loop.

⚙️ Algorithm: Lagrangian constrained RL
Input: cost limit \(d\), multiplier \(\lambda\gets0\), multiplier step size \(\eta_\lambda\)
repeat
collect rollouts; estimate reward return \(\hat J_R\) and cost return \(\hat J_C\)
compute reward advantages \(A^R\) and cost advantages \(A^C\) (separate critics)
policy update (e.g. PPO) on the combined advantage \(A^R-\lambda A^C\)
\(\lambda\gets\max\big(0,\ \lambda+\eta_\lambda(\hat J_C-d)\big)\) ▷ violations raise the penalty
until converged

\[0.1+0.7p\le0.3\]

\[p \le \underbrace{ \frac{0.3-0.1}{0.8-0.1} }_{2/7} \approx0.2857\]

Check answers

  1. \(p_{\max}=2/7\approx0.2857\).

  2. Toward the risky action because it has greater reward.

  3. No. It leaves the risky action sufficiently attractive that expected cost remains far above 0.30.

  4. Upward, because \(J_C-d=0.50-0.30>0\).

  5. The fast variable can repeatedly overshoot before the slow variable reacts, producing cycles around the constraint boundary.

Retrieval answers

  1. Safety must rule out excessive harm, so the worst plausible value—the upper bound—must remain below the margin.

  2. Promotion requires every component to pass. If any requirement is truly false, falsely promoting requires its level-\(\alpha\) test to make an error. Searching across candidates is different and introduces multiplicity.

Takeaway: fixed reward penalties encode one guess about the tradeoff. A Lagrange multiplier turns observed constraint violation into an adaptive penalty—but training stability and independent deployment gates still matter.
