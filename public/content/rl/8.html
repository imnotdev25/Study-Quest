🧩 Analogy: the winner’s curse

At an auction, whoever bids highest usually overestimated the item’s value; that’s why they won. Q-learning has the same problem: \(\max_a Q(s',a)\) picks the action whose estimate is most inflated by noise.

Q-learning itself is like planning “tomorrow I’ll be perfectly disciplined” while still behaving randomly today. It learns the value of the best possible behaviour, not the behaviour you’re actually showing.

Q-learning’s backup: the target takes a \(\max\) over next actions instead of sampling one.

2. The one change that creates Q-learning

SARSA learns from the next action actually selected:

\[Y_t^{\text{SARSA}} = R_{t+1}+\gamma(1-D_t)Q(S_{t+1},A_{t+1})\]

Q-learning instead uses the best currently estimated next action:

\[Y_t^{\text{Q-learning}} = R_{t+1} + \gamma(1-D_t)\max_{a'}Q(S_{t+1},a')\]

Then:

\[\delta_t=Y_t-Q(S_t,A_t)\]

\[Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\delta_t\]

This resembles correcting a line’s slope estimate using new data:

\[\text{new estimate} = \text{old estimate} + \text{step size}\times\text{error}\]

Here, however, it is a direct tabular update—not gradient descent. With a neural Q-function, the same target becomes a regression target and SGD performs the update.

Why it is off-policy

Imagine learning routes while occasionally taking random roads. Your experience comes from an exploratory driver, but your target assumes that from the next junction onward you take the best-known road.

Thus Q-learning has two policies:

  • Behaviour policy: commonly \(\epsilon\)-greedy; produces experience.

  • Target policy: greedy; represented by \(\max_{a'}Q(s',a')\).

Because they differ, Q-learning is off-policy.

Method Next-state target
Method Next-state target
SARSA Value of the action actually selected
Q-learning Maximum estimated action value

The behaviour policy must still explore. Off-policy does not mean “collect no new experience.”

A practical warning: maximization bias

Suppose every action estimate contains noise. Taking the maximum tends to select estimates whose errors are unusually positive:

\[\mathbb E[\max_a\hat Q(a)] \;\text{can exceed}\; \max_a\mathbb E[\hat Q(a)]\]

This can cause overestimation. Double Q-learning and Double DQN address this by separating action selection from evaluation.

LLM connection

An LLM agent may explore several tool calls while training. An off-policy value method can learn a greedy tool-use target from those exploratory trajectories.

For large language action spaces, directly maximizing over every possible continuation is impractical. Policy-based methods and sampled approximations become more useful later.

🔍 Deeper: maximization bias

Q-learning target: \(r+\gamma\max_{a'}Q(s',a')\), which estimates \(Q^*\) regardless of the behaviour policy.

Bias: if \(\hat Q(a)=Q(a)+\varepsilon_a\) with zero-mean noise, then by Jensen’s inequality \(\mathbb E[\max_a\hat Q(a)]\ge\max_a Q(a)\). With \(n\) equally good actions and \(\mathcal N(0,1)\) noise, the expected overestimate is \(\mathbb E[\max_i Z_i]\):

\(n\) 1 2 5 10 100
\(\mathbb E[\max Z]\) 0 0.56 1.16 1.54 2.51

Double Q-learning fixes this: one estimate picks the action and the other scores it, \(r+\gamma Q_B\big(s',\arg\max_{a'}Q_A(s',a')\big)\). The selection noise and evaluation noise are independent, so the upward bias disappears.

🔑 Key ideas

  • Q-learning = off-policy: explore however you like, learn about the greedy policy.

  • \(\max\) of noisy estimates is biased upward. Double estimators decouple “choose” from “score.”

🚶 Walkthrough: the max picks the noisiest action

Three actions, all truly worth 0. Noisy estimates \(Q(s',\cdot)=(0.4,-0.3,0.1)\). Target with \(r=0,\gamma=1\): \(\max=0.4\), so every update pushes \(Q(s,a)\) up by mistake. Double Q: estimate \(A\) picks \(\arg\max=a_1\), and an independent estimate \(B\) with values \((-0.2,0.3,0.0)\) scores it at \(-0.2\). The noise averages out instead of compounding.

Common mistakes

  • Using \(\max\) at terminal states (it must be 0).

  • Forgetting that estimate \(B\) must be trained on different updates than \(A\).

  • Decaying \(\epsilon\) to 0 too early, so some actions are never revisited.

⚙️ Algorithm: Q-learning (off-policy TD control)
Input: step size \(\alpha\), discount \(\gamma\), exploration \(\epsilon\)
\(Q(s,a)\gets0\) for every state-action pair
for each episode do
\(s\gets\) initial state
while \(s\) is not terminal do
\(a\gets\epsilon\text{-greedy}(Q,s)\); take \(a\); observe \(r,s',d\)
\(Q(s,a)\gets Q(s,a)+\alpha\big[r+\gamma(1-d)\max_{a'}Q(s',a')-Q(s,a)\big]\) ▷ greedy target
\(s\gets s'\)
end
end

4. Checks for understanding

  1. Why is Q-learning off-policy even when its behaviour is \(\epsilon\)-greedy?

  2. Does max() select the action actually taken on the following step?

  3. Why must the terminal target be only the observed reward?

  4. What happens if exploration is removed before every useful action has been tried?

  5. Why can max() systematically overestimate values when estimates are noisy?

Solutions

def choose_action(state):
    if torch.rand(()) < epsilon:
        return torch.randint(num_actions, ()).item()
    return q[state].argmax().item()

Inside the loop:

if done:
    target = torch.tensor(reward)
else:
    best_next_value = q[next_state].max()
    target = reward + gamma * best_next_value

td_error = target - q[state, action]
q[state, action] += alpha * td_error

The learned greedy actions should normally be:

state 0: right
state 1: right

The shortest successful path is two actions:

0 --right--> 1 --right--> 2

Approximate optimal values are:

\[Q^*(1,\text{right})=1\]

\[Q^*(0,\text{right}) = -0.01+0.95(1) = 0.94\]

Exact learned numbers can vary because exploration changes the sampled update sequence. A fixed seed makes the experiment reproducible, but it does not remove sampling effects.

The absolute TD error should generally shrink as estimates become consistent with their targets. Occasional exploration can still produce spikes, so inspect trends rather than requiring every update to decrease.

Check answers

  1. Experience comes from the exploratory behaviour policy, while the target evaluates a greedy policy using max.

  2. No. It selects the highest estimated action for the target, regardless of the next behaviour action.

  3. No future return exists after genuine termination.

  4. The agent can remain committed to a poor action because it never collects corrective evidence.

  5. Maximization preferentially selects actions with positive estimation errors.

Retrieval answers

  1. SARSA uses \(Q(S_{t+1},A_{t+1})\), where \(A_{t+1}\) is actually sampled.

  2. Its behaviour policy and target policy are the same policy.

Takeaway: SARSA learns the value of continuing to behave exploratorily. Q-learning explores to collect data but learns toward the greedy continuation.
