2. Cost-aware PPO uses one ratio and two advantages

PPO reuses rollout data collected by an old policy. Its importance ratio is:

\[\rho_t(\theta) = \underbrace{ \exp\!\left( \log\pi_\theta(a_t\mid s_t) - \log\pi_{\text{old}}(a_t\mid s_t) \right) }_{\text{new probability divided by collection probability}}\]

Constrained PPO first combines detached reward and cost advantages:

\[A_t^\nu = \underbrace{A_t^R}_{\text{reward credit}} - \underbrace{\nu}_{\text{learned safety price}} \underbrace{A_t^C}_{\text{cost credit}}\]

The clipped surrogate is:

\[L^{\text{clip}} = E\!\left[ \min\left( \underbrace{\rho_tA_t^\nu}_{\text{ordinary surrogate}}, \underbrace{ \operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t^\nu }_{\text{limited improvement}} \right) \right]\]

PyTorch minimizes:

\[L_{\text{actor}} = -\frac{ \sum_{i,t}m_{i,t}L^{\text{clip}}_{i,t} }{ \sum_{i,t}m_{i,t} }\]

The min matters because the advantage sign changes which direction counts as excessive improvement:

  • \(A>0,\rho>1+\epsilon\): cap the probability increase;

  • \(A<0,\rho<1-\epsilon\): cap the probability decrease;

  • updates moving in the harmful direction remain penalized.

Therefore, a ratio outside the clipping interval does not necessarily have zero gradient.

PPO clipping is not a safety constraint. The multiplier still follows raw episode cost:

\[\nu \leftarrow \left[ \nu+\eta_\nu \underbrace{(\bar C-d)}_{\text{actual cost violation}} \right]_+\]

Shapes:

  • full logits: [B, T, A]

  • actions, log-probabilities, ratios and advantages: [B, T]

  • valid-token mask: [B, T]

  • multiplier and losses: scalar []

PPO’s denominator is the policy that collected online rollouts. DPO instead compares a trainable policy with a usually fixed reference model on offline preference pairs; it has no sampled environment advantage or automatic dual constraint.

Solutions

Masked mean and log-probabilities:

def masked_mean(values, mask):
    return (
        values * mask
    ).sum() / mask.sum()

with torch.no_grad():
    old_log_probabilities = (
        old_distribution.log_prob(actions)
    )

new_log_probabilities = (
    new_distribution.log_prob(actions)
)

Importance ratios:

log_ratios = (
    new_log_probabilities
    - old_log_probabilities
)

ratios = torch.exp(log_ratios)

Constrained advantage:

actor_advantages = (
    reward_advantages
    - safety_multiplier.detach()
    * cost_advantages
).detach() * valid_mask

PPO objective:

unclipped_surrogate = (
    ratios * actor_advantages
)

clipped_ratios = ratios.clamp(
    1.0 - clip_epsilon,
    1.0 + clip_epsilon,
)

clipped_surrogate = (
    clipped_ratios * actor_advantages
)

ppo_surrogate = torch.minimum(
    unclipped_surrogate,
    clipped_surrogate,
)

actor_loss = -masked_mean(
    ppo_surrogate,
    valid_mask,
)

Diagnostics:

valid = valid_mask.bool()

outside_clip = (
    (
        ratios < 1.0 - clip_epsilon
    )
    | (
        ratios > 1.0 + clip_epsilon
    )
) & valid

objective_clipping_active = (
    unclipped_surrogate
    > clipped_surrogate
) & valid

old_log_all = torch.log_softmax(
    old_logits,
    dim=-1,
)

new_log_all = torch.log_softmax(
    new_logits,
    dim=-1,
)

old_probabilities = torch.softmax(
    old_logits,
    dim=-1,
)

token_kls = (
    old_probabilities
    * (
        old_log_all
        - new_log_all
    )
).sum(dim=-1)

mean_kl = masked_mean(
    token_kls,
    valid_mask,
)

clip_fraction = masked_mean(
    outside_clip.to(torch.float64),
    valid_mask,
)

objective_clip_fraction = masked_mean(
    objective_clipping_active.to(
        torch.float64
    ),
    valid_mask,
)

Dual update:

updated_safety_multiplier = torch.clamp(
    safety_multiplier
    + dual_lr
    * (
        episode_costs.mean()
        - cost_limit
    ),
    min=0.0,
)

There are eight valid tokens. With these values, typical diagnostics are:

\[\underbrace{\text{ratio-outside fraction}}_{7/8} =0.875\]

\[\underbrace{\text{actively clipped fraction}}_{6/8} =0.75\]

The difference is the important result: one out-of-range update moves in a harmful direction, so PPO retains its gradient.

The raw mean cost is:

\[\bar C = \underbrace{\frac{0.90+1.30}{2}}_{1.10}\]

Therefore:

\[\nu_{\text{new}} = \underbrace{1.50}_{\text{old price}} + \underbrace{0.10(1.10-1.00)}_{\text{positive violation update}} = 1.51\]

Check answers

  1. Clipping limits only excessive objective improvement. Always using the clipped ratio would also suppress corrective gradients.

  2. They define the behaviour policy that generated the data. Changing them destroys the importance ratio.

  3. No. Harmful-direction updates outside the interval retain their gradient.

  4. KL measures policy movement, not expected safety cost. A nearby policy can still violate the budget.

Retrieval answers

  1. \(\lambda_{\text{GAE}}\) controls temporal credit length; the safety multiplier learns how strongly cost affects the actor.

  2. Continuation masks stop terminal bootstrapping. Valid-token masks exclude prompt, padding and nonexistent timesteps from losses.

Takeaway: PPO clipping limits rewarded policy movement; it does not clip away unsafe behaviour or enforce a budget. Keep old log-probabilities frozen, combine reward and cost advantages carefully, and let raw episode cost update the safety multiplier.
