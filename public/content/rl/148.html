2. Hoeffding protects against worst-case variance

For independent policy-difference scores:

\[a\le d_i\le b, \qquad \Delta= \underbrace{E[d_i]}_{\text{true policy improvement}}\]

Hoeffding uses only the range \(b-a\):

\[r_k^{\mathrm H} = \underbrace{ (b-a) \sqrt{ \frac{\log(1/\alpha_k)} {2n_k} } }_{\text{range-only radius}}\]

It remains valid even if scores frequently reach both bounds. But suppose most episodes produce scores near zero. The actual variance may be far below the worst case.

Estimate that variance with:

\[\hat v_k = \underbrace{ \frac{1}{n_k-1} \sum_{i=1}^{n_k} (d_i-\bar d_{n_k})^2 }_{\text{sample variance at look }k}\]

A conservative empirical Bernstein radius is:

\[r_k^{\mathrm{EB}} = \underbrace{ \sqrt{ \frac{ 2\hat v_k\log(3/\alpha_k) }{ n_k } } }_{\text{variance-sensitive term}} + \underbrace{ \frac{ 3(b-a)\log(3/\alpha_k) }{ n_k } }_{\text{range correction for rare extremes}}\]

The lower bound is:

\[LCB_k^{\mathrm{EB}} = \underbrace{\bar d_{n_k}-r_k^{\mathrm{EB}}} _{\text{variance-adaptive lower confidence bound}}\]

Using the spending schedule:

\[\alpha_k = \underbrace{ \frac{6\alpha}{\pi^2k^2} }_{\text{error allocated to look }k}\]

and a union bound gives simultaneous validity over the scheduled looks.

The second term prevents a few initial low-variance observations from creating unjustified confidence. Early in evaluation it often dominates; later, the variance-sensitive term becomes more important.

This is not equivalent to using:

\[\bar d_n-z\frac{\hat s_n}{\sqrt n}\]

at every look. That ordinary standard-error interval remains vulnerable to optional stopping.

For OPE, the bound requires genuinely bounded scores. Raw importance-weighted scores may violate this. Clipping supplies a bound but changes the estimand and introduces bias.

Tensor shapes:

  • simulated scores: [R, T]

  • means and variances at monitoring looks: [R, K]

  • Hoeffding radii: [K]

  • empirical Bernstein radii: [R, K]

Simulation:

def simulate_running_statistics(
    positive_probability,
    negative_probability,
):
    uniforms = torch.rand(
        num_repetitions,
        maximum_episodes,
    )

    scores = torch.where(
        uniforms < positive_probability,
        torch.tensor(upper_score),
        torch.where(
            uniforms
            < (
                positive_probability
                + negative_probability
            ),
            torch.tensor(lower_score),
            torch.tensor(0.0),
        ),
    )

    cumulative_sums = scores.cumsum(
        dim=1
    )

    cumulative_square_sums = (
        scores.square().cumsum(dim=1)
    )

    sums_at_looks = cumulative_sums[
        :,
        look_sizes - 1,
    ]

    square_sums_at_looks = (
        cumulative_square_sums[
            :,
            look_sizes - 1,
        ]
    )

    running_means = (
        sums_at_looks
        / look_sizes_float[None, :]
    )

    running_variances = (
        (
            square_sums_at_looks
            - sums_at_looks.square()
            / look_sizes_float[None, :]
        )
        / (
            look_sizes_float[None, :]
            - 1.0
        )
    ).clamp_min(0.0)

    return (
        running_means,
        running_variances,
    )


(
    null_means,
    null_variances,
) = simulate_running_statistics(
    null_positive_probability,
    null_negative_probability,
)

(
    alternative_means,
    alternative_variances,
) = simulate_running_statistics(
    alternative_positive_probability,
    alternative_negative_probability,
)

Empirical Bernstein radii:

def empirical_bernstein_radii(
    sample_variances,
):
    log_terms = torch.log(
        3.0 / alpha_spending
    )[None, :]

    variance_terms = torch.sqrt(
        2.0
        * sample_variances
        * log_terms
        / look_sizes_float[None, :]
    )

    range_corrections = (
        3.0
        * score_range
        * log_terms
        / look_sizes_float[None, :]
    )

    return (
        variance_terms
        + range_corrections
    )


null_eb_radii = (
    empirical_bernstein_radii(
        null_variances
    )
)

alternative_eb_radii = (
    empirical_bernstein_radii(

)

Promotion rates:

def promotion_rate(
    running_means,
    radii,
):
    lower_bounds = (
        running_means - radii
    )

    promoted = (
        lower_bounds > 0.0
    ).any(dim=1)

    return (
        promoted
        .to(torch.float64)
        .mean()
    )


null_hoeffding_rate = promotion_rate(

The population values are:

\[\Delta_0 = \underbrace{0.05(0.1)+0.05(-0.1)}_{\text{null score mixture}} = 0\]

\[\Delta_1 = \underbrace{0.10(0.1)+0.05(-0.1)}_{\text{candidate-positive mixture}} = 0.005\]

For the alternative:

\[\operatorname{Var}(d) = \underbrace{ 0.10(0.1^2)+0.05((-0.1)^2) }_{E[d^2]=0.0015} - \underbrace{0.005^2}_{E[d]^2} = 0.001475\]

The maximum variance allowed by [-0.1, 0.1] is 0.01, so the actual variance is almost seven times smaller.

Check answers

  1. Null: 0; alternative: 0.005.

  2. No. The alternative variance is 0.001475, compared with the maximum 0.01.

  3. Empirical Bernstein, because it incorporates the much smaller observed variance.

  4. A low observed variance may simply mean rare extreme outcomes have not appeared yet; the range term protects against that.

  5. The claimed bound is invalid because the assumed score range was false.

Retrieval answers

  1. Every inspection is another chance for random noise to cross the promotion threshold, so a pointwise interval does not control the probability of ever making a false promotion.

  2. Each independent score had to lie within a known fixed range.

Takeaway: Hoeffding asks, “How bad could variance be within this range?” Empirical Bernstein also asks, “How variable have the scores actually been?” The latter can certify small policy gains sooner—but only when the range, independence and monitoring plan are honest.
