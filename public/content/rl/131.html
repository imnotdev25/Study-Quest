2. Accuracy is not enough; measure risk versus coverage

A reward model normally scores every completion. Selective prediction instead allows it to defer uncertain examples to a human, verifier or stronger evaluator.

For example \(i\), define the acceptance mask:

\[a_i(\tau) = \underbrace{ \mathbf 1[u_i\le\tau] }_{\text{accept only if uncertainty }u_i\text{ is below threshold }\tau}\]

The coverage is:

\[C(\tau) = \underbrace{ \frac1n\sum_{i=1}^{n}a_i(\tau) }_{\text{fraction handled automatically}}\]

Using squared reward error:

\[\ell_i = \underbrace{ \left(\hat r_i-r_i\right)^2 }_{\text{loss between predicted and trusted reward}}\]

the selective risk is:

\[R(\tau) = \underbrace{ \frac{ \sum_i a_i(\tau)\ell_i }{ \sum_i a_i(\tau) } }_{\text{average error among accepted examples}}\]

A threshold may be selected on calibration data:

\[\tau^* = \underbrace{ \arg\max_\tau C_{\mathrm{cal}}(\tau) }_{\text{retain maximum automation}} \quad \text{subject to} \quad \underbrace{ R_{\mathrm{cal}}(\tau)\le r_{\max} }_{\text{meet the permitted risk}}\]

Then freeze \(\tau^*\) and evaluate it on untouched data.

This works only when uncertainty ranks errors reasonably well. A shared blind spot can be both wrong and assigned low uncertainty. In that case, lowering \(\tau\) may perversely increase risk because the system preferentially retains its overconfident errors.

Tensor shapes:

  • reward targets, predictions and uncertainty: [N]

  • thresholds: [K]

  • acceptance matrix: [N, K]

  • coverage and selective risk: [K]

In PPO, dropping uncertain rollouts changes the training distribution. Record what was rejected and why; do not silently treat rejected samples as zero reward. Reward outputs should also remain frozen and detached.

For DPO, filtering high-disagreement preference pairs changes the offline training distribution. It may remove genuinely ambiguous examples, but also difficult prompts or underrepresented groups. This remains preference-data filtering, not online RL.

Batch generation:

def generate_batch(num_examples):
    true_rewards = torch.randn(
        num_examples
    )

    hard_examples = (
        torch.rand(num_examples)
        < hard_example_probability
    )

    blind_spots = (
        torch.rand(num_examples)
        < blind_spot_probability
    )

    error_standard_deviations = torch.where(
        hard_examples,
        torch.tensor(hard_error_sd),
        torch.tensor(easy_error_sd),
    )

    prediction_errors = (
        error_standard_deviations
        * torch.randn(num_examples)
        + blind_spot_bias
        * blind_spots.to(torch.float32)
    )

    predicted_rewards = (
        true_rewards + prediction_errors
    )

    uncertainty = (
        torch.where(
            hard_examples,
            torch.tensor(1.00),
            torch.tensor(0.25),
        )
        + 0.08
        * torch.randn(num_examples)
    )

    uncertainty = torch.where(
        blind_spots,
        torch.full_like(
            uncertainty,
            0.05,
        ),
        uncertainty,
    )

    uncertainty = uncertainty.clamp_min(
        0.0
    )

    return (
        true_rewards,
        predicted_rewards,
        uncertainty,
        hard_examples,
        blind_spots,
    )

Risk–coverage calculation:

def risk_coverage_curve(
    true_rewards,
    predicted_rewards,
    uncertainty,
):
    squared_errors = (
        predicted_rewards
        - true_rewards
    ).square()

    accepted = (
        uncertainty[:, None]
        <= thresholds[None, :]
    )

    accepted_counts = accepted.sum(
        dim=0
    )

    coverage = (
        accepted
        .to(torch.float32)
        .mean(dim=0)
    )

    selective_risk = (
        (
            accepted.to(torch.float32)
            * squared_errors[:, None]
        ).sum(dim=0)
        / accepted_counts.clamp_min(1)
    )

    return (
        coverage,
        selective_risk,
        squared_errors,
    )

Threshold Coverage Selective risk

The selected threshold is typically 0.90: it handles roughly 82% of examples while meeting the calibration risk target.

Randomly retaining 82% leaves risk near the full-population value. Informative uncertainty rejects most difficult examples and lowers risk.

But every blind spot has uncertainty 0.05, so nearly 100% of them are accepted. At threshold 0.10, blind spots form an unusually large fraction of the tiny accepted set, causing risk to explode. Stricter abstention is therefore not automatically safer.

Check answers

  1. It shows the prediction error among accepted examples as the automatically handled fraction changes.

  2. Selecting \(\tau\) adapts it to calibration noise. Reusing those outcomes would produce optimistic final risk.

  3. When serious errors are assigned lower uncertainty than ordinary correct examples.

  4. Route them to another evaluator, human labelling or an explicit conservative protocol; preserve their metadata rather than silently replacing rewards.

  5. Report coverage and risk by prompt family, language, safety category, difficulty, response length and other deployment-relevant groups.

Retrieval answers

  1. Pairwise error correlation determines how much nominal ensemble size translates into independent information:

\[M_{\mathrm{eff}} = \underbrace{ \frac{M}{1+(M-1)\rho} }_{\text{independent-equivalent model count}}\]

  1. Member disagreement removes the shared error component, but that component remains in the ensemble mean.

Takeaway: abstention helps only when uncertainty identifies errors. Always inspect the full risk–coverage curve—especially its strictest region—because an overconfident shared blind spot can survive every uncertainty threshold.
