2. Ensemble size is not effective ensemble size

Imagine consulting sixteen weather apps that all consume the same faulty weather station. Their agreement is less reassuring than sixteen independent measurements.

Let each reward model’s error have variance \(\sigma^2\), with pairwise error correlation \(\rho\). The ensemble mean error is:

\[\bar\epsilon=\frac1M\sum_{m=1}^M\epsilon_m\]

In general:

\[\operatorname{Var}(\bar\epsilon) = \frac{1}{M^2} \sum_{i=1}^{M} \sum_{j=1}^{M} \operatorname{Cov}(\epsilon_i,\epsilon_j)\]

If every pair has correlation \(\rho\):

\[\operatorname{Var}(\bar\epsilon) = \sigma^2 \left[ \rho+\frac{1-\rho}{M} \right]\]

For independent models, \(\rho=0\), giving the familiar \(\sigma^2/M\). For correlated models:

\[\lim_{M\rightarrow\infty} \operatorname{Var}(\bar\epsilon) = \rho\sigma^2\]

More models cannot remove the shared component.

Define the effective ensemble size by:

\[\operatorname{Var}(\bar\epsilon) = \frac{\sigma^2}{M_{\mathrm{eff}}}\]

Then:

\[M_{\mathrm{eff}} = \frac{M}{1+(M-1)\rho}\]

Sixteen models with \(\rho=0.75\) have:

\[M_{\mathrm{eff}} = \frac{16}{1+15(0.75)} \approx1.31\]

There is another trap: member disagreement measures mostly the unshared error:

\[E[s^2] = \sigma^2(1-\rho)\frac{M-1}{M}\]

Thus highly correlated models can show low disagreement while their ensemble mean remains unreliable.

Tensor shapes:

  • correlation settings: [C]

  • shared noise: [C, B, N, 1]

  • independent member noise: [C, B, N, M]

  • ensemble errors: [B, N]

  • selected maximum per prompt pool: [B]

For reward-model ensembles, diversity should involve data sources, annotator groups, architectures, objectives and training pipelines—not merely different random seeds.

DPO does not ordinarily average scalar reward models, but preference models or label generators trained on the same data can have equally correlated blind spots. Consensus among them is not independent evidence.

Hints

Construct correlated errors as:

\[\epsilon_m = \sigma \left[ \sqrt{\rho}\,z_{\mathrm{shared}} + \sqrt{1-\rho}\,z_m \right]\]

Both noises have unit variance, so each model’s marginal error variance remains \(\sigma^2\).

  • Use correlations[:, None, None, None] for broadcasting.

  • Flatten two member tensors before torch.corrcoef.

  • Reduce the member dimension with .mean(dim=-1).

  • Use correction=0 for population-style variance.

  • Best-of-\(N\) optimism is the mean of each row’s maximum.

  • The expected within-ensemble variance is:

\[\sigma^2(1-\rho)\frac{M-1}{M}\]

Solutions

Correlated errors:

shared_noise = torch.randn(
    num_settings,
    num_prompt_pools,
    num_candidates,
    1,
)

independent_noise = torch.randn(
    num_settings,
    num_prompt_pools,
    num_candidates,
    maximum_models,
)

rho = correlations[
    :, None, None, None
]

reward_model_errors = (
    error_sd
    * (
        rho.sqrt()
        * shared_noise
        + (
            1.0 - rho
        ).sqrt()
        * independent_noise
    )
)

Empirical correlations:

Ensemble diagnostics:

rows = []

for setting_index, correlation in enumerate(
    correlations
):
    for model_count in model_counts:
        member_errors = reward_model_errors[
            setting_index,
            ...,
            :model_count,
        ]

        ensemble_errors = member_errors.mean(
            dim=-1
        )

        empirical_mean_variance = (
            ensemble_errors.var(
                correction=0
            )
        )

        theoretical_mean_variance = (
            error_sd ** 2
            * (
                correlation
                + (
                    1.0 - correlation
                ) / model_count
            )
        )

        empirical_within_variance = (
            member_errors.var(
                dim=-1,
                correction=0,
            ).mean()
        )

        theoretical_within_variance = (
            error_sd ** 2
            * (
                1.0 - correlation
            )
            * (
                model_count - 1
            )
            / model_count
        )

        selected_optimism = (
            ensemble_errors.max(
                dim=1
            ).values.mean()
        )

        effective_model_count = (
            model_count
            / (
                1.0
                + (
                    model_count - 1
                )
                * correlation
            )
        )

        rows.append(
            torch.stack([
                correlation,
                torch.tensor(
                    float(model_count)
                ),
                empirical_mean_variance,
                theoretical_mean_variance,
                empirical_within_variance,
                theoretical_within_variance,
                selected_optimism,
                effective_model_count,
            ])
        )

results = torch.stack(rows)

For sixteen members, the theoretical comparison is:

Error correlation Mean-error variance Disagreement variance Effective \(M\)
Error correlation Mean-error variance Disagreement variance Effective \(M\)
0.00 0.0625 0.9375 16.00
0.25 0.2969 0.7031 3.37
0.75 0.7656 0.2344 1.31

The most correlated ensemble has the smallest visible disagreement but the largest ensemble-mean error. Consequently, selecting the best of 64 candidates still finds a large positive error.

For \(\rho>0\):

\[\lim_{M\rightarrow\infty}M_{\mathrm{eff}} = \frac1\rho\]

Thus:

  • \(\rho=0.25\) can never exceed an effective size of 4;

  • \(\rho=0.75\) can never exceed approximately 1.33.

Check answers

  1. Every pair contributes a covariance term that averaging does not cancel, leaving the floor \(\rho\sigma^2\).

  2. It approaches \(1/\rho\), rather than growing without limit.

  3. Disagreement removes the shared component before measuring spread; that shared component remains in the ensemble mean.

  4. Vary training data, annotators, model families, objectives and information sources—not only seeds.

  5. On deployment-like and optimization-selected outputs, especially the high-reward tail where the policy will concentrate.

Retrieval answers

  1. It subtracts a multiple of member disagreement from mean predicted reward, making uncertain candidates less attractive.

  2. If all members inherit the same bias, they agree with one another while remaining wrong.

Takeaway: count independent error sources, not checkpoints. A large, highly correlated reward ensemble can be confidently wrong—and strong optimization will still locate those shared errors.
