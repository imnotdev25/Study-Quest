🧩 Analogy: compound interest, and Atomic Habits

Atomic Habits points out that getting 1% better every day compounds to \(1.01^{365}\approx38\times\) in a year. The same math bites PPO: if every token’s probability ratio is only \(1.01\), a 500-token response’s sequence probability has changed by \(1.01^{500}\approx145\times\). Each token passes the clip check, but the sequence has drifted a lot.

All of these per-token ratios sit well inside a \(\pm0.2\) clip.

2. PPO compares the current policy with the rollout policy

LLM rollouts are generated by an old policy \(\pi_{\text{old}}\). During optimization, PPO compares the current policy with that exact rollout policy:

\[\rho_{i,t} = \frac{ \pi_\theta(a_{i,t}\mid s_{i,t}) }{ \pi_{\text{old}}(a_{i,t}\mid s_{i,t}) }\]

Compute the ratio in log space:

\[\rho_{i,t} = \exp\left[ \log\pi_\theta(a_{i,t}\mid s_{i,t}) - \log\pi_{\text{old}}(a_{i,t}\mid s_{i,t}) \right]\]

The token-level clipped objective is:

\[L^{\text{clip}} = -\operatorname{mean}_{i,t} M_{i,t} \min \left[ \rho_{i,t}\hat A_{i,t}, \operatorname{clip} (\rho_{i,t},1-\epsilon,1+\epsilon) \hat A_{i,t} \right]\]

Clipping prevents selected token probabilities from moving too far during one rollout update.

But the complete response ratio is:

\[\rho_i^{\text{sequence}} = \prod_t \rho_{i,t} = \exp\left( \sum_t\log\rho_{i,t} \right)\]

Even modest token changes compound. If every token ratio is 1.05 over 100 tokens:

\[1.05^{100}\approx131.5\]

Therefore, token clipping does not guarantee a tightly bounded sequence-probability change.

Practical diagnostics include:

  • token clip fraction;

  • ratio percentiles;

  • approximate KL;

  • sequence log-ratio distribution;

  • response length;

  • updates or epochs per rollout batch.

Tensor shapes:

  • old and current selected log-probabilities: [B, T]

  • token ratios, advantages and masks: [B, T]

  • sequence log-ratios and ratios: [B]

  • PPO loss: scalar

DPO compares policy-versus-reference log-ratios on preference pairs. It does not use an old rollout policy or PPO’s clipped importance ratio.

🔍 Deeper: token ratios vs sequence ratios

\(\rho(y)=\prod_t\rho_t=\exp\Big(\sum_t\log\rho_t\Big)\). The per-token clip only bounds each factor; it doesn’t bound the sum of logs.

  • Monitor the sequence log-ratio \(\sum_tm_t\log\rho_t\), its spread, and the clip fraction.

  • GSPO uses a length-normalized sequence ratio \(\big(\prod_t\rho_t\big)^{1/|y|}=\exp\big(\frac1{|y|}\sum_t\log\rho_t\big)\) and clips that, which keeps sequence drift comparable across lengths.

  • Too many epochs on stale rollouts push more and more tokens into the clip region. When most tokens are clipped, the batch has nothing left to teach.

🔑 Key ideas

  • Small per-token changes compound into large sequence changes.

  • Watch sequence log-ratios, not just token ratios.

🚶 Walkthrough: sequence log-ratio

100 tokens, each \(\rho=1.02\). \(\sum\log\rho=100\ln1.02=1.98\), so the sequence ratio is \(e^{1.98}=7.24\). Every token passes a \(\pm0.2\) clip, yet the sequence became \(7\times\) more likely. GSPO’s normalized ratio \(e^{1.98/100}=1.02\) is clipped like a token.

Common mistakes

  • Monitoring only the mean token ratio.

  • Running more PPO epochs to “use the data better.”

  • Comparing sequence ratios across very different lengths.

Debugging experiments

Reverse the ratio:

log_ratios = (
    old_log_probs - current_log_probs
)

The update now interprets probability increases as decreases and vice versa.

Next, forget to detach stored rollout log-probabilities. If the old policy remains in the graph, optimization can move both sides of the ratio rather than comparing against a fixed behavior policy.

Finally, perform many optimization epochs on the same rollout batch. Ratios continue moving away from one, clip fraction rises and most samples may stop supplying useful actor gradients. A falling training loss does not guarantee healthy policy updates.

Solutions

Token ratios:

log_ratios = (
    current_log_probs
    - old_log_probs
)

ratios = log_ratios.exp()

Clipped ratios:

clipped_ratios = ratios.clamp(
    1.0 - clip_epsilon,
    1.0 + clip_epsilon,
)

Surrogate terms:

unclipped_terms = (
    ratios * advantages
)

clipped_terms = (
    clipped_ratios * advantages
)

ppo_terms = torch.minimum(
    unclipped_terms,
    clipped_terms,
)

Masked loss:

ppo_loss = -(
    ppo_terms * mask
).sum() / mask.sum()

Sequence ratios:

sequence_log_ratios = (
    log_ratios * mask
).sum(dim=-1)

sequence_ratios = (
    sequence_log_ratios.exp()
)

Clip fraction:

clip_fraction = (
    (
        (ratios[valid] < 1.0 - clip_epsilon)
        | (ratios[valid] > 1.0 + clip_epsilon)
    )
    .to(ratios.dtype)
    .mean()
)

The sequence ratios are:

\[1.3^6\approx4.83\]

\[0.7^6\approx0.118\]

\[1.1^3\approx1.331\]

Thus, clipping around [0.8, 1.2] at each token does not place the complete response ratio inside that interval.

Responses 0 and 1 lie in their clipped regions. In this simplified construction, their selected log-probabilities receive zero gradient because the clipped branch is constant. Response 2 remains inside the trust region and supplies gradient.

All padded positions must have zero gradient.

Check answers

  1. PPO only has importance-ratio evidence for actions actually sampled by the rollout policy; computing ratios for unsampled vocabulary items would define a different objective.

  2. Sequence probability is a product of conditional token probabilities, so small multiplicative changes compound with length.

  3. The policy may have moved too far, the learning rate or epoch count may be excessive, and much of the batch may no longer provide an unclipped learning signal.

  4. Otherwise, numerator and denominator describe different events, making the ratios meaningless even if the tensor shapes match.

Retrieval answers

  1. No future environment return exists after genuine termination, so bootstrapping would introduce an artificial critic value.

  2. A token limit is an external collection boundary; unless the task defines it as failure, the underlying generation could have continued.

Takeaway: PPO clipping is local to sampled token probabilities. Monitor sequence log-ratios and clip fraction alongside token ratios, keep the old policy fixed, and avoid repeatedly optimizing stale rollouts until nearly every token is clipped.
