🧩 Analogy: grade the essay, not the question

When a teacher grades your essay, they don’t grade the exam question you copied at the top. You didn’t write it. PPO for LLMs applies the same rule: the prompt and any padding are masked out, and only the tokens the policy generated get ratios, advantages and gradients.

Only \(m=1\) tokens enter the PPO loss.

2. PPO on generated tokens

An LLM rollout policy \(\pi_{\text{old}}\) generates responses. For every generated token, store its old log-probability:

\[\log\pi_{\text{old}}(y_{b,t}\mid s_{b,t})\]

During several optimization epochs, the current policy reevaluates those same tokens. Their probability ratio is:

\[r_{b,t} = \exp\left( \log\pi_\theta(y_{b,t}\mid s_{b,t}) - \log\pi_{\text{old}}(y_{b,t}\mid s_{b,t}) \right)\]

  • \(r=1\): unchanged probability.

  • \(r>1\): sampled token became more likely.

  • \(r<1\): sampled token became less likely.

PPO uses the token-level clipped objective:

\[J_{\text{clip}} = \frac{ \sum_{b,t}M_{b,t} \min\left( r_{b,t}\hat A_{b,t}, \operatorname{clip}(r_{b,t},1-\epsilon,1+\epsilon) \hat A_{b,t} \right) }{ \sum_{b,t}M_{b,t} }\]

The optimizer minimizes:

\[L_{\text{policy}}=-J_{\text{clip}}\]

The minimum removes the incentive for an excessively large beneficial change:

  • positive advantage: increasing \(r\) beyond \(1+\epsilon\) stops helping;

  • negative advantage: decreasing \(r\) below \(1-\epsilon\) stops helping;

  • harmful changes remain visible even outside the interval.

Use token ratios rather than multiplying ratios across an entire response. A long product can become extremely large or small and gives poor control over individual token changes.

For batch size \(B\) and generated length \(T\):

  • old and current selected log-probabilities: [B, T]

  • advantages: [B, T]

  • response mask: [B, T]

  • ratios and surrogate terms: [B, T]

  • masked objective: scalar

Two different policy anchors

  • \(\pi_{\text{old}}\): frozen snapshot that generated the current rollout; used for PPO ratios.

  • \(\pi_{\text{ref}}\): frozen SFT model; used for behavioural KL regularization.

The old policy changes after collecting each new rollout batch. The reference usually remains fixed.

Full LLM PPO combines this policy loss with a critic loss, GAE advantages, reference-KL control, entropy diagnostics and fresh rollout collection.

DPO does not run this rollout-and-update loop. It optimizes fixed chosen/rejected pairs directly.

🔍 Deeper: the masked token-level loss

Per-token ratio: \(\rho_t=\exp\big(\log\pi_\theta(y_t|\cdot)-\log\pi_{\text{old}}(y_t|\cdot)\big)\). Always compute it from log-probs, in this direction. \[\mathcal L^{\text{CLIP}}=-\frac{\sum_tm_t\min\big(\rho_t\hat A_t,\ \operatorname{clip}(\rho_t,1\pm\epsilon)\hat A_t\big)}{\sum_tm_t}.\] Checklist: \(\pi_{\text{old}}\) log-probs are recorded once at rollout time and never updated. \(\hat A_t\) is detached (it’s a label). GAE runs only over response tokens. The KL shaping \(-\beta(\log\pi_\theta-\log\pi_{\text{ref}})\) goes into each \(r_t\), and the reward-model score goes on the last real token.

🔑 Key ideas

  • Same clipped surrogate as before, now applied per generated token.

  • Most LLM-PPO bugs are snapshot, direction, detach or mask errors.

🚶 Walkthrough: three tokens, one clipped

\(A=+1\), \(\epsilon=0.2\). Log-ratios \((0.1,-0.3,0.25)\), so \(\rho=(1.105,0.741,1.284)\). Clipped terms: \((1.105,\ 0.741,\ 1.2)\). Token 3 is clipped and gives no gradient. Clip fraction \(=1/3\). Objective \(=1.015\).

Common mistakes

  • Recomputing old log-probs with dropout on (or after updates).

  • The ratio direction flipped to \(\pi_{\text{old}}/\pi_\theta\).

  • Clip fraction near 0.5 or more, which means too many epochs or a learning rate that’s too high.

Hints

  • Compute ratios as exp(new - old).

  • Clamp ratios, not log-ratios.

  • Use torch.minimum elementwise.

  • Multiply by the mask before summing.

  • Divide by response_mask.sum().

  • Optimizers minimize, so negate the objective.

  • A common sampled KL approximation is \(r-1-\log r\).

Debugging experiment

Reverse the ratio:

log_ratios = old_log_probs - new_log_probs

The update is now interpreted backward: increasing a sampled token’s probability looks like a decrease.

Then remove the response mask. The artificial padding advantages dominate the objective and produce padding gradients, even though those positions were never generated actions.

  2. Why can a harmful change remain active beyond the clipping interval?

Solutions

Ratios:

log_ratios = (
    new_log_probs
    - old_log_probs.detach()
)

ratios = log_ratios.exp()

Surrogate terms:

unclipped_terms = (
    ratios * advantages.detach()
)

clipped_ratios = ratios.clamp(
    1.0 - clip_epsilon,
    1.0 + clip_epsilon,
)

clipped_terms = (
    clipped_ratios * advantages.detach()
)

Masked objective and loss:

surrogate_terms = torch.minimum(
    unclipped_terms,
    clipped_terms,
)

objective = (
    surrogate_terms * response_mask
).sum() / response_mask.sum()

policy_loss = -objective

Diagnostics:

outside_clip = (
    (ratios - 1.0).abs()
    > clip_epsilon
).float()

clip_fraction = (
    outside_clip * response_mask
).sum() / response_mask.sum()

approximate_kl = (
    (
        ratios - 1.0 - log_ratios
    ) * response_mask
).sum() / response_mask.sum()

The valid ratios are approximately:

row 1: [1.000, 1.492, 0.670, 0.741]
row 2: [0.741, 1.350, 1.000]

Zero-gradient, beneficially clipped positions include:

  • positive advantage with ratio 1.492;

  • negative advantage with ratio 0.670;

  • negative advantage with ratio 0.741;

  • positive advantage with ratio 1.350.

The first row’s final valid token has positive advantage and ratio 0.741. That is a harmful probability decrease, so its unclipped term remains active. PPO must retain pressure to reverse it.

Five of seven valid ratios are outside the interval, giving:

\[\text{clip fraction}=\frac57\approx0.714\]

This diagnostic counts all outside ratios—even harmful changes whose gradients remain active. It does not mean exactly 71.4% of gradients were removed.

The padding gradient should be exactly zero despite the padding advantages of 99.

Check answers

  1. Token-level ratios control changes at each generated decision and avoid unstable sequence-level probability products.

  2. Clipping removes incentives for excessive improvement; it does not hide changes that worsen the surrogate.

  3. Most rollout tokens have moved substantially from their generating policy. Reduce epochs, learning rate, or update size and inspect KL.

  4. No. Clipping modifies the sampled objective; it is not a hard distribution constraint. Old-policy KL and reference-policy KL must be monitored separately.

Retrieval answers

  1. The old policy generated the current rollout and defines PPO ratios; the reference policy is the longer-lived SFT anchor used for KL control.

  2. They are fixed credit signals. Allowing gradients into them can make the target move instead of updating only the policy.

Takeaway: LLM PPO applies the familiar clipped surrogate to generated tokens. Correct old-policy snapshots, log-ratio direction, detached advantages and response masks are what make the equation correspond to the intended training loop.
