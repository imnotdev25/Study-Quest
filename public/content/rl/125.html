2. Two losses can fight over one backbone

An LLM actor–critic may share a transformer representation:

\[h_\theta(x)\in\mathbb R^{B\times T\times H}\]

with separate heads:

\[\text{logits}=W_\pi h_\theta \quad [B,T,V]\]

\[V=W_vh_\theta \quad [B,T]\]

The masked losses might be:

\[L_\pi = -\mathbb E_{\text{valid}} \left[ \log\pi_\theta(a_t|s_t)\hat A_t \right]\]

\[L_V = \frac12\mathbb E_{\text{valid}} \left[ (V_\theta(s_t)-\hat R_t)^2 \right]\]

and:

\[L_{\text{total}} = L_\pi+c_vL_V\]

For shared backbone parameters:

\[\nabla_\theta L_{\text{total}} = g_\pi+c_vg_V\]

The coefficient \(c_v\) is not “the critic’s percentage of training.” Its influence depends on:

\[c_v\lVert g_V\rVert\]

and its alignment with the policy gradient:

\[\cos(g_\pi,g_V) = \frac{g_\pi^\top g_V} {\lVert g_\pi\rVert\lVert g_V\rVert}\]

  • positive cosine: losses broadly cooperate;

  • near zero: mostly independent directions;

  • negative cosine: gradient conflict.

Consider one shared scalar \(\theta\). A positive-advantage action gives:

\[L_\pi=-\log\sigma(\theta)\]

At \(\theta=0\):

\[\frac{\partial L_\pi}{\partial\theta}=-0.5\]

SGD subtracts this negative slope, increasing \(\theta\) and the action probability.

If the critic target is \(-2\):

\[L_V=\frac12(\theta+2)^2, \qquad \frac{\partial L_V}{\partial\theta}=2\]

The critic pushes \(\theta\) in the opposite direction. They cancel when:

\[-0.5+c_v(2)=0 \quad\Rightarrow\quad c_v=0.25\]

Reward scale matters too. Multiplying returns by ten makes the initial MSE gradient roughly ten times larger and the value loss roughly one hundred times larger. Advantage normalization does not normalize critic targets.

Separate critic parameters avoid direct interference but require more memory. Detaching shared features before the value head protects the actor backbone, but then only the value head—not the shared representation—learns from value loss.

DPO has no value critic. However, any auxiliary loss sharing its policy backbone can create the same gradient-interference problem.

Solutions

Individual gradients:

actor_gradient = torch.autograd.grad(
    policy_loss(theta_probe),
    theta_probe,
)[0].detach()

critic_gradient = torch.autograd.grad(
    value_loss(
        theta_probe,
        value_target,
    ),
    theta_probe,
)[0].detach()

gradient_cosine = (
    actor_gradient * critic_gradient
) / (
    actor_gradient.abs()
    * critic_gradient.abs()
).clamp_min(1e-12)

critical_value_coefficient = (
    -actor_gradient / critic_gradient
)

One-step updates:

combined_gradients = (
    actor_gradient
    + value_coefficients
    * critic_gradient
)

one_step_thetas = (
    -learning_rate
    * combined_gradients
)

one_step_action_probabilities = (
    torch.sigmoid(one_step_thetas)
)

Shared training:

for _ in range(num_steps):
    actor_losses = policy_loss(
        shared_thetas
    )

    critic_losses = value_loss(
        shared_thetas,
        value_target,

    total_loss = (
        actor_losses
        + value_coefficients
        * critic_losses

    total_loss.backward()

            learning_rate
            * shared_thetas.grad

At initialization:

\[g_\pi=-0.5,\qquad g_V=2\]

Their cosine is -1: complete opposition.

The combined gradients are:

\(c_v\) Combined gradient SGD effect
\(c_v\) Combined gradient SGD effect
0.00 \(-0.50\) increases action probability
0.10 \(-0.30\) increases it more slowly
0.25 \(0.00\) no initial update
1.00 \(1.50\) decreases rewarded-action probability

With \(c_v=0.25\), \(\theta=0\) is exactly stationary in this toy example. With \(c_v=1\), critic pressure eventually pushes the action probability toward roughly 0.23.

Separate parameters remove this direct conflict: the actor probability rises while the critic independently approaches -2.

Scaling the value target from -2 to -20 changes:

\[g_V: 2\rightarrow20\]

\[L_V: 2\rightarrow200\]

and the cancellation coefficient changes:

\[0.25\rightarrow0.025\]

The same configured value coefficient can therefore become ten times stronger relative to the policy gradient.

Check answers

  1. Both heads depend on the shared representation, so value-loss backpropagation modifies features subsequently used to compute policy logits.

  2. Actual influence depends on gradient magnitude and direction, not just the scalar multiplying the loss.

  3. The losses request opposing changes in the shared parameters; sufficiently strong critic gradients can cancel or reverse actor learning.

  4. It protects the actor backbone but prevents the critic from improving that shared representation; only parameters downstream of the detach point learn from value loss.

  5. Log isolated actor and critic gradient norms, their cosine, coefficient-weighted norm ratio, combined norm, policy KL, value loss, explained variance and clip fractions.

Retrieval answers

  1. done may combine true termination with an external truncation. Only true termination necessarily removes bootstrap value.

  2. A truncated final TD residual can include the final-state bootstrap, while stopping GAE recursion prevents residuals from an unrelated chunk from leaking backward.

Takeaway: tune the value coefficient in gradient space, not loss-name space. With a shared backbone, a large or badly scaled critic gradient can quietly cancel the very policy improvement PPO is trying to make.
