2. Replace history weights with occupancy weights

Per-decision importance sampling uses the complete action history through time \(t\):

\[\rho_{0:t} = \underbrace{ \prod_{k=0}^{t} \frac{\pi(A_k\mid S_k)} {\mu(A_k\mid S_k)} }_{\text{probability correction for one complete history}}\]

Many different histories may reach the same current state and action. Marginalized importance sampling averages those history weights together.

Define the time-specific occupancy:

\[d_t^\pi(s,a) = \underbrace{ P_\pi(S_t=s,A_t=a) }_{\text{probability target policy occupies }(s,a)\text{ at time }t}\]

The marginalized ratio is:

\[w_t(s,a) = \underbrace{ \frac{d_t^\pi(s,a)} {d_t^\mu(s,a)} }_{\text{target-to-behavior occupancy correction}}\]

It is a conditional average of cumulative ratios:

\[w_t(s,a) = \underbrace{ E_\mu[ \rho_{0:t} \mid S_t=s,A_t=a ] }_{\text{history ratios averaged after histories merge}}\]

Therefore:

\[\hat V_{\mathrm{MIS}} = \frac1N \sum_{i=1}^{N} \sum_{t=0}^{T-1} \underbrace{\gamma^t}_{\text{discount}} \underbrace{w_t(S_t^{(i)},A_t^{(i)})}_{\text{current occupancy ratio}} \underbrace{R_t^{(i)}}_{\text{observed reward}}\]

This is a Rao–Blackwellization of PDIS: conditioning and averaging remove irrelevant history variation without changing the expectation.

It still requires occupancy support:

\[d_t^\pi(s,a)>0 \Longrightarrow \underbrace{ d_t^\mu(s,a)>0 }_{\text{logged policy reaches the required pair}}\]

In realistic problems, occupancy ratios must be estimated, which can introduce bias. For an autoregressive LLM whose state is the complete prefix, histories rarely merge; MIS may offer little benefit. A compressed agent state can help only if it preserves the information needed for rewards and transitions.

DPO’s reference-policy ratio is not an occupancy-ratio estimator and does not make logged deployment evaluation unbiased.

Tensor shapes:

  • states, actions and rewards: [R, N, T]

  • state occupancies: [T+1, S]

  • state–action occupancies and ratio tables: [T, S, A]

  • repeated estimates: [R]

Hints

Occupancy propagation is:

\[d_t^\pi(s,a) = \underbrace{ d_t^\pi(s)\pi(a\mid s) }_{\text{state occupancy times action probability}}\]

\[d_{t+1}^\pi(s') = \underbrace{ \sum_{s,a} d_t^\pi(s,a)P(s'\mid s,a) }_{\text{move occupancy through the environment}}\]

  • Use state ^ action for the XOR transition.

  • Index policy probabilities with policy[states, actions].

  • Marginal ratios require a time index as well as state and action.

  • Use clamp_min(1e-12) only for numerical protection; inspect every zero denominator.

  • ESS should sum weights across episodes, independently for each repetition and timestep.

Solutions

Exact occupancy:

def exact_occupancy(policy):
    state_occupancy = torch.zeros(
        horizon + 1,
        num_states,
    )

    state_action_occupancy = torch.zeros(
        horizon,
        num_states,
        num_actions,
    )

    state_occupancy[0, 0] = 1.0

    for time in range(horizon):
        state_action_occupancy[time] = (
            state_occupancy[time, :, None]
            * policy
        )

        for state in range(num_states):
            for action in range(num_actions):
                next_state = state ^ action

                state_occupancy[
                    time + 1,
                    next_state,
                ] += state_action_occupancy[
                    time,
                    state,
                    action,
                ]

    return (
        state_occupancy,
        state_action_occupancy,
    )


behavior_state_occ, behavior_sa_occ = (
    exact_occupancy(behavior_policy)
)

target_state_occ, target_sa_occ = (
    exact_occupancy(target_policy)
)

exact_target_value = (
    discounts[:, None, None]
    * target_sa_occ
    * reward_table[None, :, :]
).sum()

Logged trajectories:

states = torch.zeros(
    num_repetitions,
    episodes_per_repetition,
    horizon,
    dtype=torch.long,
)

actions = torch.zeros_like(states)

rewards = torch.zeros(
    num_repetitions,
    episodes_per_repetition,
    horizon,
)

current_states = torch.zeros(
    num_repetitions,
    episodes_per_repetition,
    dtype=torch.long,
)

for time in range(horizon):
    states[..., time] = current_states

    action_one_probabilities = (
        behavior_policy[
            current_states,
            1,
        ]
    )

    sampled_actions = (
        torch.rand(
            num_repetitions,
            episodes_per_repetition,
        )
        < action_one_probabilities
    ).to(torch.long)

    actions[..., time] = sampled_actions

    rewards[..., time] = reward_table[
        current_states,
        sampled_actions,
    ]

    current_states = (
        current_states ^ sampled_actions
    )

Importance weights:

step_ratios = (
    target_policy[states, actions]
    / behavior_policy[states, actions]
)

cumulative_ratios = step_ratios.cumprod(
    dim=-1
)

marginal_ratio_table = torch.where(
    behavior_sa_occ > 0,
    target_sa_occ
    / behavior_sa_occ.clamp_min(1e-12),
    torch.zeros_like(behavior_sa_occ),
)

time_indices = torch.arange(
    horizon
).view(1, 1, horizon)

marginal_weights = marginal_ratio_table[
    time_indices,
    states,
    actions,
]

Estimators:

unweighted_estimates = (
    discounts * rewards
).sum(dim=-1).mean(dim=1)

pdis_estimates = (
    discounts
    * cumulative_ratios
    * rewards
).sum(dim=-1).mean(dim=1)

mis_estimates = (
    discounts
    * marginal_weights
    * rewards
).sum(dim=-1).mean(dim=1)

Diagnostics:

means = all_estimates.mean(dim=0)

biases = means - exact_target_value

standard_deviations = all_estimates.std(
    dim=0,
    correction=1,
)

rmses = (
    (
        all_estimates
        - exact_target_value
    )
    .square()
    .mean(dim=0)
    .sqrt()
)


def ess_fraction(weights):
    effective_sample_sizes = (
        weights.sum(dim=1).square()
        / weights.square()
        .sum(dim=1)
        .clamp_min(1e-12)
    )

    return (
        effective_sample_sizes.mean(dim=0)
        / episodes_per_repetition
    )


pdis_ess_fractions = ess_fraction(
    cumulative_ratios
)

mis_ess_fractions = ess_fraction(
    marginal_weights
)

At timestep seven:

\[\operatorname{ESS}_{\mathrm{PDIS}} \approx \underbrace{0.025N}_{\text{about 8 of 300 episodes}}\]

while:

\[\operatorname{ESS}_{\mathrm{MIS}} \approx \underbrace{0.43N}_{\text{about 129 of 300 episodes}}\]

PDIS remembers which exact sequence reached the current pair. MIS forgets irrelevant historical differences once those histories merge.

Check answers

  1. MIS replaces a noisy history ratio with its conditional expectation given the current state and action.

  2. An occupancy ratio is undefined when the target reaches a pair that behavior never reaches.

  3. The complete prefix is effectively the complete history, so conditioning on it may average over no alternative histories.

  4. It must preserve reward-relevant and transition-relevant information so that the resulting process is approximately Markov.

  5. Use FQE as a model baseline and marginalized ratios to correct its TD residuals—often called marginalized doubly robust evaluation.

Retrieval answers

  1. FQE averages continuation values under the fixed target policy; Q-learning maximizes over actions and evaluates a changing greedy policy.

  2. Logged Bellman loss constrains only observed state–action pairs. Unsupported target actions can receive arbitrary values without affecting that loss.

Takeaway: cumulative ratios ask, “How unlikely was this exact history?” Marginal ratios ask, “How unlikely is the state–action pair where it ended up?” When histories genuinely merge, the second question can retain far more effective data.
