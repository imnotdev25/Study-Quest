2. Pairwise labels reveal a winner, not the winning distance

A reward model assigns scalar scores to two completions:

\[r_w=r_\phi(x,y_w), \qquad r_l=r_\phi(x,y_l)\]

The Bradley–Terry preference model uses their margin:

\[P(y_w\succ y_l) = \sigma(r_w-r_l) = \sigma(\Delta r)\]

Its numerically stable loss is:

\[L_{\mathrm{RM}} = -\log\sigma(\Delta r) = \operatorname{softplus}(-\Delta r)\]

Adding the same constant to both rewards changes nothing:

\[(r_w+c)-(r_l+c)=\Delta r\]

Thus the absolute reward offset is unidentified.

For perfectly separable preference data:

\[\frac{\partial L}{\partial\Delta r} = -\sigma(-\Delta r)<0\]

at every finite margin. Loss keeps decreasing as:

\[\Delta r\rightarrow\infty\]

Pairwise accuracy may reach 100% almost immediately, while reward magnitudes continue growing. If these raw scores become PPO rewards, later reward-model checkpoints implicitly weaken the same KL coefficient:

\[\pi^*(y) \propto \pi_{\mathrm{ref}}(y) \exp(r(y)/\beta)\]

A preference label is like knowing which runner crossed first; it does not tell you whether the lead was one centimetre or one kilometre.

Tensor shapes:

  • paired token inputs: [B, 2, T]

  • winner/loser rewards: [B, 2]

  • reward margins and labels: [B]

  • pairwise loss: scalar

Useful controls include reward-head regularization, early stopping, fixed normalization statistics and temperature calibration:

\[P(y_w\succ y_l) = \sigma\left(\frac{\Delta r}{T}\right)\]

Fit \(T\) on untouched human preferences. Pairwise accuracy alone cannot choose it.

DPO uses a similar logistic preference loss, but its margin is constructed from policy/reference log-probability ratios. It does not train a separate scalar reward model or perform online RL.

offset - 0.5 * weight * difference

  • Use F.softplus(-margins) instead of manually computing -log(sigmoid(...)).

  • Accuracy is the fraction of margins strictly above zero.

  • Add regularization as:

\[\frac{\lambda}{2}w^2\]

  • For a uniform reference and reward difference \(w\):

\[P_{\mathrm{PPO}}(\text{preferred}) = \sigma(w/\beta)\]

  • Brier score is mean squared probability error.

  • Dividing every margin by a positive temperature preserves ranking.

Solutions

Offset invariance:

winner_scores = (
    common_offset
    + 0.5
    * probe_weight
    * feature_differences
)

loser_scores = (
    common_offset
    - 0.5
    * probe_weight
    * feature_differences
)

probe_loss = F.softplus(
    -(
        winner_scores
        - loser_scores
    )
).mean()

The weight receives a gradient, while the common-offset gradient is exactly zero.

Reward-model training:

def train_reward_model(l2_strength):
    weight = torch.tensor(
        0.0,
        requires_grad=True,
    )

    optimizer = torch.optim.SGD(
        [weight],
        lr=learning_rate,
    )

    records = []
    maximum_step = max(checkpoint_steps)

    for step in range(maximum_step + 1):
        margins = (
            weight
            * feature_differences
        )

        data_loss = F.softplus(
            -margins
        ).mean()

        total_loss = (
            data_loss
            + 0.5
            * l2_strength
            * weight.square()
        )

        if step in checkpoint_steps:
            with torch.no_grad():
                accuracy = (
                    margins > 0.0
                ).to(torch.float64).mean()

                mean_confidence = torch.sigmoid(
                    margins
                ).mean()

                induced_ppo_probability = torch.sigmoid(
                    weight / ppo_beta
                )

                records.append(
                    torch.stack([
                        torch.tensor(float(step)),
                        weight.detach(),
                        data_loss.detach(),
                        total_loss.detach(),
                        accuracy,
                        mean_confidence,
                        induced_ppo_probability,
                    ])
                )

        if step == maximum_step:
            break

        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

    return (
        torch.stack(records),
        weight.detach(),
    )

Temperature calibration:

oracle_temperature = (
    unregularized_weight.clamp_min(
        1e-12
    )
)

temperature_calibrated_probabilities = torch.sigmoid(
    unregularized_weight
    * feature_differences
    / oracle_temperature
)

temperature_calibrated_brier = (
    temperature_calibrated_probabilities
    - true_preference_probabilities
).square().mean()

At step zero, all margins are tied. After the first positive update, every pair is correctly ordered, so accuracy becomes 100%.

For the unregularized model, the loss continues falling after accuracy saturates:

\[w\rightarrow\infty, \qquad \sigma(wd_i)\rightarrow1\]

Consequently, the induced KL-regularized policy also becomes increasingly extreme:

\[P_{\mathrm{PPO}}(\text{preferred}) = \sigma(w/\beta) \rightarrow1\]

The regularized model reaches a finite compromise:

\[\frac{\partial L_{\mathrm{data}}}{\partial w} +\lambda w=0\]

In this constructed example, held-out human probabilities use latent scale 1. The oracle temperature divides the oversized margin back to that scale:

\[\frac{wd}{T} = \frac{wd}{w} = d\]

It restores probability calibration while preserving every ranking.

Check answers

  1. Pairwise likelihood depends only on \(r_w-r_l\); a shared offset cancels exactly.

  2. Every finite positive margin can be increased to reduce logistic loss further when no examples oppose the ordering.

  3. No. Lower loss may only mean larger confidence margins, which can make PPO rewards badly scaled.

  4. Report held-out log loss, Brier score or calibration error, margin mean/std/quantiles, reward length correlation, subgroup calibration and score drift across checkpoints.

  5. DPO removes the separately deployed scalar reward model, but separable preferences can still push policy log-ratio margins outward. Its reference policy and \(\beta\) control that pressure; it still does not provide calibrated online utility.

Retrieval answers

  1. Multiply the KL coefficient by the same factor: \(\beta'=c\beta\), preserving \(r/\beta\).

  2. Clipping is nonlinear and changes expected utilities; it can even reverse which action has the higher expected reward.

Takeaway: perfect preference accuracy does not define a trustworthy reward scale. Before feeding reward-model scores into PPO, validate and freeze their margin distribution—or the same \(\beta\) will silently represent a different objective.
