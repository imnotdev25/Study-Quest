🧩 Analogy: two identical hotel corridors

Two hotel floors have identical corridors. Standing in one, you can’t tell which floor you’re on, unless you remember which elevator button you pressed. Tool agents face this constantly: the current tool output looks the same in different situations, and only history tells them apart.

2. The agent may observe only part of the state

An MDP assumes \(s_t\) contains everything needed to predict the future. Tool agents often receive only an observation \(o_t\):

  • a tool may hide internal state;

  • an API response may omit information;

  • earlier messages may leave the context window;

  • a summary may discard an important constraint.

Two different hidden states can therefore produce the same observation while requiring different actions. This is observation aliasing.

A partially observable process can be written as:

\[o_t\sim O(o_t\mid s_t)\]

A memoryless policy uses:

\[a_t\sim\pi_\theta(a_t\mid o_t)\]

A history-aware policy instead uses:

\[h_t=(o_0,a_0,\ldots,o_t)\]

or a compressed recurrent state:

\[z_t=f_\theta(z_{t-1},o_t,a_{t-1})\]

\[a_t\sim\pi_\theta(a_t\mid z_t)\]

Think of \(z_t\) as a notebook. If two identical-looking situations require different actions, the notebook must contain the missing clue.

For actor training:

\[L_\pi= -\frac{\sum_{i,t}M_{i,t} \log\pi_\theta(a_{i,t}\mid z_{i,t}) \hat A_{i,t}} {\sum_{i,t}M_{i,t}}\]

Detach \(\hat A\), but keep gradients through the recurrent state within the trajectory. Reset recurrent state at episode boundaries.

Tensor shapes:

  • observations: [B, T, D];

  • recurrent outputs: [B, T, H];

  • action logits: [B, T, A];

  • actions, advantages and masks: [B, T];

  • GRU hidden state: [layers, B, H].

An LLM’s context acts as explicit memory. Context truncation, incorrect masking or lossy summarization can turn a previously observable task into a partially observable one.

DPO can prefer successful complete traces over unsuccessful ones, but it still trains from fixed comparisons. It does not collect fresh observations or repair missing environment state through exploration.

🔍 Deeper: beliefs and memory

A POMDP adds observations \(o\sim O(\cdot|s)\). The Markov “state” becomes the belief \(b_t(s)=P(s_t=s\mid o_{1:t},a_{1:t-1})\), updated by Bayes: \(b_{t+1}(s')\propto O(o_{t+1}|s')\sum_sP(s'|s,a_t)\,b_t(s)\). Policies therefore condition on history, via an RNN state or, for LLMs, the context window. Limit: a memoryless policy in the corridor above can’t beat 50%, while a policy with memory gets 100%.

🔑 Key ideas

  • Identical observations that need different actions require history.

  • Reset memory only at real boundaries, and test under context truncation.

🚶 Walkthrough: why memoryless caps at 50%

In “hall” the policy must pick L or R with the same probability \(q\) in both cases. Success \(=\tfrac12q+\tfrac12(1-q)=\tfrac12\) for every \(q\). With memory of the cue: \(1\).

Common mistakes

  • Truncating context so the cue falls off.

  • Resetting hidden state mid-episode (on a truncation boundary).

  • Not resetting it at a new episode (leaking the previous episode’s memory).

Debugging experiments

Reset memory before the final step:

final_states, _ = recurrent_encoder(
    observations[:, 1:]
)

The model now sees only the shared neutral observation and should fall toward chance.

Next, carry final_hidden into the following batch without resetting it. Information can leak between unrelated prompts, making evaluation depend on batch ordering.

For variable-length traces, reading recurrent_states[:, -1] may select padding. Select each trajectory’s final valid position using its length or mask.

Detaching the hidden state between truncated training segments is sometimes necessary for memory control. Detaching at every step blocks long-range credit assignment.

Solutions

Batch generation:

def make_batch(size):
    hidden_mode = torch.randint(
        0, 2, (size,)
    )

    cue = F.one_hot(
        hidden_mode,
        num_classes=2,
    ).to(torch.float32)

    neutral = torch.zeros_like(cue)

    observations = torch.stack(
        [cue, neutral],
        dim=1,
    )

    targets = hidden_mode

    return observations, targets

Policy forward passes:

memoryless_logits = memoryless_policy(
    observations[:, 1]
)

recurrent_states, final_hidden = (
    recurrent_encoder(observations)
)

recurrent_logits = recurrent_head(
    recurrent_states[:, -1]
)

Losses:

memoryless_loss = F.cross_entropy(
    memoryless_logits,
    targets,
)

recurrent_loss = F.cross_entropy(
    recurrent_logits,
    targets,
)

Evaluation:

with torch.no_grad():
    observations, targets = make_batch(10_000)

    memoryless_predictions = (
        memoryless_policy(
            observations[:, 1]
        ).argmax(dim=-1)
    )

    recurrent_states, _ = (
        recurrent_encoder(observations)
    )

    recurrent_predictions = (
        recurrent_head(
            recurrent_states[:, -1]
        ).argmax(dim=-1)
    )

    memoryless_accuracy = (
        memoryless_predictions == targets
    ).to(torch.float32).mean()

    recurrent_accuracy = (
        recurrent_predictions == targets
    ).to(torch.float32).mean()

The final observation is [0, 0] for every example. A memoryless model therefore produces identical logits for both hidden modes and remains near 50%.

The GRU can retain the initial cue in its hidden state and should approach 100%.

Check answers

  1. Hidden state describes the environment; the observation contains only the information exposed to the agent.

  2. Truncation can remove evidence needed to distinguish states that now look identical.

  3. Detach advantages, returns and frozen rollout quantities. Preserve gradients through within-trajectory policy memory.

  4. Compare performance with full versus truncated histories, group failures by identical observations, shuffle histories, inspect hidden-state probes and test counterfactual earlier cues.

Retrieval answers

  1. Otherwise, rewards from one prompt can propagate into another prompt and create fictitious credit.

  2. A sampled action must remain valid under the training distribution; mismatched masks can produce undefined log-probabilities and invalid PPO ratios.

Takeaway: when identical current observations require different actions, the policy needs history. Reset memory at real boundaries, preserve it within trajectories and evaluate explicitly under context truncation.
