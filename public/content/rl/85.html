🧩 Analogy: grading homework you already memorized

If a student memorized the answers to the exact worksheet, they’ll score 100% on it, which says nothing about whether they understand. A reward model evaluated on the same logs it was trained on is that student. Its residuals look like zero because it memorized, not because it’s accurate. Cross-fitting makes every prediction out of sample.

3-fold cross-fitting: each fold’s predictions come from a model that never saw it.

2. A zero residual can mean memorization, not accuracy

For a contextual decision, doubly robust evaluation uses:

\[\hat J_{\text{DR}} = \frac1N\sum_i \left[ \sum_a\pi(a\mid x_i)\hat q(x_i,a) + \rho_i \left( r_i-\hat q(x_i,a_i) \right) \right]\]

If a flexible outcome model trains on evaluation row \(i\), it may memorize:

\[\hat q(x_i,a_i)=r_i\]

The residual becomes zero, but this says nothing about the unobserved counterfactual actions. The DR correction is disabled exactly where it is needed.

Cross-fitting prevents this:

  1. Split complete episodes into \(K\) folds.

  2. Train the outcome model on \(K-1\) folds.

  3. predict \(Q\)-values only for the held-out fold.

  4. Repeat until every episode has held-out predictions.

  5. Compute one DR estimate from those predictions.

For row \(i\) in fold \(k(i)\):

\[\hat v_i = \sum_a \pi(a\mid x_i) \hat q_{-k(i)}(x_i,a)\]

\[\hat J_{\text{CF-DR}} = \frac1N\sum_i \left[ \hat v_i + \rho_i \left( r_i-\hat q_{-k(i)}(x_i,a_i) \right) \right]\]

The subscript \(-k(i)\) means the model never trained on episode \(i\).

For agent data, split by independent unit—usually user, prompt or complete episode—not by token. Otherwise adjacent rows from the same conversation can leak across folds.

Tensor shapes:

  • actions and rewards: [R, B]

  • all-action \(Q\)-predictions: [R, B, A]

  • selected \(Q\)-predictions and weights: [R, B]

  • repeated value estimates: [R]

DPO is still preference optimization, not OPE. If a DPO policy is evaluated using a reward model trained on the same responses, the reported reward can be contaminated by the same leakage. Use held-out prompts, cross-fitting and environmental metrics.

🔍 Deeper: cross-fitted DR

Split the logs into \(K\) folds, at the episode or user level, never inside a conversation. For fold \(k\), fit \(\hat q^{(-k)}\) on the other folds and use it only on fold \(k\): \(\hat V=\frac1n\sum_i\big[\hat q^{(-k(i))}(x_i,\pi)+\rho_i\big(r_i-\hat q^{(-k(i))}(x_i,a_i)\big)\big]\). This removes the overfitting bias, so DR’s theory (and its confidence intervals) actually apply. Keep a final, untouched evaluation set for the last word.

🔑 Key ideas

  • Impressive same-data residuals can be evidence of leakage.

  • Make every OPE prediction out of fold, with splits at the episode or user level.

🚶 Walkthrough: memorized vs honest

A flexible \(\hat q\) fit on all logs: mean in-sample \(|r-\hat q|=0.01\), so DR \(\approx\) DM, and the correction does nothing. Cross-fitted: mean \(|r-\hat q|=0.18\). That’s the model’s real error, which DR now corrects.

Common mistakes

  • Splitting turns of one user across folds.

  • Tuning hyperparameters on the final evaluation set.

  • Near-duplicate prompts in different folds.

Hints

  • Selected probability is \(p\) for action 1 and \(1-p\) for action 0.

  • Scatter with tensors shaped [R, B, 1].

  • Gather the logged \(Q\)-value using the same action indices.

  • Cross-fitting trains on fold_ids != heldout_fold.

  • Broadcast the training-row mask across repetitions.

  • Compute an action’s fitted mean using only matching training rows.

  • The oracle model uses true_reward_means[actions].

Debugging experiments

  • Train and evaluate the outcome model on identical rows. Training residuals can look excellent while OPE is badly biased.

  • Split tokens from one conversation across folds. The model can reconstruct held-out tokens from neighboring context.

  • Fit preprocessing, feature selection or hyperparameters on all folds. Leakage is not limited to neural-network weights.

  • Create folds by stored row order when deployment data changes over time. Random folds may hide temporal drift.

  • Use too many folds with rare actions. Some training folds may contain no samples for an action.

  • Select the best reward model using the final evaluation fold. That fold is no longer untouched.

  • Leave predictions connected to the training graph. Detach and persist fold-specific predictions before OPE.

Solutions

Probabilities, ratios and IS:

behavior_action_probabilities = torch.where(
    actions == 1,
    torch.tensor(
        behavior_one_probability
    ),
    torch.tensor(
        1.0 - behavior_one_probability
    ),
)

target_action_probabilities = torch.where(
    actions == 1,
    torch.tensor(
        target_one_probability
    ),
    torch.tensor(
        1.0 - target_one_probability
    ),
)

weights = (
    target_action_probabilities
    / behavior_action_probabilities
)

is_estimates = (
    weights * rewards
).mean(dim=1)

Leaky model:

leaky_q.scatter_(
    dim=-1,
    index=actions.unsqueeze(-1),
    src=rewards.unsqueeze(-1),
)

leaky_logged_q = (
    leaky_q.gather(
        dim=-1,
        index=actions.unsqueeze(-1),
    ).squeeze(-1)
)

leaky_direct_terms = (
    leaky_q
    * target_policy[None, None, :]
).sum(dim=-1)

leaky_residuals = (
    rewards - leaky_logged_q
)

leaky_dr_estimates = (
    leaky_direct_terms
    + weights * leaky_residuals
).mean(dim=1)

Cross-fitted model:

for heldout_fold in range(2):
    training_rows = (
        fold_ids != heldout_fold
    )

    heldout_rows = (
        fold_ids == heldout_fold
    )

    for action in range(num_actions):
        matching_training_rows = (
            training_rows[None, :]
            & (actions == action)
        )

        counts = (
            matching_training_rows
            .sum(dim=1)
        )

        reward_sums = (
            rewards
            * matching_training_rows
        ).sum(dim=1)

        assert bool(
            (counts > 0).all()
        )

        fitted_means = (
            reward_sums / counts
        )

        crossfit_q[
            :,
            heldout_rows,
            action,
        ] = fitted_means[:, None]

Cross-fitted DR:

crossfit_logged_q = (
    crossfit_q.gather(
        dim=-1,
        index=actions.unsqueeze(-1),
    ).squeeze(-1)
)

crossfit_direct_terms = (
    crossfit_q
    * target_policy[None, None, :]
).sum(dim=-1)

crossfit_dr_estimates = (
    crossfit_direct_terms
    + weights
    * (
        rewards
        - crossfit_logged_q
    )
).mean(dim=1)

Oracle and diagnostics:

oracle_logged_q = (
    true_reward_means[actions]
)

oracle_direct_value = (
    target_policy
    * true_reward_means

oracle_dr_estimates = (
    oracle_direct_value
    + weights
    * (
        rewards
        - oracle_logged_q

    target_policy
    * true_reward_means
).sum()

means = all_estimates.mean(dim=0)

biases = (
    means - exact_target_value
)

standard_deviations = (
    all_estimates.std(
        dim=0,
        correction=1,
    )
)

rmses = (
    (
        all_estimates
        - exact_target_value
    )
    .square()
    .mean(dim=0)
    .sqrt()
)

The exact target value is:

\[J(\pi) = 0.2(0.2)+0.8(0.9) = 0.76\]

The memorizer has exactly zero logged residual:

\[r_i-\hat q(x_i,a_i)=0\]

Its DR correction therefore vanishes. Because it predicts zero for the unseen action, its expected estimate is only:

\[0.8(0.2)(0.2) + 0.2(0.8)(0.9) = 0.176\]

A perfect training residual has produced a severely biased evaluation.

Typical results are:

  • IS: mean near 0.76, standard deviation around 0.10;

  • leaky DR: mean near 0.176;

  • cross-fitted DR: mean near 0.76, standard deviation around 0.035;

  • oracle DR: mean near 0.76, with slightly lower variance.

Check answers

  1. A memorizer can force \(r-\hat q=0\) without learning counterfactual rewards, disabling the correction term.

  2. Each evaluated reward becomes independent of the data used to fit its corresponding outcome prediction, conditional on the fold construction.

  3. Split complete episodes—and usually group by user, prompt family or conversation—to prevent correlated information crossing folds.

  4. No. Cross-fitting controls model leakage; it cannot infer outcomes for actions absent from the logging policy.

Retrieval answers

  1. Sequential DR weights \(r_t+\gamma\hat V(s_{t+1})-\hat Q(s_t,a_t)\).

  2. A useful model removes predictable return variation, leaving smaller residuals for potentially large importance ratios to amplify.

Takeaway: impressive same-data residuals can be evidence of leakage. Generate every OPE prediction out of fold, split at the episode or user level, and preserve a genuinely untouched final evaluation set.
