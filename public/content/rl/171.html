🧩 Analogy: grading the essay, not every comma

A strict editor who rejects your whole essay because one comma moved is overreacting, and one who ignores a rewrite because “each sentence changed only a little” is underreacting. GSPO judges the whole response: how much more likely is this entire answer now, on a per-token average? Then it clips that one number.

2. The objective (Zheng et al., 2025; used for Qwen3)

The reward and advantage belong to the whole response, but GRPO’s ratios are per token, which is a mismatch the paper argues adds noise and destabilizes training, especially for Mixture-of-Experts models. GSPO uses one ratio per response, the geometric mean of the token ratios: \[s_i(\theta)=\Big(\frac{\pi_\theta(y_i|x)}{\pi_{\text{old}}(y_i|x)}\Big)^{1/|y_i|}=\exp\Big(\frac{1}{|y_i|}\sum_t\log\frac{\pi_\theta(y_{i,t}|\cdot)}{\pi_{\text{old}}(y_{i,t}|\cdot)}\Big),\] \[\mathcal J_{\text{GSPO}}=\mathbb E\Big[\frac1G\sum_{i=1}^G\min\big(s_i\hat A_i,\ \operatorname{clip}(s_i,1-\epsilon,1+\epsilon)\hat A_i\big)\Big].\] The \(1/|y_i|\) exponent keeps \(s_i\) in the same range regardless of length. Because \(s_i\) moves much less than individual token ratios, the clip range is tiny: about \(3\times10^{-4}\) to \(4\times10^{-4}\) in the paper, versus GRPO’s \(0.2\)–\(0.27\).

🔍 Deeper: gradient and the token variant

Without clipping, \(\nabla\mathcal J=\mathbb E\big[\frac1G\sum_is_i\hat A_i\frac{1}{|y_i|}\sum_t\nabla\log\pi_\theta(y_{i,t}|\cdot)\big]\): every token of a response gets the same weight. GSPO-token allows per-token advantages (useful for multi-turn): \(s_{i,t}=\operatorname{sg}[s_i]\cdot\frac{\pi_\theta(y_{i,t})}{\operatorname{sg}[\pi_\theta(y_{i,t})]}\). Numerically \(s_{i,t}=s_i\), and with equal \(\hat A_{i,t}\) it matches GSPO exactly.

🔑 Key ideas

  • One length-normalized ratio per response, clipped as a whole.

  • The clip range is orders of magnitude smaller than PPO’s because the ratio means something different.

🚶 Walkthrough: one outlier token

100 tokens, one token’s log-ratio is \(+2\), and the rest are 0. That token’s ratio is \(e^2=7.39\): a token-level clip would clip it. The sequence ratio \(e^{2/100}=1.020\) is above \(1+4\times10^{-4}\), so with \(A>0\) the whole response is clipped and gives no gradient. The decision is made once, for the response.

Common mistakes

  • Using GRPO’s 0.2 clip with GSPO’s ratio (almost nothing is ever clipped).

  • Forgetting the \(1/|y_i|\) exponent (long responses get extreme ratios).

  • Averaging the masked log-ratio over padding.

Solutions

import torch


def gspo_loss(logp_new, logp_old, adv, mask, eps_low=3e-4, eps_high=4e-4):
    # logp_*: [G, T] token log-probs; adv: [G]; mask: [G, T]
    log_ratio = ((logp_new - logp_old) * mask).sum(1) / mask.sum(1)   # mean token log-ratio
    s = log_ratio.exp()                                               # geometric-mean sequence ratio
    unclipped = s * adv
    clipped = s.clamp(1 - eps_low, 1 + eps_high) * adv
    return -torch.min(unclipped, clipped).mean()


# 100-token response; one token's log-ratio is 2.0, the rest are 0.
T = 100
logp_old = torch.full((1, T), -1.0)
logp_new = logp_old.clone()
logp_new[0, 7] += 2.0
mask = torch.ones(1, T)
token_ratios = (logp_new - logp_old).exp()
seq_ratio = (((logp_new - logp_old) * mask).sum(1) / mask.sum(1)).exp()
print(f"largest token ratio {token_ratios.max().item():.2f}  -> clipped by a 0.2 token clip")
print(f"GSPO sequence ratio {seq_ratio.item():.4f}  -> compared with [1-3e-4, 1+4e-4]")
print(f"GSPO loss with A=+1: {gspo_loss(logp_new, logp_old, torch.tensor([1.0]), mask).item():.5f}")

Output:

largest token ratio 7.39  -> clipped by a 0.2 token clip
GSPO sequence ratio 1.0202  -> compared with [1-3e-4, 1+4e-4]
GSPO loss with A=+1: -1.00040

The loss is \(-1.0004=-(1+4\times10^{-4})\cdot1\): the ratio was clipped at its upper bound, so it carries no gradient.

Check answers

  1. \(s_i\) is a geometric mean over many tokens, so it moves far less than any single token ratio.

  2. Responses of any length share one numerical range, so one clip works for all of them.

  3. When different parts of a response deserve different advantages, e.g. multi-turn agent trajectories.

Retrieval answers: (1) \(1.01^{500}\approx145\). (2) The objective is flat, so there’s no gradient.

Takeaway: match the unit of the ratio to the unit of the reward. When rewards are per response, GSPO clips per response.
