2. Use a model for predictable value and weights for residual mistakes

For logged context \(x_i\), define the model baseline:

\[m_i = \underbrace{ \sum_a\pi(a\mid x_i)\hat q(x_i,a) }_{\text{modelled target-policy reward}}\]

and the factual residual:

\[e_i = \underbrace{ R_i-\hat q(x_i,A_i) }_{\text{model's error on the observed action}}\]

Ordinary doubly robust evaluation is:

\[\hat V_{\mathrm{DR}} = \underbrace{\frac1N\sum_im_i}_{\text{direct-model baseline}} + \underbrace{ \frac1N\sum_iw_ie_i }_{\text{importance-weighted error correction}}\]

where:

\[w_i = \underbrace{ \frac{\pi(A_i\mid x_i)} {\mu(A_i\mid x_i)} }_{\text{target-to-behavior ratio}}\]

Self-normalized DR instead normalizes only the correction:

\[\hat V_{\mathrm{SNDR}} = \underbrace{\frac1N\sum_im_i}_{\text{baseline remains unweighted}} + \underbrace{ \frac{\sum_iw_ie_i} {\sum_iw_i} }_{\text{self-normalized residual correction}}\]

Do not normalize the baseline: it already represents a target-policy expectation.

SNDR often reduces variance because it both:

  1. weights residual errors rather than full rewards;

  2. prevents random total weight from changing the correction’s scale.

The cost is finite-sample ratio bias. With correct propensities but an imperfect model:

\[E\!\left[ \frac{\sum_iw_ie_i}{\sum_iw_i} \right] \ne \underbrace{ E_\pi[e] }_{\text{required correction}}\]

It remains consistent under adequate support. In sequential weighted DR, normalize cumulative weights separately at each timestep—not across timesteps, padding or unrelated batches.

DPO supplies neither an environment \(Q\)-model nor deployment logging propensities. Normalizing DPO reference ratios does not create a doubly robust policy evaluator.

Tensor shapes:

  • actions, rewards, weights and residuals: [R, N]

  • estimates: [R]

  • stacked estimators: [R, 5]

Hints

The model baseline is:

\[m = \underbrace{ 0.5(0.2)+0.5(0.4) }_{\text{target expectation under the imperfect model}} = 0.30\]

Use:

importance_weights.sum(dim=1)

as the SNIS/SNDR denominator.

The estimators are:

\[\hat V_{\mathrm{SNIS}} = \frac{\sum_iw_iR_i}{\sum_iw_i}\]

\[\hat V_{\mathrm{DR}} = m+\frac1N\sum_iw_i e_i\]

\[\hat V_{\mathrm{SNDR}} = m+\frac{\sum_iw_i e_i}{\sum_iw_i}\]

All evaluation quantities should be detached from any trainable reward or value model.

Debugging experiments

  • Normalize the model baseline along with the residual correction.

  • Use max_a q_model[a] instead of the target-policy expectation.

  • Normalize weights across repetitions rather than within each evaluation dataset.

  • Include padded tokens in a sequential normalization denominator.

  • Learn q_model on the same outcomes without cross-fitting.

  • Report SNDR without raw mean-weight, maximum-weight and support diagnostics.

  • Treat lower SNDR variance as proof that its finite-sample bias is zero.

Solutions

Logged data:

actions = (
    torch.rand(
        num_repetitions,
        episodes_per_repetition,
    )
    < behavior_policy[1]
).to(torch.long)

reward_probabilities = (
    true_action_values[actions]
)

rewards = (
    torch.rand(
        num_repetitions,
        episodes_per_repetition,
    )
    < reward_probabilities
).to(torch.float64)

importance_weights = (
    target_policy[actions]
    / behavior_policy[actions]
)

exact_target_value = (
    target_policy
    * true_action_values
).sum()

Model quantities:

model_baseline = (
    target_policy
    * q_model
).sum()

logged_predictions = (
    q_model[actions]
)

residuals = (
    rewards
    - logged_predictions
)

Estimators:

ips_estimates = (
    importance_weights
    * rewards
).mean(dim=1)

weight_sums = (
    importance_weights.sum(dim=1)
    .clamp_min(1e-12)
)

snis_estimates = (
    (
        importance_weights
        * rewards
    ).sum(dim=1)
    / weight_sums
)

direct_method_estimates = torch.full_like(
    ips_estimates,
    model_baseline,
)

dr_estimates = (
    model_baseline
    + (
        importance_weights
        * residuals
    ).mean(dim=1)
)

sndr_estimates = (
    model_baseline
    + (
        importance_weights
        * residuals
    ).sum(dim=1)
    / weight_sums
)

Error diagnostics:

all_estimates = torch.stack([
    ips_estimates,
    snis_estimates,
    direct_method_estimates,
    dr_estimates,
    sndr_estimates,
], dim=1)

means = all_estimates.mean(dim=0)

biases = (
    means - exact_target_value
)

standard_deviations = (
    all_estimates.std(
        dim=0,
        correction=1,
    )
)

rmses = (
    (
        all_estimates
        - exact_target_value
    )
    .square()
    .mean(dim=0)
    .sqrt()
)

results = torch.stack([
    means,
    biases,
    standard_deviations,
    rmses,
], dim=1)

Support diagnostics:

rare_counts = (
    actions == 1
).sum(dim=1)

zero_rare_mask = (
    rare_counts == 0
)

zero_rare_fraction = (
    zero_rare_mask
    .to(torch.float64)
    .mean()
)

zero_rare_means = (
    all_estimates[
        zero_rare_mask
    ].mean(dim=0)
)

raw_mean_weights = (
    importance_weights.mean(dim=1)
)

The probability of observing no rare action is:

\[P(K=0) = \underbrace{0.98^{100}}_{\text{all episodes take action 0}} \approx0.133\]

In those datasets, the rare-action model error cannot be measured. SNDR remains near the model baseline plus common-action noise; normalization cannot construct the missing correction.

Replacing:

q_model = true_action_values

makes the conditional residual means zero:

\[E[R-\hat q(A)\mid A] = \underbrace{0}_{\text{correct outcome model}}\]

so both DR and SNDR should be centered near the true value, with substantially reduced variance.

  2. Yes. Correct importance ratios repair the imperfect model in expectation.

  3. Usually here, because it normalizes weights and corrects residuals rather than full rewards.

Retrieval answers

  1. Normalized nonnegative weights sum to one, making SNIS a convex combination of observed rewards.

  2. Under adequate support, SNIS bias shrinks with sample size. A fixed clipping threshold generally retains asymptotic clipping bias.

Takeaway: self-normalize the correction, not the model baseline. SNDR can be much calmer than raw IPS, but its finite-sample stability still depends on a credible value model and observed support for the policy branches that matter.
