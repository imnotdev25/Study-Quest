2. Repeated episodes share hidden causes

Suppose user \(u\) produces episode \(t\), with paired candidate-control reward difference:

\[D_{u,t} = \tau+B_u+\epsilon_{u,t}\]

where:

  • \(\tau\): population-average policy effect;

  • \(B_u\): persistent user-specific effect;

  • \(\epsilon_{u,t}\): episode noise.

Twenty episodes from one user repeatedly observe the same \(B_u\). They are not twenty independent users.

With \(U\) users and \(T\) episodes per user:

\[\operatorname{Var}(\hat\tau) = \frac{\sigma_B^2}{U} + \frac{\sigma_\epsilon^2}{UT}\]

A naive row-independent calculation incorrectly uses:

\[\operatorname{Var}_{\text{naive}}(\hat\tau) = \frac{\sigma_B^2+\sigma_\epsilon^2}{UT}\]

It pretends repeated episodes also average away user variation.

Within-cluster correlation is:

\[\rho = \frac{\sigma_B^2} {\sigma_B^2+\sigma_\epsilon^2}\]

For equal cluster size \(T\), the approximate design effect is:

\[1+(T-1)\rho\]

Tensor shapes:

  • repeated experiments and episode differences: [R, U, T]

  • per-user mean differences: [R, U]

  • estimates and standard errors: [R]

For real agent evaluation, bootstrap or compute uncertainty over independent users, tasks or source prompts. Keep all dependent turns together. With variable-length trajectories, use masks rather than treating padding as reward zero.

DPO may train on many preference pairs derived from one prompt family or annotator. Those pairs still need cluster-aware evaluation uncertainty; DPO’s pairwise loss does not make them independent.

Hints

  • user_effects should have shape [R, U, 1] so it broadcasts across episodes.

  • Average episodes first to obtain [R, U].

  • The cluster SE is the standard deviation of user means divided by \(\sqrt U\).

  • Coverage means lower <= true_effect <= upper.

  • The theoretical cluster SE is:

\[\sqrt{ \frac{\sigma_B^2}{U} + \frac{\sigma_\epsilon^2}{UT} }\]

Debugging experiments

  • Randomly shuffle or discard user IDs before computing uncertainty.

  • Bootstrap individual episodes instead of complete users.

  • Split turns from the same conversation across evaluation folds.

  • Treat padding as valid zero-reward episodes.

  • Report thousands of episodes while hiding that they came from eight users.

  • Use a normal confidence interval with only a handful of clusters.

  • Rescale rewards without rescaling the reported standard error.

Solutions

Simulation:

user_effects = (
    between_user_sd
    * torch.randn(
        num_repetitions,
        num_users,
        1,
    )
)

episode_noise = (
    within_user_sd
    * torch.randn(
        num_repetitions,
        num_users,
        episodes_per_user,
    )
)

paired_differences = (
    true_effect
    + user_effects
    + episode_noise
)

Effect estimates:

user_mean_differences = (
    paired_differences.mean(dim=2)
)

effect_estimates = (
    user_mean_differences.mean(dim=1)
)

row_mean_estimates = (
    paired_differences.mean(
        dim=(1, 2)
    )
)

maximum_identity_error = (
    effect_estimates
    - row_mean_estimates
).abs().max()

Naive standard errors:

flat_differences = (
    paired_differences.reshape(
        num_repetitions,
        -1,
    )
)

naive_row_standard_errors = (
    flat_differences.std(
        dim=1,
        correction=1,
    )
    / math.sqrt(
        num_users
        * episodes_per_user
    )
)

Cluster-aware standard errors:

cluster_standard_errors = (
    user_mean_differences.std(
        dim=1,
        correction=1,
    )
    / math.sqrt(num_users)
)

Intervals and diagnostics:

naive_lower_bounds = (
    effect_estimates
    - z_value
    * naive_row_standard_errors
)

naive_upper_bounds = (
    effect_estimates
    + z_value
    * naive_row_standard_errors
)

cluster_lower_bounds = (
    effect_estimates
    - z_value
    * cluster_standard_errors
)

cluster_upper_bounds = (
    effect_estimates
    + z_value
    * cluster_standard_errors
)

naive_coverage = (
    (
        (naive_lower_bounds <= true_effect)
        & (true_effect <= naive_upper_bounds)
    )
    .to(torch.float64)
    .mean()
)

cluster_coverage = (
    (
        (cluster_lower_bounds <= true_effect)
        & (true_effect <= cluster_upper_bounds)
    )
    .to(torch.float64)
    .mean()
)

empirical_estimator_sd = (
    effect_estimates.std(correction=1)
)

mean_naive_se = (
    naive_row_standard_errors.mean()
)

mean_cluster_se = (
    cluster_standard_errors.mean()
)

theoretical_cluster_se = math.sqrt(
    between_user_sd**2 / num_users
    + within_user_sd**2
    / (
        num_users
        * episodes_per_user
    )
)

theoretical_naive_se = math.sqrt(
    (
        between_user_sd**2
        + within_user_sd**2
    )
    / (
        num_users
        * episodes_per_user
    )
)

intraclass_correlation = (
    between_user_sd**2
    / (
        between_user_sd**2
        + within_user_sd**2
    )
)

design_effect = (
    1.0
    + (
        episodes_per_user - 1
    )
    * intraclass_correlation
)

effective_independent_rows = (
    num_users
    * episodes_per_user
    / design_effect
)

Here:

\[\rho = \frac{1}{1+0.25} = 0.8\]

and:

\[\text{design effect} = 1+19(0.8) = 16.2\]

Thus, the nominal 2,000 rows contain approximately:

\[\frac{2000}{16.2} \approx123\]

independent-row equivalents.

The correct estimator standard deviation is:

\[\sqrt{ \frac{1}{100} + \frac{0.25}{100(20)} } \approx0.101\]

The naive calculation reports:

\[\sqrt{ \frac{1.25}{2000} } = 0.025\]

Typical coverage is therefore:

  • naive row interval: roughly 0.38;

  • cluster-aware interval: roughly 0.95.

Check answers

  1. Repeated episodes continue sharing the same \(B_u\); only new independent users average away that component.

  2. No. With equal cluster sizes, both means are algebraically identical. Clustering changes uncertainty.

  3. Resample complete independent clusters—such as users or source tasks—not their individual rows.

  4. A raw row mean weights prolific users more heavily. Define the estimand first, then use user weighting, masks and cluster-aware uncertainty accordingly.

Retrieval answers

  1. Otherwise the model may memorize the same label whose residual it later evaluates, artificially driving the correction toward zero.

  2. Keep every dependent cluster—user, source prompt, template family or conversation—inside one fold.

Takeaway: count independent sampling units, not database rows. Repeated episodes improve estimates of each user’s mean, but they do not create new users or justify row-level confidence intervals.
