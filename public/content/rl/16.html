🧩 Analogy: judging a decision: tomorrow vs next year

Was taking that new job a good decision? Judge it by tomorrow’s mood and you get a quick, steady, but short-sighted answer. Judge it a year later and you get the true answer, but mixed with a lot of unrelated luck. GAE blends every horizon in between with a dial \(\lambda\): \(\lambda=0\) means “judge by tomorrow,” and \(\lambda=1\) means “wait for the full outcome.”

2. Why one-step advantage can be too short-sighted

One-step actor-critic uses:

\[\delta_t = R_{t+1} +\gamma(1-D_t)V(S_{t+1}) -V(S_t)\]

This TD error reacts quickly, but an early action only receives information through the critic’s next-state estimate.

Monte Carlo returns propagate the complete outcome backward, but can be noisy. Generalized Advantage Estimation, or GAE, blends these extremes:

\[\hat A_t^{\text{GAE}(\gamma,\lambda)} = \delta_t+ \gamma\lambda(1-D_t) \hat A_{t+1}^{\text{GAE}}\]

Think of \(\lambda\) as controlling how far later TD surprises echo backward:

  • \(\lambda=0\): \(\hat A_t=\delta_t\), purely one-step.

  • Larger \(\lambda\): more later TD errors influence the current action.

  • \(\lambda\approx1\): more Monte Carlo-like, with lower bias but typically higher variance.

The critic’s return target is then commonly:

\[\hat R_t=\hat A_t+V(S_t)\]

Termination, truncation and padding

These masks mean different things:

  • True termination: future return is zero, so stop bootstrapping and GAE recursion.

  • Time-limit truncation: the environment could continue, so bootstrap from the final value estimate.

  • Padding: nonexistent data; it must contribute neither targets nor gradients.

For trajectory batches:

  • rewards, dones, valid mask: [B, T]

  • values: [B, T+1]

  • TD errors and advantages: [B, T]

  • actor log-probabilities: [B, T]

Practical normalization

Advantages are often normalized over valid tokens or timesteps:

\[\tilde A = \frac{A-\mu_A}{\sigma_A+\epsilon}\]

This controls gradient scale, but does not repair a badly trained critic. Padding must be excluded from the mean and variance.

LLM connection

For an LLM rollout, each generated token is one action. GAE can propagate a later reward or critic surprise backward across earlier tokens. Response masks are essential: prompt and padding tokens must not enter policy or value losses.

🔍 Deeper: GAE from n-step advantages

\(n\)-step advantage: \(\hat A^{(n)}_t=\sum_{l=0}^{n-1}\gamma^l\delta_{t+l}\). This telescopes to \(\sum_{l<n}\gamma^lr_{t+l+1}+\gamma^nV(s_{t+n})-V(s_t)\).

GAE is an exponentially weighted average of all of them: \[\hat A^{\text{GAE}}_t=(1-\lambda)\sum_{n\ge1}\lambda^{n-1}\hat A^{(n)}_t=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}.\] \(\lambda=0\) gives \(\delta_t\) (one-step TD). \(\lambda=1\) gives \(G_t-V(s_t)\) (Monte Carlo).

Compute it backward in one pass: \(\hat A_t=\delta_t+\gamma\lambda(1-d_{t+1})\hat A_{t+1}\). The effective horizon is about \(1/(1-\gamma\lambda)\): roughly 17 steps for \(\gamma=0.99,\lambda=0.95\).

🔑 Key ideas

  • \(\lambda\) is a bias-variance dial between TD and MC.

  • The masks matter: a surprise must never travel across an episode boundary.

🚶 Walkthrough: GAE by hand

\(\gamma=0.9,\lambda=0.8\). Rewards \(r_1=0,r_2=1\); values \(V(s_0)=0.5,V(s_1)=0.4\); \(s_2\) terminal. \(\delta_1=1-0.4=0.6\), \(\delta_0=0+0.9(0.4)-0.5=-0.14\). \(\hat A_1=0.6\), \(\hat A_0=-0.14+0.72(0.6)=0.292\). Targets: \(\hat R_0=0.792\), \(\hat R_1=1.0\). Check: the \(\lambda\)-return \(=(1-\lambda)G^{(1)}+\lambda G^{(2)}=0.2(0.36)+0.8(0.9)=0.792\). It matches.

Common mistakes

  • Using done flags at \(t\) instead of \(t+1\) (off-by-one masks).

  • Normalizing advantages before computing the value targets \(\hat A+V\).

  • Letting padding steps feed values into real ones.

⚙️ Algorithm: Generalized Advantage Estimation (GAE)
Input: rewards \(r_{1:T}\), values \(V(s_0),\dots,V(s_T)\), done flags \(d_{1:T}\), \(\gamma\), \(\lambda\)
\(A\gets0\)
for \(t=T-1\) down to \(0\) do
\(\delta_t\gets r_{t+1}+\gamma(1-d_{t+1})V(s_{t+1})-V(s_t)\)
\(A\gets\delta_t+\gamma\lambda(1-d_{t+1})\,A\) ▷ surprises never cross an episode boundary
\(\hat A_t\gets A\)
end
return advantages \(\hat A_t\) and value targets \(\hat R_t=\hat A_t+V(s_t)\)

Hints

  • Consecutive values are values[:, :-1] and values[:, 1:].

  • Continuation mask: 1.0 - dones.

  • GAE recursion uses gamma * gae_lambda.

  • Apply valid[:, t] during the reverse recursion.

  • Use std(unbiased=False) and add approximately 1e-8.

  • Divide the masked policy-loss sum by valid.sum().

  • Detach normalized advantages in the actor loss.

4. Checks for understanding

  1. What does increasing \(\lambda\) change?

  2. Why does true termination stop the GAE recursion?

  3. Why should truncation not automatically set done=1?

  4. Does advantage normalization change which samples are above or below the batch mean?

Solutions

TD errors:

deltas = (
    rewards
    + gamma * (1.0 - dones) * values[:, 1:]
    - values[:, :-1]
) * valid

GAE recursion:

for t in reversed(range(rewards.shape[1])):
    running_gae = (
        deltas[:, t]
        + gamma
        * gae_lambda
        * (1.0 - dones[:, t])
        * running_gae
    )

    running_gae = running_gae * valid[:, t]
    advantages[:, t] = running_gae

Critic targets:

value_targets = (
    advantages + values[:, :-1]
) * valid

Normalization:

mean = valid_advantages.mean()
std = valid_advantages.std(unbiased=False)

normalized[valid_positions] = (
    valid_advantages - mean
) / (std + 1e-8)

Masked actor loss:

actor_loss = -(
    log_probs
    * normalized.detach()
    * valid
).sum() / valid.sum()

Expected unnormalized advantages are approximately:

tensor([
    [0.4811, 0.4460, 0.3000, 0.0000],
    [0.1802, 0.1391, 0.0960, 0.0500]
])

For trajectory two, the final TD error is:

\[0+\gamma V(S_4)-V(S_3) = 0+0.9(0.5)-0.4 = 0.05\]

That value remains because the final boundary is a truncation, not a true termination.

The padded log-probability’s gradient should be exactly zero.

Check answers

  1. Larger \(\lambda\) lets later TD errors influence earlier actions more strongly, usually lowering bias while raising variance.

  2. Nothing after a genuine terminal state belongs to the episode’s future return.

  3. A truncated process could have continued; discarding its final value creates a systematically shortened target.

  4. No. Subtracting one mean and dividing by a positive standard deviation preserves whether a value lies above or below that mean.

Retrieval answers

  1. \(\delta_t=R_{t+1}+\gamma(1-D_t)V(S_{t+1})-V(S_t)\).

  2. The target must remain fixed for the critic update, and the actor loss must not optimize the critic through its advantage weight.

Takeaway: GAE decides how far TD surprises travel backward. \(\lambda\) controls the bias–variance trade-off; correct termination and padding masks control whether the calculation is valid at all.
