🧩 Analogy: the cautious new driver

A new driver who knows they sometimes oversteer stays away from the cliff edge, even though the edge road is shorter. They’re judging the road given how they actually drive, mistakes included. That’s SARSA: it learns the value of the policy you really follow, exploration and all.

Cliff walking. With \(\epsilon\)-greedy exploration, SARSA learns the safe path because its own random steps near the edge are costly.

2. From state values to action values

TD(0) estimated:

\[V^\pi(s)\]

That tells us how good a state is, but it does not directly tell us which action to choose.

For control, estimate:

\[Q^\pi(s,a)\]

SARSA applies temporal-difference learning to action values.

Its name comes from the complete transition tuple:

\[(S_t,A_t,R_{t+1},S_{t+1},A_{t+1})\]

The SARSA target is:

\[Y_t = R_{t+1} + \gamma(1-D_t) Q(S_{t+1},A_{t+1})\]

The TD error is:

\[\delta_t = Y_t-Q(S_t,A_t)\]

And the update is:

\[Q(S_t,A_t) \leftarrow Q(S_t,A_t)+\alpha\delta_t\]

The important detail is \(A_{t+1}\): SARSA uses the action the policy actually selected in the next state.

Why SARSA is on-policy

Suppose your driving policy explores by occasionally taking unfamiliar roads.

SARSA asks:

What return should I expect while driving with this exploratory behaviour?

It does not pretend that you will always make the best-known next choice. If the policy sometimes explores into bad actions, those consequences appear in its action values.

That makes SARSA on-policy:

  • behaviour policy: generates experience;

  • target policy: policy being evaluated and improved;

  • in SARSA, they are the same policy.

An \(\epsilon\)-greedy SARSA target is therefore:

\[R_{t+1} + \gamma Q(S_{t+1},A_{t+1}), \quad A_{t+1}\sim\pi_\epsilon\]

The next session’s Q-learning target will instead use:

\[R_{t+1} + \gamma\max_aQ(S_{t+1},a)\]

That small replacement—sampled action versus maximum action—is the central difference.

LLM connection

Imagine an LLM agent whose current policy sometimes explores unfamiliar tool calls.

SARSA evaluates the continuation the policy actually samples. It therefore includes the consequences of the policy’s exploratory behaviour rather than assuming an ideal next action.

LLM post-training rarely uses tabular SARSA directly, but this on-policy idea becomes important in policy gradients and PPO.

🔍 Deeper: on-policy targets

SARSA update: \(Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma Q(s',a')-Q(s,a)\big]\) with \(a'\sim\pi(\cdot|s')\), the action you’ll actually take.

Expected SARSA averages instead of sampling: \(r+\gamma\sum_{a'}\pi(a'|s')Q(s',a')\). It has the same expectation with lower variance.

Why the edge is costly: with \(\epsilon=0.1\) and 4 actions, each step on the edge row falls in with probability about \(\epsilon/4=0.025\). Over 8 edge steps, \(P(\text{fall})\approx1-(0.975)^8\approx0.18\), so the expected cost is about \(0.18\times100=18\), which dwarfs the few steps saved.

🔑 Key ideas

  • SARSA = on-policy TD control: the target uses the next action you really take.

  • It learns behaviour that is safe given your own exploration.

🚶 Walkthrough: SARSA vs Q-learning on the same transition

\(Q(s,a)=0.5\), \(r=0\), \(\gamma=0.9\), \(\alpha=0.1\). At \(s'\): \(Q(s',\text{safe})=2\), \(Q(s',\text{cliff})=-10\). The agent’s next action happened to be cliff (exploration).

  • SARSA target \(=0+0.9(-10)=-9\), so \(Q(s,a)\gets0.5+0.1(-9.5)=-0.45\).

  • Q-learning target \(=0+0.9(2)=1.8\), so \(Q(s,a)\gets0.5+0.1(1.3)=0.63\).

SARSA “remembers” that it sometimes slips. Q-learning assumes perfect play next time.

Common mistakes

  • Picking \(a'\) for the target and then sampling a different \(a'\) to execute.

  • Not resetting \(a\) at the start of each episode.

  • Using \(\epsilon=0\) and expecting SARSA to learn caution.

⚙️ Algorithm: SARSA (on-policy TD control)
Input: step size \(\alpha\), discount \(\gamma\), exploration \(\epsilon\)
\(Q(s,a)\gets0\) for every state-action pair
for each episode do
\(s\gets\) initial state; \(a\gets\epsilon\text{-greedy}(Q,s)\)
while \(s\) is not terminal do
take \(a\); observe \(r,s',d\)
\(a'\gets\epsilon\text{-greedy}(Q,s')\) ▷ the action you will really take
\(Q(s,a)\gets Q(s,a)+\alpha\big[r+\gamma(1-d)Q(s',a')-Q(s,a)\big]\)
\(s\gets s',\ a\gets a'\)
end
end

A complete runnable version:

import torch

torch.manual_seed(7)

num_states = 3
num_actions = 2

alpha = 0.2
gamma = 0.95
epsilon = 0.2

q = torch.zeros(num_states, num_actions)


def choose_action(state):
    if torch.rand(()) < epsilon:
        return torch.randint(num_actions, ()).item()
    return q[state].argmax().item()


for episode in range(500):
    state = 0
    action = choose_action(state)

    for step in range(30):
        next_state = (
            max(0, state - 1)
            if action == 0
            else min(2, state + 1)
        )

        done = next_state == 2
        reward = 1.0 if done else -0.01

        if done:
            target = torch.tensor(reward)
            next_action = None
        else:
            next_action = choose_action(next_state)
            target = reward + gamma * q[next_state, next_action]

        td_error = target - q[state, action]
        q[state, action] += alpha * td_error

        if done:
            break

        state = next_state
        action = next_action

print(q)
print(q.argmax(dim=1))

Check answers

  1. It learns about and improves the same policy that generates its experience.

  2. The action actually selected by the current policy.

  3. A genuine terminal state has no future action or future return.

  4. The value of a policy that continues to make exploratory choices, including their costs.

  5. TD targets and TD errors grow correspondingly, potentially requiring a smaller learning rate or reward normalization.

Retrieval answers

  1. \(R_{t+1}+\gamma(1-D_t)V(S_{t+1})\).

  2. The target should supervise the current prediction; allowing target-side gradients changes the intended semi-gradient update.

Takeaway: SARSA learns, “How good is this action if I continue behaving as I actually behave?” The next action in its target is sampled—not imagined to be optimal.
