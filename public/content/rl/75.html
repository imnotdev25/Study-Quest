🧩 Analogy: a dice roll vs a doctor’s first rare case

A fair die is unpredictable, but you know exactly how unpredictable: that’s aleatoric noise, and more data won’t reduce it. A doctor seeing a rare disease for the first time is uncertain because they haven’t seen enough: that’s epistemic ignorance, and data fixes it. An ensemble of critics can tell the two apart: they agree on a die, and they disagree on the rare disease.

2. A wide return distribution does not always mean ignorance

Suppose a search tool sometimes finds excellent evidence and sometimes finds nothing. Even with unlimited training data, its outcome remains variable. This is aleatoric uncertainty: randomness inherent in the environment.

Now suppose a database tool has barely appeared in training. Different critics predict very different values for it. This is epistemic uncertainty: uncertainty caused by limited knowledge.

A distributional critic estimates outcome variability:

\[Z_m(s,a)\]

An ensemble of \(M\) critics estimates model disagreement. Using the law of total variance:

\[\operatorname{Var}(Z) = \underbrace{ \mathbb E_m[ \operatorname{Var}(Z_m) ]}_{\text{aleatoric}} + \underbrace{ \operatorname{Var}_m[ \mathbb E[Z_m] ]}_{\text{epistemic}}\]

Think of weather:

  • every forecast predicts variable rain: aleatoric uncertainty;

  • forecasters disagree with each other: epistemic uncertainty.

For conservative deployment, use a lower-confidence score:

\[Q_{\text{LCB}}(s,a) = \bar Q(s,a) - \beta\sigma_{\text{epistemic}}(s,a)\]

For exploration, the sign may be reversed:

\[Q_{\text{UCB}}(s,a) = \bar Q(s,a) + \beta\sigma_{\text{epistemic}}(s,a)\]

High disagreement is not proof that an action is bad. It means the system lacks evidence.

Tensor shapes:

  • ensemble quantiles: [M, A, N]

  • per-model means and variances: [M, A]

  • aleatoric and epistemic variances: [A]

DPO does not perform online uncertainty-directed exploration. Ensembles of preference or reward models can reveal disagreement, but missing failure modes shared by every model remain invisible.

🔍 Deeper: law of total variance

For an ensemble of \(M\) critics, each predicting a mean \(\mu_m\) and variance \(\sigma^2_m\): \[\operatorname{Var}[Z]=\underbrace{\tfrac1M\textstyle\sum_m\sigma_m^2}_{\text{aleatoric}}+\underbrace{\tfrac1M\textstyle\sum_m(\mu_m-\bar\mu)^2}_{\text{epistemic}} .\] Use them differently: aleatoric risk calls for risk-aware objectives (CVaR). Epistemic uncertainty calls for exploration during training, or pessimism (\(\bar\mu-k\cdot\text{sd}\)) at deployment. Caveat: members trained on the same data with the same biases can agree confidently and all be wrong (Topic 131).

🔑 Key ideas

  • Outcome noise and model ignorance need different responses.

  • Ensemble agreement is not proof of correctness.

🚶 Walkthrough: decompose by action

Seen action: means \((1.0,1.1,0.9)\), variances \((4,4,4)\). Aleatoric 4, epistemic 0.0067: noisy but understood. Unseen action: means \((1.0,3.0,-1.0)\), variances \((0.5,0.5,0.5)\). Aleatoric 0.5, epistemic 2.67: the critics simply don’t know.

Common mistakes

  • Adding the two uncertainties and treating the sum one way.

  • An ensemble with identical seeds and data.

  • Reading low ensemble spread as calibrated confidence.

Hints

  • Quantiles are on the final dimension.

  • Models are on dimension 0.

  • Use population variance with correction=0 everywhere.

  • To compute direct variance, rearrange to [A, M*N].

  • Clamp variance before sqrt to guard against tiny negative round-off.

  • Conservative scoring subtracts epistemic standard deviation.

Debugging experiments

Compute variance across the action dimension. The code runs, but the result compares different decisions instead of uncertainty within one decision.

Use correction=1 in only part of the calculation. Mixed variance conventions break the decomposition.

Create an “ensemble” by copying the same checkpoint three times. Epistemic variance becomes zero even though no independent uncertainty estimate exists.

Multiply all returns by 100. Uncertainty bonuses scale too; \(\beta\) cannot be transferred blindly between reward scales.

4. Checks for understanding

  1. Which uncertainty can usually be reduced by collecting more relevant data?

  2. Why doesn’t a distributional critic alone measure epistemic uncertainty?

  3. Why might deployment use an LCB while exploration uses a UCB?

  4. What can make ensemble disagreement falsely small?

Solutions

Per-model and ensemble means:

model_means = (
    quantile_predictions.mean(dim=-1)
)

ensemble_means = (
    model_means.mean(dim=0)
)

Aleatoric uncertainty:

within_model_variances = (
    quantile_predictions.var(
        dim=-1,
        correction=0,
    )
)

aleatoric_variances = (
    within_model_variances.mean(dim=0)
)

Epistemic uncertainty:

epistemic_variances = (
    model_means.var(
        dim=0,
        correction=0,
    )
)

Total-variance verification:

decomposed_total_variances = (
    aleatoric_variances
    + epistemic_variances
)

flattened_predictions = (
    quantile_predictions
    .permute(1, 0, 2)
    .reshape(num_actions, -1)
)

direct_total_variances = (
    flattened_predictions.var(
        dim=1,
        correction=0,
    )
)

maximum_decomposition_error = (
    decomposed_total_variances
    - direct_total_variances
).abs().max()

Risk-sensitive choices:

epistemic_standard_deviations = (
    epistemic_variances
    .clamp_min(0.0)
    .sqrt()
)

pessimistic_scores = (
    ensemble_means
    - beta
    * epistemic_standard_deviations
)

optimistic_scores = (
    ensemble_means
    + beta
    * epistemic_standard_deviations
)

mean_choice = ensemble_means.argmax()

pessimistic_choice = (
    pessimistic_scores.argmax()
)

optimistic_choice = (
    optimistic_scores.argmax()
)

The model means are:

\[\begin{bmatrix} 1&1\\ 1&3\\ 1&5 \end{bmatrix}\]

For action 0, all critics agree on mean 1, but each predicts a wide outcome distribution:

\[\sigma^2_{\text{aleatoric}}\approx2.667, \qquad \sigma^2_{\text{epistemic}}=0\]

For action 1, each critic predicts a narrow distribution, but their means disagree:

\[\sigma^2_{\text{aleatoric}}\approx0.0067, \qquad \sigma^2_{\text{epistemic}}\approx2.667\]

The raw mean and UCB select action 1. With \(\beta=1.5\), the LCB penalizes its disagreement enough to select action 0.

Check answers

  1. Epistemic uncertainty; targeted data can make models agree. Aleatoric randomness may remain.

  2. One critic estimates possible outcomes under its learned model, not uncertainty about whether that model is correct.

  3. Deployment may avoid unsupported actions, while exploration deliberately visits them to gain information.

  4. Shared initialization, identical bootstrap data, correlated model errors, insufficient ensemble diversity and common misspecification.

Retrieval answers

  1. A distributional critic retains spread, skew, multimodality and tail behavior.

  2. Otherwise the critic can move its own bootstrap target, creating a coupled and unstable regression objective.

Takeaway: outcome variance and model ignorance require different responses. Penalize disagreement for conservative deployment, investigate it during exploration, and never interpret ensemble agreement as proof of correctness.
