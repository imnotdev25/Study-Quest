🧩 Analogy: one employee, two bosses

An employee with two bosses gets two sets of instructions. If one boss shouts much louder, the employee follows that one, even when the quiet boss was right. A shared actor–critic network is that employee: the policy loss and the value loss both send gradients into the same trunk, and the larger gradient wins.

Both losses write into the same trunk parameters.

2. Shared parameters receive competing instructions

An LLM PPO model may share a transformer backbone between:

  • an actor head producing token probabilities;

  • a critic head predicting values.

A common total loss is:

\[L_{\text{total}} = L_{\pi} + c_V L_V - c_H H + \beta L_{\mathrm{KL}}\]

The shared parameters receive the sum of every weighted gradient:

\[\nabla L_{\text{total}} = \nabla L_\pi + c_V\nabla L_V - c_H\nabla H + \beta\nabla L_{\mathrm{KL}}\]

The coefficients are therefore gradient weights—not cosmetic labels.

Think of two people moving the same steering wheel. The actor may push the representation toward a higher-reward token while the critic pushes it toward more accurate return prediction. Their gradients can:

  • align: both improve under the same update;

  • be orthogonal: little direct interaction;

  • conflict: improving one locally harms the other.

Measure this with cosine similarity:

\[\cos(g_\pi,g_V) = \frac{g_\pi^\top g_V} {\lVert g_\pi\rVert\lVert g_V\rVert}\]

A negative value indicates conflict.

Loss magnitudes alone are insufficient. A small loss may have a large gradient, and parameterization changes gradient scale. Log per-term gradient norms on the shared backbone.

Tensor shapes:

  • shared representation: [hidden]

  • actor and critic gradient vectors: [hidden]

  • real flattened shared-parameter gradients: [num_shared_parameters]

  • each loss: scalar

DPO ordinarily has no critic. Its preference loss can still conflict with auxiliary SFT, KL or regularization losses when they share parameters.

🔍 Deeper: gradient conflict

Total loss \(\mathcal L=\mathcal L_\pi+c_V\mathcal L_V\), so the trunk gets \(g=g_\pi+c_Vg_V\). The actor’s intended direction survives only if \(g^\top g_\pi>0\), i.e. \[\|g_\pi\|^2+c_V\,g_V^\top g_\pi>0 .\] If \(g_V\) points against \(g_\pi\) and \(c_V\|g_V\|\) is large, the trunk update reverses the policy improvement. Scale matters: \(\mathcal L_V\) is in squared return units. Doubling the reward scale quadruples \(\mathcal L_V\), which is like quadrupling \(c_V\) without touching the config.

Diagnostics: log \(\|g_\pi\|\), \(\|c_Vg_V\|\) and \(\cos(g_\pi,g_V)\) on the shared parameters. The total loss alone can’t show any of these.

🔑 Key ideas

  • \(c_V\) controls how strongly the critic moves the shared model.

  • Measure per-loss gradient norms and alignment, or separate the trunks.

🚶 Walkthrough: the critic reverses the actor

On the trunk: \(g_\pi=(1,0)\), \(g_V=(-3,1)\), \(c_V=0.5\). So \(g=(1,0)+(-1.5,0.5)=(-0.5,0.5)\). \(g^\top g_\pi=-0.5<0\): the descent step now moves the policy against its own improvement. With \(c_V=0.25\), \(g=(0.25,0.25)\) and \(g^\top g_\pi=0.25>0\).

Common mistakes

  • Tuning \(c_V\) by watching the total loss.

  • Changing the reward scale without revisiting \(c_V\).

  • Logging gradient norms over all parameters instead of the shared ones.

  1. Should a positive advantage make gradient descent increase or decrease the selected action’s logit?

  2. Will the actor and critic gradients have positive or negative cosine similarity?

  3. Which value coefficient can reverse the actor’s desired movement?

  4. Does a smaller numerical value loss guarantee a smaller critic gradient?

Hints

  • For a selected binary action, use F.logsigmoid(actor_logit).

  • The optimizer minimizes, so negate log-probability times advantage.

  • Use half squared error: 0.5 * (prediction - target).square().

  • Obtain gradients with torch.autograd.grad(..., retain_graph=True).

  • An SGD parameter step is -learning_rate * gradient.

  • Detach the advantage and return target.

Debugging experiments

Let the advantage depend on the critic without detaching it:

coupled_advantage = (
    return_target - value_prediction
)

bad_policy_loss = -(
    selected_log_prob * coupled_advantage
)

Now the actor loss differentiates through the credit signal. The critic path can change the shared representation merely to manipulate the advantage.

Next, replace a masked mean value loss with an unmasked sum. Longer responses and padding can enlarge the critic gradient, silently changing its balance with the actor.

Finally, inspect only total gradient norm. A normal-looking total can hide two large opposing gradients that nearly cancel.

Solutions

Actor loss:

actor_logit = (
    shared * actor_direction
).sum()

selected_log_prob = F.logsigmoid(
    actor_logit
)

policy_loss = -(
    selected_log_prob
    * advantage.detach()
)

Critic loss:

value_prediction = (
    shared * critic_direction
).sum()

value_loss = 0.5 * (
    value_prediction
    - return_target.detach()
).square()

Separate gradients:

policy_gradient = torch.autograd.grad(
    policy_loss,
    shared,
    retain_graph=True,
)[0]

value_gradient = torch.autograd.grad(
    value_loss,
    shared,
)[0]

Cosine similarity:

gradient_cosine = F.cosine_similarity(
    policy_gradient,
    value_gradient,
    dim=0,
)

Combined update:

combined_gradient = (
    policy_gradient
    + coefficient * value_gradient
)

parameter_step = (
    -learning_rate * combined_gradient
)

At initialization:

\[g_\pi=[-0.5,-0.25]\]

and:

\[g_V=[1,-1]\]

Their dot product is negative:

\[g_\pi^\top g_V=-0.25\]

so the losses conflict on the shared representation.

With small \(c_V\), the selected-action logit increases as requested by the positive advantage. With c_v=10, the critic dominates and the same combined SGD update decreases that logit.

Check answers

  1. Reward scaling changes returns and advantages, which changes actor and critic gradient scales—often differently because value loss is squared.

  2. No. Multi-objective learning naturally creates conflicts; cosine similarity is a diagnostic, not a correctness test.

  3. Separate heads may not interact directly, but the shared backbone receives both gradients and determines their real interference.

  4. Log policy/value losses, shared gradient norms, their cosine similarity, update norm, explained variance, policy KL, clip fractions and raw reward scale.

Retrieval answers

  1. Outside the clipping range, the selected clipped prediction can be constant with respect to the current value, producing zero gradient.

  2. Advantages are fixed credit signals for the actor update. Detaching them prevents unintended differentiation through the critic or return-construction path.

Takeaway: tuning \(c_V\) means tuning how strongly the critic moves shared model parameters. Measure per-loss gradient norms and alignment; total loss alone cannot reveal dominance, cancellation or conflict.
