2. The independent sample is usually the episode

Rewards within one trajectory share states, history and task difficulty. Model this as:

\[Y_{it} = \underbrace{\theta}_{\text{population mean}} + \underbrace{U_i}_{\text{episode-wide effect}} + \underbrace{\epsilon_{it}}_{\text{step-specific noise}}\]

Here \(i\) indexes episodes and \(t\) indexes steps. Define:

\[Z_i = \underbrace{\frac1T\sum_{t=1}^{T}Y_{it}}_{\text{one episode's score}}, \qquad \hat\theta = \underbrace{\frac1N\sum_{i=1}^{N}Z_i}_{\text{average across independent episodes}}\]

Its variance is:

\[\operatorname{Var}(\hat\theta) = \underbrace{\frac{\sigma_U^2}{N}}_{\text{episode uncertainty; extra steps do not remove it}} + \underbrace{\frac{\sigma_\epsilon^2}{NT}}_{\text{step noise; more steps help}}\]

Flattening all \(NT\) steps and pretending they are independent effectively discards the first term. The resulting confidence interval is too narrow.

The cluster bootstrap instead samples complete episodes:

\[I_{b1},\ldots,I_{bN} \overset{\mathrm{iid}}{\sim} \operatorname{Uniform}\{1,\ldots,N\}\]

\[\hat\theta_b^* = \underbrace{ \frac1N\sum_{j=1}^{N}Z_{I_{bj}} }_{\text{bootstrap estimate from resampled episodes}}\]

A percentile interval uses:

\[CI_{95\%} = \underbrace{ \left[ Q_{0.025}(\hat\theta^*), Q_{0.975}(\hat\theta^*) \right] }_{\text{central 95\% of bootstrap estimates}}\]

For OPE, \(Z_i\) can be an episode-level IPS, DR or cross-fitted influence score rather than a raw reward mean.

Tensor shapes:

  • rewards: [R, N, T]

  • episode scores: [R, N]

  • estimates and standard errors: [R]

  • cluster-bootstrap indices: [B, N]

For LLM agents, resample complete task trajectories. If several trajectories belong to one user or prompt family, resample that higher-level cluster. For DPO evaluation, resample prompts or users—not chosen/rejected tokens. DPO itself remains offline preference optimization, not online RL.

Hints

  • Broadcast episode effects from [R, N, 1] across time.

  • An episode score is its mean across dimension 2.

  • The naive calculation flattens dimensions N and T.

  • The cluster calculation takes the standard deviation across episode scores.

  • Bootstrap indices must select episodes together with all their dependent steps.

Debugging experiments

  • Shuffle and resample individual tokens from trajectories.

  • Put episodes from one user into several supposedly independent clusters.

  • Bootstrap cross-fitted rows while separating rows that shared nuisance-model training.

  • Add one enormous importance-weight episode and inspect how often it appears.

  • Interpret a narrow bootstrap interval as evidence that the estimator is unbiased.

Solutions

Generate the data:

episode_effects = (
    episode_effect_sd
    * torch.randn(
        num_studies,
        num_episodes,
        1,
    )
)

step_noise = (
    step_noise_sd
    * torch.randn(
        num_studies,
        num_episodes,
        steps_per_episode,
    )
)

rewards = (
    true_value
    + episode_effects
    + step_noise
)

Standard errors:

episode_scores = rewards.mean(dim=2)

estimates = episode_scores.mean(dim=1)

naive_step_standard_errors = (
    rewards
    .flatten(start_dim=1)
    .std(dim=1, correction=1)
    / math.sqrt(
        num_episodes * steps_per_episode
    )
)

cluster_standard_errors = (
    episode_scores.std(
        dim=1,
        correction=1,
    )
    / math.sqrt(num_episodes)
)

true_standard_error = torch.sqrt(
    episode_effect_sd.square()
    / num_episodes
    +
    step_noise_sd.square()
    / (
        num_episodes
        * steps_per_episode
    )
)

Coverage:

naive_lower_bounds = (
    estimates
    - z_value * naive_step_standard_errors
)

naive_upper_bounds = (
    estimates
    + z_value * naive_step_standard_errors
)

cluster_lower_bounds = (
    estimates
    - z_value * cluster_standard_errors
)

cluster_upper_bounds = (
    estimates
    + z_value * cluster_standard_errors
)

naive_coverage = (
    (
        (naive_lower_bounds <= true_value)
        & (true_value <= naive_upper_bounds)
    )
    .to(torch.float64)
    .mean()
)

cluster_coverage = (
    (
        (cluster_lower_bounds <= true_value)
        & (true_value <= cluster_upper_bounds)
    )
    .to(torch.float64)
    .mean()
)

empirical_standard_error = estimates.std(
    correction=1
)

Bootstrap one study:

observed_episode_scores = episode_scores[0]

    observed_episode_scores[

)

    low=0,
    high=observed_steps.numel(),
    size=(
        num_bootstrap_samples,

    ),

    observed_steps[token_indices]
    .mean(dim=1)
)

cluster_bootstrap_se = (
    cluster_bootstrap_estimates.std(
        correction=1
    )
)

token_bootstrap_se = (
    token_bootstrap_estimates.std(
        correction=1
    )
)

cluster_bootstrap_interval = (
    cluster_bootstrap_estimates.quantile(
        quantiles
    )
)

token_bootstrap_interval = (
    token_bootstrap_estimates.quantile(
        quantiles
    )
)

The theoretical standard error is:

\[SE = \sqrt{ \underbrace{\frac{1^2}{100}}_{\text{episode effect}} + \underbrace{\frac{0.5^2}{100(10)}}_{\text{step noise}} } \approx 0.101\]

Typical results are:

  • empirical standard error: approximately 0.10;

  • episode/cluster estimate: approximately 0.10;

  • naive token estimate: approximately 0.035;

  • episode-level coverage: about 94–95%;

  • token-level coverage: only about 50%.

More tokens reveal each sampled episode more precisely. They do not create more independent episodes.

Check answers

  1. No. As \(T\) grows, step noise vanishes, but the \(\sigma_U^2/N\) term remains.

  2. The episode-level interval, because episodes are the independent units.

  3. It breaks within-episode dependence and invents an effective sample size near \(NT\).

  4. Resample the highest plausibly dependent unit: episode, user, conversation or prompt family.

  5. No. Bootstrap uncertainty cannot remove estimator bias, missing support or reward-model invalidity. With fitted nuisances, either bootstrap the entire fitting pipeline or resample valid out-of-fold influence scores.

Retrieval answers

  1. Excluding each scored outcome prevents a nuisance model from memorizing and cancelling its own residual correction.

  2. Fold membership should follow the largest dependent unit—typically complete episodes, users, conversations or prompt families.

Takeaway: count independent decisions, not tensor rows. Ten correlated steps from one agent episode provide more detail about that episode, but they are not ten independent deployment trials.
