2. A mean critic hides the shape of outcomes

A standard critic predicts one number:

\[V(s)=\mathbb E[G\mid s]\]

Two states can have identical expected return while one is reliable and the other alternates between success and catastrophe.

A distributional critic models the random return:

\[Z(s)\overset{D}{=}G\]

Quantile critics predict returns at fixed probability levels:

\[q_i(s)\approx F^{-1}_{Z(s)}(\tau_i)\]

For five evenly spaced quantiles:

\[\tau=[0.1,0.3,0.5,0.7,0.9]\]

The first output describes a bad lower-tail outcome; the last describes a strong outcome.

Given target return \(y\), define:

\[u=y-q_i\]

Quantile Huber loss is:

\[\rho_{\tau_i}^{\kappa}(u) = \left| \tau_i-\mathbf 1[u<0] \right| \frac{H_\kappa(u)}{\kappa}\]

where:

\[H_\kappa(u)= \begin{cases} \frac12u^2,&|u|\le\kappa\\ \kappa(|u|-\frac12\kappa),&\text{otherwise} \end{cases}\]

The asymmetric weight makes low quantiles react strongly when their prediction is too high.

For bootstrapped distributional RL, targets look like:

\[y_j = r+\gamma(1-d) q_j^{\text{target}}(s',a')\]

Detach target-network quantiles exactly as with an ordinary TD target.

Tensor shapes:

  • predicted quantiles: [B, N]

  • target samples or target quantiles: [B, K]

  • pairwise errors: [B, N, K]

  • reduced loss: scalar

DPO compares fixed response pairs and has no return critic. A distributional critic is useful in online RL when the policy must reason about variability or tail outcomes.

🔍 Deeper: quantile regression

Predict \(N\) quantiles \(\theta_1,\dots,\theta_N\) at levels \(\tau_i=\frac{2i-1}{2N}\). Train each with the pinball loss \(\ell_\tau(u)=u\,(\tau-\mathbb 1[u<0])\), where \(u=z-\theta\) and \(z\) is a target sample. Distributional Bellman: \(Z(s,a)\overset{D}{=}R+\gamma Z(s',a')\): the whole distribution is backed up, not just its mean. QR-DQN uses a Huber-smoothed pinball loss (algorithm box below). Its mean recovers the usual critic: \(Q=\frac1N\sum_i\theta_i\).

🔑 Key ideas

  • A scalar critic gives the average, and a quantile critic shows its pieces.

  • Read the lower quantiles for risk-sensitive decisions.

🚶 Walkthrough: pinball loss at \(\tau=0.9\)

Target \(z=5\). Predict \(\theta=4\): \(u=1\), loss \(=1\times0.9=0.9\). Predict \(\theta=6\): \(u=-1\), loss \(=1\times0.1=0.1\). Under-predicting a high quantile costs 9\(\times\) more, which pushes \(\theta\) up toward the 90th percentile.

Common mistakes

  • Quantile crossing (\(\theta_i>\theta_{i+1}\)): sort the quantiles, or parameterize them as increments.

  • Collapsing to the mean for decisions that are supposed to be risk-aware.

  • Using MSE on quantiles (that predicts the mean every time).

⚙️ Algorithm: Quantile-regression distributional TD (QR-DQN)
Input: network outputting \(N\) quantiles \(\theta_i(s,a)\), levels \(\tau_i=\frac{2i-1}{2N}\), target network \(\theta^-\)
for each minibatch \((s,a,r,s',d)\) do
\(a^*\gets\arg\max_{a'}\frac1N\sum_j\theta^-_j(s',a')\) ▷ act on the mean
target samples \(z_j\gets r+\gamma(1-d)\,\theta^-_j(s',a^*)\) for \(j=1,\dots,N\)
\(u_{ij}\gets z_j-\theta_i(s,a)\)
gradient step on \(\frac1N\sum_i\sum_j\big|\tau_i-\mathbb 1[u_{ij}<0]\big|\cdot\operatorname{Huber}_\kappa(u_{ij})\)
end

Debugging experiments

Replace each row of target_samples with ten copies of its mean. Both states become identical to the critic, destroying all tail information.

Reverse the error definition to prediction - target without changing the indicator. The asymmetric weights now learn the wrong quantiles.

Set every tau to 0.5. All five outputs learn approximately the median rather than different parts of the distribution.

Increase return scale by 1_000 while retaining kappa=0.1. Almost every error enters the linear Huber region; inspect gradient scale and consider normalizing returns.

Solutions

Quantile levels:

taus = (
    torch.arange(
        num_quantiles,
        dtype=target_samples.dtype,
    )
    + 0.5
) / num_quantiles

Pairwise errors:

errors = (
    targets.detach()[:, None, :]
    - predictions[:, :, None]
)

absolute_errors = errors.abs()

Huber loss and quantile weighting:

huber = torch.where(
    absolute_errors <= kappa,
    0.5 * errors.square(),
    kappa * (
        absolute_errors
        - 0.5 * kappa
    ),
)

quantile_weights = (
    taus[None, :, None]
    - (
        errors.detach() < 0
    ).to(errors.dtype)
).abs()

per_pair_loss = (
    quantile_weights
    * huber
    / kappa
)

Optimization:

for step in range(1_500):
    loss = quantile_huber_loss(
        predicted_quantiles,
        target_samples,
    )

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

Diagnostics:

with torch.no_grad():
    final_quantiles = (
        predicted_quantiles.detach()

    target_means = target_samples.mean(

Both target means are:

\[\mathbb E[G_0]=1\]

\[\mathbb E[G_1] = 0.8(3)+0.2(-7) = 1\]

The learned patterns should be approximately:

\[q(s_0)\approx[1,1,1,1,1]\]

\[q(s_1)\approx[-7,3,3,3,3]\]

Quantile Huber smoothing may move values slightly inward. Averaging five evenly spaced quantiles gives an approximation of the mean:

\[\frac{-7+3+3+3+3}{5}=1\]

Yet the lower deciles are dramatically different.

Check answers

  1. It retains spread, skew, multimodality and tail outcomes rather than only their average.

  2. Every predicted probability level must be located relative to samples from the complete target distribution.

  3. It is a numerical approximation whose accuracy depends on quantile placement, count and training error.

  4. Monitor quantile loss, crossings, predicted versus empirical quantiles, estimated mean error, tail calibration and results by return scale.

Retrieval answers

  1. For costs, upper-tail CVaR averages outcomes in the worst \(1-\alpha\) fraction.

  2. Ties at the threshold can include far more samples than the intended tail size; top-\(k\) selection fixes the empirical fraction.

Takeaway: a scalar critic says what happens on average; a quantile critic shows how that average is assembled—including the failures hidden in its lower tail.
