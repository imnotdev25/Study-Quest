2. Replace the critic with group comparisons

PPO commonly trains a critic \(V_\phi(x)\) to estimate a baseline. For LLM reasoning tasks, critic training adds memory, computation and another possible source of instability.

Group Relative Policy Optimization samples \(G\) responses for each prompt:

\[y_{i,1},\ldots,y_{i,G} \sim \pi_{\text{old}}(\cdot\mid x_i)\]

Each response receives reward \(R_{i,j}\). GRPO forms advantages by comparing responses generated for the same prompt:

\[\mu_i = \frac1G\sum_{j=1}^{G}R_{i,j}\]

\[\sigma_i = \sqrt{ \frac1G\sum_j(R_{i,j}-\mu_i)^2 }\]

\[\hat A_{i,j} = \frac{R_{i,j}-\mu_i} {\sigma_i+\epsilon}\]

A response need not have positive absolute reward. It receives positive advantage when it performs better than its prompt’s group.

GRPO then uses a PPO-style ratio:

\[r_{i,j}(\theta) = \exp\left( \log\pi_\theta(y_{i,j}\mid x_i) - \log\pi_{\text{old}}(y_{i,j}\mid x_i) \right)\]

and clipped objective:

\[J = \frac1{BG} \sum_{i,j} \min\left( r_{i,j}\hat A_{i,j}, \operatorname{clip}(r_{i,j},1-\epsilon,1+\epsilon) \hat A_{i,j} \right)\]

Why normalize within each prompt?

Suppose an easy prompt produces rewards [1, 1, 1, 1], while a hard prompt produces [0, 0, 0, 1].

Global normalization mixes prompt difficulty with response quality. Group normalization asks the more useful local question:

Which sampled response was better than the alternatives for this same prompt?

Important limits

  • If every group reward is identical, every advantage is zero.

  • Group size 1 always produces zero centered advantage.

  • Small groups give noisy means and standard deviations.

  • One extreme reward can strongly affect the whole group.

  • GRPO removes the learned critic, not the need for reliable rewards.

  • Reference-model KL is commonly added to control policy drift.

Tensor shapes:

  • policy logits: [prompts, responses]

  • sampled responses: [prompts, group]

  • rewards and advantages: [prompts, group]

  • old/current log-probabilities: [prompts, group]

DPO differs fundamentally: it learns from fixed chosen/rejected pairs. GRPO generates groups from the current policy and performs online reward-based updates.

🔍 Deeper: group-relative advantages

\(\hat A_i=\dfrac{R_i-\operatorname{mean}(R_{1:G})}{\operatorname{std}(R_{1:G})+\varepsilon}\), shared by every token of response \(i\). Example: \(R=(1,0,1,0)\), mean 0.5, sample std 0.577, so \(\hat A=\pm0.87\).

When does a group carry signal? Only if the rewards differ. With binary rewards and solve rate \(p\): \(P(\text{useful})=1-p^G-(1-p)^G\).

Bigger groups rescue hard (\(p\approx0.05\)) and easy (\(p\approx0.95\)) prompts. DAPO’s “dynamic sampling” simply drops zero-signal groups and refills the batch.

🔑 Key ideas

  • GRPO replaces the critic with same-prompt competition.

  • No variation within the group means no gradient.

🚶 Walkthrough: one failure among successes

\(R=(1,1,1,0)\). Mean \(0.75\), sample std \(0.5\). \(\hat A=(0.5,0.5,0.5,-1.5)\). The single failure gets a large negative push, three times the size of each success’s positive push, and the advantages sum to 0.

Common mistakes

  • Using \(\varepsilon=0\) (division by zero when all rewards are equal).

  • Normalizing across prompts instead of within each prompt’s group.

  • Forgetting to share \(\hat A_i\) across all tokens of response \(i\).

⚙️ Algorithm: Group Relative Policy Optimization (GRPO)
Input: policy \(\pi_\theta\), reference \(\pi_{\text{ref}}\), group size \(G\), clip \(\epsilon\), KL weight \(\beta\), inner steps \(\mu\)
repeat
\(\pi_{\text{old}}\gets\pi_\theta\)
for each prompt \(x\) in the batch do
sample \(y_1,\dots,y_G\sim\pi_{\text{old}}(\cdot|x)\); score \(R_1,\dots,R_G\)
\(\hat A_i\gets(R_i-\operatorname{mean}R)/(\operatorname{std}R+\varepsilon)\) ▷ every token of \(y_i\) shares \(\hat A_i\)
drop the group if \(\operatorname{std}R=0\) ▷ no signal
end
for \(\mu\) gradient steps do
\(\rho_{i,t}\gets\pi_\theta(y_{i,t}|\cdot)/\pi_{\text{old}}(y_{i,t}|\cdot)\); \(k_{i,t}\gets\frac{\pi_{\text{ref}}}{\pi_\theta}-\log\frac{\pi_{\text{ref}}}{\pi_\theta}-1\)
\(\mathcal L\gets-\frac1G\sum_i\frac{1}{|y_i|}\sum_t\Big[\min\big(\rho_{i,t}\hat A_i,\operatorname{clip}(\rho_{i,t},1\pm\epsilon)\hat A_i\big)-\beta k_{i,t}\Big]\)
gradient step on \(\mathcal L\)
end
until done

Debugging experiment

Normalize across every prompt and response:

advantages = (
    rewards - rewards.mean()
) / (
    rewards.std(unbiased=False) + 1e-8
)

Now absolute prompt reward levels influence the comparison. If one prompt systematically has larger rewards, it can dominate updates even when the within-prompt ranking quality is similar.

Also remove 1e-8. Prompt 2 has zero reward variance, causing division by zero and nan advantages.

Solutions

Sample responses:

sampled_responses = old_policy.sample(
    (group_size,)
).transpose(0, 1)

Gather rewards:

rewards = reward_table.gather(
    dim=1,
    index=sampled_responses,
)

Group-relative advantages:

group_means = rewards.mean(
    dim=1,
    keepdim=True,
)

group_stds = rewards.std(
    dim=1,
    keepdim=True,
    unbiased=False,
)

advantages = (
    rewards - group_means
) / (
    group_stds + 1e-8
)

Old-policy log-probabilities:

old_log_probs = old_policy.log_prob(
    sampled_responses.transpose(0, 1)
).transpose(0, 1)

Current log-probabilities:

current_log_probs = current_policy.log_prob(
    sampled_responses.transpose(0, 1)
).transpose(0, 1)

Clipped objective:

ratios = (
    current_log_probs
    - old_log_probs.detach()
).exp()

unclipped = (
    ratios * advantages.detach()
)

clipped = (
    ratios.clamp(
        1.0 - clip_epsilon,
        1.0 + clip_epsilon,
    )
    * advantages.detach()
)

objective = torch.minimum(
    unclipped,
    clipped,
).mean()

policy_loss = -objective

Prompts 0 and 1 should eventually prefer:

prompt 0 → response 3
prompt 1 → response 2

Prompt 2 always receives:

\[R=[0,\ldots,0]\]

Therefore:

\[R_{2,j}-\mu_2=0\]

and every advantage is zero. Its logits receive no expected gradient and should remain uniform:

\[[0.25,0.25,0.25,0.25]\]

If group_size = 1, then for every prompt:

\[\mu_i=R_{i,1}\]

so:

\[R_{i,1}-\mu_i=0\]

No learning occurs.

Check answers

  1. The group reward mean provides a prompt-dependent baseline without learning \(V_\phi(x)\).

  2. No sampled response is better or worse than its group, so all centered advantages are zero.

  3. No. Finite sampled groups can make relative advantages noisy, especially for small groups or sparse rewards.

  4. GRPO optimizes the supplied verifier or reward model aggressively; removing the critic does not correct a flawed objective.

Retrieval answers

  1. When every sampled reward is identical, subtracting the baseline produces zero advantages.

  2. It is the frozen snapshot that generated the current response group and supplies the denominator of the PPO ratio.

Takeaway: GRPO replaces a learned critic with same-prompt competition. It is attractive when several responses can be sampled and checked, but its signal disappears without within-group reward variation—and it remains only as trustworthy as the reward being compared.
