🧩 Analogy: an athlete and a coach

REINFORCE is like an athlete who only learns from the final scoreboard. Actor-critic adds a coach on the sideline who says “that move was better than I expected” right after each move. The athlete (actor) chooses the moves. The coach (critic) predicts how things will go, and the coach’s surprise is the athlete’s lesson.

The critic turns each transition into a TD error \(\delta_t\), which acts as the actor’s advantage.

2. Actor and critic

Think of two collaborators:

  • The actor chooses what to do: \(\pi_\theta(a\mid s)\).

  • The critic predicts how promising the current situation is: \(V_\phi(s)\).

After a transition, the critic constructs a one-step prediction target:

\[Y_t = R_{t+1} +\gamma(1-D_t)V_\phi(S_{t+1})\]

The difference between the target and the current prediction is the TD error:

\[\delta_t = Y_t-V_\phi(S_t)\]

This TD error is also a one-step advantage estimate:

\[\hat A_t=\delta_t\]

It tells the actor whether the sampled action worked out better or worse than the critic expected.

The two losses are:

\[L_{\text{actor}} = -\log\pi_\theta(A_t\mid S_t)\, \operatorname{stopgrad}(\delta_t)\]

\[L_{\text{critic}} = \frac12 \left(V_\phi(S_t)-\operatorname{stopgrad}(Y_t)\right)^2\]

Two detachments matter:

  • Detach \(Y_t\): the critic performs a semi-gradient TD update instead of moving both sides of its target.

  • Detach \(\delta_t\) in the actor loss: the actor should change action probabilities, not manipulate the critic to manufacture a convenient advantage.

Unlike REINFORCE, actor-critic can update before the episode ends. Bootstrapping usually lowers variance, but an inaccurate critic introduces bias.

  • actor logits: [B, actions]

LLM connection

In LLM RL, the actor is the token policy and the critic estimates each prefix:

\[V_\phi(x,y_{<t})\]

The critic helps answer whether the sampled next token led to a better continuation than expected. PPO-based RLHF commonly uses this actor–critic structure.

🔍 Deeper: the TD error is an advantage estimate

\(\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)\). If \(V=V^\pi\) exactly, \[\mathbb E[\delta_t\mid s_t,a_t]=\mathbb E[r_{t+1}+\gamma V^\pi(s_{t+1})\mid s_t,a_t]-V^\pi(s_t)=Q^\pi(s_t,a_t)-V^\pi(s_t)=A^\pi(s_t,a_t).\] Losses: actor \(-\operatorname{sg}[\delta_t]\log\pi_\theta(a_t|s_t)\), critic \(\tfrac12\big(\operatorname{sg}[r+\gamma V_\phi(s')]-V_\phi(s)\big)^2\).

The trade: if \(V_\phi\) is wrong, \(\delta_t\) is biased. You give up some correctness for much lower variance and per-step updates.

🔑 Key ideas

  • The critic learns what to expect, and the actor learns from the surprise.

  • Detach \(\delta\) in the actor loss so the actor doesn’t move the critic.

🚶 Walkthrough: two TD errors

\(\gamma=0.9\), \(V(s)=1.0\).

  • Non-terminal: \(r=0.5\), \(V(s')=2.0\), so \(\delta=0.5+1.8-1.0=1.3\). The actor makes \(a\) more likely, and the critic moves \(V(s)\) up (\(1.13\) with step 0.1).

  • Terminal: \(r=0.5\), so \(\delta=0.5-1.0=-0.5\). This was worse than expected.

Common mistakes

  • Forgetting to detach \(\delta\) in the actor loss, so the actor’s gradient reshapes the critic.

  • Bootstrapping \(V(s')\) after a terminal step.

  • Making the actor’s learning rate much larger than the critic’s (the actor chases a noisy critic).

⚙️ Algorithm: One-step online actor-critic
Input: actor \(\pi_\theta\), critic \(V_\phi\), step sizes \(\beta_a,\beta_c\)
\(s\gets\) initial state
for each step do
\(a\sim\pi_\theta(\cdot|s)\); take \(a\); observe \(r,s',d\)
\(\delta\gets r+\gamma(1-d)V_\phi(s')-V_\phi(s)\) ▷ treated as a constant
\(\phi\gets\phi+\beta_c\,\delta\,\nabla_\phi V_\phi(s)\) ▷ critic: reduce TD error
\(\theta\gets\theta+\beta_a\,\delta\,\nabla_\theta\log\pi_\theta(a|s)\) ▷ actor: \(\delta\) acts as the advantage
\(s\gets s'\) (reset if \(d=1\))
end

3. PyTorch exercise — a tiny online actor-critic

The task has two nonterminal states:

  • At state 0, action 1 continues to state 1; action 0 ends with reward 0.

  • At state 1, action 1 ends with reward 1; action 0 ends with reward 0.

Complete the TODOs:

from torch.distributions import Categorical

torch.manual_seed(7)

gamma = 1.0
critic_weight = 0.5

Debugging experiment

Remove .detach() here:

actor_loss = -log_prob * advantage

Now the actor loss also produces gradients for critic_values. The optimizer can reduce the actor loss partly by changing the critic rather than only changing the policy.

Also try removing torch.no_grad() around the target. The critic can then move the next-state value through the target, changing the intended semi-gradient update.

Solutions

action = policy.sample()
log_prob = policy.log_prob(action)
with torch.no_grad():
    next_value = (
        torch.tensor(0.0)
        if done
        else critic_values[next_state]
    )

    target = reward + gamma * next_value
advantage = target - value
actor_loss = -log_prob * advantage.detach()
critic_loss = 0.5 * advantage.pow(2)

Both states should eventually prefer action 1:

state 0: continue
state 1: collect reward

Initially:

\[\operatorname{softmax}([0,0])=[0.5,0.5]\]

Near convergence:

\[V(1)\approx1\]

and, because action 1 is almost always selected in both states:

\[V(0) \approx \gamma V(1) \approx1\]

State 1 observes the reward directly. State 0 learns through the bootstrapped estimate \(V(1)\), so reward information propagates backward after the critic begins learning state 1.

Exact values and success rates need not change monotonically because actions remain sampled.

Check answers

  1. It compares the observed one-step outcome with the critic’s expectation: positive means better than expected and negative means worse.

  2. Gradient descent decreases that action’s log-probability.

  3. It replaces a noisy complete return with an immediate reward plus a learned value estimate.

  4. No. The critic may accurately evaluate a poor policy; track episodic return or success rate as well.

Retrieval answers

  1. \(A_t=G_t-b(S_t)\).

  2. The advantage is supervision for the actor; without detachment, the policy loss can also optimize the baseline’s construction.

Takeaway: the critic learns what to expect; the actor learns from the surprise. Actor-critic trades some critic bias for earlier, typically lower-variance policy updates.
