2. Compare completions answering the same prompt

GRPO samples \(G\) completions for each prompt and compares their rewards:

\[y_{qj}\sim \underbrace{\pi_{\text{old}}(\cdot\mid x_q)} _{\text{rollout policy}}, \qquad j=1,\ldots,G\]

Instead of training a value critic, it constructs a prompt-specific baseline:

\[\mu_q = \underbrace{ \frac1G\sum_{j=1}^{G}R_{qj} }_{\text{mean reward for this prompt}}\]

\[\sigma_q^2 = \underbrace{ \frac1G\sum_j(R_{qj}-\mu_q)^2 }_{\text{within-prompt reward variance}}\]

\[\widehat A_{qj} = \underbrace{ \frac{R_{qj}-\mu_q} {\sqrt{\sigma_q^2+\epsilon}} }_{\text{completion quality relative to its peers}}\]

A reward of 0.6 may be good for a difficult prompt but poor for an easy one. Group normalization adjusts for prompt difficulty without learning \(V_\phi(x)\).

GRPO still uses an old-policy importance ratio:

\[\rho_{qjt}(\theta) = \underbrace{ \exp\left[ \log\pi_\theta(a_{qjt}\mid s_{qjt}) - \operatorname{stopgrad} \log\pi_{\text{old}}(a_{qjt}\mid s_{qjt}) \right] }_{\text{current probability relative to rollout probability}}\]

A common clipped objective is:

\[L_{\text{GRPO}} = E\left[ \frac1{|y_{qj}|} \sum_t \min\left( \underbrace{\rho_{qjt}\widehat A_{qj}}_{\text{ordinary surrogate}}, \underbrace{ \operatorname{clip}(\rho_{qjt},1-\varepsilon,1+\varepsilon) \widehat A_{qj} }_{\text{limited improvement}} \right) \right]\]

The same sequence advantage is broadcast across completion tokens, just as in the previous policy-gradient session.

GRPO removes the learned value network, not the baseline. Its baseline is the sampled group. Consequences:

  • small groups give noisy comparisons;

  • equal-reward groups have zero reward gradient;

  • every prompt requires multiple generations;

  • reward quality still determines what is learned;

  • token credit remains coarse.

A leave-one-out baseline is:

\[b_{q,-j} = \underbrace{ \frac1{G-1}\sum_{k\ne j}R_{qk} }_{\text{other completions only}}\]

It avoids using completion \(j\)’s own reward in its baseline. For simple mean-centering:

\[R_{qj}-b_{q,-j} = \underbrace{ \frac{G}{G-1}(R_{qj}-\mu_q) }_{\text{same direction, different scale}}\]

GRPO implementations commonly also add reference-KL regularization. Remember:

  • \(\pi_{\text{old}}\) defines PPO/GRPO ratios;

  • \(\pi_{\text{ref}}\) limits cumulative SFT drift.

DPO has neither online completion groups nor an old-policy ratio. It optimizes frozen preference pairs directly.

Shapes:

  • group rewards and advantages: [P, G]

  • actions, ratios and masks: [P, G, T]

  • logits: [P, G, T, V]

Solutions

Group-relative advantages:

group_means = rewards.mean(
    dim=1,
    keepdim=True,
)

centered_rewards = (
    rewards - group_means
)

group_variances = (
    centered_rewards.square().mean(
        dim=1,
        keepdim=True,
    )
)

group_advantages = (
    centered_rewards
    / torch.sqrt(
        group_variances
        + normalization_epsilon
    )
).detach()

Leave-one-out comparison:

leave_one_out_baselines = (
    rewards.sum(dim=1, keepdim=True)
    - rewards
) / (group_size - 1)

leave_one_out_advantages = (
    rewards
    - leave_one_out_baselines
)

leave_one_out_identity_error = (
    leave_one_out_advantages
    - (
        group_size
        / (group_size - 1)
    )
    * centered_rewards
).abs().max()

Frozen rollouts:

with torch.no_grad():
    actions = old_distribution.sample()

    old_log_probabilities = (
        old_distribution.log_prob(actions)
    )

Importance ratios:

log_ratios = (
    new_log_probabilities
    - old_log_probabilities
)

ratios = torch.exp(log_ratios)

token_advantages = (
    group_advantages[..., None]
)

Clipped objective:

unclipped_surrogate = (
    ratios * token_advantages
)

clipped_surrogate = (
    ratios.clamp(
        1.0 - clip_epsilon,
        1.0 + clip_epsilon,
    )
    * token_advantages
)

token_surrogate = torch.minimum(
    unclipped_surrogate,
    clipped_surrogate,
)

completion_objectives = (
    (
        token_surrogate
        * valid_mask
    ).sum(dim=-1)
    / valid_mask.sum(dim=-1)
)

reward_objective = (
    completion_objectives.mean()
)

actor_loss = -reward_objective

Diagnostics:

outside_clip = (
    (
        ratios < 1.0 - clip_epsilon
    )
    | (
        ratios > 1.0 + clip_epsilon
    )
) & valid_mask.bool()

clip_fraction = (
    outside_clip
    .to(torch.float64)
    .sum()
    / valid_mask.sum()
)

uniform_prompt_gradient = (
    per_prompt_gradient_norms[0]
)

padded_gradient_max = (
    new_logits.grad
    * (
        1.0 - valid_mask
    )[..., None]
).abs().max()

advantage_mean_error = (
    group_advantages.mean(dim=1)
).abs().max()

Prompt 1 has rewards [0, 1, 0, 1], so:

\[\mu_1=0.5, \qquad \sigma_1=0.5\]

\[\widehat A_1 = \underbrace{[-1,\ 1,\ -1,\ 1]}_{\text{failures discouraged; successes reinforced}}\]

Prompt 2 has mean 0.5:

\[\widehat A_2 \approx [-1.414,\ 0,\ 1.414,\ 0]\]

Prompt 0 has no reward variation, so all its advantages and its reward-objective gradient are zero.

If a reference-KL penalty were included, that prompt could still receive a KL gradient pulling it toward the reference. Therefore “zero GRPO reward gradient” does not necessarily mean “zero total training gradient.”

Check answers

  1. The sampled mean and standard deviation of completions answering the same prompt replace the learned value baseline.

  2. More samples usually estimate relative prompt difficulty more reliably and increase the chance of observing diverse outcomes, at greater generation cost.

  3. No. A sequence-level group advantage is normally broadcast across tokens; it does not determine which token caused the outcome.

  4. Yes. The reward component is zero, but reference-KL regularization can still move the policy toward its anchor.

Retrieval answers

  1. Pass@\(K\) benefits from additional search: \(1-(1-p)^K\). The per-sample success probability \(p\) need not change.

  2. Every reward equals the group mean, so every centered advantage is zero.

Takeaway: GRPO removes the value model, not variance or baselines. It compares several completions for the same prompt, broadcasts their detached relative advantages across tokens, and applies a PPO-style clipped update against the frozen rollout policy.
