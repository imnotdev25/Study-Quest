🧩 Analogy: a stock price

A stock price squeezes years of uncertain future profits into one number today. \(V(s)\) does the same for a situation: “how good is it to be here, given how I’ll behave?” \(Q(s,a)\) is more specific: “how good is it to be here and do this?”

Being at the gym door has a high \(V\). Being at the gym door and turning around to go home has a low \(Q\).

2. Why value functions exist

Suppose you are choosing between two flats. You do not judge a flat only by today’s rent. You summarize its likely future consequences—commute, repairs and comfort—into an overall value.

RL does something similar.

State value

Under policy \(\pi\), the value of state \(s\) is the expected return starting there:

\[V^\pi(s) = \mathbb E_\pi[G_t\mid S_t=s]\]

This answers:

How good is this situation if I continue following policy \(\pi\)?

Action value

The action value fixes the first action before returning to the policy:

\[Q^\pi(s,a) = \mathbb E_\pi[G_t\mid S_t=s,A_t=a]\]

This answers:

How good is taking this particular action here, then following \(\pi\)?

The relationship is:

\[V^\pi(s) = \sum_a \pi(a\mid s)Q^\pi(s,a)\]

So \(V^\pi(s)\) is the policy-weighted average of the available action values.

The Bellman expectation equation

From the previous session:

\[G_t=R_{t+1}+\gamma G_{t+1}\]

Take its expectation:

\[V^\pi(s) = \sum_a \pi(a\mid s) \sum_{s'}P(s'\mid s,a) \left[ R(s,a,s')+\gamma V^\pi(s') \right]\]

Despite its size, it says only:

\[\boxed{\text{value now} = \mathbb E[\text{reward now} + \gamma\text{ value next}]}\]

For an action value:

\[Q^\pi(s,a) = \sum_{s'}P(s'\mid s,a) \left[ R(s,a,s')+\gamma V^\pi(s') \right]\]

This is called bootstrapping: we update one estimate using another estimate.

The equation looks circular because \(V\) appears on both sides. Dynamic programming resolves this by repeatedly applying a Bellman backup:

\[V_{k+1}=r_\pi+\gamma P_\pi V_k\]

Eventually the estimates converge to a fixed point:

\[V_{k+1}\approx V_k\]

This requires a known environment model \(P\) and \(R\). Later, Monte Carlo and TD learning will estimate values from experience instead.

Example MDP

There are three states:

  • State 0: starting area

  • State 1: near the goal

  • State 2: terminal

At states 0 and 1:

  • Action 0 means progress.

  • Action 1 means wait and receive \(-1\).

Progressing from state 1 reaches the terminal state and gives \(+5\).

LLM connection

For an LLM:

  • \(V(\text{prefix})\): predicted quality of completing the current prefix.

  • \(Q(\text{prefix},\text{next token})\): predicted quality after choosing a particular next token.

A critic used in LLM RL approximates values because enumerating every possible continuation is impossible.

🔍 Deeper: the Bellman equation is a linear system

\(V^\pi(s)=\sum_a\pi(a|s)\sum_{s'}P(s'|s,a)\big[r(s,a,s')+\gamma V^\pi(s')\big]\) and \(V^\pi(s)=\sum_a\pi(a|s)\,Q^\pi(s,a)\).

In vector form, \(\mathbf v=\mathbf r_\pi+\gamma P_\pi\mathbf v\), so \[\mathbf v=(I-\gamma P_\pi)^{-1}\mathbf r_\pi .\] The inverse always exists for \(\gamma<1\), because \(P_\pi\)’s eigenvalues have magnitude at most 1.

Worked example. Two states that always swap: \(A\to B\) pays 1 and \(B\to A\) pays 0, with \(\gamma=0.9\). \(V_A=1+0.9V_B\) and \(V_B=0.9V_A\), so \(V_A=1+0.81V_A\), which gives \(V_A=1/0.19\approx5.26\) and \(V_B\approx4.74\). Check: from \(A\) the rewards are \(1,0,1,0,\dots\), so \(V_A=1+0.81+0.81^2+\dots=1/(1-0.81)\).

Why iterating works: each sweep \(V_{k+1}=\mathbf r_\pi+\gamma P_\pi V_k\) shrinks the error by at least a factor of \(\gamma\), so \(\|V_k-V^\pi\|_\infty\le\gamma^k\|V_0-V^\pi\|_\infty\).

🔑 Key ideas

  • \(V\) scores a state, \(Q\) scores a state-action pair, and \(V=\mathbb E_{a\sim\pi}[Q]\).

  • Small problems can be solved exactly with one matrix inverse. Big ones need iteration, and then learning.

🚶 Walkthrough: three sweeps on the swap MDP

\(A\to B\) pays 1, \(B\to A\) pays 0, \(\gamma=0.9\), synchronous updates from \(V=0\):

sweep \(V_A\) \(V_B\)
0 0 0
1 1.00 0.00
2 1.00 0.90
3 1.81 0.90
\(\infty\) 5.26 4.74

The error shrinks by about \(\gamma\) per sweep, so reaching \(10^{-3}\) takes roughly 70 sweeps.

Common mistakes

  • Mixing old and new values by accident (decide: synchronous or in-place).

  • Forgetting to weight by \(\pi(a|s)\) when the policy is stochastic.

  • Giving terminal states a nonzero value.

⚙️ Algorithm: Iterative policy evaluation
Input: transitions \(P(s'|s,a)\), rewards \(r(s,a,s')\), policy \(\pi\), discount \(\gamma\), tolerance \(\theta\)
\(V(s)\gets0\) for every state
repeat
\(\Delta\gets0\)
for each state \(s\) do
\(v\gets V(s)\)
\(V(s)\gets\sum_a\pi(a|s)\sum_{s'}P(s'|s,a)\big[r(s,a,s')+\gamma V(s')\big]\)
\(\Delta\gets\max(\Delta,|v-V(s)|)\)
end
until \(\Delta<\theta\)
return \(V\approx V^\pi\)

4. Checks for understanding

  1. Can the same state have different values under two policies?

  2. Why is \(V^\pi(s)\) an average of \(Q^\pi(s,a)\)?

  3. Does a high immediate reward guarantee a high action value?

  4. A researcher computes policy * q_values but forgets .sum(dim=1). What does the resulting tensor represent?

  5. Why can’t ordinary dynamic programming be applied directly to a large LLM environment?

Solutions

r_pi = (policy * rewards).sum(dim=1)

p_pi = (
    policy.unsqueeze(-1) * transitions
).sum(dim=1)

values = torch.zeros(3)

for iteration in range(100):
    new_values = r_pi + gamma * (p_pi @ values)

    delta = (new_values - values).abs().max()
    values = new_values

    if delta < 1e-6:
        break

expected_next_value = transitions @ values
q_values = rewards + gamma * expected_next_value

Check answers

  1. Yes. Value includes the future actions selected by the policy.

  2. The policy samples among actions, so expected state value must weight each action value by its selection probability.

  3. No. The action may transition into a poor future state.

  4. It contains each action’s weighted contribution, shape [states, actions], rather than one value per state.

  5. We do not know a tractable transition model over all prefixes and continuations, and the state and action spaces are enormous.

Retrieval answers

  1. \(G_t=R_{t+1}+\gamma G_{t+1}\).

  2. The current state must contain the history information needed to predict the next state and reward.

Takeaway: \(V\) evaluates a situation, \(Q\) evaluates a situation-plus-action, and a Bellman backup converts future value into present value.
