To estimate how a new strategy would play, a coach uses old match footage and asks, play by play, “what would happen next if we followed the new strategy from here?” FQE does this with Bellman regression: no importance-weight products, just repeated supervised learning on logged transitions.

2. Replace importance-weight products with Bellman backups

Fitted Q Evaluation—FQE—evaluates a fixed target policy \(\pi\) from offline transitions without multiplying trajectory importance ratios.

Starting with \(\hat Q_0\), repeatedly construct:

\[y_i = r_i+ \gamma(1-d_i) \sum_{a'} \pi(a'\mid s'_i) \hat Q_k(s'_i,a')\]

Then regress:

\[\hat Q_{k+1} = \arg\min_Q \frac1N\sum_i \left( Q(s_i,a_i)-y_i \right)^2\]

After convergence:

\[\hat J_{\text{FQE}} = \mathbb E_{s_0} \left[ \sum_a \pi(a\mid s_0)\hat Q(s_0,a) \right]\]

The next action is averaged under the target policy. Using:

\[\max_{a'}Q(s',a')\]

would evaluate a greedy policy instead of the requested target policy.

FQE avoids exploding importance products, but exchanges that problem for extrapolation risk. If the target policy chooses an action absent from the logs, its \(Q\)-value may remain near initialization while the observed Bellman loss still looks excellent.

Practical rules:

  • detach Bellman targets;

  • preferably use a lagged target network;

  • zero bootstrap values at terminal states;

  • include the same legal-action masks used by the target policy;

  • audit state-action coverage, not only training loss;

  • keep the evaluated policy fixed throughout fitting.

Tensor shapes:

  • transitions: states, actions, rewards and dones [N]

  • target-policy probabilities: [S, A]

  • learned \(Q\)-table: [S, A]

  • Bellman targets and predictions: [N]

For LLM agents, the “state” is the complete history and the “action” may be a token, tool call or structured command. This makes coverage and generalization much harder than in a small table.

DPO trains a policy from preference comparisons. FQE instead estimates that policy’s interactive environmental return from logged transitions; it requires outcome-bearing logs, not merely chosen/rejected pairs.

🔍 Deeper: FQE and its failure mode

Iterate \(Q_k\gets\arg\min_Q\sum_i\big(Q(s_i,a_i)-[r_i+\gamma\sum_{a'}\pi(a'|s'_i)Q_{k-1}(s'_i,a')]\big)^2\) (algorithm in the box below). Strength: no products of ratios, so the variance doesn’t explode with horizon. Silent failure: the target queries \(Q(s',a')\) for \(a'\sim\pi\). If the logs never took \(a'\) at \(s'\), that value is pure extrapolation, and the regression loss can still look perfect.

🔑 Key ideas

  • FQE replaces importance products with target-policy Bellman regression.

  • It fails silently where the target policy asks about unseen actions.

🚶 Walkthrough: a support gap

Logs at \(s'\) contain only action \(L\) (value 1). The target policy takes \(R\) at \(s'\). A linear \(Q\) fit happens to extrapolate \(Q(s',R)=4\), so the FQE estimate inflates by \(\gamma\cdot3\), while the training loss on logged pairs is about 0.

Common mistakes

  • Taking a \(\max\) in the target (that’s control, not evaluation).

  • Reading small Bellman loss as accuracy.

  • No check of \(\pi\)’s action coverage in the logs.

⚙️ Algorithm: Fitted Q Evaluation (FQE)
Input: logged transitions \((s_i,a_i,r_i,s'_i,d_i)\), fixed target policy \(\pi\), iterations \(K\)
\(Q_0\gets0\)
for \(k=1,\dots,K\) do
\(y_i\gets r_i+\gamma(1-d_i)\sum_{a'}\pi(a'|s'_i)\,Q_{k-1}(s'_i,a')\) ▷ expectation under \(\pi\), not a max
\(Q_k\gets\) regression fit on \(\{(s_i,a_i)\mapsto y_i\}\)
end
return \(\hat V(\pi)=\operatorname{mean}_{s_0}\sum_a\pi(a|s_0)\,Q_K(s_0,a)\)

Hints

  • Concatenate first-step and second-step tensors.

  • Index target_q with fit_next_states.

  • Multiply its action dimension by target_policy[fit_next_states].

  • Multiply bootstrapped values by (~fit_dones).to(torch.float64).

  • Copy into the target table inside torch.no_grad().

  • Encode a pair as state * num_actions + action.

  • torch.bincount(..., minlength=num_states * num_actions) builds coverage counts.

Debugging experiments

  • Replace the target-policy expectation with .max(dim=-1).values. You silently evaluate another policy.

  • Remove torch.no_grad() around Bellman targets. The critic begins chasing a target connected to itself.

  • Bootstrap through terminal transitions. Terminal-state initialization leaks into every predecessor.

  • Inspect only final loss. The support-gap model can fit all observed equations while assigning nonsense to unseen actions.

  • Initialize unseen \(Q\)-values to 10 instead of 0. The reported value changes despite identical logged evidence.

  • Change the target policy after fitting without refitting FQE. Its Bellman targets described the old policy.

  • In an LLM batch, omit action masks when computing the next-policy expectation. Invalid tools or padding tokens enter the value target.

The exact state-one value is:

\[V^\pi(1) = 0.1(0)+0.9(3) = 2.7\]

Therefore:

\[Q^\pi(0,1) = 0+\gamma V^\pi(1) = 0.9(2.7) = 2.43\]

and:

\[V^\pi(0) = 0.2(1)+0.8(2.43) = 2.144\]

With complete coverage, FQE should learn approximately:

\[\hat Q \approx \begin{bmatrix} 1&2.43\\ 0&3\\ 0&0 \end{bmatrix}\]

After removing every (state=1, action=1) transition, that entry receives no regression gradient and remains near zero. The resulting estimate approaches:

\[\hat V(0) \approx 0.2(1)+0.8(0) = 0.2\]

Yet its observed-transition Bellman loss can still be close to zero.

Check answers

  1. It learns a critic through one-step Bellman regression rather than multiplying action-probability ratios across the entire horizon.

  2. FQE estimates \(Q^\pi\); changing the next-action distribution changes the Bellman operator and therefore the evaluated policy.

  3. Bellman loss only checks logged state-action pairs. It cannot validate unsupported counterfactual actions that affect the target-policy expectation.

  4. Report state-action counts, target-policy mass on rare actions, Bellman residuals by subgroup, initialization sensitivity, target-network stability, held-out error, reward scale and estimates from alternative OPE methods.

Retrieval answers

  1. A memorizer can make \(r-\hat q=0\) on training rows while having arbitrary counterfactual predictions, disabling DR’s correction.

  2. Split whole episodes and usually group by user, prompt family or conversation so correlated information cannot cross folds.

Takeaway: FQE replaces high-variance importance products with target-policy Bellman regression. It works well where logs provide coverage—and can fail silently where the target policy asks about unseen actions.
