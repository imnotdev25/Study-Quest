2. Use each logged episode to score both policies

A doubly robust pseudo-outcome for policy \(\pi\) is:

\[\psi_i^\pi = \underbrace{ \sum_a \pi(a)\hat q(a) }_{\text{modelled policy value}} + \underbrace{ \frac{\pi(A_i)}{\mu(A_i)} \left(R_i-\hat q(A_i)\right) }_{\text{weighted correction from episode }i}\]

Its value estimate is:

\[\hat V^\pi = \underbrace{ \frac1N\sum_i\psi_i^\pi }_{\text{mean DR pseudo-outcome}}\]

For candidate \(\pi_1\) and control \(\pi_0\), calculate the episode-wise difference:

\[d_i = \underbrace{\psi_i^{\pi_1}-\psi_i^{\pi_0}} _{\text{paired evidence about improvement}}\]

Then:

\[\hat\Delta = \underbrace{ \hat V^{\pi_1}-\hat V^{\pi_0} }_{\text{estimated improvement}} = \frac1N\sum_i d_i\]

The paired standard error is:

\[\widehat{SE}_{\mathrm{paired}} = \underbrace{ \frac{\operatorname{SD}(d_1,\ldots,d_N)} {\sqrt N} }_{\text{uncertainty of the policy difference}}\]

Equivalently:

\[\operatorname{Var}(\hat\Delta) = \frac{ \overbrace{\operatorname{Var}(\psi^{\pi_1})}^{\text{candidate variance}} + \overbrace{\operatorname{Var}(\psi^{\pi_0})}^{\text{control variance}} - \overbrace{2\operatorname{Cov}(\psi^{\pi_1},\psi^{\pi_0})}^{\text{shared episode noise cancels}} }{N}\]

When the scores move together, ignoring covariance produces an unnecessarily wide interval.

A one-sided promotion rule is:

\[LCB = \underbrace{ \hat\Delta-z_{1-\alpha}\widehat{SE}_{\mathrm{paired}} }_{\text{conservative improvement estimate}} >0\]

Pair only genuine shared sampling units. For agent evaluation, that is usually an episode, task or user—not individual correlated tokens. Nuisance predictions should be out-of-fold, detached, and computed without candidate-selection leakage.

DPO can optimize a policy from preference pairs, but it does not supply logging propensities or convert this calculation into online RL. A DPO checkpoint may still be evaluated with paired tasks, provided the evaluator is valid.

Tensor shapes:

  • actions, rewards and policy scores: [R, N]

  • paired differences: [R, N]

  • estimates and standard errors: [R]

Hints

  • Sample action 1 with probability behavior_policy[1].

  • The model baseline is (policy * q_model).sum().

  • Use policy[actions] / behavior_policy[actions].

  • A mean estimator’s influence value is its pseudo-outcome minus its sample mean.

  • The incorrect unpaired variance adds the two score variances without subtracting covariance.

  • Promotion occurs when the one-sided lower bound exceeds zero.

Debugging experiments

  • Shuffle candidate episodes before forming differences.

  • Pair rows merely because they share a batch position.

  • Estimate uncertainty from tokens while episodes are the independent units.

  • Fit q_model on each episode’s own outcome without cross-fitting.

  • Reuse this evaluation set to select the candidate and then claim confirmatory significance.

  • Allow evaluation losses to backpropagate into the policy or reward model.

  • Report a narrow interval without overlap and propensity diagnostics.

Solutions

Logged data:

def sample_logged_data():
    actions = (
        torch.rand(
            num_repetitions,
            episodes_per_repetition,
        )
        < behavior_policy[1]
    ).to(torch.long)

    reward_probabilities = (
        true_action_values[actions]
    )

    rewards = (
        torch.rand_like(reward_probabilities)
        < reward_probabilities
    ).to(torch.float64)

    return actions, rewards

DR scores:

def dr_scores(policy, actions, rewards):
    model_baseline = (
        policy * q_model
    ).sum()

    importance_weights = (
        policy[actions]
        / behavior_policy[actions]
    )

    logged_predictions = (
        q_model[actions]
    )

    scores = (
        model_baseline
        + importance_weights
        * (
            rewards
            - logged_predictions
        )
    )

    return scores

Paired comparison:

paired_actions, paired_rewards = (
    sample_logged_data()

The exact values are:

\[V^{\pi_0} = \underbrace{0.55(0.40)+0.45(0.60)}_{\text{control mixture}} = 0.49\]

\[V^{\pi_1} = \underbrace{0.45(0.40)+0.55(0.60)}_{\text{candidate mixture}} = 0.51\]

\[\Delta = \underbrace{0.51-0.49}_{\text{true improvement}} = 0.02\]

The large gain comes from:

\[\operatorname{Cov} \left( \psi^{\pi_1}, \psi^{\pi_0} \right) \approx \underbrace{0.2401}_{\text{shared reward and action noise}}\]

which nearly cancels the two individual score variances.

Check answers

  1. 0.02.

  2. Strongly positive: both scores respond to the same logged action and reward.

  3. The paired SE, because shared episode noise is subtracted.

  4. The covariance benefit disappears; the estimated effect remains roughly centered but becomes much noisier.

  5. Independent logs cannot cancel episode-level randomness. More rows do not necessarily mean more information about a contrast.

Retrieval answers

  1. The numerator and denominator are computed from the same weighted episodes and therefore move together; their covariance contributes to ratio uncertainty.

  2. No. Standard errors quantify sampling variation, not estimator bias, unsupported actions or invalid nuisance models.

Takeaway: when two policies can be evaluated on the same logged episodes, estimate the episode-wise score difference and its standard error directly. Policy improvement is a paired estimand—not two unrelated value estimates.
